# 反手挑打与反手台内快点（Backhand Flick / Flip，Quick Tap）

适用：用反手主动进攻台内短球（第二跳不出台）。弹挑最适合短的不转、上旋、侧上旋球；快点用来处理对方发到反手位或摆到反手位、刚弹起的短球；下旋弱、球偏高时也可以挑｜难度：弹挑、快点中等；对下旋开拍挑中高｜相关卡片：`../techniques/backhand-banana-flick.md` `../techniques/forehand-flick.md` `../techniques/backhand-drive-punch.md` `../techniques/backhand-tear.md` `../techniques/backhand-block.md` `../techniques/backhand-loop-vs-backspin.md` `../techniques/short-touch.md` `../techniques/push.md` `../techniques/long-push.md` `../techniques/receive.md` `../techniques/footwork.md` `../techniques/transitions.md` `../techniques/penhold.md` `../fundamentals/grip.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/spin.md`

> 全文按右手横拍写，左手持拍者左右互换。直拍反手（直拍横打）的挑法见 `../techniques/penhold.md`。
> 出处缩写：`LH:N` = Larry Hodges 文章 https://www.tabletenniscoaching.com/node/N ；`TOTW 日期` = Hodges「Tip of the Week」文章（各篇直接链接见文末）；`PS` = PingSkills 课程，`PSQ` = PingSkills 教练答问；`BK-词条` = 百度百科（可编辑百科，可信度中等）。完整链接见文末。

## 1. 定义与用途

**反手挑打（backhand flick/flip）**：横拍选手在台内用反手把短球直接打成进攻球。Hodges 的定义很朴素：反手挑"就是一板普通反手，只是手腕甩得更多"（LH:33）；传统反手挑"对大多数旋转都是带轻上旋的标准反手攻"（LH:3621）。百科说反手挑主要是横板选手在用（BK-接发球）。中文维基把台内反手进攻列为"反手弹击、拧拉（常形成出台对攻）"（中文维基「乒乓球」），本卡讲以弹击为主的那一类（弹挑）。拧拉另有一张卡。

**用途**：抢先上手，让对方发球后没法从容抢攻第三板；Hodges 说反手挑在接发球时很有用，不是要不要学的问题，是学哪一种的问题（LH:3621）。挑打的目的是"抢先上手，形成进攻优势"，不能为挑而挑（BK-挑打）。

| 手段 | 动作特征 | 典型来球 | 出处 |
|---|---|---|---|
| 弹挑（传统反手挑） | 引拍小，以肘为轴，前臂带手腕向前弹出；撞击为主、略带摩擦；回球较平或带轻上旋 | 短的不转、上旋、侧上旋球；下旋弱的球 | LH:33、LH:3621、PSQ When to use banana flick |
| 开拍挑（对下旋） | 拍面打开，向上、向前打，追求中等速度和旋转，重深度和落点 | 短下旋（Hodges 本人的打法） | LH:3621、TOTW 2024-04-29 |
| 台内快点（quick tap） | 几乎不引拍，靠手腕和手指弹击；动作小而急。上旋、不转球打中上部；下旋球拍面稍后仰、摩擦中下部 | 对方发到反手位的短球，或摆到反手位的短球（摆短多为下旋） | BK-快点；BK-正手快点 |
| 暴挑 / 翻挑 | 暴挑：自己发力、出手集中，力求得分；翻挑：以控制为主，威胁较小 | 球偏高、下旋弱时暴挑；只求先上手时翻挑 | BK-挑打 |
| 拧拉（banana flick） | 台内小弧圈，带上旋，通常还带侧旋 | 见 `../techniques/backhand-banana-flick.md` | LH:3621 |

**快点和反手快拨的区别**：快点只用于台内短球，强调在上升期出手；快拨用于出台球（BK-快点）。快拨、出台弹击见 `../techniques/backhand-drive-punch.md`。

**快点和挑的区别**：两者动作形态很像；快点更突出"快"和"突然"，向前撞击的成分更多，适合抢攻台内短球；挑更注重稳定和控制。该词条还写明快点"主要用于处理台内下旋球"（BK-正手快点；词条讲的是正手，原理可参照）。

**反手撇**：中文维基把"撇"列为正、反手都可用的台内技术（"正、反手摆短、劈长（搓）、撇"），但**本次没有找到反手撇的可靠动作定义**。百度百科唯一的动作描述"晃撇"写的是侧身位用正手搓侧旋，属于搓类（BK-接发球）；同一词条另说判断不准时可以"轻轻地托一板或撇一板"，但没有讲动作。所以本卡不写反手撇的动作要领，也不把它等同于任何一种挑。

### 挑还是拧：怎么选

| 来球 / 情况 | 首选 | 依据 |
|---|---|---|
| 短的不转、上旋、侧上旋球 | **弹挑**：果断、快、平，打穿 | PS 教练："不转或上旋的短发球可以用普通挑"（PSQ When to use banana flick）；对短上旋要"快而平的触球"（PS Returning Short Topspin Serves） |
| 短下旋、侧下旋 | **会拧就拧**；PS 说拧对下旋比对上旋还容易 | PSQ When to use banana flick；PSQ How to flick backspin ball |
| 下旋弱、弧线偏高 | 挑（可以暴挑） | BK-挑打：业余选手在这两种条件下挑成功率高；PSQ To Push or flick："球较高、旋转不强时可以考虑挑" |
| 低而重的下旋 | 摆短更安全；不会拧又想上手，就开拍向上挑，只求中等质量。**两说并存**：Hodges 认为只要拍面打开得足够多、向后下方擦，重下旋往往比不转球还好挑（LH:3611）；PingSkills 则认为不转和上旋更容易挑、重下旋摆短更安全 | PSQ To Push or flick；PSQ How to flick backspin ball；LH:3621；LH:3611 |
| 对方摆到反手位、刚弹起的近网短球 | **快点**，抢早出手（击球时间见第 4 节）；摆短多为下旋，拍面要稍后仰、多带摩擦（第 4 节） | BK-快点；BK-正手快点 |
| 想上手但来球低、需要更大挥速 | 拧。PS 指出正手台内很难挥出足够拍速，反手拧能让拍从更靠后的位置起动 | PS Attacking Short Serves |
| 训练时间少、年纪较大、手臂有负担 | 先练传统挑：不难练，越用越稳；拧要大量练习，对手臂有一定负担 | LH:3621；TOTW 2024-04-29（精英水平以下，传统反手挑够用） |
| 半出台球 | 能拉就拉（`../techniques/backhand-loop-vs-backspin.md`） | BK-接发球："能拉接，不要搓撇" |

PS 教练给的学习顺序是：先学会普通反手挑，再学拧和草莓挑（PSQ Backhand flick）。

## 2. 三位标杆怎么做

**马龙**
- 2020 东京奥运半决赛决胜局对奥恰洛夫，"马龙反手翻挑命中"（央视网，单场描述）。"翻挑"是解说用词，不能据此判断是哪种挑。
- Hodges 说世界上许多甚至大多数顶尖选手会用反手接正手位短球，"包括马龙"（LH:3650，只有这一个来源）。
- 单场统计（2020 世界杯半决赛对张本智和，Edges & Nets 分析博客，非官方）：张本挑打 50 次、失误 7 次；马龙只挑 12 次、0 失误，直接得分 4 次（张本 10 次），这 4 次都是"控制好、落点好的慢球"，不是重挑。这个统计没有区分正手、反手，也没有区分挑和拧。
- 2015 年转型期，他本人说改的技术"除了发球，还包括一些反手拧，还有短球上也跟过去有一些变化"（央视网 2015-02-05）。
- 反手挑的握拍、拍面角度等细节：暂无可靠出处。

**张继科**
- 传统反手弹挑、快点的个人特点：暂无可靠出处（英文维基说他"反手台内挑世界最好之一"，但这句没有引用，不采用）。
- 他的台内反手武器是拧拉。他本人说练拧是从上旋来球开始，再练弱下旋，最后练强下旋（《卓球レポート》2019），这个由易到难的顺序本卡练法也采用了。拧的细节见 `../techniques/backhand-banana-flick.md`。

**樊振东**
- 传统反手弹挑的个人特点：暂无可靠出处。
- 论文统计（Jin & Ma 2026）：接发球第二板，他用反手主动上手明显多于正手，反手拧拉使用率显著高于其他技术；作者也指出他**反手上手后的连续进攻能力有待提高**。对业余选手的提醒是：挑完要能接住下一板（见 3.6）。
- 接发球准备：对方抛球时他上身稍抬、小跳起动（PSQ Analysis of movements on return of serve；LH:3491）。
- 刘国梁评价他"台内前三板更加细腻"（新京报，央视网转载 2021-07-30）。

**小结**：张继科、樊振东的公开资料显示反手台内上手以拧为主；马龙的资料以摆短为主，挑得少而稳，统计里没有区分挑和拧；传统弹挑是 Hodges、PingSkills 建议业余选手先掌握的基础版本。

## 3. 动作分解

**来源说明**：专门讲反手挑分解动作的可靠资料很少。下表有出处的标在括号里；没有标出处的部位要领，是按"反手挑＝缩小、加了手腕的反手攻"（LH:33、LH:3621）从反手攻要领推出来的定性描述（反手攻见 `../techniques/backhand-drive-punch.md`）。每张表最后一行写快点的不同之处。

**上步和退回（占这项技术的一半）**：
- 反手位短球：可以上右脚（持拍手同侧脚，BK-接发球），也可以上左脚。Hodges 讲了两者的代价：上右脚，反手打得更有力，但右侧身体压在反手位，再去补正手位更难；上左脚，能更快向右滑步补正手位。建议徒手两种都试，并假设对方会回球（LH:33）。
- 中路或正手位的短球想用反手接：上右脚（Hodges 说多数好手接所有短球都上右脚，LH:33）。要让球落在反手击球点上，就得把身体放到球的左后方，让球出现在身体正前偏左（这是按反手击球点推出来的，不是原文）。Hodges 说只要能快速退回，正手位短球也可以过去用反手挑（TOTW 2022-04-25）；许多顶尖选手包括马龙都这么接（LH:3650）。LH:33 也强调，上步之后必须退回原准备位置。
- 上步前可以先用另一只脚垫一小步（BK-挑打；BK-快点）；脚和手臂要同时进入台内（BK-快点）。
- 判断要早：PS 教练说，看起来好像顶尖选手提前移动了，其实是他们从对方挥拍里读到了线索、而且移动极快（PSQ Reading direction of serve early）。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 离台约一小步（BK-台内球）；两脚比肩略宽，右脚稍前，脚跟提起（BK-接发球）；前脚掌着地，随时能上步 | 脚跟踩实，判断出短球后迈不出去 |
| 膝 | 微屈、有弹性；对方抛球或出手时上身稍抬、小跳起动（樊振东例） | 直腿站；或蹲得过死 |
| 髋 | 略前屈，朝向球台 | 臀部后坐，上步时重心跟不上 |
| 腰/躯干 | 上体稍前倾（BK-接发球） | 上体后仰、离台太远 |
| 肩 | 放松、平 | 耸肩、紧张 |
| 大臂/肘 | 肘在体前，不贴身、不外张 | 肘夹死在腰侧 |
| 前臂 | 置于体前，约与台面同高 | 前臂垂到台面以下 |
| 手腕 | 放松，不提前锁住 | 提前用力 |
| 手指/握拍 | 握松：别人从背后应能把拍抽走（LH:2271）。反手时拇指可稍上移、多压一点（CETV-握拍；LH:3676）；PingSkills 主张用不夸张的通用握法、不刻意换握，两说并存，见 `../fundamentals/grip.md` | 捏死拍，手腕没法弹 |
| 拍面/拍头 | 手位较高，不低于台面（BK-台内球）；拍放在正反手之间 | 拍放得太低，接短球前要先抬手 |
| 视线/头 | 看对方触球部位、挥拍方向和弧线，判断旋转和长短（BK-接发球） | 只看球，不看对方动作 |
| 快点 | 同上，站得更"迎前"，因为要抢上升期 | — |

### 3.2 引拍（与上步同时）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 球快过网时，上步脚插到台下（BK-接发球）；距离不够先垫步 | 不上步，只伸手去够 |
| 膝 | 上步腿屈膝、前顶，重心压到上步脚上 | 腿伸直，重心留在后脚 |
| 髋 | 随上步前移，重心完全跟上（BK-台内球） | 臀部掉在后面 |
| 腰/躯干 | 前探，身体贴近球台（BK-快点）；基本不转腰 | 弯腰太多，头远低于来球，看不清弧线 |
| 肩 | 略含胸，右肩略微下沉（BK-弹打） | 右肩后拉、身体侧转过大 |
| 大臂/肘 | 肘前顶，手臂靠近身体（BK-弹打）；肘保持弯曲，手臂不伸直（BK-台内球） | 肘往后拖，或手臂伸直够球 |
| 前臂 | 前臂收到胸腹前，引拍很短（BK-弹打；LH:33） | 习惯性大引拍（BK-快点列为首要错误） |
| 手腕 | 手腕稍向内收（向身体方向屈），拍头指向左下或自己的腹部方向，为弹出蓄力（BK-快点"手腕稍内收"） | 手腕不蓄，只能用手臂推 |
| 手指/握拍 | 放松 | 引拍时就握紧 |
| 拍面/拍头 | 按旋转预置拍面：下旋立起或后仰，下旋越强越打开（BK-弹打）；不转立起、打得更平（PSQ Flick / Flip in detail）；上旋、侧上旋稍关（BK-弹打；LH:33） | 用一个固定拍面对付所有球 |
| 视线/头 | 跟住球的弹起，判断高点 | 上步时低头看脚 |
| 快点 | 几乎不引拍；手臂自然弯曲，手腕稍内收（BK-快点）。上旋、不转拍面稍立（BK-快点）；下旋拍面稍后仰（BK-正手快点） | 引拍一大就赶不上击球时间 |

PS 教练提醒：**在上步的过程中就把挑的起始拍位摆好**；拍形摆对了，就能打出一板像样的球。很多人走到台前手却自动变成了搓的姿势（PSQ Executing Strokes）。

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 上步脚踏稳后再出手 | 脚还在空中就挥拍，击球点乱 |
| 膝 | 轻微蹬伸，把重心向前送；对下旋稍向前上 | 膝不动，全靠手 |
| 髋 | 借上步向前的惯性帮手臂发力（BK-挑打） | 髋往后撤 |
| 腰/躯干 | 稳定，小幅前送 | 转腰抡臂，拍子迟到 |
| 肩 | 稳，不大幅转动 | 肩带着拍向右横扫 |
| 大臂/肘 | 以肘为轴，大臂基本不动（BK-弹打） | 大臂大摆（BK-快点列为错误） |
| 前臂 | 向前加速，对下旋向前上；前臂发力撞击为主（BK-接发球） | 前臂只推不加速 |
| 手腕 | 由内收位置向外、向前突然弹开；百科叫"外展"（BK-接发球；BK-弹打） | 手腕僵直不弹，或甩得过大失去控制 |
| 手指/握拍 | 引拍时松，触球瞬间才握紧（BK-正手快点写的是正手，原理相同） | 一直握死，手感差 |
| 拍面/拍头 | 保持预置拍面，不在挥拍中途乱翻 | 对下旋挥拍时把拍面关上，球下网 |
| 视线/头 | 头稳，眼睛盯到触球 | 提前抬头看对方 |
| 快点 | 手臂几乎不发力，靠手腕、手指瞬间弹击，"点到为止"（BK-快点） | 手臂参与太多，动作变慢 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心在上步脚上，另一只脚脚尖撑地 | 重心在后脚，够着打 |
| 膝 | 仍然弯曲，身体稳定 | 膝伸直，人"站起来"打 |
| 髋 | 贴近球台，在球的后方 | 髋离台远，手臂被迫伸直 |
| 腰/躯干 | 前倾、稳定 | 上体后仰，球被打高 |
| 肩 | 放松、不耸 | 耸肩、肩部发力 |
| 大臂/肘 | 肘在体前，手臂仍保留弯曲（BK-弹打） | 肘锁直，失去弹性 |
| 前臂 | 向前撞击为主（BK-接发球） | 前臂向右上方横扫 |
| 手腕 | 突然一个小幅外展，同时适当给球一点摩擦，保证准确（BK-接发球） | 纯撞不摩擦，对下旋时下网 |
| 手指/握拍 | 握紧，拍面稳定 | 触球时拍面晃 |
| 拍面/拍头 | 按来球定拍面（第 4 节）；多用靠近拍头的位置触球（BK-弹打，单一来源） | 用拍柄附近的位置触球，球没劲 |
| 视线/头 | 头稳，盯住触球点 | 头跟着手动 |
| 快点 | 上升期（BK-快点；另一词条写高点期或上升后期，见第 4 节）；上旋、不转打中上部，下旋向前压、多带摩擦（BK-正手快点） | 球已下降才打，快点就失效了（BK-快点）；对下旋只撞不擦，下网 |

**击球点**：在身体正前偏左、台内，击球点靠前（BK-台内球）；用脚把身体送到球后面，不要伸手去够。

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 上步脚准备蹬回 | 随挥时继续往前冲，退不回来 |
| 膝 | 保持弯曲 | 站直 |
| 髋 | 不再前移 | 髋继续前顶，失去平衡 |
| 腰/躯干 | 稳定 | 随挥时转体 |
| 肩 | 放松 | 抬肩 |
| 大臂/肘 | 手臂不完全伸直（BK-弹打） | 甩到手臂完全伸直 |
| 前臂 | 短收，指向出球方向 | 大幅向右上方甩 |
| 手腕 | 弹出后放松 | 手腕僵住 |
| 手指/握拍 | 立即放松 | 一直握紧 |
| 拍面/拍头 | 拍头指向目标；对下旋稍向上，对不转或上旋更向前、更低 | 对不转或上旋时向上翻，球出界 |
| 视线/头 | 看出球线路，同时看对方的准备动作 | 欣赏自己的球 |
| 快点 | 触球后立即收拍，动作很小（BK-快点） | 随挥过长 |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 上步脚蹬地，**立即退回**原准备位置（LH:33；TOTW 2022-04-25） | 挑完人留在台前 |
| 膝 | 屈膝保持弹性，用碎步调整（BK-台内球） | 脚下发死 |
| 髋 | 随脚后撤，回到球台中线后方 | 髋还在台内 |
| 腰/躯干 | 恢复稍前倾 | 直起来"看结果" |
| 肩 | 放松 | — |
| 大臂/肘 | 肘回到体前 | 手臂还伸在台上 |
| 前臂 | 拍回到体前中间 | 拍停在右上方 |
| 手腕 | 放松，准备下一板 | — |
| 手指/握拍 | 回到中性握法 | — |
| 拍面/拍头 | 拍头对准对方，准备快撕、反带或挡（BK-挑打） | 拍面朝天 |
| 视线/头 | 盯对方击球 | 低头 |
| 快点 | 对方回球弧线通常偏高，要迅速准备下一板进攻（BK-快点） | 没有准备衔接 |

**为什么还原决定成败**：挑打后对方回球快；被对方看准线路后，如果没有第二板，挑反而让自己被动。挑的人需要有快撕、反带能力来衔接（BK-挑打）。一项研究比较了反手拧拉后接反手快挡和接正手快挡（Niu 2026，10 名国家一级男运动员）：接正手的整体用时更长、球拍位移更大。弹挑后的衔接没有专门研究，这里按同理推断：下一板可能用正手时，退得要更早。衔接见 `../techniques/transitions.md`、`../techniques/backhand-tear.md`、`../techniques/backhand-block.md`。

## 4. 拍面角度、击球点、击球时间、触球部位

拍面角度的口径：**拍面与台面的夹角**，90° 是垂直，小于 90° 为前倾，大于 90° 为后仰（CETV-击球技巧）。详见 `../fundamentals/racket-angle-timing-contact.md`。

| 来球 | 拍面 | 触球部位 | 挥拍方向 | 出处 |
|---|---|---|---|---|
| 不转 | 接近垂直 | 中部偏上 | 向前，打得更平 | PSQ Flick / Flip in detail："上旋或不转可以打得更平" |
| 上旋、侧上旋 | 稍前倾 | 中上部 | 向前，快而平，直接打穿 | BK-弹打；BK-接发球；PS Returning Short Topspin Serves；LH:33："对侧上旋或弱下旋发球，拍面关一点，直接打穿" |
| 弱下旋 | 立起或稍后仰 | 后中部到中下部 | 向前略向上，撞击带摩擦 | BK-弹打；BK-接发球。Hodges（LH:33）认为弱下旋也可以把拍面关一点直接打穿；百科主张立起或稍后仰带摩擦，两说并存，按实际出球高低调整 |
| 重下旋 | 明显打开 | 球的后下方 | 向上、向前，以摩擦为主（"向上擦"） | LH:33："拍面打开更多，向上擦球"；LH:3621；PSQ Flick / Flip in detail："下旋越多越要擦" |
| 快点（上旋、不转短球） | 稍立 | 中上部 | 向前弹 | BK-快点 |
| 快点（下旋短球） | 引拍时稍后仰，触球时由后仰向前压 | 中下部 | 向前，多带摩擦（反胶尤其要擦，才能上台） | BK-正手快点（讲的是正手，原理可参照） |

- **击球时间**：弹挑以**高点期**为基准（BK-接发球的"挑接"）；半出台球挑时在接近最高点触球（PS Reading Half-Long Serves）；快点在上升期（BK-快点）。两个百科词条对快点时机说法不一：BK-快点写上升期，BK-正手快点写高点期或上升后期。错过上升期，球一下落就不能快点了，一般只能改成劈长等别的处理（BK-快点）。
- **击球点**：身体正前偏左、台内、靠前（BK-台内球）。手臂保持弯曲，肘在体前。
- **触拍部位**：多用靠近拍头的部位（BK-弹打，单一来源）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：（垫步）上步 → 重心前移 → 以肘为轴、前臂加速 → 手腕（和手指）弹出。反手挑主要靠前臂和手腕，"手腕发力占比很高"（BK-挑打）；挑接"以前臂发力撞击球为主"（BK-接发球）；快点几乎只靠手腕和手指，手臂几乎不发力（BK-快点）。台内不靠转腰，腿的作用是把身体送到位，并提供向前的惯性（BK-挑打）。
- **方向**：以向前为主；来球下旋越强，越要向上。
- **撞击与摩擦**：不转、上旋球以撞为主，可以打得更平；下旋球必须多擦（PSQ Flick / Flip in detail）。百科讲弹击下旋叫"打摩"：用瞬间爆发力"打"出去的摩擦，以摩擦为主、打为辅（BK-弹打，单一来源）。
- **力量**：Hodges 对下旋挑时追求中等速度和旋转，重视深度和落点（LH:3621）；马龙在那场比赛里挑出的 4 个直接得分都是控制好、落点好的慢球（Edges & Nets）。来球高时才暴挑，或改用动作略大的反手发力抽杀（BK-弹打）。
- **线路**：Hodges 说挑一般打两个大角，用手腕调方向可以把直线藏到最后，对方要到最后一刻才知道方向（LH:33，原文接在正手挑后面）。反手具体怎么调，参照下面 PS 对波尔的分析。可以挑对方反手大角、正手大角和中路（正反手转换点）；对方发完球想用正手抢攻时，挑两个大角（TOTW 2022-04-25）。PingSkills 分析波尔接张继科逆旋转发球的挑：利用来球侧旋和拍面角度控制方向，**身体姿势不变、只微调手腕**就能改变落点（PS How Timo Boll Disguises His Flick Placement）。

## 6. 面对不同来球的调整

| 情况 | 调整 |
|---|---|
| 短不转 | 拍面立起，向前、打得更平（PSQ Flick / Flip in detail）；别把不转当下旋打，向上用力太多会冒高（PS How to Return No-Spin Pushes） |
| 短上旋、侧上旋 | 要果断，打得快而平，敢于冒一点险（PS Returning Short Topspin Serves）；拍面关一点，直接打穿（LH:33） |
| 下旋弱、偏高 | 最适合挑，可以暴挑（BK-挑打；PSQ To Push or flick）；拍面关一点打穿（LH:33）还是立起带摩擦（百科），按出球高低调整 |
| 低而重的下旋 | 摆短更安全（PSQ To Push or flick）；会拧就拧（PSQ How to flick backspin ball）；要挑就大幅打开拍面向上挑，只求中等质量（LH:3621）。两说并存：Hodges 认为只要拍面打开得足够多、向后下方擦，重下旋往往比不转球还好挑，能把来球下旋转成回球上旋（LH:3611）；PingSkills 则认为不转和上旋更容易挑、重下旋摆短更安全（PSQ How to flick backspin ball；PSQ To Push or flick） |
| 左侧旋（正手钟摆发球，向接球者左侧拐，LH:34） | 拍面略向左偏，击球偏右（BK-接发球） |
| 右侧旋（反手发球，向接球者右侧拐，LH:34） | 拍面向右偏，击球偏左（BK-接发球） |
| 对方摆到反手位、刚弹起的短球 | 快点抢早出手，打对方空当或追身（BK-快点）。摆短多为下旋：引拍时拍面稍后仰，触球时向前压、多带摩擦，别用"稍立、只弹不擦"的上旋快点打法，否则容易下网（BK-正手快点） |
| 正手位短球 | 可以上右脚（LH:33）过去用反手接，挑完马上退回（TOTW 2022-04-25）；许多顶尖选手包括马龙都这么接（LH:3650）；但要防对方用同一个动作发正手短和反手长，所以正手挑也要练（LH:3650；`../techniques/forehand-flick.md`） |
| 半出台 | 能出台就拉（BK-接发球；`../techniques/backhand-loop-vs-backspin.md`）；判断为短的再挑 |
| 偏高的近网球 | 动作稍大，转为反手发力抽杀（BK-弹打） |
| 生胶、正胶反手 | 弹击的威力比反胶大，回球下沉；反胶弹击后要准备正手衔接（BK-弹打，单一来源）。器材见 `../fundamentals/equipment-and-technique.md` |
| 对手喜欢等你挑 | 和摆短、劈长混用。Hodges 说每次都挑会限制你的发展，挑和摆（长、短）都要会（TOTW 2025-11-03）；摆短见 `../techniques/short-touch.md` |

## 7. 关键数据参考

- **关节角度、拍速、各阶段时长**：本次检索没有找到传统反手挑或快点的同行评审运动学数据。唯一相关的研究是 Niu 2026（10 名国家一级男运动员，200 Hz 三维动作捕捉），它研究的是第一板之后接正手或反手快挡的球拍速度和时长；研究的第一板是拧拉（banana flick / Chiquita），不是传统挑，也没有给出第一板本身的关节角度。所以本卡**不给**肘角、腕角、拍速的数字，只把它"接正手快挡用时更长、球拍位移更大"的定性结论按同理推到弹挑上（见 3.6）。
- **快点**：拍面角度、动作范围暂无可靠数据，只写定性。
- **马龙挑打单场统计**：挑 12 次 0 失误、直接得分 4 次（都是控制好的慢球），对手张本挑 50 次、7 失误、直接得分 10 次（Edges & Nets，2020 世界杯半决赛一场；分析博客、非官方；没有区分正反手和挑、拧），不能推广成他的生涯数据。
- **概念**：短球指如果不打，会在本方台面弹两次的球（LH:30；PS Forehand Flick）；半出台指第二跳落在端线附近的球（BK-台内球）。
- **拍摄帧率**：台内动作小而快，普通 30 fps 很难抓到触球那一帧（这是经验判断，不是文献测量）。按设计要求用 120/240 fps 慢动作拍，见 `../analysis/recording-guide.md`。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 挑下网 | 来球是下旋，拍面没打开，纯撞不擦（快点打摆短下旋时最常见）；或击球太晚，球已经下落 | 下旋大幅打开拍面向上擦（LH:33、LH:3621）；快点对下旋拍面稍后仰、多带摩擦（BK-正手快点）；在高点期前出手；低而重的下旋改摆短（PSQ To Push or flick） |
| 挑出界、冒高 | 对不转或上旋还用后仰拍面向上擦；随挥向上翻 | 不转拍面立起、打得更平（PSQ Flick / Flip in detail）；上旋、侧上旋拍面关一点，直接打穿（LH:33）；随挥短而向前 |
| 动作慢，错过击球点 | 引拍过大；大臂、前臂大摆；判断到出手拖沓（BK-快点） | 默念"无引拍、快弹击"；定点短球只练小动作，一发现动作变大就停下重做（BK-快点） |
| 手臂伸直够着打 | 没上步或上步不够；臀部掉在后面（BK-台内球） | 先动脚后出手，上步脚插到台下，重心完全跟上 |
| 走到台前手变成了搓的姿势 | 移动中没摆好挑的起始拍形，临场犹豫（PSQ Executing Strokes） | 上步时就把拍摆到挑的起始位置；先在多球里只挑不搓 |
| 手腕不弹，球没速度 | 握拍太紧，手腕锁死；引拍时手腕没有内收蓄力 | 握松（LH:2271），引拍时腕稍内收，触球瞬间才弹出、握紧 |
| 球没威胁，被对方反撕、反拉 | 为挑而挑，来球不适合；只会一条线（BK-挑打） | 只在下旋弱或球高时挑；大角、中路、直线都练；把方向藏到最后（LH:33；PS How Timo Boll…） |
| 挑完接不住下一板 | 没有还原；不会快撕、反带（BK-挑打） | 练"上步—挑—退回—衔接"一体化（第 9 节第 6 步） |
| 侧旋球挑偏 | 拍面没有按侧旋方向偏转 | 左侧旋拍面向左偏、击球偏右，右侧旋反过来（BK-接发球）；用多球单练一种侧旋 |
| 反手接正手位短球后，被打反手大角或正手长球 | 退得慢；过度依赖反手 | 挑完马上退（TOTW 2022-04-25）；正手挑也要会（TOTW 2022-04-25；LH:3650） |
| 每个短球都挑，失误多 | 不会摆短，只能挑 | 挑和摆都练（TOTW 2025-11-03） |
| 腕、肘酸痛 | 全靠手腕硬甩；练习量增加太快 | 让腿和前臂参与；循序加量，见 `../training/physical-and-injury.md` |

## 9. 练习方法（入门 → 进阶）

1. **徒手进出步**：对镜做"垫步→上步→小引拍弹挑→蹬回"。左脚、右脚两种上步都试，按对方会回球来做（LH:33）。Hodges 的徒手步法套路里也有"进台接正手短球、退回拉"这一项（TOTW 2024-05-06）。
2. **定点反手位短球**：同伴发反手位定点短球（先用不转或轻上旋，PS 教练说这类球最容易挑（PSQ How to flick backspin ball）），只挑斜线，先求命中率，再练角度（BK-快点）。
3. **按旋转逐一加难度**：挑稳第 2 步的球后，按弱下旋→重下旋→侧旋→侧上旋→事先不知道旋转的混合来球逐一加难度。Hodges 主张一项技术拆开一部分一部分练，这个顺序参照他的 TOTW 2025-01-20；他本人建议从简单下旋开始（之后重下旋、不转、侧旋、侧上旋）。两种起点都可以，按自己哪种球挑得更稳来选。张继科练拧也是由易到难（上旋→弱下旋→强下旋），可以参照。
4. **重下旋专练**：同伴反复发低、短、重下旋，你只练挑，不打完这一分（LH:3611）。
5. **快点**：先定点、上升期快点，杜绝引拍；再改成不定点短球，用半步调整位置，同时保持小动作（BK-快点）。
6. **挑后衔接**：反手挑后接反手快挡或快撕，再练挑后接正手（同类组合在拧拉上有研究，Niu 2026）；也可以练反手挑接反手拉直线（Butterfly 训练视频，Angel Naranjo）。
7. **反手接正手位短球**（本卡设计的练法）：同伴发正手位短球，你上右脚用反手挑，马上退回；同伴有时改发反手位长球，你要能接住。依据是 LH:3650 提醒对方可能用同一个动作发正手短和反手长。
8. **挑、摆混合**：同伴发同一种短下旋，你按教练口令或自己判断交替挑、摆短、劈长（TOTW 2025-11-03；`../techniques/receive.md`）。
9. **接发球实战**：先反复接同一种难接的发球，再加入变化，最后在比赛里用（PS How to Practice Receiving）。
10. **进阶到拧**：挑熟练以后再学拧拉（PSQ Backhand flick），见 `../techniques/backhand-banana-flick.md`。

## 10. 视频检查要点

**机位**：`../analysis/recording-guide.md` 对台内挑打首选**侧面（略高于球台）**，备选斜前 45°。主机位：侧面、略高于台面，看上步深度、臀部有没有掉在后面、手臂前伸、拍面后仰程度、挥拍方向。补充机位：挑打者左前方斜前 45°，看肘的位置、手腕弹出、击球点在身体前方偏左多少。全身入画，脚和台面也要拍进去。用 120/240 fps 慢动作，导出后用 `--capture-fps` 校正真实帧率。台内动作很小，脚本可能找不到挥拍（`NO_STROKES` 警告），这时用 `--start/--end` 截出这一板再分析。

| 阶段 | 关键帧看什么 | 对应指标 |
|---|---|---|
| 准备 | 离台一小步；膝微屈；拍不低于台面 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 引拍/上步 | 上步脚有没有插到台下；重心是否跟到上步脚；引拍是否很小；肘是否前顶 | `weight_shift.backswing_end`（0＝持拍侧右脚，1＝左脚；上右脚时应接近 0，上左脚时接近 1，要按实际上的哪只脚来读）、`knee_min_deg.{playing,other}`、`trunk_lean_deg.backswing_end`、`backswing_ms`（应很短）、`elbow_angle_deg.backswing_end` |
| 迎球 | 是否以肘为轴，大臂是否大摆；有没有大幅转体 | `elbow_body_gap_m`、`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`（都应很小）、`forward_ms`、`peak_hand_speed`（只和自己的其他板比） |
| 击球瞬间 | 击球点在身体正前偏左、台内；手臂是否伸直；头是否稳；左手是否在平衡位置 | `contact_forward_m`、`contact_lateral_m`（方向约定见 `../analysis/metrics-reference.md`）、`contact_height_level`、`elbow_angle_deg.contact`（接近 180° 说明手臂伸直了）、`trunk_lean_deg.contact`、`head_motion`、`free_arm_height_level` |
| 随挥 | 挥拍方向：下旋更向上，不转或上旋更向前；收拍短 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`（不应过高）、`elbow_angle_deg.finish`、`follow_ms` |
| 还原 | 是否立即退回：看随挥结束后几帧上步脚有没有收回、髋有没有离开台面（看分解图） | `weight_shift.finish`、`weight_shift.delta` 作参考；`recovery_dist` 只看拍有没有回到体前 |
| 整体 | 识别正反手；数据是否可信 | `side_guess`（应为反手）、`sequence_ms.{hip,shoulder,elbow}` 和 `sequence_order_ok`（台内动作小，参考价值低）、`shoulder_width_ratio.{backswing_end,contact}`（只在斜前 45° 机位上看：比值明显变小说明身体侧转过大）、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

**拍面和手腕只能看手部放大图**：骨架模型测不出拍面，单机位对前臂旋前、旋后的测量误差很大（Shrestha 2026）。要看击球前后的手部放大图（`stroke_NN_zoom.jpg`）和触球原图（`stroke_NN_contact_raw.jpg`）：引拍末手腕是否内收、拍头是否指向左下；触球瞬间手腕是否向外、向前弹开；对下旋拍面是否打开、对不转或上旋拍面是否立起；是否用靠近拍头的部位触球。如果 `quality.reliable` 为假，或手腕在 `low_visibility_parts` 里，就不要下结论，按 `../analysis/recording-guide.md` 重拍。

## 11. 自查清单

- [ ] 判断出短球后先动脚：反手位上右脚或左脚，知道两者的代价；正手位用反手时上右脚过去，挑完快速退回
- [ ] 上步脚插到台下，重心跟上，臀部没有掉在后面
- [ ] 手位不低于台面，引拍很小：肘前顶，前臂收到胸腹前，手腕稍内收
- [ ] 以肘为轴，前臂带手腕向外、向前弹出；手臂始终不伸直
- [ ] 按旋转定拍面：不转立起、打得平；上旋、侧上旋稍关、向前打穿；下旋打开向上擦
- [ ] 弹挑在高点期击球，快点抢早出手；快点打摆短的下旋时拍面稍后仰、多带摩擦
- [ ] 握拍松，触球瞬间才握紧；多用靠近拍头的部位触球
- [ ] 随挥短，拍头指向目标；会挑两个大角和中路，能用手腕把方向藏到最后
- [ ] 挑完立即退回，能接住对方的反撕、反带，正手也能接上
- [ ] 低而重的下旋会改用摆短或拧，不硬挑
- [ ] 知道什么球挑、什么球拧、什么球快点
- [ ] 半出台能拉就拉
