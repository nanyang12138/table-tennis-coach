# 反手快拨、反手攻球、反手弹击与推挤（Backhand Drive / Counterhit / Punch）

适用：近台反手位的上旋球、不转球、半高球、较弱下旋球｜难度：入门（快拨、攻球）→ 中级（弹击、推挤）→ 高级（反手扣杀）｜相关卡片：[反手挡](../techniques/backhand-block.md) · [反手撕](../techniques/backhand-tear.md) · [反手拉上旋](../techniques/backhand-loop-vs-topspin.md) · [反手拉下旋](../techniques/backhand-loop-vs-backspin.md) · [正手扣杀](../techniques/forehand-smash.md) · [直拍](../techniques/penhold.md) · [握拍](../fundamentals/grip.md)

> 本卡按右手横拍写；左手持拍者左右互换。拍面角度统一用"拍面与台面的夹角"：90° 为垂直，小于 90° 为前倾，大于 90° 为后仰；击球时间按"上升期 → 上升后期 → 高点期 → 下降前期 → 下降后期"五段划分（[CETV-击球技巧]）。

## 1. 定义与用途

这一组技术的共同点是：**以撞击为主、摩擦为辅，拍面前倾，前臂主导，动作小、出手快**。英文教学里统称反手攻/反手对攻（backhand drive / backhand counterhit）：拍面大致与挥拍方向垂直，大部分力量变成球速而不是旋转（[S2]）。按发力大小和用途分五种：

| 技术 | 什么时候用 | 核心 | 击球时间 |
|---|---|---|---|
| 反手快拨（quick backhand counter） | 近台对上旋、不转、对方慢拉慢搓过来的球；稳节奏、压落点 | 借力为主，以肘为支点，前臂小幅前推，手腕相对固定 | 上升前期（[乒乓网-拨撕]） |
| 反手攻球（backhand drive） | 近台相持，主动加速、调动 | 前臂由左后向右前上加速，手腕外转，重心左→右 | 上升期，中上部（[CETV-攻球]）；初学先打高点期（[BK-反手攻]） |
| 反手弹击（backhand punch / flick-hit） | 来球较慢、偏高、旋转弱（含弱下旋）时突然加速；常打对方正手位空当（[BK-弹打]） | 以肘为轴，前臂和手腕爆发式弹出 | 上升后期或高点期；弹下旋更早（[BK-弹打]） |
| 反手推挤（push-squeeze） | 近台对弧圈、上旋球时压低弧线、打大角度 | 前臂上提，向左前下方"挤压"，带侧下旋 | 上升期，击球左侧中上部（[BK-挤推]） |
| 反手扣杀（backhand smash） | 反手位的高球，来不及侧身时 | 来球较高时由弹击"转为动作略大的反手发力抽杀"（[BK-弹打]）；扣时肩要抬起（[LH-811]） | 暂无专门出处 |

**弹击的适用限制**（[BK-弹打]）：弹击突然性强、威力大，但"没有旋转且失误较多"，现在乒坛用得少，"一般由反手生胶或正胶选手使用，或在来球较高时弹击一板"；对方"全力正手暴冲时使用存在较高失误率"。反胶选手可以学，但要把它当作偶尔的变化，而不是相持主力。

**弹击的代表人物**：百科列横拍瓦尔德内尔、直拍刘国梁（率先使用）（[BK-弹打]）。中文维基称直拍推挡快攻的蒋澎龙"對於較慢來球所用的反手彈擊也是其一大特色"（[维基-蒋澎龙]）；直拍横打的王皓"能反面弹打、快拉"（[维基-王皓]）。注意后两人和刘国梁都是**直拍**，用的是直拍反面（或推挡面）的弹击，横拍选手只借鉴"对慢球突然加速"的用法，握法细节见 [直拍](../techniques/penhold.md)。

**推挤的来源说明**：百科"挤推"词条把它归在推挡球（以直拍为主）之下，动作要点"与快推相似"，未找到专讲横拍推挤的来源；横拍沿用同样要领：前臂上提、上升期触左侧中上部、向左前下挥。特点是"弧线低，角度大，且带有侧下旋"，出手快、不吃转（[BK-挤推]）。

**用途**：保持回合、施加压力、为更有威胁的进攻创造机会（[S2]）。教育电视台的两面攻战术要求"正、反手攻球都要有线路变化和落点变化"，并"以压对方反手为主，然后攻击对方正手或中路"（[CETV-两面攻]）。

**与反手撕、反手拉的区别**（乒乓网把快拨和快撕的区别讲得最清楚）：

| | 快拨 / 攻球 / 弹击 | 反手快撕（[反手撕](../techniques/backhand-tear.md)） | 反手拉（[拉上旋](../techniques/backhand-loop-vs-topspin.md)、[拉下旋](../techniques/backhand-loop-vs-backspin.md)） |
|---|---|---|---|
| 触球 | 撞击为主，"打"进球里 | 主动发力加摩擦，前臂"外展→内收"，手腕轻微外展再内扣 | 薄摩擦为主，"刷"球 |
| 幅度 | 最小 | 比快拨稍大 | 最大，拍从更低处起 |
| 时机 | 上升前期～上升期 | 上升后期或高点期，"吃住球再出手" | 视来球而定，常更晚 |
| 挥拍方向 | 向前为主，略向上 | 向前上 | 向上成分明显，下旋越重越向上 |
| 球的特点 | 快、平、旋转少 | 又快又转 | 弧线高、旋转强 |

乒乓网的建议是"先练会快拨建立手感，再学快撕提升威胁"（[乒乓网-拨撕]）。PingSkills 的说法也一致：想让反手更快，就让触球"稍平、更向前"（a slightly flatter contact and directing the action more forward）（[PS-更快反手]）。

**反手扣杀单独说明**：PingSkills 把它列为高级课，但明确建议"尽量不用反手扣杀，改用正手扣"，只有被逼在反手位时才用（[PS-反手扣杀]）。日文维基也说扣杀主要用正手，横拍和直拍都能反手扣；直拍有一种做法：右脚在前、引开非持拍手、以肩为支点挥臂并压上体重，预备动作小、不易被读出线路（[S5]）。PingSkills 扣杀页的技术只在视频里，页面文字没有动作要领；本卡对横拍反手扣杀能给的有出处要领只有上表那两条。Hodges 认为正反手扣杀都值得练，给出了反手也能做的练法（见第 9 节，[LH-811]）。

## 2. 三位标杆怎么做

三人的反手快拨/攻球**没有找到可靠的动作分解资料**（拍面角度、肘角、转腰幅度都没有）。下面只列有出处的观察：

**马龙**
- 刘国梁 2020 年复盘威海世界杯："他的反手体系有明显进步……他可以更加相信自己的反手"（[央视-马龙2020]）。
- 评论文章说东京奥运决赛中，马龙除了反手拧（flick）和反手对攻（counter），还用减力切挡打乱樊振东的节奏（[Khaleej-2021]，评论，非教练分析）。减力挡见 [反手挡](../techniques/backhand-block.md)。
- 独立分析网站 Edges and Nets 从热身视频观察到：反手对攻时马龙的肘"收得稍低、更贴近身体"（tends to tuck his elbow a little bit lower in）（[EN-2021]，单一来源博客）。
- 百科提到马龙 2024 年大满贯有"大跨步反手弹击"，但只有一条中华网标题转引、原文打不开，**暂无可靠出处，不采用**。

**张继科**
- PingSkills 问答里，有人问 2012 伦敦奥运决赛中张继科的反手，教练回答：动作看起来不大，但手腕用得非常有效（using his wrist very effectively），加上多年比赛练出的极好时机（impeccable timing），这需要大量击球（[PSQ-张继科]）。
- 新浪体育 2016 评论："以往张继科的反手占优"，但里约决赛后三局"在反手相持上处于下风"（[新浪-2016]）——反手强项也会被压制。
- 他最有名的反手是台内拧拉，见 [反手拧拉](../techniques/backhand-banana-flick.md)。

**樊振东**
- 一项基于全运会高速摄像比赛视频的**定性**研究观察到：他反手进攻时引拍幅度更小、击球更早、击球点离身体更近、击球时重心稳；肘向前顶、拍的位置相对固定，形成"打摩结合"；随挥以肘向前为主；整体"紧凑、发力集中、还原快"（[Jin&Ma-2026]，仅定性比较，无角度数值）。
- 刘国梁评价他"反手变直线更加稳定"（[央视-樊振东2021]）；巴黎奥运男单决赛最后一分是一板反手直线进攻（[央视-樊振东2025]）。
- Edges and Nets 观察到：反手对攻时他比马龙腋下更开、肘"稍高"，作者推测利于正反手转换，但中路可能更易被针对（[EN-2021]，单一博客观点）。

**业余可以学什么**：从樊振东的定性研究（[Jin&Ma-2026]）可以学到引拍小、击球早、肘向前、拍形稳；从张继科"动作不大、靠手腕和时机"（[PSQ-张继科]）可以学到：把速度花在"早"和时机上，而不是挥大臂。马龙只有单一博客的肘位观察，不足以归纳成要点。更多见 [马龙](../players/ma-long.md)、[张继科](../players/zhang-jike.md)、[樊振东](../players/fan-zhendong.md)。

## 3. 动作分解

以下以**反手攻球**为主线；快拨、弹击、推挤、扣杀的不同写在每表末行"变化"里。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 近台，两脚与肩同宽或稍宽，前脚掌着地、脚跟微离地（[CETV-姿势]）。脚序：教材说法不一（CETV"右脚稍前"，百科"左脚稍前"）。建议：快节奏相持用**略偏正手的站位**（右脚稍后），便于正反手转换；时间多、要发大力时可站平行甚至右脚稍前（[LH-3310]）。百科给出快拨离台约 40 厘米（单一来源） | 站太远，只能等球下降再打；脚跟踩实，起动慢 |
| 膝 | 微屈，随时可左右换重心 | 直腿站，重心高 |
| 髋 | 正对来球方向，不提前转 | 侧身过多，反手位来球被挤 |
| 腰/躯干 | 上体略前倾、收腹（[CETV-姿势]），身体尽量正对来球（[BK-反手攻]） | 后仰、塌腰 |
| 肩 | 放松，不耸 | 耸肩导致整条手臂僵 |
| 大臂/肘 | 肘自然下垂在体侧略前，离身体留空间 | 大臂贴死在身上（"夹肘"） |
| 前臂 | 横拍准备时前臂自然平举，拍头朝上（[CETV-姿势]） | 拍放得太低（腰以下） |
| 手腕 | 自然放松 | 已经提前翻成反手形状、僵住 |
| 手指/握拍 | 握手式，握松；反手攻时**拇指稍向上移动**（[CETV-握拍]）。Hodges 主张打反手时拇指多压一点，让拍头略向右转，拍面稍关，拇指在拍后面"顶住"把拍推进球里（[LH-3676]）；PingSkills 则主张一个不夸张、兼顾两面的握法，不刻意换握（[PS-换握]）——两说并存，自己试 | 握死（别人从背后抽不走拍）（[LH-2271]） |
| 拍面/拍头 | 在身体前方，拍头朝上偏左 | 拍头下垂 |
| 视线/头 | 盯对方拍面和出球 | 看自己的拍 |
| 变化 | 快拨：站位更近，百科写离台约 40 厘米、两脚平行与肩同宽、脚跟微抬（[BK-快拨]）。弹击：手臂尽量贴近身体、略含胸，上身保持稳定、不晃动（[BK-弹打]） | — |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 先用小步让球正对身体略偏左；重心偏左脚（[CETV-攻球]） | 不动脚，用手够球 |
| 膝 | 有资料描述为：引拍时左膝前屈、右膝稍直，右脚掌内侧蹬地（[BK-反手攻]、[BK-快拨]，单一来源） | 两膝僵直 |
| 髋 | 跟着腰略向左转，幅度很小 | 大幅转髋，来不及还原 |
| 腰/躯干 | 腰略向左拧（[BK-反手攻]）；快拨"轻微拧转，不能大幅转动"（[BK-快拨]） | 转得像反手拉 |
| 肩 | 右肩随转体稍向内收；弹击时"略微含胸"（[BK-弹打]） | 右肩后拉过多 |
| 大臂/肘 | 肘稍抬起作支撑但不固定；肘稍前（弹击要求"肘关节前顶"） | 肘先往后拖 |
| 前臂 | 前臂向怀里收，**与台面大致平行**，把拍引到**腹前偏左**（[BK-反手攻]、[BK-快拨]）。反手攻引拍肘角接近 90°，百科自注"只是大致范围，不能生搬硬套"（[BK-反手攻]）；快拨大小臂夹角约 100°～90°（[BK-快拨]，单一来源） | **引拍太低**：以后只会由下向上"蹭"球，摩擦有余撞击不足（[BK-反手攻]） |
| 手腕 | 内收，拍头指向左侧（[BK-反手攻]、[BK-快拨]）；快拨时手腕可略下垂，与前臂一起弹击发力（[BK-快拨]） | 手腕不内收、拍头不指左，后面没有外展的空间 |
| 手指/握拍 | 拇指准备发力，食指稳住拍面 | 引拍时就握紧 |
| 拍面/拍头 | 稍前倾；CETV 指出"拍面前倾过早"是常见错误，引拍时拍面可稍后仰一点，击球时再外转压出前倾（[CETV-纠错]） | 引拍时就盖死，挥拍变成往下砸 |
| 视线/头 | 判断来球旋转、高低 | 头随引拍左转 |
| 变化 | 快拨：几乎不引拍。弹击：手臂尽量贴近身体，前臂引到胸腹前。推挤：前臂**上提**，拍引到身体前上方（[BK-挤推]）。扣杀：动作比弹击"略大"（[BK-弹打]）；直拍可右脚在前、引开非持拍手、预备动作小（[S5]）；其余引拍细节暂无专门出处 | — |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心由左脚移向右脚，**不需要大步，只是重心转移**（[PSQ-反手转腰]） | 往前冲步 |
| 膝 | 右膝前屈、左膝稍直，配合重心转换；有教学比喻为拳击的小幅快速前后动（[BK-快拨]，单一来源） | 膝不动，全靠手 |
| 髋 | 随重心向右前小幅回转 | 髋往后坐 |
| 腰/躯干 | 近台只需稍转腰（[PSQ-反手转腰]）；以"拧"为主，不大幅转动 | 大幅转体，球速不增反乱 |
| 肩 | 稳定，作为前臂发力的底座 | 耸肩、晃肩 |
| 大臂/肘 | 大臂相对稳定，**肘随之向前顶出**（[BK-快拨]）；肘不要先于拍向前冲 | 击球时**肘先向前**、抬肘（[BK-反手攻]） |
| 前臂 | 由左后向右前上加速，前臂发力为主（[CETV-攻球]）；前臂外旋 | 只用肩甩大臂 |
| 手腕 | 由内收转为外展、伸腕并外转，使拍面前倾（[BK-反手攻]、[CETV-攻球]）；快拨时手腕"相对固定，不主动加力"（[乒乓网-拨撕]） | 快拨时乱甩腕，稳定性差 |
| 手指/握拍 | 拇指在拍后面推（[LH-3676]），在触球前一刻握紧 | 全程握死 |
| 拍面/拍头 | 拍头由指向左转向指向右前方（[BK-反手攻]） | 拍头一直指左，球偏右出界 |
| 视线/头 | 头稳，盯球到拍前 | 头前冲或抬头 |
| 变化 | 推挤：手臂向**左前下方**挥，伸腕幅度大（[BK-挤推]）。弹击：以肘为轴，前臂和手腕爆发式打开 | — |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心正在过渡到右脚，两脚都着地 | 单脚离地 |
| 膝 | 保持弯曲 | 起跳或站直 |
| 髋 | 基本正对来球方向 | 已转到朝右 |
| 腰/躯干 | 稳住，作为支点 | 前后晃 |
| 肩 | 平稳 | 持拍肩下沉 |
| 大臂/肘 | 肘在身前，与身体留有空间（不夹、不外张） | 大臂与身体夹太紧 |
| 前臂 | 正在快速前送，**未完全伸直**（[BK-快拨]） | 已经伸直，再无发力空间 |
| 手腕 | 外展、外转，带出拍面前倾（[BK-反手攻]、[CETV-攻球]） | 手腕没外转，拍面前倾不够（见拍面行） |
| 手指/握拍 | 握紧，拇指顶住 | 握得松软，被来球顶开 |
| 拍面/拍头 | 稍前倾，**拍面接近垂直于挥拍方向**（[S2]），触球中上部 | 拍面前倾不够 → 偏高出界（[CETV-纠错]） |
| 视线/头 | 看到球撞到拍 | 闭眼、看落点 |
| 变化 | 快拨：上升前期触球，手腕相对固定、不主动加力（[乒乓网-拨撕]）。弹击：直接弹击球的中部（[BK-弹打]）。推挤：触球左侧中上部，带侧下旋（[BK-挤推]）。扣杀：直拍以肩为支点、压上体重（[S5]）；横拍暂无专门出处 | — |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到右脚或两脚之间（[BK-反手攻]） | 重心仍在左脚，球没压上 |
| 膝 | 右膝承重，仍弯 | 膝伸直 |
| 髋 | 随势小幅向右 | 被手臂带着大转 |
| 腰/躯干 | 稳定 | 前扑 |
| 肩 | 放松 | 继续耸肩用力 |
| 大臂/肘 | 肘前顶后自然停住 | 大臂甩出、肘高过肩 |
| 前臂 | 随势挥至**右肩前**（[BK-反手攻]）；随势"尽可能小"（[BK-反手攻]） | 收拍过远过高，来不及还原 |
| 手腕 | 自然停住 | 继续甩 |
| 手指/握拍 | 放松 | 一直握死 |
| 拍面/拍头 | 拍面仍前倾，指向出球方向 | 拍面翻成朝天（变成"捞"） |
| 视线/头 | 看对方 | 盯着球飞 |
| 变化 | 快拨：几乎没有随挥，"堵"一下就收。弹击：出手动作要小，完成后手臂不完全伸直（[BK-弹打]）。扣杀：随挥细节暂无专门出处 | — |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心从右脚回到两脚之间，前脚掌着地、脚跟微离地，准备下一板 | 重心留在右脚、脚跟踩实，下一板起动慢 |
| 膝 | 回到微屈，保持弹性 | 随挥后膝伸直，重心升高，下一板要重新下蹲 |
| 髋 | 回到正对来球方向 | 髋还朝右，下一板反手位来球被挤 |
| 腰/躯干 | 回到正对来球、上体略前倾 | 还停在右转，或上体直起后仰 |
| 肩 | 放松回位 | 仍耸着，下一板手臂发僵 |
| 大臂/肘 | 肘回到体侧略前，与身体留空间 | 手臂留在身体右前方，或回收时夹死 |
| 前臂 | 前臂收回身前，拍回到腹前高度；Hodges 主张每板回中立位（[LH-3731]），PingSkills 认为应根据来球直接把拍移到下一板位置（[PS-复位]），两说并存 | 前臂垂下，拍掉到腰下 |
| 手腕 | 回自然位 | 停在外展位，下一板没有内收引拍的余地 |
| 手指/握拍 | 从触球时的握紧回到放松 | 一直握死，手臂酸、动作僵（[LH-2271]） |
| 拍面/拍头 | 拍头朝上，拍面回到身前 | 拍头下垂或拍面朝天 |
| 视线/头 | 看对方拍面判断下一板 | 盯着自己打出的球，判断晚 |
| 变化 | 快拨、弹击都要"击球后，重心以及手臂迅速还原"（[BK-快拨]、[BK-弹打]） | — |

## 4. 拍面角度、击球点、击球时间、触球部位

- **拍面角度**：攻球、快拨都是"稍前倾"（[CETV-攻球]、[BK-快拨]），没有可靠的具体度数，只能按来球调整：上旋越强越前倾，来球越转越要"关"拍（[PS-反手挡]的原则同样适用）；弹击弱下旋时要竖起或稍后仰，下旋越强后仰越多（[BK-弹打]）。PingSkills 的"更快的反手"=触球更平、更向前（[PS-更快反手]）。
- **击球点**：身体前方偏左、腹前到胸前之间；"球拍与来球距离不宜太近"，否则发不上力（[BK-快拨]）。CETV 的描述是"胸前击球"（[CETV-攻球]）。
- **击球时间**：快拨上升前期（[乒乓网-拨撕]）；攻球上升期（[CETV-攻球]）。百科强调**初学者先打高点期**，太早抢上升期会"只会借力不会发力"（[BK-反手攻]）。弹击、快撕上升后期或高点期（[BK-弹打]、[乒乓网-拨撕]），但弹下旋要更早，"球一落台"就出手（[BK-弹打]）。扣杀的击球时间暂无专门出处。推挤上升期（[BK-挤推]）。
- **触球部位**：中上部（攻球、快拨）；中部（弹击）；左侧中上部（推挤）。触拍位置：弹击多用靠近拍头的部位（[BK-弹打]，单一来源）。
- 共通定义见 [拍面角度、击球时间与触球](../fundamentals/racket-angle-timing-contact.md)。

## 5. 发力：顺序、方向、摩擦与撞击

- **发力来源**：近台反手以前臂为主（[CETV-攻球]），手腕配合；腿和腰提供支撑和小幅重心转移，"右脚掌内侧蹬地"（[BK-反手攻]）。弹击和扣杀需要更完整的链条："从蹬地开始，力量经腰、肩稳定传导"，再依次打开腕与小臂、小臂与上臂、上臂与胸的关节夹角（[BK-弹打]，单一来源）。
- **方向**：攻球向右前上（[CETV-攻球]）；快拨向右前方（[BK-快拨]）；推挤向左前下（[BK-挤推]）；弹击"前臂以及手腕快速外展，向前发力"（[BK-弹打]）；扣杀方向暂无专门出处。
- **撞击与摩擦**：攻、拨、弹以撞击为主。注意同一百科"弹打"词条里对弹击下旋的描述是"摩擦为主，打为辅助"，对上旋则是"直接弹击球的中部"——即**对上旋/不转以撞为主，对弱下旋要带摩擦**。
- **借力 vs 发力**：快拨"借力为主，少发力"；快撕、弹击、扣杀主动发力（[乒乓网-拨撕]、[BK-弹打]）。
- **拇指**：Hodges 称拇指是反手的关键，给击球"支撑和稳定性"，把拍"推进球里"（[LH-3676]）。
- 力学背景（来自反手**拉**的研究，不是本技术的测量）：贴台快节奏时，骨盆和上躯干转动受限，拍速下降（[IK2016b]）——这也是近台反手要靠前臂和时机而不是大转体的原因。总论见 [发力与身体](../fundamentals/power-and-body.md)。

## 6. 面对不同来球的调整

| 来球 | 选什么 | 怎么调 |
|---|---|---|
| 一般上旋（对方攻、轻拉） | 快拨 / 攻球 | 上升期，拍稍前倾，向前为主 |
| 加转弧圈 | 快拨压住，或改用快撕、推挤 | 拍面更前倾、更早、更向前下压；吃转出界时先关拍 |
| 不转、慢球 | 弹击 / 攻球加力 | 等到上升后期或高点期主动打 |
| 弱下旋（慢搓、半出台） | 弹击（或改反手拉） | 拍面竖起或稍后仰，下旋越强越后仰、越向上；弹下旋时出手要更早，球一落台拍就切到球下方再压腕回摆（[BK-弹打]，单一来源）；重下旋别弹，改 [拉下旋](../techniques/backhand-loop-vs-backspin.md) |
| 半高球、高球 | 弹击 / 反手扣杀 | 来得及就侧身用正手扣（[PS-反手扣杀]）；来不及就由弹击转为动作略大的反手发力抽杀（[BK-弹打]） |
| 对方准备全力正手暴冲 | 慎用弹击 | 此时弹击"存在较高失误率"（[BK-弹打]），改快拨或挡 |
| 追身（中路）来球 | 快拨 | 先让位，脚来不及时身体侧让出空间（[PS-中路球]） |
| 快节奏正反手交替 | 用略偏正手站位（右脚稍后）打反手 | 身体仍向左转，转正手更快（[LH-3310]）；见 [正反手转换](../techniques/transitions.md) |
| 被对方（尤其直拍）加力推挤 | 开拍面快回带摩擦，或拍面稍后仰送切，或稍退台反手加转慢拉（[BK-挤推]，原文案例是横拍两面反胶对直拍反手加力推挤） | 快回要借力多于发力、下手够快；慢拉不求快，要拉得转、长 |

**器材**：弹击用生胶、正胶威力更大、回球下沉；反胶弹击后要准备转正手进攻（[BK-弹打]，单一来源）。见 [器材与技术](../fundamentals/equipment-and-technique.md)。

**线路与落点**（Hodges，[LH-3423]）：反手相持应瞄四个点——
1. **反手大角外**（出边线）：来球偏短或落在你反手大角时可打得更斜，逼对方移动；
2. **反手底角深**：最基本的一板，最深、可用台面最大；
3. **对方持拍肘（中路）**：正反手转换点，逼对方犹豫、让出一角；
4. **正手大角**：对方被调到反手后突然变，要真正打到大角，最好快、带隐蔽。

两角之间的区域"很少去"。打正手时要有隐蔽，甚至可以先瞄一边、最后一刻改另一边（[LH-3423]）。樊振东的"反手变直线"就是这一招的高水平版本（第 2 节）。

## 7. 关键数据参考

- **本次没有找到测量反手快拨/攻球/弹击关节角度、拍速或时长的同行评审研究**（biomech 检索结论）。反手**拉**的肘角、角速度见 [反手拉上旋](../techniques/backhand-loop-vs-topspin.md)，不要套用。
- 横拍与直拍比较（测的是反手**上旋击球/拉球**，不是快拨或攻球）：反手球速、拍速横拍更高，正手无显著差别（[Xia2020]）。仅作背景。
- 教学资料里的数字（都是单一来源，仅供参考）：快拨离台约 40 厘米、大小臂夹角约 100°～90°（[BK-快拨]）；反手攻引拍时肘部夹角接近 90°，百科自注"只是大致范围，不能生搬硬套"（[BK-反手攻]）。
- 练习目标：Hodges 建议练到正反手各连续 100 板（[LH-14]）；PingSkills 用 30 秒计数挑战（[PS-训练101]）。

## 8. 常见错误：表现 → 原因 → 纠正

1. **球总是往前上"拱"、压不住上旋、出界** → 引拍太低，由下向上蹭球 → 引拍到腹前偏左、前臂与台面平行，向前多于向上（[BK-反手攻]）。
2. **球下网** → 拍面前倾过早 → 徒手做引拍，让拍面稍后仰，击球时再外转（[CETV-纠错]）。
3. **球偏高出界** → 拍面前倾不够 → 用平击发球练习体会手腕外旋（[CETV-纠错]）。
4. **肘先往前冲、抬肘** → 用大臂带动，前臂没发力 → 大臂相对稳定，让前臂带拍先走，肘随后顶出（[BK-反手攻]、[BK-快拨]）。
5. **大臂夹死** → 紧张或站太近 → 肘与身体留空间，放松肩部（[BK-反手攻]、[CETV-纠错]）。
6. **只会借力、打不出主动发力的球** → 入门就抢上升期 → 先在高点期练完整动作，再提前（[BK-反手攻]）。
7. **离球太近、手臂打直** → 站位或步法不到位 → 先动脚，保持前臂弯曲击球（[BK-快拨]）。
8. **快拨不稳、落点乱** → 手腕乱动 → 快拨手腕相对固定，用前臂"推"（[乒乓网-拨撕]）。
9. **反手扣杀失误多** → 用反手处理本该侧身的球 → 有时间就正手扣（[PS-反手扣杀]）。
10. **球软、无冲击** → 握拍太松或拇指没顶住 → 触球瞬间握紧，拇指在拍后支撑（[LH-3676]）。
11. **动作僵、手臂酸** → 握得太死 → 握松到别人能从背后把拍抽走（[LH-2271]）。

更多见 [错误索引](../training/errors-index.md)。

## 9. 练习方法（入门 → 进阶）

1. **徒手挥拍**：每天 100 次反手攻，体会腰的小幅扭转和重心转换（[LH-54]、[CETV-纠错]）。
2. **自抛自攻**：站反手半台，自抛球后反手攻斜线（[CETV-纠错]）。
3. **一攻一挡**：同伴推挡或挡，你反手攻斜线；先慢后快，直到连续 100 板（[LH-14]、[CETV-纠错]）。
4. **对攻斜线 → 中路直线**：两人反手对攻斜线，再对攻中路直线（[CETV-纠错]）。
5. **一点打两点**：你一点攻两点，对方两点推一点（[CETV-纠错]）。
6. **四点落点练习**：反手相持中依次打反手大角外、底角、对方持拍肘、正手大角；再进阶为反复压反手底角，等机会变正手（[LH-3423]）。
7. **快拨 → 快撕组合**：慢球快拨，见到半高或质量不高的来球立刻换快撕（[乒乓网-拨撕]）。
8. **轻重练习（Hard-Soft Drill）**：同伴挡，你一板中等力量的攻、一板扣杀交替（或两板中等一板扣，便于专注技术；Hodges 说它其实该叫 Hard-Medium Drill），落点固定；正反手都能练（[LH-811]）。
9. **反手扣杀**：发下旋—同伴搓—你反手拉到同伴反手—同伴挡回—你反手扣，全在反手位完成；拉时沉肩，扣时肩要抬起来（[LH-811]）。
10. **多球**：喂上旋、不转、弱下旋、半高球交替，练选技术（[PS-多球]）。

完整训练计划见 [练习汇编](../training/drills.md)。

## 10. 视频检查要点

**机位**：正面或斜前 45°，拍全身、看得到双脚（[录像指南](../analysis/recording-guide.md)）；用 120/240 帧慢动作，导出后若文件帧率与拍摄帧率不同，运行时加 `--capture-fps`。正面拍时肘角在手臂朝镜头时不准，以手部放大图为准。

| 阶段 | 关键帧看什么 | 对应指标（定义见 [指标参考](../analysis/metrics-reference.md)） |
|---|---|---|
| 识别 | 脚本是否判成反手 | `side_guess` 应为 backhand；`contact_lateral_m` 应接近 0 或为负 |
| 准备 | 站宽、膝弯、拍在身前 | `stance_width_ratio`、`knee_angle_deg.playing.ready` / `knee_angle_deg.other.ready` |
| 引拍结束 | 拍在腹前偏左、不低于腰；肘不贴死 | `elbow_angle_deg.backswing_end`、`trunk_lean_deg.backswing_end`、`shoulder_width_ratio.backswing_end`、`x_factor_deg`（应很小） |
| 迎球挥拍 | 是否有拖肘/肘先走；节奏是否紧凑 | `backswing_ms`、`forward_ms`（同一视频内比较，越短越紧凑）、`peak_hand_speed`；`sequence_ms.hip` / `sequence_ms.shoulder` / `sequence_ms.elbow` 和 `sequence_order_ok` 只对攻球、弹击、扣杀有参考意义，快拨以前臂为主可不看 |
| 击球瞬间 | 击球点在身体前方、腹到胸高；肘与身体有空间 | `contact_forward_m`（应为正）、`contact_height_level`（扣杀打高球时偏高；快拨、攻球、弹击多在 0～1 之间；同一视频内应稳定）、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`knee_angle_deg.playing.contact`、`trunk_lean_deg.contact`、`shoulder_width_ratio.contact` |
| 随挥 | 收在右肩前、手臂没伸直、方向以向前为主 | `elbow_angle_deg.finish`（接近伸直说明手臂打直）、`finish_height_level`、`swing_path.angle_deg`（应比反手拉明显更平；推挤可能为负）、`follow_ms` |
| 全程 | 重心左→右；头稳 | `weight_shift.delta`（反手重心从另一侧脚移向持拍侧脚，应为负值或接近 0；明显为正说明重心反了）、`shoulder_turn_deg` / `hip_turn_deg`（应小）、`knee_min_deg.playing` / `knee_min_deg.other`、`head_motion`（越小越稳）、`free_arm_height_level` |
| 还原 | 拍回身前 | `recovery_dist`（小说明还原到位） |
| 可信度 | 先看能不能信 | `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`；不可靠时只给定性意见并建议重拍 |

**拍面角度只看手部放大图**（`stroke_NN_zoom.jpg`、`stroke_NN_contact_raw.jpg`）：击球帧拍面是否稍前倾（不是朝天、也不是盖死）；拍头是否由指左转向指右前；手腕是否已外展、外转；拇指是否在拍后顶住。骨架模型测不出拍面和握拍。

**对照教学视频自查**：PingSkills 的反手攻课把动作归结为三个位置——脚位、引拍起点、收拍终点（"your feet position, the starting position of the bat and where the stroke should finish"）（[PS-反手攻]）。对应到上表，就是重点看"准备""引拍结束""随挥"三帧。

## 11. 自查清单

- [ ] 准备时拍在身前、拍头朝上，膝微屈，前脚掌着地
- [ ] 快节奏时站位略偏正手，时间多时可站平行
- [ ] 引拍到腹前偏左，前臂与台面大致平行，不低于腰
- [ ] 引拍时手腕内收、拍头指左，拍面不过早盖死
- [ ] 击球时大臂稳、前臂前送、肘随后前顶，不先冲肘、不抬肘
- [ ] 击球点在身体前方，离球不太近，前臂未伸直
- [ ] 快拨上升前期、手腕固定；攻球上升期；弹击上升后期或高点期
- [ ] 拍面稍前倾，触球中上部；弱下旋时竖拍或稍后仰
- [ ] 重心由左脚移到右脚，不跨大步
- [ ] 随挥收在右肩前、幅度小，马上还原
- [ ] 触球瞬间握紧、拇指在拍后顶住，其余时间握松
- [ ] 能有意识地打反手大角外、底角、对方持拍肘、正手大角四个点
- [ ] 高球有时间就侧身正手扣，不硬用反手扣
