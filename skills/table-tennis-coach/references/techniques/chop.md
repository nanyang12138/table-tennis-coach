# 削球（Chop）

适用：中远台防守对方的拉球、扣杀；削球手的主技术；攻球手被逼离台时的应急手段｜难度：高（加转/不转变化与削弧圈更难）｜相关卡片：`../techniques/push.md` `../techniques/long-push.md` `../techniques/lob-and-fish.md` `../techniques/backhand-block.md` `../techniques/forehand-loop-vs-backspin.md` `../techniques/backhand-loop-vs-backspin.md` `../techniques/forehand-smash.md` `../techniques/short-touch.md` `../techniques/footwork.md` `../techniques/transitions.md` `../techniques/tactics.md` `../fundamentals/spin.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/equipment-and-technique.md`

> 全文按右手横拍写；左手持拍者左右互换。
> 出处缩写：`BK-词条` = 百度百科（可编辑百科，可信度中等，常转引《乒乓世界》）；`LH:N` = Larry Hodges 文章 https://www.tabletenniscoaching.com/node/N ；`PS` = PingSkills 课程简介（视频需登录，只引用公开文字）。完整链接见文末。

## 1. 定义与用途

**削球（chop）**：在中远台，球拍由上向前下方切削，使回球带下旋（或不转、侧旋）的防守技术。英文维基称它"本质上是更大、更重的搓球，在远离球台处击球；拍面主要朝前、可能略朝上，挥拍方向基本向下"（"a bigger, heavier push, taken well back from the table…the direction of the stroke is straight down"）。BK-削球：击球时球拍后仰，由体侧上方向前下方挥拍，挥拍呈圆弧路线，在来球下降期触球中下部；回球速度慢、弧线长、下旋强，靠旋转和落点变化牵制对方。

**分类**（BK-削球）：按站位分近削、远削；按旋转分加转削、不转削；按目的有削逼角球、削弧圈球。英文维基另列侧旋削：削球可以"从不转到飘"改变下旋量，也能加侧旋（拐向球台或拐离进攻方），并改变落点（"Table tennis grips and playing styles"）。

**近削与远削**（BK-削球）：

| | 近削 | 远削 |
|---|---|---|
| 特点 | 动作幅度小、回球速度快、前进力较强 | 动作大、球速慢、弧线长 |
| 用途 | 近削逼角，对付轻拉和一般上旋球，有一定威胁 | 对付扣杀、弧圈球、提拉球；便于削转与不转、变落点；以削为主的选手必须掌握 |
| 引拍 | 向上引拍比肩略高 | 向上（右上/左上）引拍，增大用力距离 |
| 发力 | 前臂为主，手腕配合下压，**击球后没有前送** | 正手上臂带前臂、反手前臂和手腕加速切削；正手击球后**顺势前送**，反手顺势挥至右侧下 |
| 拍面 | 按来球调节后仰角度 | 后仰，触中下部 |

**谁需要学**：
- 削球手（chopper）：主技术。英文维基：削球手放弃主动，用尽量晚击球的慢、飘的下旋削球消耗对方（"slow, floating backspin chops executed as late as possible"），对方回球质量下降时再反攻。
- 攻球手：PingSkills 指出正手削"主要由防守选手使用，但攻球手被逼离台时也可用"。Hodges 建议所有人都学会四种防守（挡、削、鱼跃/放高球、防守性反拉），尤其在被调离位置时偶尔在反手大角削一板（LH:3549）。
- 削和搓、放高球的区别：搓是近台对下旋（`../techniques/push.md`）；放高球/鱼跃是退台用上旋保命（`../techniques/lob-and-fish.md`）；切挡（chop block）是近台挡球时加下旋（`../techniques/backhand-block.md`）。

## 2. 三位标杆怎么做

三人都是进攻型打法，**没有找到三人在比赛中使用削球的可靠出处**，下面只写有出处的相关内容。

- **马龙**：评论文章提到他在东京奥运决赛中用反手**切挡（chop-block）**打乱樊振东节奏："It comes back faster than a chop but it's so much slower than a normal counter"（比削球快、比正常反击慢得多）（Khaleej Times，2021-08-05，评论，单一来源）。这是近台挡球技术，不是削球，动作见 `../techniques/backhand-block.md`。同文还说他会不时退后一步离台变化节奏。
- **张继科**：暂无可靠出处。
- **樊振东**：暂无可靠出处。

**想看削球的高水平示范**，看削球打法代表人物（非本 skill 的三位标杆，资料来自 BK-横板削球、BK-削球、CETV-接发球抢攻页）：丁松（削中反拉，侧身正手发球抢攻强）、朱世赫（站位中近台、**高点期**削，弧线低、角度大，能连续反拉）、金景娥（站位中远台、**下降前期**削，弧线低、失误少，正手转与不转变化好）、王婷婷（两面反胶削球，英文维基也提到）。马龙、张继科、樊振东的打法档案见 `../players/ma-long.md` `../players/zhang-jike.md` `../players/fan-zhendong.md`（档案里没有削球内容）。

## 3. 动作分解

**站位**：以削为主的打法基本站位约离台 1 米（扬州职大；BK-横板削球"正手削球时站位离台约 1 米"）；近削更近台。正手远削"站位中台左脚稍前，上体稍向右转，重心落于右脚"；反手远削"中台站位右脚稍前，上体左转，重心落于左脚"（BK-削球）。即：**削哪边，哪边的脚在后、重心先压在那边的脚上**。

**步法**：防守型选手要覆盖的距离比攻球手大得多（PS Defensive Footwork）。BK-横板削球："步法是攻削结合打法的生命线"。前后移动：上前之后退台时，先看对方往哪里进攻，先拉开空间，方向明确后**转身并用并步/滑步（shuffle）**进入削球位置（PS Moving In and Out as a Defensive Player）。左右移动以并步、跨步为主，大角度用交叉步；来球离身体一步以内（含追身球）用单步，BK-单步把"削追身球"列为单步的用法（单一来源）（各步法要领见 `../techniques/footwork.md`）。核心：先到位、侧身，再削；脚不到位只能用手够，回球必高。

**正手远削 vs 反手远削**（BK-削球原文；击球点距离为单一来源，仅作参考）：

| 项目 | 正手远削 | 反手远削 |
|---|---|---|
| 站位 | 中台，"左脚稍前，上体稍向右转，重心落于右脚" | 中台，"右脚稍前，上体左转，重心落于左脚" |
| 准备 | "持拍手臂自然弯曲于腹前" | 持拍手"自然弯曲放松置于胸前" |
| 引拍 | "向右上方引拍与肩同高，拍面后仰" | "向左上方引拍约与肩高，拍柄向下" |
| 发力 | "上臂带动前臂由右上向左前下方加速切削，手腕向下转动用力" | "从左上方向右前下方挥动，拍面后仰，用前臂和手腕加速用力切削" |
| 击球点 | "在右侧离身体40厘米处"，下降期、中下部 | "球拍在胸前偏左30厘米处"，下降期、中下部 |
| 随挥 | "顺势前送" | "顺势挥至右侧下" |
| 补充 | — | PS 反手削：拍从左耳附近开始、向右膝方向挥，在身前触球（"start with the bat near your left ear""contacting the ball in front of your body"） |

下面 3.1–3.6 按身体部位展开，两者不同处分开写。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 中远台站位，两脚开立略宽于肩，前脚掌着地；判断来球方向后先移动到球的侧后方 | 站在近台等球，被拉后来不及退；脚跟踩死 |
| 膝 | 微屈，有弹性，便于前后大范围起动 | 直腿，退台慢 |
| 髋 | 判断正手削时髋向右转、反手削时向左转（BK-削球"上体稍向右/左转"） | 髋正对球台，侧身不够 |
| 腰/躯干 | 上体稍前倾、放松；正手削重心压右脚，反手削压左脚 | 上体后仰，重心在脚跟 |
| 肩 | 放松；随髋转向来球一侧 | 耸肩、肩紧 |
| 大臂/肘 | 自然弯曲；正手削"持拍手臂自然弯曲于腹前"，反手削"置于胸前"（BK-削球） | 手臂伸直、肘贴死身体 |
| 前臂 | 放在身前，不下垂 | 前臂垂到腰下，引拍要走很长的路 |
| 手腕 | 自然，不预先锁死 | 过早翘腕或压腕 |
| 手指/握拍 | 横拍正常握，握得稍松，触球瞬间再收紧（握法见 `../fundamentals/grip.md`） | 全程捏紧，手感差、转不转做不出区别 |
| 拍面/拍头 | 拍在体前、正反手之间 | 拍放得太低，引拍来不及 |
| 视线/头 | 盯对方击球动作判断旋转、力量和落点，再看球的飞行和弹跳 | 只看球，判断旋转晚 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 正手：右脚稍后；反手：右脚稍前（BK-削球）。来得及就侧身（PS 反手削"Turn side-on if you have time"） | 两脚平行正对球台，只能用手 |
| 膝 | 屈膝蓄力，准备随下降期的球降低重心 | 膝不弯，后面只能弯腰 |
| 髋 | 正手向右转、反手向左转，与肩同向 | 只转肩不转髋，动作发僵 |
| 腰/躯干 | 随引拍向持拍侧（正手）或非持拍侧（反手）转体，重心压后脚 | 躯干不转，力量只来自手臂 |
| 肩 | 随转体打开；持拍侧肩不过分抬高 | 耸肩导致挥拍变"砍" |
| 大臂/肘 | 正手：手臂向右后上方移动，前臂提起、球拍上举（BK-削球）；反手：向左上方引拍 | 引拍太低，挥拍距离不够，削不转 |
| 前臂 | 远削：引到约与肩同高（BK-削球）；近削：比肩略高 | 引拍过高过大，来不及；近削引拍过大 |
| 手腕 | 正手略后伸、拍面后仰；反手"拍柄向下"（BK-削球） | 手腕翻得太多，拍面过于朝天 |
| 手指/握拍 | 保持稍松 | 捏死 |
| 拍面/拍头 | 拍头朝上、拍面后仰；反手削时拍在左耳附近（PS 反手削"start with the bat near your left ear"） | 拍面已经平放朝天，只能托球 |
| 视线/头 | 跟球到下降期，头稳 | 头跟着引拍一起转走 |

**节奏**：反手受身体限制，"引拍动作要特别讲究节奏"（BK-削球）——按来球速度决定引拍早晚，快球早引、动作紧凑。

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 球下降时，重心由后脚向前移（正手由右脚向左脚；反手随挥拍移向右前，此为按挥拍方向的推断） | 重心停在后脚，回球无力、不过网 |
| 膝 | 随球下落而下沉，让击球点保持在合适高度 | 只弯腰不屈膝，视线和拍面一起变 |
| 髋 | 正手向左转、反手向右转，带动躯干 | 髋不动 |
| 腰/躯干 | "随着身体向左转，上臂带动前臂同时向左前下方用力"（BK-削球，正手）；削球难点是"手臂、腰、腹和腿的协调用力" | 只用手臂"砍"球 |
| 肩 | 肩随转体向前下方送 | 肩不动，手臂单独动 |
| 大臂/肘 | 正手远削：上臂带动前臂（BK-削球）；反手远削：以前臂和手腕加速切削为主（BK-削球）；近削：以前臂为主（BK-削球） | 正手远削时只动前臂，力量不足、回球短 |
| 前臂 | 正手由右上向左前下方加速切削；反手由左上向右前下方挥动（BK-削球）；反手削可理解为从左耳向右膝方向挥（PS 反手削） | 挥拍方向几乎垂直向下且不向前，回球下网 |
| 手腕 | 远削手腕向下转动用力、加速；削加转弧圈时手腕"相对固定"（BK-削球） | 削弧圈时手腕乱抖，回球过高 |
| 手指/握拍 | 触球前开始收紧 | 一直松，拍面被来球撞开 |
| 拍面/拍头 | 拍面后仰、由上向下呈圆弧挥动（BK-削球）；拍头始终高于手腕 | 拍头下垂，变成"捞" |
| 视线/头 | 盯住球的下降段 | 抬头看对方，提前分心 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚踩稳，重心在移动中 | 跳起来削，失去支撑 |
| 膝 | 屈，击球点低时更屈 | 腿直，只能弯腰够球 |
| 髋 | 正在转回 | 已经转完或没转 |
| 腰/躯干 | 稳定，不前扑也不后仰 | 后仰，拍面随之过分后仰 |
| 肩 | 放松但跟着转体 | 紧 |
| 大臂/肘 | 正手：击球点在身体右侧（BK"在右侧离身体40厘米处"，单一来源，仅作参考）；反手：胸前偏左（BK"球拍在胸前偏左30厘米处"，单一来源，仅作参考） | 击球点贴身或伸得过远 |
| 前臂 | 加速经过触球点 | 触球时减速"送" |
| 手腕 | 远削：加速摩擦；削加转弧圈：相对固定 | 削弧圈时手腕翻腕，回球冒高 |
| 手指/握拍 | 收紧 | 松 |
| 拍面/拍头 | 后仰但不过分：拍面主要朝前略朝上（英文维基）；削加转弧圈时来球越转越竖（BK-削球）。攻球手应急削：拍面更朝前（LH:3219"racket facing more forward, not so much up"） | 拍面朝天，回球冒高（LH:3219，针对应急削） |
| 视线/头 | 头稳，眼睛看到触球 | 头随挥拍转走 |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心完成转移 | 重心还在后脚 |
| 膝 | 保持屈膝 | 立刻站直，影响下一板 |
| 髋 | 正手转向左、反手转向右，跟完 | 戛然停住 |
| 腰/躯干 | 随挥拍方向转完 | 躯干后仰 |
| 肩 | 随挥 | 紧 |
| 大臂/肘 | 正手远削"顺势前送"，反手远削"顺势挥至右侧下"；**近削击球后没有前送**（BK-削球） | 近削也大幅前送，动作还原慢 |
| 前臂 | 正手挥至左前下方；反手"顺势挥至右侧下"（BK-削球），即右膝方向（PS） | 随挥方向向上，变成托 |
| 手腕 | 放松 | 仍然锁死 |
| 手指/握拍 | 放松 | 一直捏紧 |
| 拍面/拍头 | 结束在身体前下方 | 结束在身体侧面，挥拍没有向前分量 |
| 视线/头 | 看回球落点和对方动作 | 看自己的拍子 |

| 膝 | 恢复弹性微屈 | 腿直 |

| 腰/躯干 | 恢复稍前倾 | 后仰 |
| 肩 | 放松 | 紧 |
| 大臂/肘 | 手臂回到体前 | 手臂吊在身体下方 |

## 4. 拍面角度、击球点、击球时间、触球部位

- **拍面角度**：后仰（>90°），但**以朝前为主**。英文维基：拍面"主要朝前、可能略朝上"；BK-削加转弧圈："拍面不能过分后仰"，来球旋转越强拍面越竖。Hodges 对攻球手应急削要求"拍面更朝前"（LH:3219）。来球速度：PS 反手削"快球挥拍更垂直（向下）、慢球多向前挥"。**没有找到有出处的具体度数，只写定性**。
- **击球点**：正手在身体右侧、腹前一带，削加转弧圈"右腹前为宜，并适当放低"；反手在胸前偏左、身前（BK-削球；PS 反手削"contacting the ball in front of your body"）。
- **击球时间**：下降期（BK-削球）；削加转弧圈在**下降后期**——BK-削球给出的理由是"此时，球的旋转已减弱"，另一条理由是击球点放低时"可利用来球部分向上的反弹力形成自然的回球弧线"（教材解释的转述，不是测量结论）；但远削"不能过于低于台面"（BK-削球）。应急削：让球落到**台面高度或以下**（LH:3219）。削球手整体**尽量晚击球**（英文维基）。高水平的例外：朱世赫高点期削（BK-横板削球）。击球时间分期见 `../fundamentals/racket-angle-timing-contact.md`。
- **触球部位**：正式削球以中下部为准（BK-削球）。Hodges 给**攻球手应急削**的建议是触球偏后部、别削得太"底"，否则球冒高；他也指出高水平削球手会让球落得更低，再触得更靠下、擦得更薄（LH:3219）。
- **近削与远削的区别**：近削引拍比肩略高、前臂为主、手腕下压、**击球后不前送**；远削引拍约与肩高，正手上臂带前臂、反手前臂和手腕加速切削，正手**顺势前送**、反手顺势挥至右侧下；远削站位约离台 1 米（第 1 节表格）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：腿（重心由后脚移向前脚）→ 髋、腰转回 → 肩 → 上臂 → 前臂 → 手腕（远削时）。BK-削球把难点概括为"手臂、腰、腹和腿的协调用力"。总的发力链原理见 `../fundamentals/power-and-body.md`。
- **方向**：由上向前下，圆弧路线（BK-削球）。来球越快越偏"向下"，越慢越偏"向前"（PS 反手削）。
- **摩擦与撞击**：削球靠**摩擦**制造下旋（BK"利用球拍的摩擦力切削击球"），但远削"要保持足够的撞击力，否则球不会过网"（BK-削球）。应急削要"主要向下薄擦"（"graze the ball with a mostly downward stroke"，LH:3219）。没有找到摩擦/撞击比例的数字。
- **加转 vs 不转**：
  - 加转：拍面略开、薄擦、加速切过球，手腕参与（与搓加转同理，见 `../techniques/push.md`）。
  - 不转：用与加转**相似的手法**（CETV-削中反攻），只改：触球位置换到拍面上不同位置、**减少手腕动作**、触球稍向前（PS Disguising No-Spin Pushes and Chops）。外形要像，否则不起作用。
  - 侧旋削：英文维基说削球可加侧旋，拐向球台或拐离进攻方。BK-横板削球给了使用场景：对方盯拉反手位时，可"削一板侧旋球"（或反手兜、拉一板）牵制，伺机侧身抢拉空当。具体手法没找到可靠文字；按旋转原理（`../fundamentals/spin.md`），挥拍在向下的同时加入横向分量、触球偏侧下部即可带侧下旋——这是原理推论，不是引用。
- **器材的影响**：许多削球手反手用长胶或防弧胶皮削、正手反胶进攻（英文维基）；PS 指出长胶能吸收上旋的速度和旋转，比反胶更容易把球控回台面。器材与动作的关系见 `../fundamentals/equipment-and-technique.md`。

## 6. 面对不同来球的调整

| 来球 | 调整 |
|---|---|
| 加转弧圈 | 下降后期、右腹前略低处击球——击球点"一般选在右腹前为宜，并适当放低些，这样可利用来球部分向上的反弹力形成自然的回球弧线"；拍面不过分后仰，旋转越强拍面越竖、手臂向下压得越多；手腕相对固定（BK-削球，四条要点原文针对加转弧圈） |
| 前冲弧圈 | 退到中远台给自己时间；早引拍、动作紧凑；挥拍更竖直向下（PS 反手削：来球越快，挥拍越竖直）。**暂无专讲削前冲弧圈的可靠出处**；BK 的四条要点原文针对加转弧圈，能否直接套用没有出处 |
| 扣杀 | 同样退台、早引拍、挥拍更竖直向下（PS 反手削）。削扣杀是难技术，"球很快，动作必须恰到好处"（PS Chopping a Smash） |
| 轻拉、一般上旋 | 可用近削：动作小、前臂为主、手腕下压、不前送，可以逼角（BK-削球） |
| 慢、高的拉球 | 可多向前挥（PS 反手削）；或者直接放弃削，转为反攻（削中反攻，见下） |
| 长胶/防弧对手的回球 | 本卡以反胶削为准；对手胶皮特性见 `../fundamentals/equipment-and-technique.md` |
| 对方吊短 | 快速上前、贴近球、回球压低：再吊短或快搓到底线（PS How to Return Drop Shots as a Defender）。预防：自己的削球削深，对方就难吊短 |
| 追身（中路、持拍手腋下附近） | 追身球打的是横拍正反手交界处（BK-追身球；英文维基"crossover"）。削球在中远台，时间比近台多，**先用脚让位**：来球离身体一步以内时，用单步让位后再削（BK-单步：单步用于"削追身球"，单一来源；要领见 `../techniques/footwork.md` 的单步）；移到球的一侧再侧身，选定正手或反手，不要原地夹肘用手"切"。宽站位便于左右"让"，慢球就用脚移到位（PS How to Handle Balls Aimed at Your Middle；PS 该课讲的是进攻回球，这里借用其让位原则）。削追身只有步法层面的出处，没有专讲削追身手法的教学原文；正反手交界的处理见 `../techniques/transitions.md` |
| 被逼离台的攻球手（应急削） | 三原则（LH:3219）：① 让球落到台面高度或以下；② 触球偏后部而非底部，拍面更朝前，主要向下薄擦；③ 攻球手削下旋常出界，因为不习惯下旋球会"飘"，所以瞄准时想象让球落在**自己这侧**台面，它会飘过去。Hodges 建议被调离位置时，偶尔在反手大角削一板，尤其是对方用大角度挡球（angled block）时（LH:3549），非削球手突然削一板也会让对方不适应 |

**削中反攻（chop-and-attack）**：先用削球创造机会，再反攻得分。CETV-削中反攻：以逼角加转削球为主伺机反攻，或以"转、低、稳、变"的削球迫使对方在走动中拉攻；方法是正反手削逼角结合正手攻或侧身攻对方右侧空当，或削两大角长球结合正反手反攻；要点是：①注意旋转强度变化，**削加转后用相似手法削不转**，让对方拉出高球再反攻；②尽量压低弧线，防对方扣杀突击；③逼角时配合削另一角，让对方走动中击球。反攻的球用扣杀或拉冲：`../techniques/forehand-smash.md` `../techniques/forehand-loop-vs-topspin.md`；高水平还有削中反拉（丁松、朱世赫，BK-横板削球）。从削到攻的衔接：先停住重心、上前一步，见 `../techniques/transitions.md`。战术全貌见 `../techniques/tactics.md`。

**如何对付削球**（详细战术见 `../techniques/tactics.md`）：
- 不要板板全力进攻。Hodges：削球手靠你的失误得分；通常拉一板，若对方削得好、你没法轻松打死，就**搓一板重新开始**；你的拉球越转，削回来的下旋越重；拉得旋转较少时回来的下旋也少（LH:3320）。因此正手要有可靠的对长下旋搓球（`../techniques/long-push.md` `../techniques/push.md`）。
- **拉攻**是快攻打法对付削球的主要战术：连续拉创造机会，再突击、扣杀；"拉、扣的力量要有较大的悬殊"，使对方措手不及；要有耐心，没把握的机会球不要过凶（CETV-拉攻）。
- 变化速度、把削球手拉近推远，不要让他舒服地在一个位置削（PS Speed Against Defenders；PS Long-Pimple Choppers：先拉一板再搓一板）。
- **吊短（drop shot off a chop）**：削球手在远台舒服时，放一板短球把他引上前，打断节奏，给下一板进攻创造机会（PS Drop Shot off a Chop）。**什么时候吊**：拉攻中放短球，"要在对方站位较远并且来球比较近网时进行"，落点容易靠近球网，加大对方上前的距离和难度；**吊完怎么接**：放短后扣杀，"如果对方靠台极近，可对准对方身体方向扣杀"，让他难以让位（CETV-拉扣吊结合）。手法同摆短，见 `../techniques/short-touch.md`；对付放高球的吊短见 `../techniques/lob-and-fish.md`。
- 拉下旋削球的动作见 `../techniques/forehand-loop-vs-backspin.md` `../techniques/backhand-loop-vs-backspin.md`；发短球也能削弱削球手：台面挡着，他接短发球的下旋要少得多（LH:30）。

## 8. 常见错误：表现 → 原因 → 纠正

1. **回球冒高** → 拍面太朝天、削得太"底"（LH:3219，这是 Hodges 对攻球手应急削的建议；他也指出高水平削球手会让球落得更低，再触得更靠下、擦得更薄）；或削弧圈时手腕不固定（BK-削球） → 正式削球触球中下部（BK-削球）、拍面不过分后仰；应急削触球偏后部、拍面更朝前；削弧圈时锁住手腕、来球越转拍面越竖并加大下压。
2. **下网** → 挥拍只向下没有向前，撞击力不够（BK"要保持足够的撞击力"） → 远削加前送；对慢球多向前挥。
3. **出界（多见于攻球手）** → 不习惯下旋球会飘长（LH:3219） → 瞄准时让球"落在自己这边"，轻削。
4. **击球太早、在高点削** → 心急 → 等到下降期，削弧圈等到下降后期；自己喊"落—削"。
5. **击球点过低（远低于台面）** → 退得太远或等太久 → 远削"不能过于低于台面"（BK-削球）；调整站位。
6. **只用手臂砍** → 没有转体和重心转移 → 先侧身、重心压后脚，挥拍时由腿和腰带动（第 5 节顺序）。
7. **转与不转一眼就看穿** → 削不转时动作明显变小或变慢 → 用同样的引拍与挥速，只改触球位置和手腕（PS；CETV）。
8. **近削动作太大** → 把远削动作搬到近台 → 引拍比肩略高、前臂为主、击球后不前送。
9. **脚不到位、伸手够球** → 判断慢、步法少 → 先移动再削；练前后、左右移动削（第 9 节）。
10. **削完不还原、被吊短打穿** → 削完就站住 → 削完立即回位，并练"削—上前接吊短—退回"。
11. **追身球被夹住** → 原地不让位 → 先用脚让开，选定一面再削。

## 9. 练习方法（入门 → 进阶）

1. **徒手模仿**：对镜子做正手（右上→左前下）和反手（左耳→右膝）削球的引拍和挥拍，重点是侧身、重心转移、拍面朝前略后仰。
2. **多球（攻球手先练这一步）**：陪练在台边喂中等力量的上旋长球，你在中台削回，先定点正手、再定点反手；熟练后让陪练变化落点和力量。
3. **一拉一削定点**：对方慢拉弧圈，你削斜线，要求低、长、稳。
4. **加转/不转交替**：同样手法，一板加转一板不转；请对方说出判断，判断准说明你的手法还不够像。
5. **削弧圈专项**：对方拉加转弧圈，你练下降后期、右腹前击球、手腕固定。
6. **两点/全台移动削**：对方拉两角，你左右移动削；再加前后：对方偶尔吊短，你上前接短（PS How to Return Drop Shots as a Defender），再按 PS Moving In and Out 的要领退台。
7. **近削逼角**：对方轻拉，你近削两大角。
8. **削中反攻**：削若干板后，对方故意拉出高球，你上前反攻；再练"削加转—削不转—对方冒高—反攻"。
9. **削扣杀/削前冲**：高级内容，先由陪练控制力量（PS Chopping a Smash）。
10. **攻球手应急削**：自己站在正手位，陪练突然打反手大角，你按 LH:3219 三原则削回；比赛里偶尔用。
11. **作为攻球手练对付削球**：对方削，你"拉一板—搓一板"循环（LH:3320、PS Long-Pimple Choppers），并加入吊短（PS Drop Shot off a Chop）。没有削球陪练时可用多球：PS 指出多球可以模拟"对削来球进攻"（playing against a chop）的回合（PS Varying Your Multiball Feeds）。

## 10. 视频检查要点

**机位**：主机位放在持拍手一侧（右侧）的侧面，机器离开球台足够远，保证中远台站位时**全身+球台端线**都在画面里，看引拍高度、重心转移、击球点高低和挥拍方向；补拍正面或斜 45° 看侧身程度和反手削的拍面（`../analysis/recording-guide.md`）。手机慢动作 120/240 fps，导出后用 `--capture-fps` 校正（削球挥拍慢、时长长，未校正时容易报 `POSSIBLE_SLOWMO`）。

| 阶段 | 关键帧看什么 | 对应指标（脚本输出） |
|---|---|---|
| 准备 | 是否站在中远台、膝微屈、重心不在脚跟 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 引拍 | 是否侧身；拍是否举到约肩高（远削）或比肩略高（近削）；正手重心压右脚、反手压左脚 | `shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`、`shoulder_width_ratio.backswing_end`（越小越侧身）、`weight_shift.backswing_end`（正手应接近 0＝右脚；反手应偏向 1＝左脚）、`elbow_angle_deg.backswing_end`、`backswing_ms`。拍子举多高脚本不直接给，看关键帧 |
| 迎球 | 是否由上向前下挥；是否先转体再动手臂 | `swing_path.{up,horiz,angle_deg}`（`swing_path.up` 应为负，即向下；`swing_path.angle_deg` 应为负；`horiz` 包含左右移动，不能单独说明有没有向前送，前送要看随挥关键帧（远削拍子是否送到身前），并参考 `contact_forward_m`）、`sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`、`forward_ms`、`peak_hand_speed` |
| 击球瞬间 | 击球点高度：削弧圈在腹前偏低，应急削在台面高度或以下；正手在身体右侧、反手在胸前偏左；头是否稳 | `contact_height_level`（0＝髋、1＝肩，削球一般应偏低）、`contact_forward_m`、`contact_lateral_m`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`knee_angle_deg.{playing,other}.contact`、`trunk_lean_deg.contact`（不应后仰）、`head_motion`、`free_arm_height_level` |
| 随挥 | 远削是否向前下送出；近削是否没有前送；收拍是否在身前下方（反手削收在右膝方向） | `finish_height_level`（应低）、`follow_ms`（近削应短）、`elbow_angle_deg.finish`、`weight_shift.finish`、`weight_shift.delta` |
| 还原 | 是否马上回到准备位；脚步是否回到中远台、能否上前接吊短 | `recovery_dist`：越小说明手回到准备位越彻底；脚步回位脚本不测，看还原关键帧 |
| 整体 | 正反手识别、发力链、数据可信度 | `side_guess`、`knee_min_deg.{playing,other}`、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

说明：`weight_shift` 里 0＝持拍侧（右）脚、1＝另一只脚。正手削由右脚移向左脚，`delta` 应为正；反手削按 BK 描述的挥拍方向（左上→右前下）推断重心应移向右脚，`delta` 应为负或接近 0——这是推断，以关键帧为准。

**拍面角度和触球部位**：骨架模型测不出拍面。必须看击球前后的**手部放大图**（`stroke_NN_zoom.jpg`、`stroke_NN_contact_raw.jpg`）目测：拍面是否过于朝天（易冒高）、反手削时拍柄是否朝下、削弧圈时触球前后手腕是否保持不动、加转与不转两板的拍面和手腕是否看起来一样。中远台时人在画面里较小，若 `quality.reliable` 为假或手腕在 `low_visibility_parts` 中，不下结论，按 `../analysis/recording-guide.md` 拉近机位重拍。

## 11. 自查清单

- [ ] 削之前已移动到位，并侧身（正手右脚在后、反手右脚在前）
- [ ] 引拍够高：远削约与肩同高，近削比肩略高
- [ ] 等到下降期再削，削加转弧圈等到下降后期；没有在高点心急
- [ ] 击球点不过分低于台面（应急削：台面高度或以下即可）
- [ ] 拍面后仰但主要朝前，触球中下部（应急削触球偏后部、别削太"底"）
- [ ] 挥拍由上向前下，远削有前送，近削没有前送
- [ ] 削弧圈时手腕固定；来球越转拍面越竖、下压越多
- [ ] 发力来自腿和腰的转动，不是只用手臂砍
- [ ] 加转和不转两板动作看起来一样
- [ ] 回球低、长；削逼角时也会削另一角
- [ ] 削完立即还原，能上前处理吊短、再退回
- [ ] 遇到追身球先用脚让位
- [ ] 有机会时敢于反攻（削中反攻）
- [ ] 作为攻球手：会应急削；对付削球手不盲目连续进攻，会搓、会吊短
