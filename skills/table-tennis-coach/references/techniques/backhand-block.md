# 反手挡（Backhand Block）

适用：近台被对方弧圈、扣杀压在反手位或中路时｜难度：入门（普通挡）→ 中级（减力挡、加力挡）→ 高级（侧拐挡、切挡）｜相关卡片：`../techniques/backhand-drive-punch.md` `../techniques/backhand-tear.md` `../techniques/backhand-loop-vs-topspin.md` `../techniques/forehand-counter-block.md` `../techniques/penhold.md` `../techniques/footwork.md` `../techniques/transitions.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/spin.md`

> 本卡按右手横拍写；左手持拍者左右互换。直拍的推挡、快推、加力推、减力挡见 `../techniques/penhold.md`，本卡只写横拍反手。
> 拍面角度统一用"拍面与台面的夹角"：90° 为垂直，小于 90° 为前倾（"关"），大于 90° 为后仰（"开"）（中国教育电视台《击球技巧》口径）。

## 1. 定义与用途

**挡（block）**：来球刚从台面弹起时，把球拍放在球的去路上，主要借来球的速度和旋转把球送回去（英文维基 Glossary："placing the racket in front of the ball right after the ball bounces"）。挡回的球一般保留来球的旋转性质，通常是上旋（同上）。挡的对象是上旋来球（弧圈、攻球、扣杀）；下旋球挡不了，用搓或拉（`../techniques/push.md`、`../techniques/backhand-loop-vs-backspin.md`）。

PingSkills 把反手挡看成"缩短的反手攻"：对方球快，你只需要也只来得及做很短的动作。PingSkills 训练计划第 33 课说，顶尖选手被压时都能用稳定的挡把球留在台上，这是成为好球员的前提。

本卡覆盖五种做法，按"自己加不加力"排列：

| 做法 | 英文 | 核心动作 | 主要用途 |
|---|---|---|---|
| 减力挡（借力挡、卸力挡） | dead block / off-speed block | 触球瞬间手臂、手腕后收，握拍放松 | 变节奏、打乱对方时机，让回球轻、短、慢；配合加力挡、对付爱退台的对手尤其有效（Hodges 753） |
| 普通挡 | block | 拍子伸到球前，触球时前臂、手腕稍向前 | 稳住、过渡 |
| 加力挡（撞） | punch / jab block | 平、向前短促一撞 | 来球偏慢、偏高或落台偏短，有时间时反压 |
| 快带 | topspin block（"kiss of topspin"） | 刚弹起时向前上方轻带出上旋 | 相持中主动；完整技术见 `../techniques/backhand-tear.md` |
| 侧拐挡 / 侧切挡（切挡） | sidespin block / chop block | 触球时拍子横移（侧拐）或向下、斜下切（切挡） | 变化，打乱对方节奏，偶尔用 |

术语说明：中文资料里"侧拐挡""侧切挡""切挡"叫法不统一。本卡按动作区分：拍子**横移**出侧旋的叫侧拐挡；**向下或斜下**切、出下旋或侧下旋的叫切挡 / 侧切挡（也有人叫搓挡、削挡；英文 chop block、sidespin-chop block）。

## 2. 三位标杆怎么做（马龙 / 张继科 / 樊振东；只写有出处的）

**马龙**
- 反手**切挡**是他的变化手段。时评（Khaleej Times，2021，评论文章，作者不是教练）写东京奥运会决赛："Ma Long's backhand chop-block threw Fan Zhedong off his rhythm time and again. It comes back faster than a chop but it's so much slower than a normal counter"——比削球快、比正常反击慢得多，打乱对手平衡。美国教练 Hodges（2016）也写"world #1 Ma Long likes to use it"，同时指出马龙平时多用反手借上升期反拉（"usually does the counterlooping version"），切挡只是变化。
- 东京奥运决赛对樊振东时，他愿意让年轻对手先上手，再拖住回合反击（Khaleej Times 同文，评论："comfortable in allowing his younger opponent to initiate the attack"）。这是对这一场的评论，不是泛化的打法结论。
- 2020 年刘国梁评价马龙"反手体系有明显进步……可以更加相信自己的反手"（央视网转新华社）。
- 独立分析网站 Edges and Nets（2021）观察到热身时的反手对攻（standard backhand counter）中马龙肘部收得更低（"tuck his elbow a little bit lower in"）。这是反手对攻（counter）的观察，单一来源，没有专门讲挡。

**张继科**
- 2008 年搜狐评论称他"衔接快速、反拉反带速度快"，没有拆到动作细节。
- PingSkills 教练评 2012 伦敦奥运决赛：他的反手相持动作看起来很小，却打出很快的速度，因为"using his wrist very effectively"，加上极好的击球时机。这条讲的是反手相持，不是专门讲挡。
- 反例：2016 年里约决赛评论说他后三局"反手相持时完全处于下风"（新浪），不要把他的反手说成"相持无敌"。
- **他反手挡（减力挡、切挡等）的具体做法：暂无可靠出处。**

**樊振东**
- 一项定性研究（Jin & Ma 2026，比赛高速视频，无角度数值）观察他的**反手进攻**：引拍幅度小、击球早、击球点离身体近、击球时重心稳、肘向前顶、拍形相对固定。这些特点和挡、加力挡的要求一致，但研究对象是进攻，不是挡。
- Edges and Nets（2021，单一来源）观察到热身时的反手对攻（counter）中他比马龙腋下更开、肘略高；作者推理"原则上"应有利于正反手转换（"in principle should"，单一博客观点，不是观察结论）。Jin & Ma 2026 则观察到高强度相持中他的正反手转换偶有不稳，两者有张力。
- 央视网多次报道他靠"更强的相持能力"拉开比分（如 2019 亚洲杯对马龙）。
- **他反手挡的具体做法：暂无可靠出处。**

## 3. 动作分解

反手挡没有明显的大引拍，六个阶段都很短。下表"要领"写普通挡，括号里注明减力挡、加力挡、侧拐挡、切挡的不同。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚 / 步法 | 近台，离台尽量在一臂之内（Hodges）；两脚约同肩宽或稍宽，以平行站位为主（中文资料对反手近台脚序写法不一：中国教育电视台《正手攻球、反手攻球》写"右脚稍前"，百科《反手攻球》写"左脚稍前"，没有统一说法）；前脚掌着地、脚跟微离地。对方击球前小跳一下，先假定自己"要动"，看清方向后马上起动（Hodges 3462） | 站得离台太远，只能退着挡；脚跟落地，起动慢 |
| 膝 | 微屈，随时能左右蹬 | 腿直站，重心高，被迫用手够球 |
| 髋 | 正对来球方向，不要提前转向侧面 | 髋已经转到左侧，来中路球时被卡住 |
| 腰 / 躯干 | 上体略前倾、收腹 | 后仰躲球 |
| 肩 | 放松、平 | 耸肩，动作发僵 |
| 大臂 / 肘 | 肘在身体前方、略离开身体，作支点；不要夹死也不要外张过远 | 肘贴身，拍子出不去；肘离身体过远（推挡常见错误） |
| 前臂 | 大致与台面平行，指向来球方向 | 前臂下垂到腹部以下，来高球时来不及抬 |
| 手腕 | 自然、基本伸直（学动作时先保持直，PingSkills） | 手腕下垂、拍头朝下（推挡里叫"吊板"） |
| 手指 / 握拍 | 松握；有教练主张反手时拇指稍压拍（Hodges），也有教练主张一个兼顾正反手的握法、不刻意换握（PingSkills），两说并存，见 `../fundamentals/grip.md` | 握得太死，减力挡卸不了力 |
| 拍面 / 拍头 | 拍在身前、约胸腹高度，拍头指向斜前方，拍面略前倾 | 拍子垂在身体一侧 |
| 视线 / 头 | 看对方挥拍：摩擦薄、向上多的更转；向前平打的更冲（PingSkills 看旋转课："A flat contact pushes the ball forward; a fast, fine brush creates much more spin"） | 只看球不看对方拍，判断不出旋转 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚 / 步法 | 这时就要移动：右手持拍，向右移动补中路、向左移动补反手大角（Hodges 3462）；大角度来球要"向侧前方"迎上去截（Hodges 3568） | 站着不动，用手去够 |
| 膝 | 保持弯曲，移动中不起伏 | 移动时站起来 |
| 髋 | 跟着脚把身体对准来球 | 只转上身 |
| 腰 / 躯干 | 基本不转；加力挡可稍左转一点蓄力 | 大幅转腰，来不及 |
| 肩 | 不后拉 | 肩后拉成反手拉的引拍 |
| 大臂 / 肘 | 肘稍前顶，留出前臂活动空间 | 肘往后撤 |
| 前臂 | 几乎不后引，"伸向来球"（百科《挡球》："前臂与台面平行伸向来球"）；加力挡、快带可略后引到腹前 | 大引拍：对方球快，没时间（PingSkills） |
| 手腕 | 按来球旋转预先定好拍面角度 | 等球到了才临时翻腕 |
| 手指 / 握拍 | 保持松 | 提前握紧 |
| 拍面 / 拍头 | 拍子已经在球的去路上；加转弧圈更前倾（见第 6 节） | 拍面角度一成不变 |
| 视线 / 头 | 盯住来球的弧线和落点；侧旋弧圈要追着弧线看（PingSkills） | 看错弧线，挡空或擦边 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚 / 步法 | 最后一步踩实，让球正对身体中线来（PingSkills："Move sideways so the ball comes straight at you"）。Hodges 的比喻：像反着玩躲避球，要用身体去"接"球，只是用拍子挡在身前 | 身体躲开、手臂伸长去挡 |
| 膝 | 弯曲、稳定（减力挡：百科《减力挡》所引资料 [1] 说击球前重心略升高、稍屈前臂） | 下蹲过深来不及抬拍 |
| 髋 | 对准来球 | 大角度时身体扭成侧对球台（Hodges 3568） |
| 腰 / 躯干 | 稳定，略前倾 | 后仰 |
| 肩 | 放松 | 发力时耸肩 |
| 大臂 / 肘 | 肘作支点，不前后大动 | 肘向外甩 |
| 前臂 | 小幅向前迎；减力挡迎得更少 | 前臂主动大挥 |
| 手腕 | 固定拍面 | 手腕晃动，拍面不稳 |
| 手指 / 握拍 | 普通挡、减力挡松；加力挡在触球前一刻收紧 | 一直握死 |
| 拍面 / 拍头 | 拍面对准出球方向；拍在身前，尽量不够（Hodges 3624） | 拍在身体侧边，拍面歪 |
| 视线 / 头 | 头稳，看球到拍 | 提前抬头看对方 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚 / 步法 | 两脚踩稳，重心在两脚之间 | 脚还在滑动 |
| 膝 | 稳住；加力挡可配合轻微蹬地 | 膝突然伸直，拍子上抬，球冒高 |
| 髋 | 稳 | 后撤 |
| 腰 / 躯干 | 稳；加力挡用一点腰向前 | 身体后坐，球无力 |
| 肩 | 不动或微前送 | 肩后撤 |
| 大臂 / 肘 | 肘基本固定 | 肘下沉，拍面突然变开 |
| 前臂 | 普通挡：前臂和手腕稍向前，借反弹力把球挡回（百科《挡球》）。减力挡：触球瞬间有意识地做手臂和手腕后收（百科《减力挡》所引资料 [1]）。加力挡：平、向前短促一撞（PingSkills）。对极重上旋：果断地朝网的方向向下撞（PingSkills 问答："punching the ball down towards the net with quite a firm action"）。快带：向前上方轻带。切挡：向下轻切。侧拐挡：横移 | 该减力时向前推，该加力时只是放拍；对极重上旋动作犹豫、拍子软，被旋转打飞 |
| 手腕 | 普通挡固定；侧拐挡、切挡靠手腕带出横向或向下的移动 | 手腕乱动，回球不稳 |
| 手指 / 握拍 | 减力挡、切挡握得松（Hodges："holding the racket loosely"）；加力挡触球前一刻收紧 | 减力挡握得太死，卸不掉力 |
| 拍面 / 拍头 | 按来球调整（第 4、6 节）；对转弧圈至少轻撞一下，球在拍上"吃"的旋转少（Hodges 3445："Give the ball at least a light punch"） | 拍面被动、软挡转弧圈，球飞出台 |
| 视线 / 头 | 看到球碰拍 | 闭眼、扭头 |

| 脚 / 步法 | 准备下一步 | 挡完脚还钉在原地 |
| 膝 | 保持弯曲 | 起身 |
| 髋 | 回正 | — |
| 腰 / 躯干 | 稳 | 跟着手臂转 |

## 4. 拍面角度、击球点、击球时间、触球部位

**站位与重心（先于拍面）**
- 站位：近台、偏反手半台，离台尽量在一臂之内（Hodges 3739）；有百科给出挡球距台约 40–50 厘米（单一来源）。挡球要"盖住球台"，不要退台（Hodges 3568）。正常位置按对方拉到底线的深球准备，弧圈落台偏短时再上前（Hodges 3462）。
- 重心：在两脚之间、前脚掌，上体略前倾；挡球时重心几乎不左右转移，靠移动脚把身体放到球的去路上，而不是倒向一侧去够。减力挡击球前重心可略升高（百科《减力挡》所引资料 [1]）；加力挡可借一点蹬地和腰向前。重心后坐、身体后仰是挡球无力和出界的常见来源。

**拍面角度**
- 总原则：来球越转越关（越前倾），越不转越开（PingSkills："Close the bat more against heavy topspin and open it against less"）。拍面角度取决于来球的旋转、速度和落点（英文维基）。
- 普通挡：接近垂直、略前倾（百科《挡球》："拍面接近垂直"）。
- 挡慢而转的弧圈：比你感觉的还要更关，可以瞄网甚至网底（Hodges 3445）。
- 减力挡（反胶）：和普通挡一样按来球上旋强弱定，保持"合适的前倾角度"（百科《减力挡》所引资料 [1]），不要后仰。反胶挡上旋，回球仍带上旋（Hodges 865："with inverted… a topspin ball is normally catapulted back with some topspin"），拍面一后仰就容易冒高出台。
  - 注意：百科《减力挡》里"拍面一般与地面垂直、力量非常大可稍后倾、吃厚一点""对方越发力回球越下沉""不往前走"等说法，标注出自邓亚萍长胶打法总结，词条原文也说"在长胶打法中……"。长胶会把来球的上旋自然变成下旋回去（Hodges 865："long pips and (usually) hardbat automatically returns topspin as backspin"），所以回球才下沉；**反胶不要照搬拍面后倾**。长胶减力挡、削挡见 `../fundamentals/equipment-and-technique.md`。
- 加力挡（撞）：平、向前（PingSkills）。对极重上旋，PingSkills 问答建议果断地"朝网的方向向下撞"。

**击球点**
- 身体正前方、身体中线附近，不够球（Hodges 3624；PingSkills）。
- 前后：在台面上方、身前，"盖住球台"（Hodges 3568："Smother the table"）。

**击球时间**
- 上升期（刚弹起）。Hodges 753：挡弧圈要"off the bounce"，这样反而更容易、更稳，还能压对方时间、打出角度；晚了要多跑、还得判断又快又低的弹跳。百科《挡球》也写"上升期"。
- 快带：上升期，刚弹起就带（Hodges 753："topspin the ball right off the bounce"）。百科《快带》写的"上升后期或高点期"是正手快带（从正手拉球演变），反手挡式快带不适用。
- 有时间（球偏慢、偏高、落台偏短）时上前加力撞（PingSkills；Hodges 3462、753）。

**触球部位**
- 普通挡：球的中部（百科《挡球》）；对加转弧圈偏中上部（前倾的拍面自然压在中上部）。
- 侧拐挡：触球偏球的一侧。有百科写侧切是接触弧圈球旋转较弱的侧面，借力把上旋转成侧旋或侧下旋（百科《借力》，可信度一般）。
- 切挡：从球的后上方向下轻切（Hodges 865："chop down lightly"）。

## 5. 发力：顺序、方向、摩擦与撞击

- **以借力为主**：普通挡几乎不主动发力，靠来球的反弹力（百科《挡球》《借力》）。一项反手拉研究发现，来球频率高（75 球/分对 35 球/分）时拍速显著下降，作者推测可能是骨盆和上躯干转动倾向于受限所致（Iino & Kojima 2016："tended to be more restricted… This was probably because…"）。这只是类比，不是挡球研究，但说明了近台快节奏时为什么只能靠短动作和借力。
- **减力挡：主动"卸"力**。握拍放松，让球慢慢弹回去（Hodges 753："Just hold the racket loosely and let the ball rebound out slowly"）；触球瞬间手臂和手腕有意识地后收，削弱来球反弹力，使回球力量轻、落点短、球速下降（百科《减力挡》所引资料 [1]）。反胶减力挡回球仍带上旋，只是变轻变短；"越发力越下沉、不往前走"是长胶的效果，见第 4 节注意。
- **加力挡：撞击为主**。方向平、向前（PingSkills："a flat, forward contact for balls that sit up when you have a little more time"）。通用做法（本卡建议，无专门出处）：脚踩稳、腰稍向前，前臂向前短促发力，手腕固定，触球前握紧。至少轻撞一下，能减少旋转在拍上的影响（Hodges 3445）。
- **快带：撞击加少量摩擦**。前臂和手腕向前上方，带出上旋（Hodges 称这种"topspin block"是世界级水平最常见的挡）。完整发力见 `../techniques/backhand-tear.md`。
- **侧拐挡：横向摩擦**。触球时拍子横移出侧旋，左右两个方向都可以（Hodges 753）。Hodges 写右手反手通常从右向左横移（Hodges 865）。
- **切挡：向下摩擦**。触球时轻轻向下切，回球低、软，像搓球（Hodges 865）；可加横向成侧下旋。Hodges 自述侧切挡的手感是下旋多于侧旋（他说"大约六成下旋、四成侧旋"，个人感觉，不是测量）。
- 落点变化靠手腕和拍面最后一刻调整：例如瞄对方反手大角，最后一刻手腕后收改挡直线（Hodges 753）。

## 6. 面对不同来球的调整

| 来球 | 拍面 | 时间 / 位置 | 用哪种挡 | 出处 |
|---|---|---|---|---|
| 加转弧圈（慢、转，常是拉下旋后的第一板） | 明显更关，瞄网或网底 | 上升期，在身前 | 普通挡加轻撞；或向下撞向网 | Hodges 3445；PingSkills 问答 |
| 前冲弧圈（快、冲） | 按上旋强弱前倾：越转越关，越不转越开 | 上升期，借力 | 普通挡；想变节奏时减力挡 | PingSkills（拍面总原则）；Hodges 753（减力挡变节奏） |
| 扣杀、平击快球（旋转少） | 接近垂直或按来球上旋程度略前倾 | 上升期，在身前 | 普通挡；想变节奏时减力挡（握松、后收） | PingSkills（拍面）；Hodges 753；百科《减力挡》"用来对付扣杀、前冲"那句出自长胶打法总结，仅作参考 |
| 慢、旋转弱的上旋 / 假弧圈 | 拍面打开一些，否则下网 | 上升期 | 普通挡或加力撞 | PingSkills |
| 侧旋弧圈 | 拍面朝侧旋的反方向偏：球要往左偏，拍面就朝右（PingSkills 问答）；带侧旋的弧圈上旋往往没那么强，拍面别关太多，有时还要稍往上托一点，否则容易下网（同上）；手腕、手放松以减弱旋转（同上）。具体朝哪边偏，看对方的侧旋方向；不确定时先看自己第一板挡出的球往哪边偏，下一板反着调（本卡建议，不是 PingSkills 原话） | 追着弧线移动，把球放到身前再挡 | 普通挡 | PingSkills 问答 How to block sidespin topspin；PingSkills 侧旋相持课（追弧线、调拍面角度） |
| 落台偏短的弧圈 | 按旋转定 | 上前在上升期截 | 加力挡，甚至扣杀（缩短引拍） | Hodges 3462、753 |
| 偏高、慢、有时间的球 | 平 | 上升期到高点期 | 加力撞，或改反手攻 | PingSkills；`../techniques/backhand-drive-punch.md` |
| 追身球（中路） | — | 右手向右移动让出位置 | 普通挡 | Hodges 3462 |
| 反手大角 | — | 向左**并向前**迎上截球，别横着追 | 普通挡 | Hodges 3568 |
| 对方退台连续发力 | — | — | 偶尔用减力挡、切挡变节奏 | Hodges 3619、865 |

要不要挡，还是反拉：PingSkills 问答的原则是看时间，时间多就反拉，被压就挡；退后一步能换来反拉的时间。反手反拉见 `../techniques/backhand-loop-vs-topspin.md`。

**切挡、侧拐挡的使用限度**
- PingSkills：切挡风险高，"one-in-50 choice"（约五十分之一才选，教练口头估计，不是统计）；重上旋打到你的反手位时，稳挡通常更好（"Against a heavy topspin to your backhand, a safe, controlled block is usually the better option"）。原因是上旋碰到胶皮会往上飞，向下切很难压住。
- Hodges 865：极少连续切挡两次，第一板打乱节奏、把对方拉近台后，第二板就不再意外；切挡后接加力挡或反攻。
- 反胶切挡不如长胶、硬拍能把球卸得那么死，所以只作变化，不当常规挡（Hodges 865）。长胶削挡见 `../fundamentals/equipment-and-technique.md`。

## 8. 常见错误：表现 → 原因 → 纠正

1. **挡慢转弧圈总出界** → 拍面不够关；平时练挡面对的多是旋转较弱的球，形成了错误本能 → 拍面比感觉的再关一点、瞄网；轻撞一下；用多球专门练挡拉下旋后的加转弧圈（Hodges 3445）。
2. **挡弱旋转球下网** → 不分来球一律压拍 → 拍面打开（PingSkills）；先判断对方是摩擦还是平打。
3. **伸手够球，身体扭着挡** → 脚不动 → 先动脚，让球正对身体来，在身前挡（Hodges 3624、3462；PingSkills）。
4. **反手大角被打穿或挡得很软** → 横着追，球越跑越远；身体扭成侧对 → 向侧前方迎上截（Hodges 3568）。
5. **挡晚了** → 站位太远，等球下降 → 贴近球台，在上升期挡（Hodges 753、3568）；击球时间过早或过晚都是挡球常见错误（百科《推挡球》）。
6. **动作太大** → 把挡做成反手攻 → 引拍和随挥都缩短（PingSkills）。
7. **肘离身体太远或外甩** → 拍面不稳 → 肘留在身前作支点（百科《推挡球》《挡球》）。
8. **手腕下垂、拍头朝下** → 握拍或手腕习惯 → 手腕放平，拍头指向斜前方（推挡里叫"吊板"，百科《推挡球》）。
9. **减力挡卸不掉力，球照样飞得又快又长** → 握太紧、触球时还在向前 → 松握，触球瞬间手臂、手腕后收（Hodges 753；百科《减力挡》所引资料 [1]）；拍面不要后仰（反胶回球仍带上旋，后仰易冒高，见第 4 节）。
10. **滥用切挡、对重上旋硬切** → 追求变化 → 以稳挡为主，切挡偶尔用、不连用（PingSkills；Hodges 865）。
11. **落点单一、提前暴露方向** → 只求挡回 → 练三个落点（正手大角、反手大角、中路），最后一刻变线（Hodges 753）。
12. **挡完站住，下一板来不及** → 没有还原和小跳 → 见 3.6。

## 9. 练习方法（入门 → 进阶）

**入门**
1. 对墙挡、自己抛球到本方台面再挡（扬州职大推挡练法）。
2. 一人攻、一人挡：先挡中线，再挡斜线、直线（扬州职大；中国教育电视台的攻球练习步骤里也有"一人攻球，一人推挡回击"）。目标是连续不失误；不少教练用"连续 100 板"作为攻球的入门目标（Hodges 转述"Many coaches swear by the '100' theory"；PingSkills 正手对攻课），挡球可以借用。

**中级**
3. 挡加转弧圈专项：对方发下旋，你搓，他拉，你挡。不打完，马上下一个球（Hodges 3445："you DON'T play out the point"）。
4. 步法挡：对方一直拉你反手半区，但故意时而拉大角、时而拉中路，你每板都先动脚再挡（Hodges 3462）。
5. 一点挡两点 / 两点挡一点（扬州职大；中国教育电视台《易犯错误及纠正方法》）。
6. 随机落点：先 80% 固定、20% 随机，再逐步加随机（PingSkills）。
7. 减力挡专项（多球）：先挡中等力量的扣杀，再过渡到挡前冲弧圈（百科《减力挡》；此段出自长胶打法总结，反胶练时拍面不要后仰，按第 4 节做）。

**进阶**
8. 发力进攻与减力挡交替：重—轻—重（Hodges 3619 "pound-pat-POUND"：自己发力扣/拉—轻挡—再发力）；百科也说减力挡与加力推结合可前后调动对方。
9. 切挡 / 侧拐挡：集中一段时间专门练，喂多球弧圈，找到"盖住球"的触球感觉（Hodges 2412）；比赛中只作变化。
10. 挡后反攻：用挡打乱对方后马上准备抢攻（Hodges 753、865）。转换见 `../techniques/transitions.md`。
11. 比赛化练习：发短下旋、对方搓长，发球方只能拉，接发球方只能挡，你做接发球挡的一方（PingSkills 训练计划第 44 课）。

更多练法见 `../training/drills.md`。

## 10. 视频检查要点

**机位**
- 主机位：正面（球台对面）或斜前 45°，腰到胸的高度，全身入画（`../analysis/recording-guide.md`）。看脚步、击球点在身体前方哪里、肘的位置、拍子横移。
- 补充机位：侧面，看拍面前倾程度、前后击球点、身体是否后仰。
- 用 120/240 帧慢动作；文件帧率和拍摄帧率不同时加 `--capture-fps`。
- 挡球手速低、动作短，自动分板可能找不到（NO_STROKES 警告）。这时先看总览图，手动定出各板时刻后用 `--strokes` 重跑（`../analysis/analysis-protocol.md`）。
- 拍面角度、握拍、侧拐挡和切挡的拍子方向，骨架测不出来，**只能看手部放大图**：`stroke_NN_zoom.jpg`（自动模式）或 `measured/measured_NN_zoom.jpg`（`--strokes` 模式），都是击球前后各 2 帧。

**各阶段看什么，对应哪个指标**（指标说明见 `../analysis/metrics-reference.md`）

| 阶段 | 关键帧里看什么 | 指标 |
|---|---|---|
| 识别 | 是否被识别为反手（击球点在身体前方或偏左） | `side_guess`、`contact_lateral_m` |
| 准备 | 站位宽度、膝是否微屈、拍是否在身前 | `stance_width_ratio`、`knee_angle_deg.playing.ready`、`knee_angle_deg.other.ready` |
| 引拍 | 有没有大引拍；肩是否后拉 | `backswing_ms`（应明显短于你自己的反手攻）、`elbow_angle_deg.backswing_end`、`shoulder_width_ratio.backswing_end` |
| 迎球 | 脚是否先动（在 `stroke_NN_strip.jpg` / `measured_NN_strip.jpg` 里看准备到引拍之间脚是否已动）、球是否来到身体中线；头是否稳、有没有甩头 | 脚步只能关键帧目测；`head_motion` 只统计引拍结束到随挥结束的鼻子位移，只作"头是否稳/是否甩头"的参考，不能判断脚是否先动 |
| 击球瞬间 | 击球点在身前、胸腹高度；肘在身前；身体不后仰 | `contact_forward_m`、`contact_height_level`、`elbow_body_gap_m`、`elbow_angle_deg.contact`、`trunk_lean_deg.contact`、`knee_angle_deg.*.contact` |
| 击球瞬间（手部放大图） | 拍面前倾程度是否和来球匹配；减力挡是否有后收；切挡向下、侧拐挡横移 | 只能目测手部放大图（`stroke_NN_zoom.jpg` 或 `measured/measured_NN_zoom.jpg`） |
| 随挥 | 随挥是否短、收在身前 | `follow_ms`、`swing_path.up`、`swing_path.horiz`、`swing_path.angle_deg`（挡、撞应较平；快带略向上；切挡向下偏）、`finish_height_level`、`elbow_angle_deg.finish` |
| 重心 | 是否后坐、躲球 | `weight_shift.backswing_end`、`weight_shift.finish`、`weight_shift.delta`（挡球重心移动通常很小；明显偏移时看图确认是动脚还是后仰） |
| 还原 | 拍是否回到身前 | `recovery_dist` |
| 加力挡 | 有无腰、前臂的连贯发力 | `peak_hand_speed`、`sequence_ms.hip`、`sequence_ms.shoulder`、`sequence_ms.elbow`、`sequence_order_ok`（单机位测转动不可靠，只作提示） |
| 稳定性 | 各板是否一致 | 同一视频内比较上述指标；`free_arm_height_level` 看平衡 |
| 可信度 | 数据能不能信 | `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`；正面机位的肘角、膝角误差大 |

## 11. 自查清单

- [ ] 准备时离台在一臂之内，膝微屈，拍在身前，拍头指斜前方
- [ ] 对方击球前小跳，先假定要动
- [ ] 每板先动脚，球来到身体中线，在身前挡，不够球
- [ ] 大角度来球向侧前方迎上截
- [ ] 引拍、随挥都很短
- [ ] 在上升期挡，没有等球下降
- [ ] 来球越转拍面越关；挡慢转弧圈敢瞄网
- [ ] 挡转弧圈至少轻撞一下
- [ ] 减力挡：握松，触球瞬间手臂、手腕后收，拍面不后仰，球回得轻、短、慢
- [ ] 加力挡只在有时间（球慢、高、短）时用，平、向前撞
- [ ] 切挡、侧拐挡只作偶尔的变化，不连用；对重上旋优先稳挡
- [ ] 能挡出三个落点，并能最后一刻变线
- [ ] 挡完马上还原或直接准备下一板
- [ ] 视频里用手部放大图核对了拍面角度
