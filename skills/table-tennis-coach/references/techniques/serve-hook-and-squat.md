# 勾手发球与下蹲发球（Tomahawk Serve & Squat Serve）

适用：已会正手钟摆发球（见 `../techniques/serve-forehand-pendulum.md`）、想增加一种旋转方向相反的发球的中级球员 · 难度：勾手中等，下蹲较高（对下肢要求高） · 相关卡片：`../techniques/serve-basics-and-rules.md` `../techniques/serve-reverse-pendulum.md` `../techniques/serve-backhand.md` `../techniques/serve-fast-long-and-high-toss.md` `../techniques/receive.md` `../fundamentals/spin.md` `../training/physical-and-injury.md`

本卡按右手持拍写；**左手持拍者左右互换**。方括号里是出处缩写，对应文末"参考来源"。

---

## 1. 定义与用途

### 1.1 先说清楚名字（术语对应没有权威出处）

| 名称 | 本卡怎么定义 | 出处情况 |
|---|---|---|
| 勾手发球（正手勾手，tomahawk） | **正手、拍头朝上（tip up）发出的侧旋类发球**，旋转方向与正手钟摆发球相反 | 英文定义来自 [H144]"Done with the forehand, tip up"；[H3735]"forehand tomahawk serves (racket tip up)"。中文"勾手发球"是否等于 tomahawk：**没有找到中文权威出处**；百度百科"勾手发球"词条讲的是排球，不能用。"hook" 只是任务里的叫法，乒乓球英文资料里没有找到出处，本卡以 tomahawk 为准 |
| 下蹲发球（下蹲砍式，squat serve，日文 しゃがみ込みサービス） | **发球时屈膝下蹲、边蹲边击球**的发球；能发左侧旋和右侧旋 | [CETV]、[JA]；生物力学见 [Yu] |
| 王子发球（王子サーブ） | 下蹲发球的一种：边下蹲边把球拍竖着往下挥，用球拍反手面切球 | [JA]、[RL]（日文资料） |
| 反手勾手（Backhand Tomahawk Serve） | 作为正手勾手的配套：动作相近，让对方难以判断球和旋转往哪边走 | [PS-BT]；动作细节在付费视频里，**页面没有公开文字，本卡不编** |

- **"勾手 = tomahawk"、"下蹲 = tomahawk"都没有权威出处。** 中文维基"丁宁"条把"下蹲式發球"写成"Tomahawk Serve"，但没有引注；英文资料里 tomahawk 指"拍头朝上的正手发球"，下蹲发球在 Yu 2018 论文里是和"站立发球"对比的另一类。两者可以重叠：ETT 作者描述自己的 tomahawk 是"In a squatting position"（蹲着发）[ETT-T]。所以本卡把它们当成两个维度：**勾手讲拍形和旋转，下蹲讲身体高度**。
- **勾手的挥拍左右方向不写死。** 同一作者 Hodges 在 [H144] 写"right-to-left motion"，在 [H3735] 又写正常勾手是"left to right"，前后矛盾。本卡只描述"拍头朝上的正手发球"及其**旋转结果**：
  - 旋转方向与正手钟摆相反："forehand pendulum and forehand tomahawk serves, with opposite spins" [H144]。
  - 右手持拍者发出的球"breaks to the left"（向左拐）[H144]；发到对方（右手）正手位时，球向远离接发球者的方向拐（"breaks away"）[H144]。
  - 接短的勾手发球"和接逆旋转或反手发球差不多" [H144]，说明它和正手逆旋转（逆钟摆，见 `../techniques/serve-reverse-pendulum.md`）、反手侧旋属于同一旋转方向。
  - 中文叫法：中国教育电视台把正手由右向左挥发出的球叫"左侧旋"、反手发的叫"右侧旋" [CETV]。把两处资料合起来推断，勾手发出的应属"右侧旋"一类——**这是推论，不是某一出处的原话**。
  - 日文维基的"巻き込みサービス"也是"拍头稍立起、发逆侧旋系"的正手发球 [JA]；它和 tomahawk 是否同一种，也没有出处。

### 1.2 勾手发球用来干什么

- **想直接得分**："More than most serves, this serve is done with the intent of winning a point outright on the serve alone." [H144]
- **发短到对方正手最有效**；从正手位发到对方正手大角，角度最大、拐得最狠；也可以在反手位发 [H144]。ETT 作者自述 95% 发到对方正手，并强调"keeping the ball short is vital" [ETT-T]。
- **短板**：中高级以上的对手能稳定拉起发到正手的长球；全套旋转比别的发球难做全，**很难发出真正很重的下旋**；所以"水平越高用得越少"，但仍是偶尔拿分的好变化 [H144]。
- 它是赛场上最常见的四种发球动作之一（另三种：正手钟摆、正手逆旋转（逆钟摆）、反手侧旋）[H144]。

### 1.3 下蹲发球用来干什么

- 属于"上手类发球"，中国运动员 20 世纪 50 年代就开始用；**能发左侧旋和右侧旋**；对方不适应时威胁很大，关键时刻往往能直接得分 [CETV]。
- 能加很强的旋转；日文维基提到的缺点之一是**还原慢**，来不及应对接发球 [JA]。中国教育电视台也提醒"以防在还未完全站起时已被对方抢攻" [CETV]。
- 横拍发下蹲球比直拍方便；**直拍要换握法，把食指移到球拍背面** [CETV]。
- 对下肢要求高：引拍结束和前挥结束时，髋、膝屈曲和踝背屈都比站立发球大得多；准备时踝背屈反而小一些 [Yu]。需要下肢力量和柔韧性。体能和伤病预防见 `../training/physical-and-injury.md`。

### 1.4 各自能发出的旋转

| 发球 | 能发的旋转 | 出处 |
|---|---|---|
| 正手勾手 | 纯侧旋；拍面后仰加下旋 → 侧下旋；拍面往前盖加上旋 → 侧上旋 | [PS-T] |
| 正手勾手 | 同一动作，按触球时机不同得侧上 / 侧 / 侧下 | [ETT-T] |
| 正手勾手（长球） | 常带更多"螺旋旋"（corkscrew，旋转轴指向对方），落台后明显跳拐 | [H144] |
| 正手勾手 | 很重的下旋难发 | [H144] |
| 反向勾手（reverse tomahawk） | 原文说用球拍的另一面（"contact the ball with the opposite side"）触球，挥拍方向与常规勾手相反（原文 "right to left instead of the normal left to right"，没说是哪一面）→ 旋转与普通勾手相反；很多人觉得难 | [H3735][H144] |
| 下蹲发球 | 右侧上、右侧下、左侧上、左侧下 | [CETV] |
| 王子发球 | 用反手面擦球左侧得侧旋；拍立起来偏上旋，拍面稍斜偏下旋 | [RL] |
| 任何发球 | 靠拍柄触球、同样用力 → 不转（"转与不转"） | [H27] |

## 2. 三位标杆怎么做

- **马龙、张继科、樊振东用勾手或下蹲发球：暂无可靠出处。** 调研没有找到任何报道或分析说他们以这两种发球为特点，所以本卡不写"马龙勾手怎么发"之类的内容。
- 有出处的、和本卡相关的事实（详见 `../players/ma-long.md`、`../players/zhang-jike.md`、`../players/fan-zhendong.md`）：
  - 马龙：央视网转《羊城晚报》称正手发球是他"擅长的"发球手法（[央视网 2020-08-17](https://sports.cctv.com/2020/08/17/ARTIkLQf0py5RhYxbY1CpOL9200817.shtml)）；高抛发球是他关键时刻的武器（[央视网 2017-06-18](http://sports.cctv.com/2017/06/18/ARTIfNwy8G6R11nxF0ygYwbd170618.shtml)）。
  - 樊振东：2017 年总决赛赛点"他逆旋转的发球造成奥恰洛夫接发球失误"（[央视网 2017-12-17](http://sports.cctv.com/2017/12/17/ARTIXdwD8tZHdwu2TdnM9SOh171217.shtml)）。正手逆旋转（逆钟摆）和勾手同属一个旋转方向（第 1.1 节），但**动作不同**，不能说他用勾手。
  - 张继科：发球类型**暂无可靠出处**（英文维基有一句说他常用逆旋转短球，但标着 citation needed，不采用）。
- 想看这两种发球的高水平示范，资料提到的使用者（**不是本卡三位标杆**）：ETT 作者说奥恰洛夫（Ovtcharov）早年常用勾手、松平健太（Kenta Matsudaira）也用 [ETT-T]；百度百科说丁宁用下蹲发球 [BK-发抢]（百科，可信度中等）；Rallys 写松平志穗是王子发球名手 [RL]。
- 对业余的启示：勾手是"变化和偶尔拿分"的工具，水平越高用得越少 [H144]；它和正手钟摆旋转相反 [H144]，适合在钟摆发球练好之后作为反方向的变化（这一条是本卡的建议）。

## 3. 动作分解

**读法：** 每个阶段一张表，"勾手"一栏按**站着发**写（蹲着发勾手时，下肢照"下蹲"一栏做）。带方括号的有出处；没带的是从第 4、5 节和规则推出来的经验做法，**没有专门出处**，请用自己的视频验证。

### 3.1 站位与准备

| 部位 | 勾手 | 下蹲 | 为什么 / 做错会怎样 |
|---|---|---|---|
| 脚/步法 | 在正手位或反手位都可以发 [H144]；想要最大角度打对方正手大角就站正手位 [H144] | 右侧旋版：左脚稍前，身体略向右偏转；左侧旋版：身体基本正对球台 [CETV] | 站位决定角度；站反了发球路线别扭，旋转方向也容易暴露 |
| 膝 | 微屈、重心放低："getting low" [PS-T] | 开始时只微屈，留出下蹲空间（准备时髋屈曲约 21°、膝约 26°，见第 7 节 [Yu]） | 准备就蹲死，下蹲时没有余量，还会提前累 |
| 髋 | 稍屈，带着上身前倾 | 同左 | 髋太直，上身离球远，只能伸手够 |
| 腰/躯干 | 上身前倾、放松 | 同左 | 僵硬的躯干会把紧张传到手臂 |
| 肩 | 放松，不耸肩 | 同左 | 耸肩时手腕甩不开 |
| 大臂/肘 | 准备时自然下垂，引拍时再抬 | 同左 | — |
| 前臂 | 放松 | 同左 | — |
| 手腕 | 放松，可以先微微后屈"上好弦" | 同左 | 手腕僵 → 拍速出不来、转不起来 [ETT-spin] |
| 手指/握拍 | 握拍松："keeping the grip loose" [PS-T]；松紧细节见 `../fundamentals/grip.md` | 横拍基本不用换握法；**直拍要把食指移到拍背** [CETV] | 握得太紧，手腕被锁死，旋转少 |
| 拍面/拍头 | 拍头朝上（tip up）[H144] | 按要发的旋转准备；王子发球拍面立起，用反手面 [RL] | 勾手拍头一垂下就变成钟摆，旋转方向全反 |
| 不执拍手 | 球静止放在张开的掌心，在台面以上、端线之后 [ITTF] | 同左。球离手前，托着球的手（球）必须静止在台面以上、端线之后，不能先放到台面以下再一路向上抛 [ITTF][HMO]；球抛出后，不执拍手只要立刻移出球与球网之间的空间 [ITTF]；击球时球必须在台面以上 [HMO] | 违例直接判失分（见"规则要点"） |
| 视线/头 | 先看对方站位，再盯球 | 同左 | — |

### 3.2 抛球

| 部位 | 勾手 | 下蹲 | 为什么 / 做错会怎样 |
|---|---|---|---|
| 不执拍手 | 从静止的掌心近乎垂直向上抛，不加旋转，离手后至少上升 16 cm [ITTF] | 同左；抛球和下蹲、挥拍要配合好，"掌握好击球时间" [CETV] | 斜抛、侧抛、抛不够高会被判违例；抛球与下蹲脱节就打不到理想高度 |
| 抛球高度 | 低抛更好控、触球前最后一刻有更多伪装空间 [H144] | 王子发球多用较高的抛球，借球下落的速度加转 [RL]；高抛的取舍见 `../techniques/serve-fast-long-and-high-toss.md` | 抛得越高越难控，也越难保证"近乎垂直" [HMO] |
| 抛球后 | 不执拍手臂立刻移出"球和球网之间的空间" [ITTF] | 同左 | 手臂留在那里会被判遮挡 |
| 脚/步法 | 两脚不动，重心稳在两脚之间 | 同左 | 抛球时挪脚，抛球位置和触球点都会变 |
| 腰/躯干、肩 | 保持前倾，肩放松；不执拍侧肩不要挡在球和接发球者之间 | 同左 | 身体挡住球会被判违例 [ITTF] |
| 大臂/肘、前臂 | 持拍臂开始抬肘、准备引拍，和抛球同时进行 | 持拍臂随下蹲开始引拍 | 等球到最高点才开始引拍，来不及 |
| 手腕、手指/握拍 | 手腕放松、握拍松 [PS-T] | 同左 | — |
| 拍面/拍头 | 拍头朝上 [H144]，拍面先不要露出要发的旋转 | 按要发的旋转准备 | 太早定拍面，对方能提前读出旋转 |
| 膝/髋 | 保持准备时的高度 | **随球下落开始下蹲**（下蹲的主要部分在引拍和前挥期间完成，见第 7 节） | 太早蹲到底，球还没下来就只能干等 |
| 视线/头 | 盯住球，头不要跟着上下大幅晃 | 下蹲时头随身体下降，但眼睛始终盯球 | 头乱动 → 触球点不稳 |

### 3.3 引拍

| 部位 | 勾手 | 下蹲 | 为什么 / 做错会怎样 |
|---|---|---|---|
| 脚/膝 | 保持低重心 [PS-T] | 继续下蹲：引拍结束和前挥结束时，髋、膝屈曲和踝背屈都比站立发球大得多；准备时踝背屈反而小一些 [Yu] | 下蹲发球不蹲够，就失去了这种发球的意义 |
| 髋 | 稍转向持拍侧 | 屈髋并有更大的髋内收 [Yu] | — |
| 腰/躯干 | 随引拍小幅转体 | 上身随下蹲降低，保持前倾 | 躯干后仰 → 拍从下往上撩，球容易高 |
| 肩、大臂/肘 | **抬肘，把手臂向外伸出** [ETT-T] | 右侧旋版从左后方引拍；左侧旋版从右后方引拍 [CETV]；王子发球在脸前竖着挥拍 [RL] | 肘不抬，拍头立不起来 |
| 前臂 | 放松，准备鞭打 | 同左 | — |
| 手腕 | 后屈蓄力；动作走向是"由下而上再盖过球"（"comes up and over"）[PS-T]，也有人从球后方右上角开始往下绕 [ETT-T]——两种路线都有人用 | 同左 | 手腕不蓄力，只能靠手臂推，转不起来 |
| 手指/拍面 | 拍头始终朝上；想加下旋，拍面开始后仰；想加上旋，拍面往前盖 [PS-T] | 按旋转调拍面（第 4 节） | 引拍时拍面就定死，伪装性差 |
| 视线/头 | 盯球 | 同左 | — |

初学建议：**整套动作太难时，先用小动作找触球** [PS-T]。

### 3.4 触球

| 部位 | 勾手 | 下蹲 | 为什么 / 做错会怎样 |
|---|---|---|---|
| 脚/膝 | 稳住，不要起身 | 仍在往下：前挥结束（FE）时膝屈曲（约 152°）比引拍结束（约 126°）还大；前挥中持拍侧（右）脚的压力中心沿脚内侧前移，最后落在大脚趾区 [Yu]；王子发球要"尽量深蹲、等球落下，在低点打" [RL] | 触球时站起来 → 触球点变高，球就高、就长 |
| 髋/躯干 | 稳定，不前冲 | 稳定在低位 | 身体前冲会把擦球变成撞球 |
| 肩 | 放松，不耸，不跟着往前送 | 同左 | 肩一送，擦球变推球 |
| 大臂/肘 | 肘在身体前侧方，不贴身也不甩太开 | 同左 | — |
| 前臂 + 手腕 | 放松的前臂—手腕"鞭打"，不刻意硬甩 [ETT-spin]；发短球时手腕用力大于前臂 [CETV] | 快速做半圆形摩擦 [CETV] | 硬甩手腕反而慢、不稳 |
| 手指/握拍 | 触球瞬间手指微收稳住拍面 | 同左 | 拍在手里转 → 拍面乱 |
| 拍面/触球位置 | 薄擦，不撞 [H24]；擦球侧面并向前 [ETT-side]；用靠拍头的位置触球转最强 [H3393] | 右侧上：拍触球中部向右侧上摩擦；右侧下：从球中下部向右侧下摩擦；左侧下：从球中部向左下摩擦 [CETV]；王子发球用反手面擦球左侧 [RL] | 撞得太实 → 球吃进海绵，快、长、不转 [ETT-spin] |
| 触球高度 | 尽量低：触球点越低，球在对方台面弹得越低 [H32] | 同左；王子发球打点高了会"出界" [RL] | 触球点高是发球偏长偏高的主要原因之一 [H583] |
| 视线/头 | 看着拍触球 | 同左 | 提前抬头看对方，触球点就飘 |

### 3.5 随挥

| 部位 | 勾手 | 下蹲 | 为什么 / 做错会怎样 |
|---|---|---|---|
| 手臂/手腕 | 随挥短而快；可以触球后反向夸张收拍（发下旋往上收、发上旋往下收），用紧凑的小半圆而不是停住再反向 [H336] | 动作要利落 [CETV] | 随挥大而慢，旋转一眼被看穿，还原也晚 |
| 拍面/拍头 | 每次收拍尽量相同，只变触球 [PS-D] | 同左 | 收拍各不相同 = 告诉对方旋转 |
| 脚/步法 | 脚不动，准备还原 | 同左 | — |
| 腰/躯干、肩 | 躯干稳住，不随收拍大幅转动 | 同左 | 大转体会让随挥变大、还原变慢 |
| 大臂/肘、前臂 | 肘和前臂跟着手腕自然收住，不再发力 | 同左 | — |
| 手指/握拍 | 触球后手指放松 | 同左 | 一直攥紧，下一板握拍僵 |
| 膝/髋 | 不动或开始准备起身 | **随挥结束就开始起身**，不要蹲在下面看球 | 蹲着看球最容易"还未完全站起时已被抢攻" [CETV] |
| 视线/头 | 转向对方，观察对方的接发球动作 | 同左 | — |

### 3.6 还原与衔接

| 部位 | 勾手 | 下蹲 | 为什么 / 做错会怎样 |
|---|---|---|---|
| 脚/步法 | 在正手位发完要回到中间偏反手的位置，准备第三板 | 随挥结束立即起身，起身的同时向后、向中间移动（经验做法，无专门出处） | 日文维基提到的缺点之一是还原慢，来不及应对接发球 [JA] |
| 膝/髋 | 回到准备姿势的屈膝高度 | 从深蹲伸膝伸髋回到准备高度——这一步需要下肢力量 [Yu] | 腿力不够，起身慢半拍 |
| 腰/躯干、肩 | 回到准备时的前倾和放松 | 起身时上身随之抬起，仍保持前倾 | 站直了，下一板启动慢 |
| 大臂/肘、前臂、手腕 | 拍回到身体前方，手腕回中立 | 同左 | — |
| 拍面/拍头 | 拍面回到中立（不前倾也不后仰），拍头从朝上回到准备时的朝向，好接第三板 | 同左；起身时拍放在身体前方，不要拖在身后 | 拍面还停在发球角度、拍拖在身后，第三板来不及调拍形 |
| 手指/握拍 | 换回对攻用的握法（如果发球时调整过） | 直拍发下蹲球时食指移到了拍背 [CETV]，发完要换回 | 握法没换回来，第三板别扭 |
| 视线/头 | 盯住对方拍触球，判断回球 | 同左 | — |
| 衔接 | 想好第三板："Serve with a plan" [H24]；发上旋短球后注意对方平挑到中路（ETT 作者吃过这个亏）[ETT-T] | 关键时刻发出高质量的下蹲球往往能直接得分 [CETV] | 发完不准备第三板，发球优势白费 |

接发球一方怎么处理勾手：发到正手大角时"向球迈步，不要伸手够，拍子保持较高"，顺旋转回直线更容易 [H144]；详见 `../techniques/receive.md`。

## 4. 拍面角度、击球点、击球时间、触球部位

| 想要的旋转 | 拍面 | 触球部位（球的哪里） | 击球点 | 击球时间 |
|---|---|---|---|---|
| 勾手纯侧旋 | 拍头朝上，接近竖直 | 球的侧面，向前擦 [ETT-side] | 身体侧前方、尽量低 | 球下落期（规则要求从最高点下落后才能击球）[HMO] |
| 勾手侧下旋 | 拍面后仰（"laying the bat back"）[PS-T] | 侧面偏下 | 同上 | 同上；挥拍下行段触球 [H28] |
| 勾手侧上旋 | 拍面往前盖（"turning it over"）[PS-T] | 侧面偏上 | 同上 | 挥拍上行段触球 [H28] |
| 勾手不转 | 动作照旧；用球拍上靠拍柄处触球 [H27] | 同纯侧旋 | 同上 | 同上 |
| 下蹲右侧上 / 右侧下 | — | 中部向右侧上 / 中下部向右侧下 [CETV] | 下蹲中、低位 | 下落期 |
| 下蹲左侧下 | — | 中部向左下 [CETV] | 同上 | 同上 |
| 王子发球 | 反手面；立起偏上旋，稍斜偏下旋 [RL] | 球的左侧 [RL] | 深蹲后的低点 [RL] | 等球落下 [RL] |

- 拍面角度：**没有可靠出处给出勾手或下蹲发球的拍面角度数字**，只写定性描述。研究还发现发球拍面角个人差异极大（从约 −98° 到 +76°），不存在"标准拍面角"（Ngo 2017）。拍面角的通用读法见 `../fundamentals/racket-angle-timing-contact.md`。
- 触球部位（球拍上）：靠拍头触球转得最多，靠拍柄几乎不转 [H3393]。
- 中国教育电视台的"下蹲左侧上旋"一句原文有残缺（"站右中部向左上方位稍平"），本卡不转述这一句的细节。

## 5. 发力：顺序、方向、摩擦与撞击

- **以摩擦为主，几乎不撞。** "accelerate your racket to full speed, and then just graze the ball" [H24]。撞得多，球就快、长、转少 [ETT-spin]。没有出处给出"摩擦/撞击比例"的数字。
- **顺序（勾手）：** 低重心稳住 → 小幅转体 → 抬肘、前臂带手腕 → 手腕鞭打。拍速主要来自放松的前臂和手腕 [ETT-spin]；发短球时手腕力量大于前臂 [CETV]。
- **顺序（下蹲）：** 下肢下蹲 → 躯干稳定在低位 → 手臂、手腕快速半圆摩擦 [CETV]（顺序是本卡归纳，无专门出处；[CETV] 只讲了"快速做半圆形摩擦"和抛球与挥拍的配合）。Yu 2018 认为下蹲发球"需要更大的下肢驱动"，并推测引拍结束时更大的屈髋屈膝可能帮助前挥时提高拍速——**这是论文作者的推测，不是测出来的拍速** [Yu]。
- **方向：** 侧旋擦球侧面并向前，下旋擦底部并向前；横着擦球背面会又弹又不转 [ETT-side]。不要把球往下砍到台上，否则球弹高 [ETT-low]。
- 更多发力原理见 `../fundamentals/power-and-body.md`、`../fundamentals/spin.md`。

## 6. 面对不同情况的调整

| 情况 | 怎么调 | 出处 |
|---|---|---|
| 想发短 | 擦得更薄、触球更低 | [H583][H32] |
| 对手能拉起你发到正手的长球（中高级以上） | 只发短，长球只做偶尔的突袭 | [H144] |
| 发长 | 长勾手常带螺旋旋，落台跳拐大；可发对方反手底线 | [H144] |
| 对手已经适应你的勾手 | 换别的发球；加反向勾手或反手勾手；不要硬发 | [H144][H3735][PS-BT][ETT-T] |
| 发上旋太多被平挑 | 在上旋、侧旋、下旋之间变化，注意第三板防中路 | [ETT-T] |
| "陷阱"组合 | 连续短球后突然发一个底线重下旋，引对方拉；或突然发快而平的直线。原文没说这个重下旋是不是用勾手动作发的；勾手本身难发重下旋 [H144]，可以用钟摆或反手发球代替 | [ETT-T]（单一作者经验） |
| 站位 | 正手位发角度大；反手位发和反手发球相似 | [H144] |
| 双打 | 球必须依次落在本方右半区和对方右半区，发球站位和落点都受限制 | [ITTF] |
| 下蹲体力下降（比赛后段） | 减少使用；深度动作需要下肢力量和柔韧，疲劳时动作难保持 | [Yu] |

## 规则要点

完整规则见 `../techniques/serve-basics-and-rules.md`。和这两种发球特别相关的：

1. **球从静止的张开掌心抛起**，近乎垂直、不加旋转、离手后至少上升 16 cm [ITTF]。"近乎垂直"指只偏几度，不是过去的 45° [HMO]。
2. **从发球开始到击球，球必须在台面水平以上、端线之后** [ITTF]。下蹲发球时要守住的是**抛球前托球的手和击球时的球**：球离手前，托着球的手必须静止在台面以上，不能先放到台面以下再一路向上抛 [HMO]；击球时球必须在台面以上 [HMO]。球抛出后，不执拍手只要立刻移出球与球网之间的空间 [ITTF]，规则没有要求它留在台面以上。
3. **球不能被身体或衣物挡住，抛球后不执拍手臂要移出球与网之间的空间** [ITTF]。下蹲、侧身时最容易让头、肩或不执拍手臂挡住球。
4. **必须在球从最高点下落时击球** [HMO]。
5. 第一次"拿不准"可以警告一次，但**明显违例不享有警告，直接判分** [HMO]。贴着合法边缘发球，风险由发球员承担 [HMO]。

## 旋转变化与伪装

- **同一动作，只变触球时机：** 下行段触球得下旋、横向段得侧旋、上行段得上旋，挥拍要快，让对方看不清在哪一段触球 [H28]。ETT 作者的勾手就是同一动作发侧上 / 侧 / 侧下 [ETT-T]。
- **发侧上、侧下比纯上、纯下更能骗人** [H28]。
- **转与不转：** 同样用力，拍头触球是转，靠拍柄触球是不转 [H27]。
- **随挥做假：** 触球后反向夸张收拍 [H336]；起始站位、引拍、收拍都保持一样，只变触球 [PS-D]。
- **左右两种侧旋都要有：** 只用一种侧旋发球，"pretty much an announcement about what type of sidespin"（等于告诉对方旋转方向）[H3688]；对手迟早会适应你的常规版本，加上反向版本，对方就得两头防，而且有些人本来就更怕某一种侧旋 [H3735]。勾手（一个方向）配正手钟摆（相反方向）[H144]；或配反向勾手 [H3735]、反手勾手 [PS-BT]。
- **下蹲发球的变化：** 同样下蹲，右侧上 / 右侧下 / 左侧上 / 左侧下 [CETV]；王子发球用拍面立起与否变上下旋 [RL]。
- **不能靠遮挡伪装**：2002 年 9 月起遮挡发球被禁止（"in September 2002, the hidden serve was banned" [JinMa]）；现行规则要求球不被身体或衣物挡住 [ITTF]。伪装只能靠动作（见 `../techniques/serve-basics-and-rules.md`）。

## 7. 关键数据参考

**下蹲 vs 站立发球的下肢角度**（Yu 2018，10 名右手持拍的国家一级女子运动员，发短球，Vicon 8 镜头 200 Hz；屈曲角，0° = 伸直）[Yu]：

| 关节 | 时刻 | 下蹲发球 | 站立发球 | 换算成本工具的"夹角"（≈180° − 屈曲角，下蹲 / 站立） |
|---|---|---|---|---|
| 髋屈曲 | 准备 RP | 20.6° ± 4.8 | 9.9° ± 0.8 | — |
| 髋屈曲 | 引拍结束 BE | 85.7° ± 0.9 | 19.6° ± 1.0 | — |
| 髋屈曲 | 前挥结束 FE | 94.3° ± 1.6 | 31.6° ± 3.2 | — |
| 膝屈曲 | 准备 RP | 25.7° ± 1.4 | 27.1° ± 2.4 | ≈154° / ≈153° |
| 膝屈曲 | 引拍结束 BE | 126.0° ± 5.6 | 22.6° ± 1.0 | ≈54° / ≈157° |
| 膝屈曲 | 前挥结束 FE | 151.8° ± 2.1 | 64.9° ± 2.4 | ≈28° / ≈115° |
| 踝背屈 | 准备 RP | 9.9° | 17.8° | — |
| 踝背屈 | 引拍结束 BE | 31.3° ± 1.4 | 14.4° ± 1.1 | — |
| 髋内收（论文符号为负） | 引拍结束 BE | 约 32° | 约 4° | — |

- 时间：整个动作 1.58 ± 0.05 s（下蹲）vs 1.57 ± 0.06 s（站立），各阶段无显著差异；其中引拍结束→前挥结束 0.20 vs 0.21 s，前挥结束→下一次开始 0.86 vs 0.87 s [Yu]。注意这是实验室用发球机定点回球的条件，**不能据此说比赛中下蹲发球还原不慢**；日文维基说的"还原慢"指比赛中应对接发球 [JA]。
- 怎么用这些数：只说明"下蹲发球膝、髋弯得多得多"，**不是标准值**。样本只有 10 名女子、单一实验室；"前挥结束"对应本工具的随挥结束，而本工具只在准备、引拍结束、击球三个时刻测膝角。论文摘要说站立发球后脚区力-时积分更高，但结果段写法相反，本卡不引用这一项。
- 单机位 MediaPipe 测膝角误差大：侧面、慢速、静态约 15°，深蹲不做质量筛选时约 25°，约 16% 的帧置信度不达标 [Yue]。所以视频里的膝角只做**同一个人前后对比**。
- 规则数字：抛球离手后至少上升 16 cm；网高 15.25 cm（可作抛球高度参照，但"抛过网高"不等于合法）[ITTF][HMO]。
- 勾手发球的拍面角、拍速、转速：**没有找到同行评审数据**。Hodges 建议触球高度"不高于约 8 英寸"[H32]，另一篇又说"至少在六英寸以内"[H24]；都是单一教练的粗略估算，本卡只写"尽量低"。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 勾手发出去的旋转和钟摆一样 | 触球时拍头垂下来了 | 对着镜子做慢动作，触球时拍头必须朝上 [H144] |
| 球又快又长、不怎么转 | 撞球，球吃进海绵 | 只用胶皮表层擦；先练纯侧旋，再加上、下旋 [ETT-spin][PS-T] |
| 发球偏高、偏长 | 触球点太高；往下砍球 | 等球落低再打；向前擦而不是向下砍 [H583][ETT-low] |
| 勾手总被对方平挑到中路 | 上旋发得太多、太单一 | 在上旋、侧旋、下旋之间变化 [ETT-T]；再加不转 [H27] |
| 发到正手的长勾手被拉死 | 对手水平够，长勾手不再有效 | 只发短，长球偶尔突袭 [H144] |
| 发不出转的下旋 | 勾手本身难发重下旋 | 接受这个限制，重下旋交给钟摆或反手发球 [H144] |
| 下蹲时被判违例 | 抛球前托球的手放到了台面以下再往上抛；击球时球已低于台面；身体挡住球 | 抛球前托球的手静止在台面以上，等球下落但仍在台面以上时击球 [ITTF][HMO]；请人从对方位置看，或用正面机位自查 |
| 下蹲发完被对方抢攻 | 还没完全站起来 | 随挥结束马上起身 [CETV][JA]；关键分再用 |
| 打不到想要的高度、空拍 | 抛球和下蹲节奏脱节 | 先徒手练"抛—蹲—挥"同步，再上球 [CETV][YZ] |
| 膝、腰酸痛，后半场动作变形 | 下肢力量、柔韧不够 | 练下肢力量和柔韧（`../training/physical-and-injury.md`）；减少使用次数 [Yu] |
| 手腕甩不开 | 握拍太紧 | 握拍放松 [PS-T]；松紧细节见 `../fundamentals/grip.md` |
| 对方一看就知道旋转 | 收拍随旋转变化 | 收拍统一，或反向夸张收拍 [PS-D][H336] |

## 9. 练习方法（入门 → 进阶）

1. **徒手模仿**：对镜做准备、抛球、勾手挥拍，确认拍头朝上 [YZ]（下蹲发球的徒手练习见第 8 条）。
2. **小动作找触球**：整套动作太难时，先用小幅度动作找到擦球的感觉 [PS-T]。
3. **先纯侧旋，再加下旋和上旋**：拍面后仰加下旋、往前盖加上旋 [PS-T]。
4. **多球练习**：一筐球连续发，先发斜线、后发直线，先不定点、后定点 [YZ]。
5. **控制长短**：目标对方正手短（第二跳不出台）；能做到再练半出台和偶尔的长球 [H144][ETT-T]。
6. **同一手法发不同旋转和落点**；配合正手钟摆或反向勾手，形成相反方向的组合 [YZ][H3735]。
7. **发球 + 第三板**：发完立刻还原，接对方的摆短、搓长、挑打 [H24]；第三板技术见 `../techniques/forehand-loop-vs-backspin.md`、`../techniques/forehand-flick.md`。
8. **下蹲发球专项**（下肢准备见 `../training/physical-and-injury.md` 第 4.4 节；下蹲对下肢要求高 [Yu]）：
   - ① 徒手"抛—蹲—挥"节奏，球不离手 [CETV]；
   - ② 半蹲发多球，只练纯侧旋，检查抛球前托球的手和击球时的球都在台面以上 [ITTF][HMO]；
   - ③ 深蹲发多球，练右侧上、右侧下两种 [CETV]；
   - ④ 加左侧旋版 [CETV]；
   - ⑤ 发完立刻起身，接一板陪练的回球。计时：用视频里 finish 到 recovery 的时刻差（见第 10 节），同一个人前后对比。
9. 结合个人特点，**练一至二套高质量的特长发球**，不要什么都练一点 [YZ]。更多练法见 `../training/drills.md`。

## 10. 视频检查要点

**机位**（见 `../analysis/recording-guide.md`）：主机位**侧面**（持拍侧），看抛球、下蹲深度、触球；补一个**正面**机位（站在对方端线后），专门查遮挡和球是否在台面以上。用 120/240 帧慢动作；慢动作导出的视频要加 `--capture-fps`。

**发球视频常见问题**：只拍发球时，自动模式可能找不到挥拍（`NO_STROKES`），或把引拍、收拍误当成一板。按 `../analysis/analysis-protocol.md`：先看 timeline，必要时用 `--timeline` 出密帧，再用 `--strokes` 手动给每一板定 5 个时刻：
- ready = 球静止在掌心、拍静止的一帧；backswing_end = 拍到引拍最远处；contact = 拍触球；finish = 拍挥到尽头；recovery = 站回准备姿势。
- 抛球不是脚本的阶段，看 timeline 判断。

| 阶段 | 关键帧里看什么 | 对应指标（只当参考） |
|---|---|---|
| 站位与准备 | 站位、膝微屈、拍头朝上（勾手）、球在掌心且在台面以上 | `stance_width_ratio`、`knee_angle_deg.playing.ready`、`knee_angle_deg.other.ready` |
| 抛球 | 球是否近乎垂直、够不够高（网高可作参照）；抛球前托球的手是否静止在台面以上；不执拍手臂抛后有没有移开；下蹲是否随球下落开始 | 无直接指标，只看图（`head_motion` 从引拍结束量到随挥结束，测不到抛球阶段，下蹲发球还会因下蹲而偏大，只做同一种发球前后对比） |
| 引拍 | 肘是否抬起、拍头是否朝上；下蹲深度 | `elbow_angle_deg.backswing_end`、`knee_angle_deg.playing.backswing_end`、`knee_angle_deg.other.backswing_end`、`trunk_lean_deg.backswing_end`、`backswing_ms` |
| 触球 | 是否还在下蹲、没有起身；击球点相对**台面**的高度（看图，脚本的高度以髋、肩为标尺，人蹲下后 `contact_height_level` 会偏大）；不执拍手位置 | `knee_min_deg.playing`、`knee_min_deg.other`、`knee_angle_deg.playing.contact`、`knee_angle_deg.other.contact`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`contact_height_level`、`contact_forward_m`、`contact_lateral_m`、`free_arm_height_level`、`trunk_lean_deg.contact`、`forward_ms`、`peak_hand_speed` |
| 随挥 | 收拍是否短、是否每次一样 | `swing_path.up`、`swing_path.horiz`、`swing_path.angle_deg`、`finish_height_level`、`elbow_angle_deg.finish`、`follow_ms` |
| 还原与衔接 | 下蹲发球多久站起来（没有直接指标：用 `--strokes` 里自己定的 recovery 时刻减 finish 时刻手算）；拍和身体是否回到准备 | `recovery_dist`（只看手回没回到准备位置）、`weight_shift.backswing_end`、`weight_shift.finish`、`weight_shift.delta` |

- **拍面角度、拍头朝向、用哪一面、触在拍上哪里（拍头还是拍柄）、擦球哪一侧，只能看手部放大图**（`measured_NN_zoom.jpg`）。骨架测不出拍面。
- 膝角：深蹲时误差可达约 25° [Yue]，腿被球台挡住时为 null；先看 `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`，不可靠就不用。
- `side_guess` 可能把发球判成正手或不确定，以图为准。发球动作小，`sequence_ms.hip`、`sequence_ms.shoulder`、`sequence_ms.elbow` 与 `sequence_order_ok`、`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`、`shoulder_width_ratio.backswing_end`、`shoulder_width_ratio.contact` 参考价值低。
- 合法性（遮挡、球在台面以上、抛球垂直）以正面机位的图为准；拿不准时直接告诉用户"这段视频判断不了"，并说明怎么重拍。

## 11. 自查清单

- [ ] 我能说清楚：勾手 = 拍头朝上的正手发球，旋转方向和正手钟摆相反。
- [ ] 勾手触球时拍头始终朝上，握拍是松的。
- [ ] 能用同一动作发出纯侧、侧下、侧上，以及不转。
- [ ] 勾手主要发对方正手短球；长勾手只偶尔用。
- [ ] 有一个和勾手旋转方向相反的发球（钟摆或反向勾手）做搭配。
- [ ] 抛球近乎垂直、离手至少 16 cm，抛完不执拍手臂立即移开。
- [ ] 下蹲发球时，抛球前托球的手和击球时的球都在台面以上，正面看不被身体挡住。
- [ ] 下蹲发球的下蹲和抛球节奏一致，触球时还在低位。
- [ ] 下蹲发球发完立即起身还原，准备第三板。
- [ ] 收拍每次一样，或者有意反向做假。
- [ ] 下肢力量和柔韧够我在一场比赛里多次下蹲而动作不变形。
- [ ] 视频里用手部放大图确认过拍面和触球位置。
