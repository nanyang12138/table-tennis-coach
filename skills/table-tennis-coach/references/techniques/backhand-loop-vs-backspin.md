# 反手拉下旋（Backhand Loop against Backspin）

适用场景：接下旋长发球、对方搓长到反手位、发球抢拉、搓中转拉；也包括反手快带下旋长球、反手拉半出台、反手台内拉｜难度：中级（先会反手攻/快拨，再学拉下旋）｜相关卡片：[反手拉上旋与反拉](../techniques/backhand-loop-vs-topspin.md)、[反手快撕](../techniques/backhand-tear.md)、[反手拧拉](../techniques/backhand-banana-flick.md)、[反手挑打](../techniques/backhand-flick.md)、[反手攻球与快拨](../techniques/backhand-drive-punch.md)、[正手拉下旋](../techniques/forehand-loop-vs-backspin.md)、[搓长](../techniques/long-push.md)、[接发球](../techniques/receive.md)、[衔接](../techniques/transitions.md)

> 本卡按右手横拍写，左手持拍者左右互换。直拍反手拉下旋改用横打（反面拉），见 [直拍](../techniques/penhold.md) 第 5.4 节（反面拉）和第 6 节（直拍反手的三种做法）。拍面角度用中国教育电视台（CETV）的口径：拍面与台面的夹角，90° 为垂直，小于 90° 叫前倾，大于 90° 叫后仰。击球时间分五段：上升期 → 上升后期 → 高点期 → 下降前期 → 下降后期。基础概念见 [拍面、击球点、击球时间](../fundamentals/racket-angle-timing-contact.md) 和 [旋转](../fundamentals/spin.md)。

## 1. 定义与用途

**定义。** 反手拉下旋是用反手从球的后下方向上、向前摩擦，把对方的下旋球变成上旋弧圈球。原理是薄而快的摩擦（PingSkills）："A fine brushing contact creates the topspin that lifts the backspin over the net; a flat contact sends it into the net"（薄刷产生的上旋能把下旋球带过网，平打会下网）。百度百科把它列为横拍弧圈选手的主要技术之一，"速度比正手快但力量旋转稍弱"，常用在接下旋发球、发球抢拉、搓中转拉（百度百科「反手拉弧圈球」）。

**本卡覆盖的几种打法：**

| 打法 | 什么时候用 | 特点 |
|---|---|---|
| 反手拉加转（高吊） | 下旋重、球低，或想先求稳 | 拍更低，挥拍更竖直，向上多，弧线高、转速大 |
| 反手前冲 | 下旋不太重、球有一定高度 | 拍面更前倾，向前多，击球时间更早，弧线低、速度快 |
| 反手慢转弧圈（slow spinny backhand） | 变节奏，尤其对付喜欢快球的挡球型对手 | 起拍低、挥拍更竖直、很薄地刷，靠手腕帮忙把球提起来（PingSkills） |
| 反手侧旋弧圈（sidespin backhand topspin） | 在稳定的直线反手拉基础上加变化 | 球带侧旋加上旋（PingSkills） |
| 反手快带下旋长球 | 来球突然、速度快的下旋长球（多在接发球） | 动作小、上升期击球、前臂和手腕突然发力（百度百科「反手快带弧圈球技术」） |
| 反手拉半出台 | 第二跳落在端线附近的球 | 判断长短最难，能出台才拉 |
| 反手台内拉 | 台内偏高或下旋不重的短球 | 台内的小弧圈；和拧拉的区别见第 6.3 节 |

术语：本卡"加转"≈"高吊"；"慢转"是加转里刻意放慢弧线、最大化旋转的一种。研究里的 Fast-Loop 记作"快拉（接近前冲）"，Slow-Loop 记作"慢拉（接近高吊/慢转）"。

**和相近技术的区别：** 来球是上旋时用 [反手拉上旋与反拉](../techniques/backhand-loop-vs-topspin.md) 或 [快撕](../techniques/backhand-tear.md)，挥拍更平、更向前；台内短球带明显侧旋的打法是 [拧拉](../techniques/backhand-banana-flick.md)；以撞击为主、带轻上旋的台内进攻是 [反手挑打](../techniques/backhand-flick.md)。

## 2. 三位标杆怎么做

> 三人反手拉下旋的拍面角度、击球点、转腰幅度：**暂无可靠出处**。以下只写有出处的说法。

- **马龙。** 2020 年刘国梁复盘威海世界杯时说他"反手体系有明显进步……可以更加相信自己的反手"（央视网转新华社，2020-11-16）。刘国梁 2019 年突击检查，看到马龙一个人加练，"30个冲下旋击中29个"（《中国体育报》2021-08-28），原文**没说是正手还是反手**。一家分析博客（Edges & Nets）统计了 2020 年世界杯半决赛对张本智和这一场：马龙前三板最想要的是"用正手对长球、尤其半出台球起板"（单场统计）。
- **张继科。** 2016 年新浪体育评论："以往张继科的反手占优，马龙的正手有优势"，同一篇也写到里约决赛后三局他的反手相持"完全处于下风"。日本蝴蝶公司《卓球レポート》描述他的典型打法是"チキータからの両ハンドドライブ"，意思是拧拉之后接两面弧圈抢主动。PingSkills 教练评价他在 2012 年伦敦奥运决赛相持中的反手：动作看着小，但"using his wrist very effectively"（手腕用得非常有效）。这说的是相持反手，不是拉下旋。他反手动作的力学细节：暂无可靠出处。
- **樊振东。** 有一篇论文（Jin & Ma 2026）用 2025 年全运会 5 场比赛的高速视频做了**定性**比较，对象是他的反手进攻（未区分来球上旋下旋），与对手相比：引拍幅度更小，击球时重心稳，击球时间更早，击球点离身体更近；肘部向前顶，拍的位置相对固定，"打摩结合"；随挥以肘向前为主，还原快。同文统计 2021–2023 年 40 场：他先上手主要靠反手；但"反手上手后的连续进攻有待提高"。论文没有给出角度数值。

业余球员怎么借鉴：学樊振东"引拍小、肘向前、还原快"的思路（他"离身体近"是相对对手的紧凑，前提是脚步到位、肘在身前，不等于让球贴着肚子打），再练好张继科式的"上手后接两面连续进攻"。半出台球如果能侧身用正手，可以像马龙那样优先用正手起板。

## 3. 动作分解

下面写的是标准形态：近中台，反手拉出台的下旋长球，以加转和前冲为主。其他打法在第 6 节写区别。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 离台大约一臂远，"Arm's length is usually about right"（Hodges）；两脚站宽，面向想打的方向（PingSkills）。判断出下旋长球后可调成右脚稍前或两脚平行：拉下旋或中远台相持用右脚在前，"腰部发力更充分，引拍幅度也相对更大"；近台快拉用左脚在前，转正手更快（百度百科「反手拉」引《全民学乒乓》） | 贴台太近，被快搓"顶住"来不及引拍（Hodges）；拉什么球都用同一种脚位 |
| 膝 | 微屈，准备随时再往下蹲 | 腿直，没法"先压低再起来" |
| 髋 | 略屈，臀部稍向后坐，重心在前脚掌 | 髋没屈，上身直立 |
| 腰/躯干 | 上身前倾 | 后仰；含胸驼背 |
| 肩 | 放松，两肩齐平 | 耸肩；肩紧张，动作发僵 |
| 大臂/肘 | 肘在身体前方，略向前（百度百科「弧圈球」：肘关节略向前） | 肘夹在肋旁，或者向后撤 |
| 前臂 | 自然弯曲，拍在腹前 | 手臂伸直 |
| 手腕 | 放松，保持中立 | 腕部过早勾起，锁死 |
| 手指/握拍 | 握松，测试方法：别人能把拍从你手里抽走（Hodges）。反手的握法有两种主张：百度百科写"反手利"、浅握、拇指调节弧线；PingSkills 主张一个正反手兼顾、不夸张的握法。详见 [握拍](../fundamentals/grip.md) | 握得太偏反手（"反手利"太深），转正手会慢（百度百科「反手拉」） |
| 拍面/拍头 | 拍在身前，**不要举太高**。准备时拍子太高，就来不及把拍放下去（Hodges） | 拍举到胸口以上 |
| 视线/头 | 盯对方的拍：不管假动作，只看触球那一刻拍的方向和速度（Hodges），判断下旋轻重和长短 | 只盯球不看拍，判断不了旋转 |
| 非持拍手 | 在体侧偏前，肘微屈、自然抬起，帮助平衡。反手拉没有专门出处，以下各阶段都按 [发力与身体](../fundamentals/power-and-body.md) 2.1 通则 | 垂在体侧，或一发力就乱甩 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 用小步调到能让球落在身前偏左的位置；重心偏向左脚，准备向右、向上蹬 | 不动脚，靠伸手够球 |
| 膝 | 下蹲到整板最低的位置，"先压低重心再起来"（百度百科「反手拉」）。研究：引拍开始时精英选手屈膝、屈髋明显大于业余（第 7 节，Wang 2018） | 蹲不下去，只靠手往上提 |
| 髋 | 腰髋向左转（百度百科「反手拉」），臀部后坐，上身前倾（百度百科「反手快带」："身体前倾臀部后撅"） | 髋不转，或者转过头，身体挡住了拍子 |
| 腰/躯干 | 上身略向左转、前倾。近台时转体幅度小，离台远才加大（PingSkills） | 近台时还大幅转腰，来不及还原 |
| 肩 | 持拍肩随上身向左、略向下内收，不要耸 | 耸肩 |
| 大臂/肘 | 肘留在身体前方，"肘部离身体稍远一些"（百度百科「弧圈球」）。另有资料写"肘关节靠近身体"（百度百科「反手拉」引百家号），说法不一，实用标准是既不贴肋也不外翻。前挥中肘在伸开（Xing 2022，数值见第 7 节） | 用"拉肘向后"的方式引拍，肘跑到身体侧后方 |
| 前臂 | 下引到腹部左下方，大约膝盖高度（PingSkills："Start the bat low, about knee height"）。**拍要低于球**（百度百科「提拉」） | 引得不够低，拍在球的上方，只能往下压，结果下网 |
| 手腕 | 屈腕，拍下垂（百度百科「弧圈球」）；手腕内收，但保持放松，留着向前甩的余地 | 腕部锁死；或者勾得过度，变成了拧拉的手型 |
| 手指/握拍 | 拇指开始准备调整拍面 | 越握越紧 |
| 拍面/拍头 | 拍头朝下。拍面稍前倾到接近垂直，**下旋越重，拍面越立**（见第 4 节） | 拍面前倾太多，"盖"着去拉下旋 |
| 视线/头 | 盯着球弹起；头在两脚之间，不跟着手臂下沉 | 低头看拍 |
| 非持拍手 | 留在体侧偏前，随上身下蹲、左转，不往后甩 | 跟着向后甩，上身被带歪 |

**引拍末端要有"一停"。** Hodges：引拍到最后拍要短暂停一下，这时手臂和肘已开始向前拉，然后才鞭打出手。"If you don't feel that slight hesitation … then you are rushing your backswing"（感觉不到这一顿，就说明引拍太仓促）。

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚蹬地，"两腿向上蹬伸"（人民网）。重心由左脚向右脚、向上移（PingSkills 问答："from your left foot to your right"，不必迈大步） | 脚不蹬，只有手在动 |
| 膝 | 伸膝（百度百科「弧圈球」："蹬地，伸膝、转腹"） | 膝始终不伸开 |
| 髋 | 向上、向前挺髋。前倾的身体打开，"提臀挺胸"（百度百科「反手快带」） | 髋往后坐，重心留在后面 |
| 腰/躯干 | 腰髋由左向右前上方转（百度百科「反手拉」），收腹再展腹，像"拧毛巾"。研究认为上躯干的转动要"晚一点"（Iino & Kojima 2016a） | 上身先转开、过早打开，手臂跟不上 |
| 肩 | 持拍肩向上顶，原文"upward thrust of the shoulder"（Iino & Kojima 2016a）。肩外展的角速度和拍速相关（Bańkosz 2018） | 肩不动，只用手臂 |
| 大臂/肘 | 以肘为轴（人民网），肘相对固定，向前送（樊振东的定性研究："elbow drives forward"）。Hodges：臂和肘先拉，拍随后像鞭梢甩出 | 肘往上抬或往后撤，前臂失去支点 |
| 前臂 | 迅速向上、向前挥（人民网），以前臂为主加速（百度百科「反手拉」）；肘在前挥中逐渐伸开 | 前臂收得过早或过晚，"吃不住球"（百度百科「弧圈球」） |
| 手腕 | 放松，由后向前甩出（PingSkills），配合"手腕向上转动"（人民网） | 手腕僵住，没有甩的动作 |
| 手指/握拍 | 握拍仍然松，拇指稳住拍面 | 发力时握死 |
| 拍面/拍头 | 拍头由下向上走。下旋越重，挥拍越竖直（PingSkills："make the stroke more vertical as the backspin gets heavier"） | 挥拍路线太平，像在攻球 |
| 视线/头 | 头稳，盯住球 | 头随身体一起往上抬 |
| 非持拍手 | 保持在髋以上，稳住上身 | 乱甩或下垂：上体晃动，击球点不稳 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 正在蹬伸，两脚都还有支撑 | 跳起来击球，失去支撑 |
| 膝 | 正在伸，还没完全伸直 | 已经站直，力量提前用完了 |
| 髋 | 向前上方送，重心不后坐 | 往前顶肚子，臀部留在后面（百度百科「反手拉」） |
| 腰/躯干 | 仍然前倾，"整个身体重心应时刻保持前倾"（百度百科「反手拉」） | 上身后仰 |
| 肩 | 向上顶，向前送 | 耸肩 |
| 大臂/肘 | 肘在身体前方，别让球贴身挤住（百度百科「反手拉」讲快拉时说"击球点不宜离身体太近"） | 球贴着肚子才打 |
| 前臂 | 前臂仍在加速，击球后拍速还会再升一点（Bańkosz 2018，数值见第 7 节）；要点是击球时不减速、挥拍要穿过球 | 前臂减速，球"软" |
| 手腕 | 伸腕（腕背屈）。研究发现，对下旋时腕背屈对拍子向上速度的贡献更大（Iino 2008） | 手腕向下勾 |
| 手指/握拍 | 用拇指微调拍面，控制弧线 | 拍面被球"顶"开 |
| 拍面/拍头 | 薄刷；尽量用靠近拍头的部位触球，原文"towards the end of the bat"（PingSkills） | 平打撞球，结果下网；用拍根触球，转速不足 |
| 视线/头 | 头稳，盯住触球点 | 抬头看球往哪飞 |
| 非持拍手 | 仍在髋以上，帮助平衡 | 掉到髋以下（第 10 节 `free_arm_height_level`） |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到右脚（百度百科「反手拉」："重心由左脚转至右脚"）。快拉（接近前冲）和斜线拉随挥时右腿负荷更大（Li 2025），右腿要能撑住 | 被惯性带着往前、往右冲出去 |
| 膝 | 伸开，但不锁死 | 膝锁直后僵住 |
| 髋 | 已经打开，朝向出球方向 | 髋往后撤 |
| 腰/躯干 | 转到正对出球方向，上身仍略前倾 | 过于向上发力，"重心后坐"（百度百科「反手拉」） |
| 肩 | 持拍肩随挥到前上方 | 肩往后拉 |
| 大臂/肘 | 肘向前上方送，收拍要过肘（PingSkills："past your elbow"） | 肘停在身体侧边 |
| 前臂 | 向右前上方挥（百度百科「反手拉」） | 横着扫过身体，"swing across your body"（PingSkills） |
| 手腕 | 自然放松，不要刻意翻腕 | 收拍时翻腕压拍 |
| 手指/握拍 | 松 | 握死 |
| 拍面/拍头 | 拉下旋时收拍要高，原文"Finish high, above head height and past your elbow"（PingSkills）。随挥朝着出球方向（Butterfly 问答） | 收拍停在胸前，球没拉起来 |
| 视线/头 | 跟着球看对方的回球 | 停下来看自己的球 |
| 非持拍手 | 随展体自然向左打开，和持拍手平衡 | 甩得过大，把身体拉偏 |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚回到可以向两边起动的位置；如果打下一板正手，左脚可以稍前（百度百科「反手拉」） | 站着看球 |
| 膝 | 重新微屈 | 腿直 |
| 髋 | 回到正对球台 | 还朝着右边 |
| 腰/躯干 | 回到前倾 | 直立 |
| 肩 | 拉完马上放松，原文："拉后手臂，尤其是肩部要迅速放松还原"（百度百科「弧圈球」） | 肩一直紧着 |
| 大臂/肘 | 回到身体前方 | 肘还举着 |
| 前臂 | 拍收回到身前，高度和下一板相适应 | 拍子还留在头顶 |
| 手腕 | 回到中立 | 腕部还锁着 |
| 手指/握拍 | 握松；如果要转正手，在这时调整握法 | 握法还卡在反手 |
| 拍面/拍头 | 下一板多半是上旋，拍面要准备好"关"一些 | 拍面还停在拉下旋的角度 |
| 视线/头 | 看对方触球，判断下一板 | 看自己刚才那一板 |
| 非持拍手 | 回到体侧偏前 | 垂下不管 |

回位：Hodges 主张每板回中立准备位；PingSkills 主张跟着来球直接把拍放到下一板的位置。初学按前者，熟练后按后者。

## 4. 拍面角度、击球点、击球时间、触球部位

| 项目 | 要领 | 出处 |
|---|---|---|
| 拍面角度 | 一般是"拍形稍前倾"（百度百科「弧圈球」反手拉加转）。**下旋越重：拍面越立、挥拍越竖直、起拍越低、收拍越高**（PingSkills："Against backspin start lower and finish higher"；"Against backspin, the stroke needs more lift and a higher finish"）。"提拉"遇强下旋，拍面甚至稍后仰（百度百科「提拉」）。拉前冲时拍面更前倾。**具体度数没有可靠出处，不写** | PingSkills；百度百科 |
| 击球点 | 在身体前方偏左，不让球贴身挤住。拍从膝高起拍（PingSkills），引拍时拍要低于球，所以击球高度比拉上旋低，大致在腰部附近或更低（由"膝高起拍、下降前期击球"推出，非测量值） | PingSkills；百度百科 |
| 击球时间 | 反手快拉在上升后期或高点期；拉强烈下旋或中远台拉，在下降前期或下降中期（百度百科「反手拉」原文"下降前期或中期"）。人民网写的是"下降期"，按五段分法大致相当于下降前期到下降后期的前段。Butterfly 问答："just after the highest point"（刚过最高点）。快带下旋长球在上升期（百度百科「反手快带」）。下旋越重，可以越晚；想打前冲，就越早 | 百度百科；人民网；Butterfly 问答 438 |
| 触球部位 | 加转和一般的拉：球的中部或中上部，摩擦为主（人民网）。提拉强下旋：球的后中下方（百度百科「提拉」）。快带：中上部（百度百科「反手快带」）。说法不一是拍面角度不同所致：拍面越立、越向上刷，触球点越偏后下 | 同上 |
| 拍上的位置 | 靠近拍头的部位（PingSkills） | PingSkills |

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：蹬地伸膝 → 髋向前上方挺 → 腰腹由左向右转 → 肩向上顶 → 肘为轴、前臂加速 → 手腕甩出。这和通用的"腿 → 髋腰 → 肩 → 臂 → 腕"一致（Hodges）。研究发现，反手拉对下旋时，持拍臂前挥获得的机械能约 77% 来自躯干的传递（对上旋约 65%）；研究还认为"肩向上顶"和"上躯干转动晚一点"是要点（Iino & Kojima 2016a）。PingSkills 说高级反手拉的力量主要来自手腕和前臂（"Most of the power in an advanced backhand topspin comes from the wrist and forearm"）。两者不矛盾：前臂的能量大部分由躯干传入，所以腿和躯干先启动，最后由前臂、手腕放松甩出。通用原理见 [发力与身体分工](../fundamentals/power-and-body.md)。
- **方向**：以向上为主，同时向前。下旋越重，向上的成分越多。研究发现，拉下旋比拉上旋击球时拍子向上的速度明显更大、向前的差不多，差别来自手臂构型（伸肘负贡献更小、腕背屈贡献更大），不是关节转得更快（Iino 2008）。注意不要"只向上"：百度百科把"过于向上发力，导致重心后坐"列为常见错误，纠正方法是"以腰带动前臂向前上方发力"。
- **摩擦与撞击**：拉弧圈是"先打后摩，又打又摩，以摩为主"（百度百科「弧圈球」引《乒乓世界》）。下旋越强，摩擦的比例越大（百度百科「提拉」）。拉前冲另有"以撞击为主，用力量克制球的旋转，再加上摩擦才能上台"的教法（百度百科「前冲弧圈球」），要求更快的拍速和更好的体能。樊振东反手的定性描述也是"打摩结合"。业余先练"薄刷能过网"，再加撞击。
- **下肢**：Li 2025（对象见第 7 节）发现，快拉（接近前冲）更依赖左腿（非持拍侧）的伸髋力矩，慢拉（接近高吊/慢转）更依赖左腿的伸膝力矩（Li 2025）。可以理解为：前冲多用"挺髋"，高吊多用"蹬膝"。
- **放松**：手臂要放松，"like a rubber band"（Hodges），挥拍要快而放松（PingSkills："fast, relaxed swing"）。

## 6. 面对不同来球的调整

### 6.1 按来球和目的调整

| 来球 / 目的 | 站位、脚序 | 引拍 | 拍面、击球时间 | 方向、收拍 |
|---|---|---|---|---|
| 轻下旋或不转的长球 → 前冲 | 近台，左脚稍前或两脚平行 | 引拍不必太低 | 拍面更前倾；上升后期或高点期 | 更向前，收拍可以稍低（PingSkills：对平球或上旋"finish a little lower"） |
| 重下旋长球 → 加转 | 右脚稍前，膝蹲得更低 | 拍引到膝高或更低 | 拍面更立；下降前期或下降中期 | 向上为主，收拍过头顶 |
| 快速、突然的下旋长球（急长发球、快搓） → 反手快带 | 正对球台可以带直线，偏侧身站位适合带斜线（百度百科） | 重心放低、前倾后撅（加大摩擦、克服下旋）；引到左腹即可，手腕微屈，引拍"不可幅度过大也不可过小"。过大会被顶住，过小摩擦不足会下网 | 拍面前倾；上升期，触球中上部 | 从左腹挥向右前上方，"前倾身体打开变为提臀挺胸"（百度百科「反手快带弧圈球技术」，**该词条没有参考文献，可信度偏低**）。PingSkills 也说：来球又快又平时缩短动作，用手腕帮忙把球提起来；如果对方常发长球，可以先退小半步 |
| 慢转（变节奏） | 同加转 | 起拍低 | 挥拍更竖直，非常薄地刷，手腕帮忙提球（PingSkills「Use a Slow, Spinny Backhand to Disrupt Blockers」）。Hodges 讲慢转弧圈（node/3587）：多用于对付重下旋，挥拍几乎竖直；让球落低（可到台面以下），膝深屈 | 弧线高、落点深。慢转"不是软绵绵的保险球"，而是全力挥拍、力量几乎都变成旋转（同上）。PingSkills 说对方搓过来的下旋长球，正是打这种变速球的好机会 |
| 侧旋反手弧圈 | 同普通反手拉 | 同上 | 触球时拍面偏向球的一侧去摩擦（人民网写的是正手"摩擦球的偏右面"，反手类推），球就带上侧上旋 | PingSkills：先把直线反手拉练稳（正文付费未读）。容错比纯上旋小（PingSkills 正手侧旋课："less margin for error than pure topspin"，原理通用）；该课还提醒只改手腕和拍面，不要横扫身体。偏侧面摩擦吃到的下旋较少（原理推论，**无专门出处**） |
| 侧下旋长球 | 预判球往哪边拐，提前站位；触球时调整到球的内侧或外侧（Hodges 讲拉侧旋发球） | 同上 | 同上 | 侧拐向外的球，伸手去够容易出界，应该上步（Hodges） |
| 中远台的下旋（对方削球、远台搓） | 右脚在前，引拍幅度更大 | 转腰更多（PingSkills：离台远时可以加大转体） | 下降前期或下降中期（百度百科「反手拉」） | 发力更完整 |
| 直线 / 斜线 | 斜线可以多用转腰 | — | 线路的变化取决于前挥早期的屈肘和中段的躯干转动（Li 2025，男子，拉下旋） | 女子研究 Xing 2022 发现打直线时躯干-骨盆转动更快；两项研究条件不同，不作定论 |

### 6.2 反手拉半出台

**怎么判断。** 半出台球的第二跳落在对方端线附近，长短很难判断（Hodges）。PingSkills：判断到最后，确认"comes long enough"（足够长）才拉；不够长就搓或挑（见 [接发球](../techniques/receive.md)）。两种处理：上前早点搓，或让球出来、用更大的动作拉（PingSkills「Two Ways to Return a Half-Long Serve」）。

**动作上的区别（按球台限制推断，无专门出处）：**
- 脚：右脚向前上一步，靠近端线，重心压在前脚上。
- 膝、髋：蹲得更低，臀部不能后坐。百度百科「台内球」说，"重心应完全跟上去，避免臀部掉在后面、手臂伸得过直"。
- 引拍：球台挡住下方，拍只能引到台面高度附近，不能引到膝高，所以主要靠前臂和手腕向上刷，挥拍更竖直。
- 击球时间：等球越过端线，在高点到下降前期击球。抢得太早会碰到台面，或者变成台内拉。
- 收拍：仍要高，但幅度比拉长球小，便于还原。

### 6.3 反手台内拉

台内拉是在台面上方把短下旋球拉成上旋，拍面相对正，向上、向前刷，是缩小版的反手拉。日文维基「卓球」把拧拉（チキータ）定义为"带侧旋的反手台内拉"，Hodges 把拧拉称为台内的小弧圈（"mini-loops from over the table"），带上旋，通常也带侧旋（node/3621）。

| 对比 | 反手台内拉（本列为经验归纳，无专门出处） | [拧拉](../techniques/backhand-banana-flick.md) |
|---|---|---|
| 旋转 | 以上旋为主 | 上旋加明显的侧旋 |
| 引拍 | 小幅，拍在台面上方 | 拍向身体内引，靠近身体（百度百科「侧拧」） |
| 击球时间 | 高点期附近 | 上升后期到下降前期（百度百科「侧拧」） |
| 手腕 | 屈腕程度和普通反手拉接近 | 手腕内旋到最大，形成"吊腕"，前臂呈"S"型，拍头指向后方（或后方偏右）（百度百科「侧拧」，单一来源） |
| 肘 | 在身体前方 | 架高前顶，和肩差不多高（百度百科「侧拧」） |
| 触球 | 球的后部、后下部，向上刷 | 球的侧后部，绕着球摩擦；侧拧"摩擦球的侧面以避开球的强旋转"（百度百科「侧拧」） |
| 适用 | 台内偏高、下旋不重的球 | 下旋较重的短球也能处理；接发球用得最多 |

两种打法都要右脚上步到台下（PingSkills），打完马上退回平衡的准备姿势。对重下旋的台内球：拍面要打开，向上刷。台内球的下旋越重，越要多摩擦（PingSkills 问答）。

### 6.4 拧拉和反手挑打的边界

Hodges 认为传统反手挑多数情况就是带轻上旋的反手攻（node/3621）。PingSkills 认为拧拉比反方向的"草莓挑"更可靠，所以顶尖选手更常用拧拉（PingSkills Strawberry Flick）。台内到底用拉、拧还是挑，看来球的高度和旋转：高、旋转弱 → 挑或台内拉；低、下旋重 → 拧或搓。

### 6.5 从反手拉下旋到连续进攻

1. **下一板多半是上旋。** 对方挡、快带或反拉，回来的是更快的上旋。拍面要从"立、向上"切换到"关、向前"。PingSkills 说反手对上旋"can be almost horizontal"（挥拍几乎可以水平）。PingSkills 在正手的同类课里指出，拉起下旋后的第二板常打出界，调整方法是拍面更关、挥拍更向前（"a more closed bat and forward swing"）；反手同理（原理类推）。第二板的打法见 [反手拉上旋与反拉](../techniques/backhand-loop-vs-topspin.md)、[快撕](../techniques/backhand-tear.md)、[反手挡](../techniques/backhand-block.md)。
2. **第二板的动作要更紧凑。** 研究发现，来球频率高时反手拉拍速下降，因为骨盆和上躯干转动受限（Iino & Kojima 2016b）；连续拉球时各关节的活动范围也比单板小（Bańkosz 2025）。所以第二板靠更早准备，不靠更大动作。
3. **脚位跟着用途换。** 拉下旋时用右脚在前，可以发力更充分；准备转正手时换成左脚稍前，转换更快（百度百科「反手拉」）。拉完用一个小调整步换回来。
4. **用旋转、弧线换时间。** 慢拉（接近高吊/慢转：高弧线、强上旋）"provides players with more time to prepare for the next stroke"，常作为过渡，为后面的进攻做准备（Li 2025）。反手拉"运用得当可以直接得分，并为正手的冲杀创造机会"（百度百科「反手拉」）。
5. **线路为下一板服务。** 打对方的反手大角、正手大角或中路追身，逼对方移动或者回球质量下降（见 [战术](../techniques/tactics.md)）；半出台能侧身就考虑正手起板（见第 2 节马龙）。
6. **专门练衔接。** 张继科、樊振东的相关说法见第 2 节；第二、三板的衔接，见第 9 节及 [衔接](../techniques/transitions.md)、[步法](../techniques/footwork.md)。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 频繁下网 | 平打撞球；拍面太前倾；拍没有低于球 | 从膝高起拍，薄刷，挥拍更竖直（PingSkills）。规则："Never topspin into the net"（宁出界不下网）；录比赛统计，拉重下旋时出界应和下网差不多多（Hodges） |
| 球又高又慢，没有威胁 | 动作太短；击球时间不对 | 用更长的动作，"just after the highest point"从球的下方击球，随挥朝出球方向（Butterfly 问答 438） |
| 被快搓、急长球顶住，出手仓促 | 站得太近；拍举得太高；引拍太晚 | 离台约一臂远，准备时拍放低，引拍末端有"一停"（Hodges） |
| 往前顶肚子，重心留在后面 | 只想着向上，髋没有向前送 | 重心始终前倾，体会收腹再展腹（"拧毛巾"），配合右胯和膝盖向前顶（百度百科「反手拉」） |
| 重心后坐，球往上飘 | 过于向上发力 | 用腰带动前臂向前上方发力，发力时肘相对固定（百度百科「反手拉」） |
| 只有手臂在动，球软 | 不会用重心；肘这个支点不稳 | 引拍时压低重心，靠重心带动挥拍向上；体会"支肘 → 收肘"的顺序（百度百科「反手拉」） |
| "吃不住球" | 前臂收得过早或过晚 | 前臂的爆发要正好在触球时（百度百科「弧圈球」） |
| 球贴着身体才打，动作憋住 | 脚没到位，击球点太近 | 先用脚调位，让球在身前偏左，不被挤住（百度百科讲快拉："击球点不宜离身体太近"） |
| 手臂横扫过身体，出界或打偏 | 挥拍方向错了 | 向右前上方挥，收拍过肘（PingSkills） |
| 收拍停在胸前 | 向上不够 | 拉下旋时收拍过头顶（PingSkills）。这是拉下旋的标准；拉上旋时收在肩到头之间是正常的，见 `../techniques/backhand-loop-vs-topspin.md` |
| 手腕乱转，稳定性差 | 手腕动作过大 | 除了拧拉，一般拉球手腕的转动幅度要小（百度百科「反手拉」）；先把基本动作的手腕练直（PingSkills） |
| 拉起来以后，第二板就出界或下网 | 拍面没从"立"切换到"关"；还原慢 | 见第 6.5 节，专门练"一拉一挡"（第 9 节） |
| 转正手很慢 | 握拍太偏反手；脚位没换 | 改浅握，拉完调回左脚稍前（百度百科「反手拉」） |

完整的错误索引见 [按症状查错](../training/errors-index.md)。

## 9. 练习方法（入门 → 进阶）

**入门**
1. **徒手挥拍**：对镜练"压低 → 停顿 → 蹬伸 → 收拍过头"（百度百科「弧圈球」列为第一步）。
2. **从拨过渡到拉**：在中台用拨的动作处理带下旋的来球。下网了，就把引拍放低到台面以下，再向上摩擦，体会"提拉"的感觉（百度百科「反手拉」引《全民学乒乓》）。
3. **反弹板或自己抛球**：等球落到下降前期或下降期，向上摩擦，把球拉上台（同上）。
4. **多球**：同伴发中路出台的下旋球，你练拉（百度百科「弧圈球」）。重点体会"先压低重心再起来"（百度百科「反手拉」），遵守"宁出界不下网"。
5. **高引导线练慢转**：在网上方拉一根高绳或横杆，让球从上面过，练薄刷（PingSkills 慢转课）。

**进阶**
6. **多球变化**：喂球变化下旋轻重和长短，模拟真实搓球（PingSkills）。
7. **搓中转拉**：两人对搓，其中一人在固定的某一板转拉（百度百科「弧圈球」）。
8. **一拉一挡**：拉一板下旋，对方挡或快带回来，你接第二板上旋。先拉固定点，再拉不固定点（百度百科「弧圈球」）。
9. **发球抢拉、接发球抢拉**：自己发短下旋，对方搓长到反手，你反手抢拉（百度百科；PingSkills「#38 Backhand 3rd Ball Attack」）。
10. **判断长短**：同伴混着发长球、半出台、短球，你只拉真正出台的球（PingSkills 半出台课）。
11. **拉后衔接**：反手拉下旋 → 反手撕或反拉 → 侧身正手，然后改成随机落点（Falkenberg 类组合练法和随机练习，见 [练习方法总库](../training/drills.md)）。
12. **从练习到比赛**：Hodges 十步法中的一步："发下旋，接对方的搓，拉起来进入相持"。

## 10. 视频检查要点

**机位**：主机位用正面或斜前方 45°（反手推荐机位）。再加拍一段侧面看膝、髋屈伸和上身前倾（侧面测这些最准）。要拍到全身和球台。用 120 或 240 fps 慢动作，分析时用 `--capture-fps` 填真实的拍摄帧率，并加 `--hand right`。**拍面角度、屈腕和伸腕、触球是不是在拍头部位，骨架测不出来，必须看手部放大图（`stroke_NN_zoom.jpg`）。** 拍摄要求见 [拍摄指南](../analysis/recording-guide.md)。

看哪张图：各阶段先看 `stroke_NN_sheet.jpg` 里对应的格；击球瞬间再看 `stroke_NN_contact_raw.jpg` 和 `stroke_NN_zoom.jpg`；看"引拍末端有没有一顿"用 `stroke_NN_strip.jpg`。

| 阶段 | 关键帧里看什么 | 对应指标 |
|---|---|---|
| 识别 | 这一板确实是反手 | `side_guess` |
| 准备 | 离台距离；两脚宽度、哪只脚在前；膝是否微屈；上身是否前倾；拍是否放得够低；非持拍手位置 | `stance_width_ratio`、`knee_angle_deg.{playing,other}.ready` |
| 引拍末 | 是否蹲到最低；拍是否到膝高、低于球；肘是否在身体前方；引拍末端有没有短暂停顿 | `knee_angle_deg.{playing,other}.backswing_end`、`knee_min_deg.{playing,other}`、`trunk_lean_deg.backswing_end`、`elbow_angle_deg.backswing_end`、`weight_shift.backswing_end`、`backswing_ms`、`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg` |
| 迎球挥拍 | 是不是先蹬腿伸膝，再转体，最后手臂（近端到远端）；手臂有没有抢先 | `sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`、`forward_ms`、`peak_hand_speed` |
| 击球瞬间 | 击球点在身前偏左、不贴身；击球高度在腰附近或以下；上身仍然前倾；头稳；非持拍手没有掉到髋以下。**放大图看拍面是否接近垂直、是否在刷球、是否用拍头部位触球** | `contact_height_level`、`contact_forward_m`、`contact_lateral_m`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`trunk_lean_deg.contact`、`knee_angle_deg.{playing,other}.contact`、`free_arm_height_level`、`head_motion` |
| 随挥 | 挥拍路径明显向上；收拍过头、过肘；没有横扫过身体；重心移到右脚，但没有后坐 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`、`elbow_angle_deg.finish`、`follow_ms`、`weight_shift.{finish,delta}` |
| 还原 | 回位距离和速度；拍是否回到身前 | `recovery_dist` |
| 质量 | 骨架覆盖率、可见度够不够；不够就按提示重拍 | `quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

判读提醒：
- `elbow_angle_deg` 是夹角（180° 为伸直）。按 Xing 2022 的结果，从 `backswing_end` 到 `contact`，夹角应该**变大**（肘在伸开）；不变或变小，多半只用了手腕或肘在后拉，看图确认。
- `weight_shift` 的 0 表示重心在持拍侧脚（右脚）上方，1 表示在另一只脚（左脚）上方。反手拉重心从左往右移，`delta` 通常为负；拉下旋以向上为主，左右移动可能很小，别只凭它下结论。
- `knee_min_deg` 越小，说明蹲得越低。和自己以前的视频或同段视频里的攻球比，看有没有"先压低再起来"；不要和论文数值比。
- `swing_path.angle_deg` 应明显为正，且比自己拉上旋时大；接近 0 说明在平打下旋。`finish_height_level` > 1 才说明手腕收到了肩以上，再在图里看是否过头。
- 正面机位测转体不可靠，`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`、`sequence_ms` 只能看趋势。真实帧率低于 100 时，`sequence_ms` 不计算。30 fps 抓不到击球瞬间，只能给大致判断，请用慢动作重拍。指标定义见 [指标说明](../analysis/metrics-reference.md)。

## 11. 自查清单

- [ ] 我先判断了：是下旋，是长球（真出台），下旋有多重。
- [ ] 离台大约一臂远，没有被快搓顶住。
- [ ] 拉下旋时脚位调过了（右脚稍前或两脚平行），拉完又调回方便转正手的位置。
- [ ] 引拍时蹲低，拍到膝高，低于球；拍头朝下，屈腕但放松。
- [ ] 肘在身体前方，不夹死，也不外翻、后撤。
- [ ] 引拍末端有一顿，没有赶着出手。
- [ ] 发力顺序是蹬腿伸膝 → 挺髋 → 转腰腹 → 肩向上顶 → 前臂 → 手腕。
- [ ] 上身始终前倾：没有向前顶肚子，也没有后坐。
- [ ] 击球点在身前偏左、不贴身；击球时间和下旋轻重匹配（重下旋晚一点，前冲早一点）。
- [ ] 薄刷，用拍头部位触球；下旋越重，拍面越立，挥拍越竖直。
- [ ] 收拍过头、过肘，挥向右前上方，没有横扫过身体。
- [ ] 拉完肩马上放松，拍面马上准备"关"，接对方回过来的上旋。
- [ ] 半出台球确认出台了才拉，否则搓或挑；台内球分清该用台内拉还是拧拉。
- [ ] 失误里下网不比出界多。
