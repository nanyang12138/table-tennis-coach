# 反手拧拉（Backhand Banana Flick / Chiquita，香蕉球）

适用：接发球和相持前三板，用反手主动进攻台内短球（第二跳不出台），含短下旋、不转、侧旋、上旋来球｜难度：高（需要大量练习）｜相关卡片：`../techniques/backhand-flick.md` `../techniques/forehand-flick.md` `../techniques/push.md` `../techniques/short-touch.md` `../techniques/long-push.md` `../techniques/receive.md` `../techniques/footwork.md` `../techniques/transitions.md` `../techniques/backhand-tear.md` `../techniques/backhand-loop-vs-backspin.md` `../fundamentals/spin.md` `../fundamentals/racket-angle-timing-contact.md` `../training/physical-and-injury.md` `../techniques/penhold.md`

## 1. 定义与用途

**是什么**：拧拉是"在台面上方打的小弧圈"，同时带上旋和（通常）侧旋（LH:3621）。英文 banana 指球拍的运动轨迹，动作主要靠手腕和前臂（英文维基 Glossary of table tennis）。Hodges 的解释：短球前面有球台挡着，没法像拉下旋那样把拍子引到球下方；于是**向侧面引拍**，用这段侧向挥拍积累速度，同时制造上旋和侧旋。挥拍从侧面开始、弯向球，轨迹像香蕉，所以叫香蕉挑（LH:1311）。日文叫チキータ（chiquita），由捷克选手科贝尔（Petr Korbel）首创，是带侧旋的反手台内拉（日文维基「卓球」）。中文叫"拧"或"拧拉"，百科的"侧拧"词条称其别名"拧拉"（BK-侧拧）。

**为什么有效**：
- 触球更偏侧面，不必正面顶着下旋向上提，所以"拉起来"容易得多（LH:1725）；PingSkills 也说打球的侧面"不会让下旋的全部力量吃进胶皮"（PSQ: Returning a heavy underspin serve）。
- 能进攻几乎所有短球，让对方马上被动（PingSkills Banana Flick）；张继科本人说，他看中的是它"能阻止对手的第三板"（《卓球レポート》2019）。
- 侧旋会打乱对方的击球节奏（LH:1311）。

**地位**：Hodges 2013 年写道，反手挑已迅速成为世界级水平对付短发球的主流接发球（LH:1311）；日文维基称拧拉已成为"现代乒乓球的主要接发球技术"（日文维基「卓球」，无第二来源）。

**起源（只作背景）**：科贝尔 1990 年欧锦赛团体赛首次在实战中使用（《卓球レポート》2019；BK-台内球同说）。百科转述：王皓在教练吴敬平指导下把拧拉和下一板衔接作为整体训练，形成特长（BK-台内球，转引网易 2022）。张继科把它打成"进攻支柱"（见第 2 节）。**不要说"张继科发明拧拉"**。

**本卡包括的几种拧法**：

| 拧法 | 做什么 | 何时用 | 出处 |
|---|---|---|---|
| 全拧 | 没有找到独立定义。由 BK-侧拧"侧拧与全拧相比更不易吃旋转"反推：全拧比侧拧更正对来球旋转，更容易吃转（**本卡反推**）；出球特点暂无出处 | 暂无出处 | BK-侧拧（反推） |
| 侧拧 | 摩擦球的**侧面**（左侧或侧上部）避开强旋转；"与全拧相比更不易吃旋转"，出球侧拐大 | 强下旋、侧下旋短球 | BK-侧拧；LH:1725 |
| 拧不转 | 没有来球旋转可借，得自己制造旋转，难拧得凶；不好拧时改用普通反手挑 | 短不转发球 | LH:2286；PSQ: When to use banana flick |
| 拧上旋/侧上旋 | 触球接近球的**顶部**，借来球上旋反弹；旋转少就打得更平、多一点撞击 | 短上旋、侧上旋发球 | LH:1725；PSQ: Flick / Flip in detail |
| 逆拧（逆チキータ） | 挥拍外形和拧拉相同（原文"チキータのスイングから"），出球侧旋与拧拉**相反**；挥拍方向和香蕉挑具体有什么不同：暂无出处 | 变化、让对方难判断 | 日文维基「卓球」 |
| 草莓挑（strawberry flick） | 挥拍：Hodges 写"拍子从左向右，而香蕉挑是从右向左（右手）"；PingSkills 写香蕉挑"绕到球的左侧"、草莓挑"绕到球的右侧"。做法：手指低于手腕、拍柄端指向台面，手腕向右甩，刷球的右侧（PSQ）。旋转/拐向：双方右手时，挑到对方正手的球会"向外跳开"（LH:1924）。与香蕉挑配合有迷惑性，但不如香蕉挑稳定，多数人只把它当变化用（LH:1924） | 少量变化 | LH:1924；PSQ: Banana and Strawberry Flick；PingSkills Strawberry Flick |

说明：**拧短下旋**：百科明确说"针对台内短下旋球则需采用立起球拍的方式拧球侧面"（BK-侧拧），也就是用侧拧，下旋越强越要打侧面（LH:1725）；什么情况下改用全拧，暂无出处。**香蕉挑本身的侧旋方向/拐向没有找到出处，本卡不给方向**；"逆拧出球侧旋相反"即以香蕉挑为参照。两家描述左右的参照不同（Hodges 说挥拍走向，PingSkills 说绕到球的哪一侧），本卡不自行换算。**逆拧和草莓挑是不是同一种技术，没有找到出处**，不要等同。普通反手挑（较平、轻上旋，近似反手攻）见 `../techniques/backhand-flick.md`。

对不转、上旋发球，Hodges 的战术建议是把拧拉和摆短、搓长**混用**（摆、搓时瞄低甚至向下切）（LH:1311）——这是战术搭配，不是拧拉动作要领，**拧拉本身不要向下压着打**。

**用反手接正手位短球**：Hodges 说"世界上许多甚至大多数顶尖选手这样做，包括马龙"（LH:3650）。老观点认为这会让你处于极端反手位、下一板正手不利；马龙等人证明他们能迅速后退并用正手发力打下一板（LH:1311）。代价：①对方能用同一动作发正手短或反手长时，你可能两边都顾不上，所以正手挑也必须练（LH:3650）；②反手位会出现大空档（BK-台内球）。正手挑见 `../techniques/forehand-flick.md`。

**业余该不该练**：想打进攻、追求较高水平的，应该练拧拉，它在高水平已是常规；但要花大量时间。时间不够就先练普通反手挑。**年长球员会觉得别扭，它会给手臂带来一定负担**（LH:3621）；百科也提醒它对手腕和肘部负荷较大（BK-侧拧）。手腕、肘有旧伤或年龄较大者先读 `../training/physical-and-injury.md`，控制练习量。同一百科词条还给业余者一个保守建议：**面对正手位短球可优先选择摆短、搓球或正手挑打，反手位来球弧线较高时再考虑用侧拧过渡**（BK-侧拧）。这和 Hodges 鼓励用反手接正手短球（LH:3650）并不矛盾：后者说的是高水平的做法，业余者先把反手位拧稳，再按自己的步法和手腕承受力决定要不要往正手位延伸。

## 2. 三位标杆怎么做

**马龙**
- Hodges 2013：马龙几年前就在比赛里用反手挑接**正手位**短球，随后迅速后撤、正手发力打下一板；推荐的马龙拧拉视频里可见他"把拍子引到侧面，然后基本是用手腕把球拉起来"，常用来接正手位短球（LH:1311）。马龙和张继科在旋转的**量和变化**上把这项技术推到了新水平（同上）。
- 2015 年转型期，马龙本人说在改的技术"除了发球，还包括一些反手拧，还有短球上"（央视网 2015-02-05）。
- 比赛实例："6平后马龙上手坚决，接发球直接拧拉得分"（央视网 2017-06-04，世乒赛对庄智渊）。
- 2020 世界杯半决赛对张本智和：全场挑打（flick，未区分拧和挑）张本 50 次、失误 7 次，马龙 12 次、0 失误；马龙的得分球多是"控制好、落点好的慢球"（Edges and Nets 2021，单场统计）。可学的是：**少而准，不为拧而拧**。
- 拍面角度、关节角度：暂无可靠出处。

**张继科**
- 《卓球レポート》2019（水谷隼访谈）：张继科最终把 chiquita 打磨成"进攻支柱"。他本人说：10～15 年前接发球以搓为主，看到 chiquita 后觉得它能阻止对手第三板；不是队里要求，是自己主动研究的。该刊写道：他看了科贝尔的拧拉，认为这项技术还有提升空间，于是反复练习，提高速度、旋转、力量综合起来的球质（记者叙述，非本人原话）。
- 《卓球レポート》2020：他是公认第一位以 chiquita 为核心称霸世界的选手，"现在拧拉的盛行源于张继科也不为过"。
- 央视网 2013 世乒赛前瞻："前三板快速凶狠、反手侧拧质量高，力量和旋转堪称世界最强"。
- 比赛实例：2010 世乒赛团体决赛用"拧拉接两面弧圈"掌握节奏（《卓球レポート》2020 Select.1）；2011 世乒赛对王励勤靠拧拉和步法追分（《卓球レポート》Rising Zhang Jike，detail/014391）；2016 里约决赛"靠着反手拧拉的特长技术"从 4:8 连得五分（新浪体育 2016-08-12）。
- 第三板也拧：2010"直通莫斯科"决胜局，他发正手不转球，马龙回高了，他"直接爆拧"（《乒乓世界》，父亲口述，单一来源）。
- 关键分反手拧拉得分率"八成以上"是**本人访谈自述**，不是技术统计（中华网转新浪 2026-09-27，百科存档截图）。
- 他本人教的练法见第 9 节。动作的拍面角度、触球部位、转腰幅度：**暂无张继科本人的可靠出处**，第 3–5 节用的是通用教学资料，不代表"张继科的做法"。

**樊振东**
- Butterfly 签约公告（2021）称他以"凶狠的香蕉球接发球"和体能支撑的两面弧圈为特点；TeamUSA 2018 称他有"危险的 banana flip"。
- Jin & Ma 2026（Frontiers 论文，分析其比赛）：反手拧拉的使用率显著高于其他技术，是对付短发球的"标志性武器"；接发球第二板用反手发起进攻显著多于正手；反手进攻直接得分率显著高于正手；但**反手进攻之后的连续进攻能力有待提高**，接发球后的线路应更多变。
- 东京奥运男单决赛第五局"以拧拉为主，积极寻求角度变化"，11:3 拿下（央视网 2021-07-31）。央视网 2017-04-16 写他"接发球拧拉"使对手反拉失误；2018-05-03 写对手面对他的"反手拧拉"毫无还手之力。
- 百科转述媒体：他的台内拧拉"绝对质量未必超过张继科，但在变线能力和后续衔接上为进攻型打法提供了新的方向"（BK-台内球，转引网易 2022）。这和上面论文"反手进攻之后连续进攻有待提高"说法相反，见第 3 节"拧后的衔接"。
- 关节角度、拍面角度：暂无可靠出处。

**业余能学的共性**：①先判断再上手，拧不是唯一选项（马龙 12 次 0 失误）；②拧完马上衔接下一板（张继科"拧接两面弧圈"；马龙拧后迅速后撤正手）；③落点和变线比单板力量更重要（樊振东第五局"寻求角度变化"；论文建议线路更多变）。

## 3. 动作分解

**步法总则**：拧拉是"脚先到、手再动"的技术。判断出短球后：
- **正手位/中路短球**：右脚向右前方上步，插到台下，重心压在前脚掌或两脚之间，右膝弯曲前顶（BK-侧拧）。距离远时可用垫步组合：右脚先垫一小步，左脚往斜后方垫步，右脚再向右前方上一步（BK-侧拧）。
- **反手位短球**：反手处理反手位短球时可上持拍同侧脚（右脚）（BK-接发球）；离得近时也可只上半步。
- 对方抛球时就开始预动，用小并步调整，再右脚插入（BK-侧拧练法第四阶段）。
- 上前时重心要完全跟上去，避免臀部掉在后面、手臂伸得过直（BK-台内球）。步法总论见 `../techniques/footwork.md`。

**方向参照**：第 3 节的方向一律按**持拍者本人视角**（"向右"＝持拍者自己的右手边）。Hodges"香蕉挑拍子从右向左"用的参照原文没有说明，和本卡描述的关系暂无出处；读者以 PingSkills"绕到球的左侧"和本卡第 3 节为准。

**术语说明（本卡约定，不是事实断言）**：百科原文写引拍时"手腕内旋至最大形成吊腕"、蓄力时"手腕内拐"，击球时"快速下压肘部带动手腕外旋"（BK-侧拧）。中文教材常用"内旋/外旋"指前臂带着手腕的**转动**；而本卡说的"内收/外展"指手腕向身体一侧弯、再向外打开的**偏斜**。两者是两个分量，本卡分开写：
- **手腕偏斜（本卡约定）**：引拍时手腕向身体一侧弯、拍头转向自己/后方，称"内收"；击球时手腕向外打开、拍头向前上甩出、拍面"亮"出来，称"外展"。
- **前臂转动**：引拍时转到百科说的"内旋至最大"，击球时反向转动（百科"外旋"），和手腕外展同时发生。**前臂旋转的解剖方向（旋前还是旋后）和幅度暂无可靠测量出处，以下为教学描述**；本卡不给角度。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 接发球站位离台约一小步（BK-台内球）；两脚比肩略宽，右脚稍前，脚跟提起（BK-接发球），随时能向右前方上步 | 站太远：PingSkills 案例中，接发球者为照顾长球站得偏后，结果拧拉总是来不及，只能改搓（PSQ: Backhand Banana Flip） |
| 膝 | 两膝微屈（BK-接发球），有弹性 | 直腿，起动慢 |
| 髋 | 略前屈，臀部不后坐 | 坐得低，上步时重心跟不上 |
| 腰/躯干 | 上体稍前倾（BK-接发球） | 后仰 |
| 肩 | 放松 | 耸肩 |
| 大臂/肘 | 肘在体前，不夹死 | 肘贴身，伸不进台内 |
| 前臂 | 置于体前，手位较高、不低于台面（BK-台内球） | 手放到台面以下，接短球要先抬手 |
| 手腕 | 放松，不提前扣 | 提前锁死 |
| 手指/握拍 | 握得稍虚，保持手腕灵活 | 捏死拍 |
| 拍面/拍头 | 拍在正反手之间，略偏反手 | 拍放太低 |
| 视线/头 | 从对方手里拿球时就开始盯球，提早判断长短（PSQ: Backhand Banana Flip） | 等球过网才判断 |

### 3.2 引拍（与上步同时完成）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚插到台下，落地与引拍完成基本同步 | 只伸手不上脚 |
| 膝 | 右膝弯曲前顶（BK-侧拧） | 膝伸直，身体够球 |
| 髋 | 髋跟着右脚向前，重心压上 | 臀部留在后面（BK-台内球） |
| 腰/躯干 | 上体前压到球的上方，身体侧对球台（BK-侧拧），为下一步腰向右转留出空间 | 上体直立，离球远 |
| 肩 | 右肩随身体前送 | 肩缩在后面 |
| 大臂/肘 | **肘前顶、架高**，与肩基本同高或略低（BK-侧拧）；肘不能完全僵硬死撑 | 肘低垂，拍头抬不起来、不能"吊腕" |
| 前臂 | 位置：向身体内收，拍引到右腹前，前臂整体呈"S"形（BK-侧拧）。转动：随手腕一起转到百科说的"内旋至最大"（BK-侧拧），为击球时反向转动留出行程；解剖方向和幅度暂无出处 | 前臂向后拉开，变成大引拍；前臂没转到位，击球时只剩手腕一点点甩 |
| 手腕 | **内收到最大**，形成"吊腕"（BK-侧拧）；拍向侧面引，而不是向下引（LH:1311） | **手腕内收不够**（吊腕不到位），没有可甩的距离 |
| 手指/握拍 | 拇指用力压住拍面（BK-侧拧）；其余手指不死握 | 全手攥紧，腕部发僵 |
| 拍面/拍头 | 拍面侧垂，拍头指向后方（BK-侧拧）；拍靠近身体，用身体"含"住球，但球与拍之间要留出挥拍距离（BK-侧拧） | 拍离身体远；或拍贴球太近，没距离加速 |
| 视线/头 | 头在球的上方，盯来球弹起 | 头偏在一侧，判断不准高度 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地，重心稳在右脚前掌 | 边打边往后退 |
| 膝 | 保持弯曲，可轻微蹬伸 | 猛站起，弧线变高 |
| 髋 | 稳定，随腰小幅转动 | 髋大幅转动，动作变大 |
| 腰/躯干 | 腰向右侧转动发力（BK-侧拧）；加入腰部时有"展腹"动作（BK-侧拧练法第三阶段） | 只有手动，身体僵住（能拧上台但没质量） |
| 肩 | 右肩带动大臂向前 | 右肩后撤 |
| 大臂/肘 | **快速下压肘部**带动手腕（BK-侧拧）；肘作为支点 | 肘一起向外甩，弧线高 |
| 前臂 | 位置：以肘为支点向前、向右上方送出，幅度比手腕小（"手腕和前臂为主"见英文维基）。转动：由引拍时的"内旋至最大"开始**反向转动**，由下压肘部带动（百科"快速下压肘部带动手腕外旋"，BK-侧拧），和手腕外展同时进行（教学描述） | 前臂大幅横扫；前臂不转、只靠手腕弯，拍面打不开 |
| 手腕 | 由内收快速向外展开，是主要加速来源（教学描述） | 手腕不动，只用手臂推 |
| 手指/握拍 | 触球前一刻手指握紧 | 一直死握 |
| 拍面/拍头 | 拍头从指向后方，沿弧线（香蕉形）绕向球的侧面 | 直线向前推出去 |
| 视线/头 | 头稳定 | 头跟着抬起 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚在台下踩稳，左脚在后支撑 | 两脚都在后面，手臂伸直够球 |
| 膝 | 右膝仍屈 | 膝伸直 |
| 髋 | 髋在球的后下方，不后坐 | 臀部后坐 |
| 腰/躯干 | 上体在球上方、略前倾 | 上体后仰 |
| 肩 | 放松，不耸 | 用力耸肩 |
| 大臂/肘 | 肘在身前，微屈，不伸直 | 肘伸直锁死（击球点太远） |
| 前臂 | 反向转动（"外旋"）仍在进行、接近完成，带着拍面由侧垂转向更"亮"（教学描述，幅度暂无出处） | 前臂还在向后找球（击球太晚）；前臂已转完、拍面早亮开，只能平推 |
| 手腕 | 外展加速，摩擦球的侧上部或左侧部（BK-侧拧） | 手腕甩完了才碰到球（时机错位） |
| 手指/握拍 | 拇指压拍，手指握紧，让拍面稳定 | 拍面在手里晃 |
| 拍面/拍头 | 触球时拍面比引拍时更"打开"、更亮，用拍头部位触球（BK-侧拧）；摩擦为主，"刷"球（LH:1311） | 拍面关得太死，正撞 |
| 视线/头 | 盯住击球点 | 提前抬头看对方 |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚开始蹬地准备后撤 | 随挥时还在向前冲 |
| 膝 | 保持弹性 | 膝锁住 |
| 髋 | 开始回收 | 继续前送失去平衡 |

| 前臂 | 短促，方向朝目标 | 向右侧大幅甩出 |

### 拧后的衔接

- **训练把拧和下一板当成一个整体**：王皓早期拧拉成绩不好，原因是拧拉与下一板衔接脱节；吴敬平让他把二者作为整体训练（BK-台内球，转引网易）。
- **常见下一板**：①对方挡/快带回反手 → 反手快撕或反手拉（见 `../techniques/backhand-tear.md`、`../techniques/backhand-loop-vs-topspin.md`）；②回正手 → 迅速后撤正手拉（马龙，LH:1311）；张继科的套路是"拧拉接两面弧圈"（《卓球レポート》2020）。
- **防追身**：对手对付总在台上反手抢攻的接发球者，常用的办法之一是把第一板打到你的肘部（追身）（LH:2652）。拧完要立刻回中，不要停在台下欣赏。
- **研究提示**：10 名国家级选手"反手拧→反手快挡"与"反手拧→正手快挡"两种衔接中，后者在多数关键时刻、尤其击球附近拍速更高，随挥结束时无差异；接正手那一板空间范围更大、击打和随挥阶段用时更长（Niu 2026，只报告了拍速和时长）。由此"拧完先退出台下再转体"是**本卡推断，论文未给出**。
- **樊振东的衔接，两种说法相反**：论文比赛统计说他"反手进攻之后的连续进攻能力有待提高"（Jin & Ma 2026；注意论文说的是 backhand attacking techniques，不专指拧拉）；百科转述媒体说他的台内拧拉"在变线能力和后续衔接上为进攻型打法提供了新的方向"（BK-台内球，转引网易 2022）。两者来源性质不同（论文统计 vs 百科转述），本卡不判谁对；"即使是标杆，衔接也是重点"是**本卡推断**。正反手转换见 `../techniques/transitions.md`。

## 4. 拍面角度、击球点、击球时间、触球部位

**拍面角度**（统一口径：拍面与台面的夹角，90° 为垂直，小于 90° 前倾，大于 90° 后仰，见 `../fundamentals/racket-angle-timing-contact.md`）：
- 引拍：拍面侧垂，拍头朝后（BK-侧拧）。
- 触球：比引拍时更打开、更"亮"（BK-侧拧）。百科给过具体度数，但只有一处来源且原网页打不开，本卡不采用。
- 按来球调：下旋越强越要多刷；上旋或不转可以打得更平（PSQ: Flick / Flip in detail，适用于所有挑类）。对上旋来球，触球接近球的**顶部**（LH:1725）。

**击球点**：在身体前方舒适的位置，靠步法调整到位（BK-侧拧）；在台内、头在球上方；肘微屈，不伸直；拍与身体距离近（"含"住球），但拍与球之间留出加速距离（BK-侧拧）。

**击球时间**（五分法：上升期→上升后期→高点期→下降前期→下降后期）：
- Hodges：对下旋通常在**刚过最高点**触球；对侧旋、上旋更多在**最高点**（LH:1311）。
- 百科词条内部有三种说法：一处"高点期或下降初期"，一处"上升后期、高点期或下降前期"，"技术定义与特点"一段还说"适用于上升前期、上升后期、高点期和下降前期"（BK-侧拧）。
- 本卡取共同区间：**高点期前后**，下旋强时可稍晚（刚过高点），上旋/不转可在高点。太早来不及引拍，太晚球已低于网、易下网。

**触球部位**：
- 侧拧：球的左侧或侧上部（BK-侧拧）；PingSkills 描述香蕉挑"绕到球的左侧"（PSQ: Banana and Strawberry Flick）。
- 出界偏长时：更多刷球的侧面，甚至更多从球上方刷（PSQ: Banana flick）。
- 对重下旋：侧面触球，不正对下旋（LH:1725；PSQ: Returning a heavy underspin serve）。
- 对上旋：接近球的顶部（LH:1725）。

## 5. 发力：顺序、方向、摩擦与撞击

**顺序**：上步、右脚踩实、重心压上 → 腰向右转（展腹）→ 肘下压、前臂转出 → 手腕由内收到外展、最后加速（BK-侧拧）。强调身体、前臂、手腕联动的"鞭打"，不是只靠手腕；百科练法第三阶段才加入腰部，说明腰是在手腕手感建立之后再加的（BK-侧拧）。

**方向**：向前上，同时带侧向，轨迹呈弧形（LH:1311）。下旋越强，向上成分越多；上旋来球更向前。手臂**不要向外甩**太多，否则弧线过高（BK-侧拧）。口诀式要求是"拧"而不是"甩"（BK-侧拧）。

**摩擦与撞击**：拧拉以摩擦为主，触球是"擦过去"的动作（LH:1311）。对上旋、不转可以多一点撞击（PSQ: Flick / Flip in detail）。没有找到摩擦与撞击比例的测量数据，本卡不给比例。

**利用来球旋转**：
- 对下旋：下旋会以上旋的形式"反弹"出来，接发者往往能拧出很强的上旋（LH:2286）。
- 对不转：没有旋转可借，旋转得全靠自己制造，所以不转球比转球更难凶狠地拧（LH:2286）。
- 对侧旋（双方都是右手）：对正手钟摆发球，Hodges 说来球侧旋与拧拉的侧旋"相合"，感觉像拉下旋，要自己加上旋；侧旋方向相反时像拉上旋，旋转从胶皮上弹回，像一次小反拉（LH:1311）。侧旋分辨见 `../fundamentals/spin.md`。

## 6. 面对不同来球的调整

| 来球 | 怎么调 | 出处 |
|---|---|---|
| 短下旋（重） | 侧拧：打侧面、多刷、向上成分多；刚过高点触球。没把握就摆短、劈长——学的阶段先搓回去更稳 | LH:1725；LH:1311；PSQ: Returning a heavy underspin serve |
| 短下旋（中、轻） | 拧拉最舒服的球；PingSkills 甚至说对下旋比对上旋**更容易** | PSQ: When to use banana flick |
| 低而近网、带一点下旋 | 香蕉挑/草莓挑都有效 | PSQ: Banana and Strawberry Flick |
| 短不转 | 没有旋转可借，得自己制造旋转，难拧得凶；可以打得更平、多一点撞击，或改用普通反手挑；战术上和摆短、搓长混用 | LH:2286；PSQ: Flick / Flip in detail；PSQ: When to use banana flick；LH:1311 |
| 侧下旋 | 按侧旋方向调整触球侧面和出球方向（见第 5 节） | LH:1311 |
| 上旋、侧上旋短球 | 触球接近球顶部，借来球上旋反弹；旋转少就打得更平、多一点撞击 | LH:1725；PSQ: Flick / Flip in detail |
| 正手位短球 | 高水平：右脚大步插到正手位台下用反手拧，回来要快，同时正手挑也要会（LH:3650；LH:1311；步法 BK-侧拧）。业余：百科建议优先摆短、搓球或正手挑打，反手位来球弧线较高时再用侧拧过渡（BK-侧拧） | LH:3650；LH:1311；BK-侧拧 |
| 半出台球 | 第二跳出台就直接拉（见 `../techniques/backhand-loop-vs-backspin.md`），不出台再拧 | BK-台内球（半出台定义） |
| 偏高的短球 | 机会球：加大力量"爆拧"，或改反手挑打 | 张继科例（《乒乓世界》2010） |
| 第三板（对方摆短回来） | 同样处理，发球后要提前判断回球长短 | 张继科例 |

**落点**：通常拧大角，凶的可以打对方中路（肘部，正反手转换点）（LH:1311）。要和摆短、搓长混用：只拧不搓，好手会退后等你，拉起来更轻松（LH:1311）。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| **手腕打开不够**①：拧不出旋转，球软、平 | 引拍没扣到底（**内收不足**），没有"吊腕"，拍头没指向后方，没有可甩的距离 | 引拍时先把手腕扣到底、拍头指后，再出手；第一阶段原地只练手腕刷球侧面（BK-侧拧） |
| **手腕打开不够**②：球被推出去、旋转弱，拍面像一块板 | 击球时手腕没有充分**外展**、前臂没反向转，拍面没"亮"出来（BK-侧拧"触球瞬间拍型可更亮"），只用手臂推 | 先在第一阶段体会"下压肘部带动手腕外旋"、拍面从侧垂转亮的感觉（BK-侧拧）；手部放大图检查触球帧拍面是否比引拍时打开 |
| 总是来不及，只能改搓 | **站位太远**，为照顾长球站得偏后；判断晚 | 接发球站离台约一小步；从对方拿球时就盯球，提早判断长短；单独反复练这一项（PSQ: Backhand Banana Flip） |
| 下网，尤其对低的强下旋 | **击球点太晚**（球已下落低于网），或正面顶下旋 | 在高点前后触球；改打侧面，加大向上成分（LH:1311、LH:1725） |
| 球撞出去出界或直接下网，没有弧线 | **只拧不摩擦**：手腕转了，但拍面在"打"球而不是"刷"球 | 拍面稍打开，用拍头部位擦过球的侧上部；出界时多刷侧面或更从上方刷（PSQ: Banana flick） |
| 弧线高、被对方打 | 手臂向外甩幅度过大 | 肘下压、手腕甩，手臂不外甩；随挥短（BK-侧拧） |
| 动作大、慢，对方读得懂 | 引拍幅度过大 | 压缩到手腕前臂范围（BK-侧拧） |
| 动作发僵、手腕手肘酸痛 | 肘完全死撑、握拍过紧，或练习量过大 | 肘保持灵活；触球前才握紧；控制量，年长者尤其注意（BK-侧拧；LH:3621；`../training/physical-and-injury.md`） |
| 够着打，手臂伸直，臀部在后面 | 只伸手不上步 | 右脚插到台下，重心跟上去（BK-台内球、BK-侧拧） |
| 拧完被对方一板打死 | 拧后不还原、没有衔接 | 拧完立即蹬地后撤、拍回反手位；练"拧＋下一板"组合（BK-侧拧、BK-台内球） |
| 每个短球都拧，失误多、被预判 | 只会拧，没有摆短、劈长变化 | 先学控制；拧、摆短、搓长混用（LH:1311） |
| 正手位空档被利用 | 过度依赖反手接正手短球 | 同时练正手挑和摆短（LH:3650，`../techniques/forehand-flick.md`） |

## 9. 练习方法（入门 → 进阶）

第 1、2 条由陪练或多球供**台内短球**，来球按张继科的顺序从上旋/不转开始（《卓球レポート》2019）。

1. **徒手/原地手腕**：站在台内小三角位置，肘前顶支撑、手腕内收吊腕、拇指压拍，只用手腕小幅转动刷球侧面，把球提上台；击球点选上升后期或高点期（BK-侧拧第一阶段）。
2. **加前臂**：手腕发力后，前臂自然向前送一小段，肘微内收避免僵硬；仍以手腕为主，腰暂不发力（BK-侧拧第二阶段）。
3. **逐步加下旋强度**：在前两阶段基础上，按张继科本人的顺序，从上旋来球过渡到稍带下旋的球，最后拧强下旋（《卓球レポート》2019）。
4. **加腰和全身**：击球时展腹，左手抬起配合平衡（BK-侧拧第三阶段）。
5. **加步法**：对方抛球即预动，小并步调整，右脚插入台内、重心压上，在移动中完成（BK-侧拧第四阶段）。先反手位，再中路，最后正手位短球。
6. **多球接发球**：请发球好的人用一筐球连续发短球，你只练拧、不打完这一分，捡完再来（LH:1311）。
7. **混合判断**：发球方随机发短下旋、不转、侧旋、长球；你拧、摆短、搓长混用（LH:1311），长球直接拉。
8. **拧＋衔接**：拧斜线 → 陪练挡回或快带 → 你接第二板，把两板当一个动作练。王皓的做法是拧后接快抽（取代原来的快撕）（BK-台内球）；回正手位就正手拉（LH:1311）。
9. **变线和变旋转**：同一动作拧大角、中路（追肘）；进阶后少量加入逆拧或草莓挑做变化（LH:1924，PingSkills）。
10. **比赛化**：在接发球轮主动使用，并统计自己拧的成功率和失误类型，回看第 8 节。

多球、组合练习的格式见 `../training/drills.md`。

## 10. 视频检查要点

**机位**：主机位用**正面或斜前 45°**（站在对面球台后方偏右，略高于台面），看手腕内收、拍头方向、肘的高度和触球时拍面；补一个**侧面**机位（站在拧拉者右侧）看右脚插入台下、膝、髋、上体前压（`../analysis/recording-guide.md`）。手机慢动作 120/240 fps，导出后用 `--capture-fps` 校正，否则 `backswing_ms`、`forward_ms` 都不对。拧拉动作小，脚本可能找不到挥拍（`NO_STROKES`），这时用 `--start/--end` 截出这一板再跑。

| 阶段 | 关键帧看什么 | 对应指标（脚本输出） |
|---|---|---|
| 准备 | 离台约一小步、膝微屈、手位不低于台面 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 引拍/上步 | 右脚是否插到台下、重心是否压到右脚；肘是否架高；引拍是否小 | `weight_shift.backswing_end`（应靠近 0＝持拍侧右脚）、`knee_min_deg.playing`、`trunk_lean_deg.backswing_end`、`elbow_angle_deg.backswing_end`、`backswing_ms`（应很短） |
| 迎球挥拍 | 肘是否下压作支点，大臂是否外甩 | `elbow_body_gap_m`、`forward_ms`、`peak_hand_speed`、`shoulder_turn_deg` |
| 击球瞬间 | 击球点在身前、台内；肘是否伸直；上体是否在球上方；头是否稳 | `contact_forward_m`、`contact_lateral_m`、`contact_height_level`、`elbow_angle_deg.contact`（接近 180° 说明手臂伸直、站远了）、`trunk_lean_deg.contact`、`head_motion`、`free_arm_height_level` |
| 随挥 | 是否向外大甩、弧线方向 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`（过高＝外甩/上撩）、`elbow_angle_deg.finish`、`follow_ms` |
| 还原 | 是否马上后撤、回中 | `weight_shift.finish`、`weight_shift.delta`、`recovery_dist` |
| 整体 | 发力顺序和数据可信度 | `sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`（台内动作小，参考价值低）、`side_guess`、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

**注意**：用反手接**正手位**短球时，手腕可能在持拍一侧，`side_guess` 可能误判为正手，要人工核对画面。

**手腕和拍面必须看手部放大图**（`stroke_NN_zoom.jpg`，击球前后几帧）：引拍末是否吊腕、拍头指后；触球帧拍面是否比引拍时打开、是否用拍头部位擦球；随挥时拍头是否指向出球方向而不是向外甩。骨架模型测不出拍面，也测不准前臂旋转（Shrestha 2026）。`quality.reliable` 为假，或手腕在 `low_visibility_parts` 里时，不下结论，按拍摄指南重拍。

## 11. 自查清单

- [ ] 接发球站位离台约一小步，手位不低于台面
- [ ] 从对方拿球时就盯球，提早判断长短和旋转
- [ ] 判断出短球后先动脚：右脚插到台下，重心压上，右膝前顶
- [ ] 肘前顶架高；手腕内收到底，拍头指向后方，拇指压拍
- [ ] 拍靠近身体，但和球之间留出加速距离
- [ ] 高点期前后触球，不等球掉到网下
- [ ] 下旋强时打球的侧面，刷而不撞；上旋来球触球接近顶部、借反弹，上旋/不转可打得更平（不向下压）
- [ ] 击球时手腕外展、前臂反向转，触球帧拍面比引拍时更"亮"
- [ ] 腰向右转、肘下压、手腕外展，顺序连贯
- [ ] 手臂不外甩，随挥短，拍头指向目标
- [ ] 能拧大角、也能拧中路（追肘）
- [ ] 拧完立即蹬地后撤、拍回反手位，准备第二板
- [ ] 拧、摆短、搓长能混用，不每球都拧
- [ ] 能用反手接正手位短球，同时也会正手挑
- [ ] 手腕、肘没有疼痛；年长者控制练习量
