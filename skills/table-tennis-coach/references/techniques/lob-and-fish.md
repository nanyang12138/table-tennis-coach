# 放高球与中远台防守：放高球、鱼跃、中远台挡（Lob, Fish / Topspin Defense, Passive Block away from the Table）

适用场景：被对方扣杀或发力弧圈压到中远台、远台，来不及也没把握反拉时；以及防守之后怎样转回进攻｜难度：中级 → 高级｜相关卡片：`../techniques/forehand-loop-vs-topspin.md` `../techniques/backhand-loop-vs-topspin.md` `../techniques/forehand-counter-block.md` `../techniques/backhand-block.md` `../techniques/chop.md` `../techniques/forehand-smash.md` `../techniques/short-touch.md` `../techniques/footwork.md` `../techniques/transitions.md` `../techniques/tactics.md` `../fundamentals/ready-stance.md` `../fundamentals/spin.md`

> 全文按右手持拍写，左手持拍者左右互换。拍面角度用"拍面与台面的夹角"口径：90° 为垂直，小于 90° 为前倾（中国教育电视台《击球技巧》）。离台距离：按扬州市职业大学教学资料的顺序，大致分为近台 30–50 cm 以内、中近台 50–70 cm、中远台 70–100 cm、远台 1 m 以外（原文后三项名称有笔误，按顺序理解）。本卡标题和正文里的"中远台防守"泛指离台防守，不限于 70–100 cm；"中远台挡"指离台稍远（大致中台到中远台）时的挡。

## 1. 定义与用途

**放高球（lob）**：在被动时退到远台，把球向上打出很高的弧线，落点深、带强上旋，用来争取调整时间（百度百科"放高球"）。正手、反手都可以放（同上；中文维基"乒乓球"的技术列表也写"正、反手放高球"）。美国教练 Larry Hodges 的说法是："A lob is basically a very high loop."（高球基本上就是一板很高的弧圈），所以拉球好的人往往学得快。

**鱼跃（fish，又叫上旋防守 topspin defense）**：离台较远（中远台到远台）时，用比放高球低得多的弧线回球，带上旋，有时加侧旋，落点深，落台后主要向前窜而不是向上弹（Hodges《Topspin Defense》：离台很远，well away from the table）。日文维基"卓球"的定义：在中台、远台（中陣・後陣）用比高球低的弧线回球，击球时间比挡球晚，在过了最高点之后击球。命名：英文 fish / topspin defense（Hodges），日文フィッシュ；没有找到统一的中文规范名称，本套卡片统一译作"鱼跃"（注意不要和救球的"鱼跃"扑救混淆）。

**中远台挡（passive block away from the table）**：离台稍远、来不及引拍时，以小动作把球挡回。日文维基把挡（block）定义为在前台、中台，在来球上升期或最高点把球挡回的防守技术；离台再远、击球时间再晚，就过渡成了鱼跃。近台挡的完整动作见 `../techniques/forehand-counter-block.md`、`../techniques/backhand-block.md`。

| | 放高球 | 鱼跃 | 中远台挡 | 防守型反拉 |
|---|---|---|---|---|
| 站位 | 远台 | 离台较远（中远台到远台，Hodges：well away from the table） | 中台到中远台 | 离台较远（Hodges：from well off the table） |
| 弧线 | 很高 | 低得多，过网后快速下坠 | 低、平 | 高于普通对拉 |
| 击球时间 | 下降后期（百度百科） | 过了最高点（日文维基） | 比近台挡晚 | 下降期，约膝高（Hodges《Counterlooping》） |
| 触球部位 | 见第 4 节（两家说法不同） | 球的后部（Hodges） | 中部偏上，随来球旋转调（推理） | 偏后 |
| 目的 | 争取时间，逼对方远距离扣杀 | 把球压低、压深，慢慢打回相持 | 先把球保住 | 用上旋顶回去，带进攻性 |

防守型反拉的动作见 `../techniques/forehand-loop-vs-topspin.md`；削球（chop）见 `../techniques/chop.md`。

**为什么有用、为什么少用：**
- 好处：球高又深，对方只能在离台较远处扣杀，扣过来的球因空气阻力很快减速，你有时间反应（Hodges《Lobbing》）；能消耗对方体力，抓住对方急于得分的心态诱使其失误（百度百科）；练放高球还能练远台步法和对重扣的反应（Hodges，2020-07-20 每周技巧）。
- 代价：放高球是唯一一种"请对方扣杀"的防守，除非对手明显比你弱或很不会扣高球，否则用它丢的分多于得的分。所以"lob only when absolutely necessary"（只在万不得已时放高球，Hodges）；百度百科也写"通常情况下不要使用，在迫不得已时再用"。Hodges 还提醒：常放高球容易养成"轻易退台"的坏习惯（2025-01-13 每周技巧）。
- Hodges 把防守分成四类：挡（最重要）、削、鱼跃和放高球、防守型反拉，并说鱼跃、放高球唯一的毛病是在不必用的时候用（2024-03-11 每周技巧《The Four Types of Defense》）。据此本卡建议业余进攻型选手：能挡、能反拉就不鱼跃，能鱼跃就不放高球（本卡据 Hodges "挡最重要""只在不得不时才鱼跃、放高球"推出）。

**反过来**：对手放高球时，你可以扣（见 `../techniques/forehand-smash.md`），也可以偶尔吊短（drop shot），见 6.6；你放高球时被对手吊短怎么办，见 6.7。

## 2. 三位标杆怎么做

**说明**：三人都是进攻型选手。没有找到可靠出处描述他们放高球、鱼跃的具体动作，这方面暂无可靠出处，下面只写有出处的防守与相持特点。

- **马龙**：评论文章观察到，他会不时离台退一步，给自己更多空间打出变化；也愿意让年轻对手先发动进攻，相信自己能把这一分拖住，再打出反击（Khaleej Times，2021-08-05）。人民网报道 2024 年澳门世界杯对户上隼辅，"马龙凭借相持优势以两个11比3赢下比赛"。但相持也有输的时候：2019 年亚洲杯决赛，"樊振东则凭借更强的相持能力，连得3分拉开领跑"（央视网）。
- **张继科**：2008 年的评论写他"衔接快速、反拉反带速度快"，"相持能力也是比较强的"（搜狐体育）。2016 年的评论认为他强在前几板凶狠的进攻，马龙强在相持、失误少（新浪体育）。资料提到的是他反拉反带速度快；他放高球、鱼跃的情况暂无可靠出处。
- **樊振东**：央视网多次把他的胜因归于相持能力（2019 亚洲杯、2021 休斯敦世乒赛决赛）。一篇 2026 年的比赛统计论文（40 场，2021–2023 年）发现他在相持段得分率最高，同时指出相持中正手大角度保护不够，来球稍晚时转髋不充分而失误（Jin & Ma 2026）。

**业余可以学的**：被压后不急着一板打死，先把球保住、再找机会反击（马龙的例子）；有能力时优先反拉、反带（张继科以反拉反带见长，搜狐 2008）；被调动到正手大角时，步法和转髋要跟上（樊振东论文指出的弱点）。

## 3. 动作分解

基准动作：**远台正手放高球**，对付对方的扣杀或发力弧圈。表里标了出处的是资料原话的转述；没标出处的，是按"高球就是很高的弧圈"（Hodges）和发力原理推出来的建议，不是某本教材的规定。每个表后面写反手放高球、鱼跃、中远台挡的不同之处。各表"拍面/拍头"行的角度都按第 4 节随来球调。

### 3.1 准备（含退台移动）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 一看出要被扣，**先尽快跑到球要去的地方**；有经验后能预判扣杀方向（Hodges）。到位时侧身站，左脚在前（百度百科；Hodges：连反手也尽量侧身） | 原地等球；退成正对球台 |
| 膝 | 屈膝、重心放低，随时能再次启动 | 直腿站着看对方扣 |
| 髋 | 随侧身向右转，髋侧对来球 | 髋正对球台，转体空间没了 |
| 腰/躯干 | 上体稍前倾，不躲球 | 怕被打，上体后仰 |
| 肩 | 左肩朝向来球方向，肩放松 | 耸肩，肩紧 |
| 大臂/肘 | 自然下垂，离开身体，留出向上挥的空间 | 肘夹在身侧 |
| 前臂 | 放松，球拍放在身体右前方较低处 | 球拍举在胸前高处，往下再引浪费时间 |
| 手腕 | 自然，不锁死 | 手腕僵硬 |
| 手指/握拍 | 握松；Hodges 的自测：别人从背后能把拍抽走 | 越紧张握得越死 |
| 拍面/拍头 | 拍头略低，准备从下往上 | 拍头朝上，只能往下砍 |
| 视线/头 | 看对方的拍形和挥拍方向判断落点；读清是扣杀还是拉冲 | 只盯球，判断晚 |

- **反手放高球**：同样尽量侧身（Hodges），右手持拍者反手侧身就是右肩朝向来球。球直冲身体来时，侧身让开，用正手或反手接，不要正对球台只用手臂反手放，那样几乎没有旋转（Hodges）。
- **鱼跃**：站位离台较远，比中远台挡更靠后；球拍放在来球路线略下方（Hodges："start with racket just below the ball"）。
- **中远台挡**：拍放在身前，几乎不引拍，重心稍前，准备迎前。

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落到右脚（百度百科：击球时重心从右脚移到左脚） | 重心在左脚，后面没东西可转移 |
| 膝 | 右膝更屈，蓄力；Hodges：好的高球需要很大力量，要像拉弧圈一样用腿和上身 | 腿不动，只靠手 |
| 髋 | 向右后转 | 不转髋 |
| 腰/躯干 | 随球拍向右下转、略下沉 | 上体直立不动 |
| 肩 | 右肩略低于左肩 | 右肩抬高（变成扣杀的引拍） |
| 大臂/肘 | 肘略伸开，大臂向右后下方 | 肘抬高 |
| 前臂 | **下沉，把球拍引到身体右后下方**（百度百科） | 引拍向后上方 |
| 手腕 | 自然或略下垂 | 手腕翘起 |
| 手指/握拍 | 仍然松 | 引拍时握紧 |
| 拍面/拍头 | 拍面角度按第 4 节随来球调（百度百科写稍前倾），拍头朝下后方 | 拍面正对来球，准备平托而不是向上擦 |
| 视线/头 | 盯来球，头保持稳定 | 头随引拍乱动 |

- **节奏**：Hodges 写"Taking a slow backswing"（慢引拍）。来球快、你又离得远，慢引拍能等球落到合适的高度，也避免引拍太猛把球打出界。
- **反手放高球**：重心在左脚，球拍引到身体左下方，再从左下向右上挥。没有找到专门的反手动作资料，这条是镜像推理。
- **鱼跃**：引拍比放高球小，球拍不必降那么低（推理）。
- **中远台挡**：只有很小的向后动作，主要靠调整拍形。

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地，重心开始从右脚移向左脚（百度百科） | 脚不动，只抡手臂 |
| 膝 | 右膝蹬伸，向上发力 | 膝一直弯着不伸 |
| 髋 | 向左转，带动上身 | 髋不转，手臂先动 |
| 腰/躯干 | 由右下向左上转，像拉弧圈那样"扫"过去（Hodges："sweeping motion, as in a loop"） | 弯腰向前扑 |
| 肩 | 右肩由低到高 | 肩不参与 |
| 大臂/肘 | **上臂向前上方挥动**（百度百科） | 只用前臂抽 |
| 前臂 | 随之向上拉起（百度百科） | 前臂向前压 |
| 手腕 | 跟随前臂，触球前不提前甩 | 提前甩腕，拍面乱 |
| 手指/握拍 | 挥动中保持手感，不突然握死 | 握死，球拍发僵 |
| 拍面/拍头 | 保持引拍时调好的角度（按第 4 节），拍头由下向上 | 拍面越挥越乱，拍头不向上走，变成平托 |
| 视线/头 | 盯住球一直到拍 | 抬头看球飞向哪里 |

- **方向**：**以向上为主**，"drive the ball mostly upward, dissipating the ball's speed by sending it upwards"（主要向上打，靠把球送高来卸掉来球的速度，Hodges）。向前用力太多，球会直接出界。
- **反手放高球**：从身体左下向右上挥，同样以向上为主；重心从左脚向右脚转移（推理，按正手镜像）；仍然要侧身、用腿和上身，像拉弧圈一样擦球（Hodges）。
- **鱼跃**：方向**以向前为主、略向上**（Hodges："a mostly forward, slightly upward stroke"），可以当成一板轻的弧圈，或者多带一点上旋的对攻（Hodges）。
- **中远台挡**：小幅向前迎，借来球的力量；离台越远，来球越慢，只放拍子挡往往送不回去，这时就要加一点向前上的挥动，也就成了鱼跃（推理）。

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心正在由右脚移向左脚 | 重心还压在右脚，或已经倒在左脚 |
| 膝 | 蹬伸进行中 | 已经站直 |
| 髋 | 转到接近正对来球方向 | 髋转过头 |
| 腰/躯干 | 稳定，上体不后仰 | 上体后仰，球飞高出界 |
| 肩 | 右肩继续向上 | 肩停住 |
| 大臂/肘 | 手臂较舒展，肘不夹 | 肘夹死，只能用手腕 |
| 前臂 | 正在向上拉 | 前臂停顿 |
| 手腕 | 稳定；想加侧旋时，手腕可以略带一点横向动作（推理） | 手腕松垮 |
| 手指/握拍 | 触球一刻有控制，但不僵 | 一触球就握死 |
| 拍面/拍头 | 角度按第 4 节随来球调，**擦**球而不是托球（Hodges："Try grazing the ball, as in a loop"） | 只是平托、没有向上擦，高而不转 |
| 视线/头 | 头稳，眼看触球点 | 头先转向对方 |

- **旋转**：加上旋和侧旋（Hodges）。日文维基写，高球落台时受旋转影响大，加强烈的上下旋或侧拐 / 螺旋旋（corkspin）能让对方难扣；侧拐见 `../fundamentals/spin.md`。
- **反手放高球**：触球时手腕稳定，向上擦球；正对球台只用手臂反手放，几乎没有旋转（Hodges）。
- **鱼跃**：触球**后部**（Hodges："Contact the ball on the back (unlike lobbing, where you'd contact the ball underneath)"），在过了最高点后击球（日文维基）。
- **中远台挡**：拍形按来球旋转调整，来球上旋越强，拍面越前倾（日文维基：挡反胶时拍面角度必须调准）。

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落到左脚（百度百科） | 重心留在右脚，下一板启动慢 |
| 膝 | 左膝承重，仍保持微屈 | 双膝站直 |
| 髋 | 转到正对或略过来球方向即停 | 转过头，失去平衡 |
| 腰/躯干 | 随挥向左上，不后仰 | 后仰着收拍 |
| 肩 | 右肩高于左肩 | 右肩不起来，收拍停在胸前 |
| 大臂/肘 | 大臂随挥至头部左前上方 | 大臂停在胸前 |
| 前臂 | 继续向上 | 突然刹车 |
| 手腕 | 自然放松 | 随挥时甩腕，拍面乱 |
| 手指/握拍 | 放松 | 收拍时握死 |
| 拍面/拍头 | 球拍收在头部左前上方，收得高（按"向上为主"推出） | 收拍向前平推 |
| 视线/头 | 立刻看对方的位置和拍形 | 盯着自己的球看它落没落台 |

- **反手放高球**：收拍到头部右前上方，重心落到右脚（推理，按正手镜像）。
- **鱼跃**：随挥更向前，收拍比放高球低（按 Hodges"向前为主"推出）。
- **中远台挡**：几乎没有随挥。

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 放完高球立刻回到能兼顾两角的位置，仍在远台，不要急着上前；对方扣得弱时再上前反攻（按 Hodges“弱扣就反攻”推出）；重心在前脚掌，对方吊短时能向前起动（见 6.7） | 站着看；或一放完就往前冲，下一板被扣在脚下；重心压在脚跟，吊短扑不到 |
| 膝 | 屈膝，准备下一次启动（向后、向两侧，也向前） | 直腿 |
| 髋 | 回到侧对或正对之间 | 仍然侧着，转不回来 |
| 腰/躯干 | 稍前倾 | 后仰喘气 |
| 肩 | 放松 | 耸肩紧张 |
| 大臂/肘 | 回到身侧 | 手臂举在头顶不放下 |
| 前臂 | 球拍回到身体右前方较低处，准备下一板放高或鱼跃；有反击机会时提高 | 拍子垂到腿边 |
| 手腕 | 自然 | 握紧不放松，手腕发僵 |
| 手指/握拍 | 松握 | 握紧不放松 |
| 拍面/拍头 | 拍头朝前 | 拍头朝下，来不及接下一板 |
| 视线/头 | 看对方准备扣哪里，同时找反攻机会（Hodges："you should always be looking for a way to counter-attack"） | 只顾防，不看机会 |

- **反手放高球**：收拍后同样把球拍放回身体前方较低处，转回能兼顾两角的准备姿势（推理）。
- **鱼跃**：球低，对方回球更快，还原要更快（推理）；PingSkills 把鱼跃说成"慢慢打回相持"（work back into the rally）的手段，还原时可以逐步向台前靠（推理）。
- 反手位被调到远台时，Hodges 建议：先把这一板打得尽量有效（主要是落点深、上旋好），再想想是怎么被调成这样的，以后避免（2015-05-11 每周技巧）。

## 4. 拍面角度、击球点、击球时间、触球部位

| 项目 | 放高球 | 鱼跃 | 中远台挡 |
|---|---|---|---|
| 拍面角度 | 两家不同：百度百科"稍前倾"（对应触中上部）；Hodges 触球下部、主要向上挥，拍面相对更立（推理）。来球上旋越强，拍面越需要前倾 | 没有找到明确说法；触球后部、向前为主，拍面比放高球更立（推理） | 随来球旋转调，上旋越强越前倾（日文维基） |
| 击球点 | 身体右侧，较低（球已落到下降后期） | 身体右侧，比放高球稍高（推理） | 身体前方 |
| 击球时间 | 下降后期（百度百科） | 过了最高点之后（日文维基） | 比近台挡晚 |
| 触球部位 | 两家不同：百度百科写"中上部"；Hodges 写"球的下部"（相对鱼跃触后部而言） | 后部（Hodges） | 中部偏上（推理） |

- **关于放高球触球部位的分歧**：百度百科（单一来源）写"拍面稍前倾……摩擦球的中上部"；Hodges 写放高球触球在球下面。两家共同点是：**以向上为主、以摩擦为主、要转**。实战里按出球效果调：球飞不高、往前冲就是触球太靠上；球没有旋转、"飘"就是在托球而不是擦球。
- **为什么击球时间晚**：远台来球在下降段，球速明显减慢（Hodges：扣杀因空气阻力很快减速），旋转减弱较少（推理）；晚打能多一点时间，也更容易把球送高（推理）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：右脚蹬地 → 髋、腰向左上转 → 上臂向前上方挥动 → 前臂向上拉起 → 触球（百度百科的动作要点；Hodges 说要像弧圈一样用腿和上身）。百度百科写"以整个手臂的发力为主"，Hodges 强调腿和上身，两者不矛盾：手臂是主要挥动部分，腿和腰提供力量来源。
- **方向**：放高球**主要向上**，用"向上送"把来球的速度卸掉（Hodges）；鱼跃**主要向前、略向上**（Hodges）。Hodges 讲对拉时的规律同样适用：离台越远，触球越靠后、挥拍越向上；离台越近、来球越快越转，触球越靠上、挥拍越向前（《Counterlooping》）。
- **摩擦与撞击**：放高球以摩擦为主（"grazing"，Hodges），百度百科写放高球"上旋力强"。鱼跃摩擦为主兼一点撞击（"一板轻的弧圈"）。中远台挡以撞击、借力为主。
- **力量大小**：好的高球需要相当大的力量（Hodges），因为要把一板重扣送到很高很深的地方；力量主要用在向上，不是向前。

## 6. 面对不同来球的调整

### 6.1 按来球

| 来球 | 特点 | 怎么调整 |
|---|---|---|
| 平扣（扣杀） | 速度快、旋转弱，减速快（Hodges） | 退远一点，等球减速；放高球或鱼跃都可以 |
| 发力弧圈、前冲 | 上旋强，落台后往前窜 | 拍面更前倾；离台不太远时优先反拉，被压得更远时鱼跃（见 `../techniques/forehand-loop-vs-topspin.md`） |
| 直冲身体的球 | 没有空间 | 侧身让开，用正手或反手放，不要正对球台只用手臂（Hodges） |
| 对方扣得弱 | 机会 | 反攻：对攻、削、反拉，有机会反扣（Hodges）；见 6.5 |
| 带侧旋的扣杀 | 落台后会拐 | 往球拐过去的那一侧移动 |

### 6.2 按站位

- 离台不太远、还有时间：首选防守型反拉；被压到更远：鱼跃。
- 远台、来不及调整：放高球。
- 被调到反手大角、只能斜后退时：Hodges 说此时多半只能"反手轻拉或鱼跃"，真正被动时才削或放高球（2015-05-11 每周技巧）。

### 6.3 落点与战术

- **深度最重要**：没有深度，对方能扣出很大角度，你完全够不着；高度主要是为了控制（Hodges：高球三要素是高度、深度、旋转，"Depth is most important of all"）。
- 上旋、侧旋交替，让球落台后突然拐（Hodges）。
- 放到你最擅长防守那一侧的斜对角，对方就难以直线扣你的弱侧；对脚步慢的对手，多调动他（Hodges）。
- 能消耗对手体力；Hodges 提到有些高手在大比分落后时会故意放高球，让对手下一局体力下降。

### 6.4 防守时的步法

- **先到位再击球**：判断出要被扣，立刻向球要去的地方移动（Hodges）。
- **侧身到位**：退台时尽量侧身，即使是反手（Hodges）。正手放高球左脚在前（百度百科）。
- **移动距离大**：防守的步法和进攻不一样，要覆盖的距离大得多（PingSkills《Defensive Footwork》）。
- **还原位置**：放完高球留在远台能兼顾两角的位置，不要急着上前；看到弱球再上（按 Hodges 的“找机会反攻”推出）。
- **也要能向前**：放高球后对方可能吊短，上前的步法见 6.7。
- **斜后退是被动选择**：Hodges 把被调到正手后再去补反手大角的三种移动分成斜前、横向、斜后，斜后退"通常只在万不得已时用"（2015-05-11）。
- 步法基础与组合步法见 `../techniques/footwork.md`；准备姿势与离台站位见 `../fundamentals/ready-stance.md`。

### 6.5 防守转反攻

- **心态**：放高球的时候，始终在找反攻或者回到相持的机会（Hodges）。
- **机会从哪来**：高球加上旋，把扣杀方逼得更远，对方的扣杀就会变弱，这时抓住机会反攻（PingSkills《Lobbing Tactics》课程简介）。日文维基也写：用鱼跃顶住对方进攻，等对方攻不下去时一口气反击。
- **反攻用什么**：突然的对攻、削球或反拉，常常能扭转回合；看到机会可以反扣；对方扣得弱就反攻（Hodges）。
- **反扣要看时机**：PingSkills 教练说反扣很难，因为离台远、来球快，放高球更稳；但来球到了合适位置可以直接反扣，或用上旋拉回去，因为放高球本来就会丢掉大多数分（PingSkills 问答）。Hodges 也写"Counter-smash if you see a chance"（有机会就反扣）。
- **过渡**：从远台回到中近台的衔接见 `../techniques/transitions.md`；削中反攻战术见 `../techniques/chop.md`，整体战术见 `../techniques/tactics.md`。

### 6.6 反过来：对手放高球时吊短（Drop Shot off a Lob）

- **做法**：尽量在球刚弹起时触球，手放松卸掉来球的速度，加一点侧旋，让球短而低（PingSkills《Drop Shot off a Lob》）。
- **什么时候用**：PingSkills 说对付很会放高球的对手时，吊短可以直接得分或把对方引到台前，让你下一板更好打；高球落得短时更容易吊。
- **分歧**：Hodges 认为一般不要对高球吊短，除非你认为能直接得分；深的高球很难吊好，短的高球直接扣死就行，所以吊短通常成功率低（《Smashing Lobs》）。
- **本卡的结论**：吊短只作**偶尔的变化**，主要手段仍是扣高球（见 `../techniques/forehand-smash.md`）。动作细节见 `../techniques/short-touch.md` 6.3。

### 6.7 放高球时被对手吊短（Returning a Drop Shot as the Lobber）

- **为什么要专门练**：吊短就是要把你从远台引到台前（PS《Drop Shot off a Lob》）。但 Hodges 说，你若赶到了这个球，对方就"让你回到了这一分里"（"you've let him back into the point"，《Smashing Lobs》）；PingSkills 也说，对方若把球打慢，退台一方其实有不少时间上前打出一板好球，吊短方反而丢了主动（PS 问答《Drop shot instead of smash》）。所以被吊短不是死球，扑不到、或冲上前回一板高球才是常丢的分。
- **预防**：高球要深。高球落在对方台面靠近网处更容易被吊（PS《Drop Shot off a Lob》）；削球同理，削得深对方就难吊（PS《How to Return Drop Shots as a Defender》）。这是 6.3"深度最重要"的又一个理由。
- **起动时机**：吊短要在球刚弹起时触球（PS《Drop Shot off a Lob》），伪装法是先摆出扣杀的架势，最后一刻贴近弹起点再吊（PS 问答《Dropshot deception》）。所以信号是：对方不等球下落，而是**向前贴近弹起点、拍子收小**。本卡建议：对方触球那一刻做小跳（`../techniques/footwork.md` 第 1 节），一看出这个信号就起动，不要等球过网；自己的高球落得浅时，提前把重心放到前脚掌。

**怎样上前（分部位；除注明出处的外均为本卡建议）**

| 部位 | 要领 | 做错了会怎样 |
|---|---|---|
| 脚/步法 | 离台远，一步到不了：先几步小而快的跑步向前，最后一步**右脚**插到台下，正手、反手位都上右脚，脚尖着地便于进出（PS《Moving In for Short Balls》）；到位时保持平衡（PS《Moving In and Out as a Defensive Player》） | 只伸手够球，没有控制；最后一步上左脚，拍子离网远 |
| 膝 | 最后一步右膝弯曲前顶，刹住身体 | 冲过头撞台，或身体还在前冲时出手，球飞长 |
| 髋 | 随上步略转向来球 | 髋正对球台冲进来，反手位球够不着 |
| 腰/躯干 | 前倾探入，不趴到台上 | 直着身子跑，到台前再弯腰，来不及 |
| 肩 | 放松，持拍侧肩随右脚向前 | 耸肩，手发僵 |
| 大臂/肘 | 肘在身前，大臂前伸把拍送进台内 | 肘夹在身侧，只能用手腕捞 |
| 前臂 | 跑动中就把拍子提到台面以上 | 跑到了才抬拍，错过上升期 |
| 手腕 | 稳定，不大幅勾腕 | 甩腕，回球忽高忽长 |
| 手指/握拍 | 握松，便于"软"触球 | 跑得急握死拍，球弹高 |
| 拍面/拍头 | 拍头朝前；拍面按要回的球调（摆短、搓见 `../techniques/short-touch.md`、`../techniques/push.md`） | 拍头朝下往上捞，只能回高 |
| 视线/头 | 盯球的弹起高度和第二跳位置；头放低，靠近球的高度 | 抬头看对方，判断不出还剩多少时间 |

**击球时间**
- 赶得早：上升期或刚弹起时触球，按下表回短、快搓或挑。
- 来不及：打下降期。但短球不打会在本方台面再弹一次（短球定义见 `../techniques/footwork.md` 3.10），这里的"下降期"只到它第二次落台之前，比远台的下降期短得多；本卡建议把拍子先伸到第二跳落点前方等球。下降期搓控制最好、易加转，但逼不住对方（`../techniques/push.md` 第 4 节，Hodges），所以要靠深度弥补。

**回球用什么**（总原则：上前要快、贴近球、回球压低，或再吊短，或快搓到底线，PS《How to Return Drop Shots as a Defender》）

| 情况 | 回球 | 说明 |
|---|---|---|
| 到得早，球在上升期、高于网 | 快搓到底线，或挑（flick） | 吊短常带一点侧旋（PS），旋转一般不强，按对方触球动作判断（本卡推断）；挑见 `../techniques/forehand-flick.md`、`../techniques/backhand-flick.md` |
| 到得及，球低 | 摆短或快搓到底线（PS） | 回短后对方也得上前，难以直接重扣（本卡推理） |
| 来不及，下降期 | 搓到底线深处 | 下降期压不住对方，深度是唯一的补偿（本卡建议） |
| 球快落到台面（或已出台下坠），只能从下往上捞 | 被迫回高 | 本卡不建议主动回高：高球管用，是因为对方要在远处扣，扣杀因空气阻力很快减速（Hodges《Lobbing》）；你在台前时这段减速时间没有了。回完立即退台（PS 问答《Lobbing》：看到球飞高就快退） |

- PingSkills 另有一课"蛇形球"（snake shot），专门对付吊短，带强旋转、击球后做迷惑动作（PS《How to Play the Snake Shot》）；属于花样球，本卡不作业余首选（本卡建议）。

**回完之后**
- 回了短而低的球：留在中近台。击球后右脚蹬地，直接退回平衡位置，准备对方再短或长到能拉（PS《Moving In for Short Balls》）；不必退回远台（本卡建议）。
- 搓到底线：退到中近台准备对方拉；退时先看对方往哪攻，先拉开空间，方向明确再转身、并步到位（PS《Moving In and Out as a Defensive Player》）。之后按本卡的挡、鱼跃处理。
- 回了高球：立即退回远台，侧身准备下一板放高球。
- 都不要贴台站住：吊短后扣杀时，对方若靠台极近，可对准身体扣，使其难以让位（CETV《拉扣吊结合》）。
- 进出衔接另见 `../techniques/transitions.md`、`../techniques/chop.md`（第 6 节"对方吊短"）。

## 7. 关键数据参考

- **没有找到放高球、鱼跃的可靠测量数据**（角度、拍速、时间），本卡不给数值，只写定性描述。
- 离台距离划分（扬州市职业大学，原文后三项名称有笔误，按顺序理解）：中远台 70–100 cm，远台 1 m 以外。鱼跃、防守型反拉按 Hodges 的"离台很远"，大致落在中远台到远台。
- **本卡不采用的数字**：
  - 英文维基写放高球"约 5 米高"、术语表写"退台 4–6 米"，都没有引用出处。
  - Hodges 写好的高球"落在离端线 1 英尺以内"，是单一来源的个人经验，只说明"越深越好"。
  - Hodges 写鱼跃"离台 8 英尺或更远开始"、"过网至少约 1 英尺，弧线离台面约 1–4 英尺时更有效（over the table）"，同样是单一来源的个人经验，只说明"离台较远""弧线比高球低得多，越低越有效"。

## 8. 常见错误：表现 → 原因 → 纠正

1. **能挡、能拉的球也放高球** → 放高球好玩、容易上瘾，养成轻易退台的习惯（Hodges） → 规定自己：能挡、能反拉的不鱼跃，能鱼跃的不放高球（本卡建议，见第 1 节）；练习赛里限制放高球次数。
2. **高球落点浅，被对方大角度扣死** → 向前的力不够或球太低 → 以深度为第一目标，宁可高一点也要深（Hodges）。
3. **高球不转，被轻松扣杀** → 只是平托、没有向上擦；或正对球台只用手臂 → 侧身，像拉弧圈一样擦球，加上旋、侧旋（Hodges）。早期器材下高球"高而不转"，进攻方很好打（百度百科）。
4. **球直接出界** → 引拍太快、向前用力太多 → 慢引拍，主要向上（Hodges）。
5. **鱼跃冒高，被扣** → 触球太靠下，像放高球那样往上捞 → 触球后部，向前为主（Hodges）。
6. **鱼跃下网或飞出** → 离台远却按近台挡的拍形和力量打 → 离台越远，触球越靠后、越向上（Hodges《Counterlooping》）。
7. **放完站着看，下一板够不着** → 没有还原意识 → 放完立刻回到远台中间，屈膝准备。
8. **放完急着上前，被扣在脚下** → 误判对方会扣弱 → 看到对方扣弱再上前。
9. **对方明明扣弱了还在放高球** → 只想保球，不找机会 → 对方扣弱就反攻（Hodges：Off a weak smash, counter attack；PingSkills《Lobbing Tactics》：look for a weaker ball）。
10. **来球位置不好也硬反扣，连续失误** → 不看时机 → 来球不在合适位置先放高球保住；位置合适时可以反扣或反拉（PingSkills 问答；Hodges：Counter-smash if you see a chance）。
11. **反手大角被调后直退，退成正对球台** → 步法不侧身 → 退台时侧身，正手放高左脚在前（百度百科；Hodges）。
12. **（进攻方）好的深高球也吊短** → 想讨巧 → 深高球不吊短，主要靠扣（Hodges：深高球很难吊好）；吊短只作偶尔变化，PingSkills 说高球落短时更容易吊；Hodges 则认为短高球直接扣死更好。
13. **被吊短时站着看，或等球过网才起动** → 重心压在脚跟；没读出对方"贴近弹起点、拍子收小"的信号 → 放完重心放前脚掌，对方触球时小跳，看出信号就起动；高球放深，少给对方吊的机会（6.7）。
14. **冲到台前回一板高球，被近距离扣死** → 来不及时本能往上捞 → 能摆短就摆短、能搓深就搓深，回球压低（PS《How to Return Drop Shots as a Defender》）；捞不起时才回高，回完立即退（6.7）。
15. **冲过头撞台、只伸手够球** → 最后一步没有上右脚、没屈膝刹住 → 最后一步右脚插入台下（PS《Moving In for Short Balls》），右膝前顶制动（本卡建议）。
16. **接完吊短贴台不动，下一板被扣身体** → 回球后没蹬回 → 回短留中近台，搓长退到中近台，回高退回远台，都不贴台（6.7，CETV《拉扣吊结合》）。

## 9. 练习方法（入门 → 进阶）

以下练法是根据本卡要领设计的建议，不是某本教材规定的标准练法。

1. **徒手动作**：侧身站好，左脚在前，慢慢做"前臂下沉 → 上臂向前上 → 收拍到头部左前上方"，体会重心从右脚到左脚。
2. **多球放高球**：同伴在台前用多球中速拉或攻到你的正手，你退到远台放高球，只要求高、深。会了以后再练反手侧身放。
3. **加旋转**：同样练法，每板有意识地擦球，交替加上旋和侧旋，让同伴说出球落台后怎么拐。Hodges 说加旋转很难，只能靠多练。
4. **鱼跃**：同伴在中近台连续拉弧圈，你离台较远回鱼跃，要求弧线低、落点深，过网后快速下坠。
5. **放高球与扣高球对练**：一人扣、一人放。放的人练远台步法和对重扣的反应（Hodges，2020-07-20 每周技巧）；扣的人顺便练扣高球（推理；见 `../techniques/forehand-smash.md`）。
6. **防守转反攻**：同伴连续扣几板后，故意扣一板弱球，你立即上前反拉、对攻或反扣；进阶时由同伴随机决定什么时候给弱球。
7. **步法**：从近台起，听信号退台、侧身到位，放一板后还原到远台中间，再左右移动放第二板。
8. **（进攻方）吊短**：同伴放高球，偶尔落短，你练球刚弹起就吊短，手放松，加一点侧旋。
9. **放高球的一方接吊短**：同伴扣几板后随机吊短，你从远台起动、最后一步上右脚，按 6.7 选回球（摆短、搓深或挑），回完按回球类型退位；先由同伴提前喊"短"，再改成不提示；进阶时同伴吊短后接着扣或拉，练"上前—退回"连贯（思路同 `../techniques/chop.md` 的"削—上前接吊短—退回"）。

## 10. 视频检查要点

**机位**：主机位放在持拍手一侧（右侧）的正侧面，镜头对着你**放高球时站的位置**（远台），不是对着球台边，保证从脚到举得最高的球拍都在画面内，人占画面高度一半以上。条件允许时，在你身后加一个机位，看对方扣到哪里、你的回球深不深。用 120/240 帧慢动作；手机慢动作导出的视频用 `--capture-fps` 填入真实帧率。对手入镜时用 `--player` 指定跟踪对象。详见 `../analysis/recording-guide.md`。

**先看的提醒**：
- 先看 `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`。远台时人容易太小，不可靠就照拍摄指南靠近一点重拍。
- 放高球挥拍慢，可能出现 `POSSIBLE_SLOWMO` 提醒，先确认帧率；也可能自动找不到挥拍（`NO_STROKES`），按 `../analysis/analysis-protocol.md` 处理。
- 脚本**量不出离台距离、球的高度和落点**，这些只能从画面里看球台边和球。

| 阶段（关键帧） | 看什么 | 对应指标 |
|---|---|---|
| 识别 | 这一板是正手还是反手 | `side_guess` |
| 准备 | 是否侧身、屈膝、站宽 | `stance_width_ratio`、`knee_angle_deg.playing.ready`、`knee_angle_deg.other.ready` |
| 引拍结束 | 重心是否在右脚；球拍是否引到右后下方；是否慢引拍 | `weight_shift.backswing_end`、`knee_angle_deg.playing.backswing_end`、`knee_min_deg.playing`、`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`、`elbow_angle_deg.backswing_end`、`trunk_lean_deg.backswing_end`、`backswing_ms` |
| 迎球挥拍 | 挥拍方向是向上为主（高球）还是向前为主（鱼跃）；腿、腰是否参与 | `swing_path.up`、`swing_path.horiz`、`swing_path.angle_deg`、`sequence_ms.hip`、`sequence_ms.shoulder`、`sequence_ms.elbow`、`sequence_order_ok`、`forward_ms`、`peak_hand_speed` |
| 击球瞬间 | 击球点高低、是否在身体右侧；上体是否后仰；肘是否夹死 | `contact_height_level`、`contact_lateral_m`、`contact_forward_m`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`trunk_lean_deg.contact`、`knee_angle_deg.playing.contact`、`head_motion` |
| 随挥 | 收拍是否高（高球）、是否偏前（鱼跃）；重心是否到左脚 | `finish_height_level`、`elbow_angle_deg.finish`、`weight_shift.finish`、`weight_shift.delta`、`follow_ms`、`free_arm_height_level` |
| 还原 | 持拍手是否回到准备时相对身体的位置（场上站位只能看画面） | `recovery_dist` |

**拍面角度只能看手部放大图**（`stroke_NN_zoom.jpg`，击球前后各 2 帧）：看拍面角度是否随来球调整（第 4 节）；是在擦球还是在托球（托球时拍面正对来球、几乎没有向上的拍头动作）；触球前后拍面是否稳定。骨架模型测不出拍面和握拍。

**判读要点**：
- 拿同一人、同一机位的拉上旋做对照：放高球的 `swing_path.angle_deg` 应明显更大（更向上）、`finish_height_level` 更高；鱼跃介于两者之间。不设绝对阈值。
- 放高球的 `contact_height_level` 通常比拉上旋低（下降后期击球）；如果接近肩高，多半是打早了。
- `weight_shift.delta` 应为正（重心从右脚移到左脚）；接近 0 说明只用了手臂。
- `recovery_dist` 只看持拍手有没有回到准备时相对身体的位置，量不出你在场上站在哪里；放高球收拍很高，如果 `recovery_dist` 偏大，说明拍子没及时放回身体右前方较低处。是否回到远台能兼顾两角的位置，只能看画面。
- 单机位测转体不可靠，`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg` 只看趋势。

**被吊短上前（6.7）**：同一正侧面机位拉远，画面同时包含你放高球的位置和球网，人会变小，先看 `quality.reliable`。起动时刻和跑动距离脚本量不出，逐帧看画面：对方触球那一帧你是否已开始向前、最后一步是不是右脚。接短球动作小，可能识别不到挥拍（`NO_STROKES`），按 `../analysis/analysis-protocol.md` 处理。识别到时看：击球瞬间是否探入到位（`contact_forward_m`、`trunk_lean_deg.contact`、`knee_angle_deg.playing.contact`、`stance_width_ratio`），是否在往上捞（`swing_path.angle_deg` 明显偏大、`finish_height_level` 偏高说明在回高），回完是否收回（`recovery_dist`）。拍面看手部放大图：摆短、搓时拍面后仰、几乎不前送；拍头朝下往上兜就是在捞。

## 11. 自查清单

- [ ] 能挡、能反拉的球没有放高球
- [ ] 一判断要被扣，先移动到位，侧身站（正手左脚在前）
- [ ] 引拍慢，球拍引到身体右后下方
- [ ] 放高球以向上为主，鱼跃以向前为主
- [ ] 腿和腰参与发力，重心从右脚移到左脚
- [ ] 拍面按来球调；是向上擦球，不是平托；能加上旋和侧旋
- [ ] 高球落点深，比高度更重视深度
- [ ] 鱼跃弧线低、触球后部，不冒高
- [ ] 来球直冲身体时侧身让开，不正对球台只用手臂
- [ ] 反手放高球也尽量侧身，不正对球台只用手臂（Hodges）
- [ ] 放完立刻还原到远台中间，不急着上前
- [ ] 对方扣弱时能马上反攻；来球位置合适时敢反扣、反拉
- [ ] （进攻方）对高球吊短只作偶尔变化
- [ ] 被吊短时及时起动、最后一步上右脚；回球压低（摆短或搓深），不在台前回高；回完按回球类型退位
