# 正手快带与正手挡（Forehand Counter-Drive & Forehand Block）

适用场景：近台、中近台被对手的弧圈球或攻球压在正手位，来不及退台或来不及大引拍｜难度：挡 ★★☆☆☆，快带、减力挡、加力带 ★★★☆☆｜相关卡片：`../techniques/forehand-drive.md` `../techniques/forehand-loop-vs-topspin.md` `../techniques/backhand-block.md` `../techniques/backhand-tear.md` `../techniques/forehand-smash.md` `../techniques/lob-and-fish.md` `../techniques/transitions.md` `../techniques/footwork.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/spin.md`

> 全文按右手横拍写；左手持拍者左右互换。直拍的推挡体系见 `../techniques/penhold.md`。

## 1. 定义与用途

**一组"借力"技术。** 对手先发力（弧圈、攻球）时，用小动作在来球弹起后较早的时刻，借来球的速度和旋转回击。按自己加多少力，从轻到重分为：

| 名称 | 是什么 | 什么时候用 |
|---|---|---|
| **减力挡**（off-speed block，又称 soft / dead block） | 触球瞬间球拍停止前送，甚至稍向后收，把来球的力"卸"掉，回球轻、短、节奏变慢 [BK-减力挡]。注意：[BK-减力挡] 原词条讲推挡和长胶打法，本卡只借用其中"触球瞬间停住或后收""先挡中等力量扣杀再挡前冲"这类通用要点 | 对方退台等着打你的快球时，突然放轻，打乱节奏 [Hodges-3619]；对付冲力大的来球 [BK-减力挡] |
| **正手挡**（forehand block） | 来球刚弹起时把球拍放到球前，球带着接近原来的能量弹回去 [en-TT]；拍面接近垂直，前臂、手腕稍向前送 [BK-挡球] | 被动、来球很快很冲、来不及引拍时保命 [Hodges-3003]；对手先上手、上旋打到正手时，用它留在相持里 [PS-forehand-block] |
| **正手快带**（forehand counter-drive；百科给的英文是 quick drive；反手卡称 topspin block） | 由正手拉球演变而来，中近台，借来球速度和旋转，在上升后期或高点期击球，动作紧凑，引拍到身体侧前方，以前臂为主 [BK-快带] | 相持中或由被动转主动时，处理速度较快的上旋来球；对手先抢攻、自己来不及退台时使用 [BK-快带] |
| **加力带**（counter-hit / aggressive block；反手对应的叫加力挡，见 `../techniques/backhand-block.md`） | 本卡对这一档的叫法，没有专讲它的出处。日文维基说挡可以变化回球质量："卸力回""原样回""把自己的力加上去回"（自分の力を上乗せして返す）；又说反击（カウンター）基本就是在挡的基础上"引拍稍大、迎着来球挥过去"（テイクバックをやや大きく取り、飛球に合わせて振り抜く）[ja-卓球] | 来球质量弱时要会进攻：反拉、扣杀，"或至少一板很凶的挡"（at least a very aggressive block）[Hodges-3003] |

**相关术语：**
- **反击**（counter）分两类：进攻型的**反拉**（counter-loop，カウンタードライブ）和偏防守的**反挡**（counter-block，カウンターブロック）[ja-卓球]。本卡讲后者以及介于两者之间的快带；反拉见 `../techniques/forehand-loop-vs-topspin.md`。
- **借力**：借来球的力量回击，与主动发力相对；对速度快的来球主要靠调整拍形，借来球撞拍的反弹力回送，自己发力较少 [BK-借力]。
- **"吸"**：百科列出的对付弧圈球的回击手段是"挡、快带、推挤、吸、反手快撕、反拉、攻打以及对拉弧圈球" [BK-弧圈球]。这是唯一出处，没有动作定义，**暂无可靠出处说明其要领**，本卡不展开。
- **"顶住"**：中国教育电视台的两面攻课程写道："两面攻战术对付弧圈球打法应坚持近台，用快带顶住对方的弧圈球，伺机采用近台反拉或中等力量扣杀弧圈球，然后转入连续进攻" [CETV-两面攻]。这就是快带在近台对抗里的位置：先顶住，再找机会转攻。

**和正手反拉的区别**（详细取舍见第 6 节）：

| | 挡 / 减力挡 | 快带 / 加力带 | 正手反拉 |
|---|---|---|---|
| 站位 | 近台，离台约 40–50 cm（单一来源）[BK-挡球] | 中近台 [BK-快带] | 能舒服反拉大多数上旋球的距离 [Hodges-3003] |
| 击球时间 | 上升期 [BK-挡球] | 上升后期或高点期 [BK-快带] | 上升后期、高点 [BK-弧圈球] |
| 引拍 | 几乎没有 | 小，到身体侧前方 [BK-快带] | 引拍后拉幅度要小（反拉提示）；前冲弧圈的通则是球拍与来球同高或稍低 [BK-弧圈球] |
| 发力 | 借力 / 卸力 | 借力为主，加前臂 | 腰、髋、前臂发力更多，以摩擦为主 [BK-弧圈球] |
| 回球 | 速度来自来球，旋转很少 [ja-卓球] | 出手快、弧线低、落点活 [BK-快带] | 自己制造上旋，盖过来球旋转 [Hodges-36] |
| 风险 | 普通被动挡回相对低（本卡判断，无出处）；但只会挡是弱点 [Hodges-3003] | 无出处给评级 | 见下 |

风险一行注：日文维基说反击类技术（反拉和反挡都算）都属高风险高回报 [ja-卓球]，所以本卡讲的反挡也不是"稳妥技术"。

## 2. 三位标杆怎么做

**先说清楚：** 关于马龙、张继科、樊振东**正手快带或正手挡的具体动作**（引拍多大、拍面多少度、在哪个时刻击球），本次没找到可靠出处，以下只写有出处的相关事实，不推测动作细节。

- **张继科**：2008 年搜狐体育评论说，他"除保持了衔接快速、反拉反带速度快等特长以外，明显增加了正手的抢拉抢冲的比例" [ZJK-搜狐2008]。原文没说"反带"是正手还是反手，也没展开"速度快"具体指什么。
- **马龙**：Khaleej Times 的评论文章（作者观点，不是技术分析）说他"愿意让年轻对手先发动进攻"（allowing his younger opponent to initiate the attack），相信自己能把这一分拖住再反击；并说"正手非常强，那一侧的相持大多是他赢" [ML-Khaleej]。另一份单场分析指出，他习惯侧身用正手覆盖反手位，所以正手大角度"常常特别空"，被对手专打 [ML-EN2021]。启示：越爱侧身，越要练好正手位的应急挡和快带。Hodges 根据马龙视频描述其**正手拉球**：绕头顶竖轴转体、头只稍前移、击球点几乎在身体正侧 [Hodges-3147]；两侧身体都参与转动、身体不前冲 [Hodges-3223]。这是拉球的观察，不是挡球。
- **樊振东**：一篇 2026 年论文统计了 2021–2023 年 40 场比赛，认为他"相持中正手保护不够；来球稍晚时，不能主动转髋，导致失误"，建议加强正手大角度的保护 [FZD-Jin2026]。这是论文作者的统计解读，不是教练组评价。它说明近台正手处理的一个要害：**来球一晚、髋转不过来就容易失误**（论文原话）；此时手臂单独去够是本卡推论。

## 3. 动作分解

以**正手快带**为主线；"挡""减力挡""加力带"与之不同的地方在表中单独标出。

**非持拍手（free arm，右手持拍者即左臂）每个阶段单列一行。** 为什么要管它：非持拍手通过躯干与持拍手联动，基本按各打法相应的用法和位置摆放，用来调整全身平衡 [ja-卓球]；PingSkills 要求用它支持平衡和上体转动，但不要刻意做大动作 [PS-free-arm]。快带、挡的转体本来就小，左臂一垂下，这点转体也会更小、还原更慢（定性，无测量研究）。准备姿势的细节见 `../fundamentals/ready-stance.md`，拉球里非持拍手怎么配合转体见 `../fundamentals/power-and-body.md`。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚与肩同宽或稍宽，前脚掌内侧着地，脚跟微离地 [CETV-姿势]；近台对攻、时间紧时两脚接近平行，靠转髋转腰，来不及退右脚 [Hodges-3484]；挡球站位左脚稍前、离台约 40–50 cm [BK-挡球] | 脚跟踩实、站死，来球一快就只剩手 |
| 膝 | 微屈、内扣 [扬州职大] | 直腿站，重心高，横移慢 |
| 髋 | 稍沉，正对或略斜对球台，准备向右转 | 髋锁死，只能用手 |
| 腰/躯干 | 上体略前倾、收腹 [CETV-姿势] | 后仰、坐臀，来球一冲就被顶退 |
| 肩 | 放松、两肩平 | 耸肩、紧张，后面会"肘上浮" [PSQ-floating] |
| 大臂/肘 | 肘部自然向下 [CETV-姿势]；大臂和身体之间留空隙（百科说约一拳宽，单一来源）[BK-正手攻] | 夹肘贴死，或肘向外张开 |
| 前臂 | 自然平举，约与台面平行 [CETV-姿势] | 前臂下垂到腰下，抬起来就晚了 |
| 手腕 | 自然放松 [CETV-姿势] | 吊腕（手腕下垂、拍头朝下） |
| 手指/握拍 | 横拍握手式；正手击球时食指稍向上移 [CETV-握拍]；握得松，别人能从背后把拍子抽走 [Hodges-2271] | 握死，前臂发僵，挡球手感差 |
| 拍面/拍头 | 球拍在身前，拍头指向预计来球方向，正反手都能照顾 [Hodges-3731] | 拍子停在上一板的收拍位置 |
| 视线/头 | 盯对手触球瞬间的球拍方向和速度来读旋转，别被假动作骗 [Hodges-79] | 只看球不看对手的拍 |
| 非持拍手 | 左臂自然弯曲，放在身体左侧、腹前左侧 [CETV-姿势][扬州职大]；手腕不低于髋（本卡推论，对应第 10 节 `free_arm_height_level` 不小于 0） | 垂在身侧或插腰：转体时左侧跟不上，来球一快只剩右臂 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 先动脚，用身体"迎"到来球路线上，在身体右侧前方挡，尽量不够球 [Hodges-3624]；大角度来球向侧前方迎上截球，不要横着追 [Hodges-3568]；重心稍压到右脚 | 脚不动、手去够 |
| 膝 | 保持弯曲，右膝稍蓄力 | 引拍时站直 |
| 髋 | 快带：随来球向右小幅转；挡：幅度比快带小，但不锁死，后面要配合转腰（见 3.3）| 转得像拉球一样大，时间不够 |
| 腰/躯干 | 快带：腰稍向右转，配合引拍；减力挡：重心略升高 [BK-减力挡] | 掷铁饼式大转体，来不及转回 [BK-弧圈球] |
| 肩 | 右肩稍后，但不下沉（下沉是拉下旋的动作）[Hodges-50] | 沉肩，球拍掉到台下 |
| 大臂/肘 | 肘为"动态支点"，基本留在身体右前方 [BK-支点]。挡：百科《挡球》（整条以直拍推挡为主，正手挡一段也这样写）说引拍时上臂贴近躯干 [BK-挡球]；横拍正手攻球则说大臂与身体留约一拳空隙 [BK-正手攻]；两说语境不同，共同点是不外张、不拖到身后 | 靠拉肘向后引拍 [BK-弧圈球] |
| 前臂 | 快带：前臂引到身体侧前方即可 [BK-快带]；挡：前臂伸向来球路线，基本不后引 [BK-挡球]；减力挡：稍屈前臂 [BK-减力挡]；加力带：引拍稍大 [ja-卓球] | 前臂引到身体后方，击球点被迫落后 |
| 手腕 | 基本固定；想挡直线时手腕稍向后翘，让拍面朝直线 [Hodges-3226] | 手腕大幅后引，拍面失控 |
| 手指/握拍 | 保持松 | 预判到快球就攥紧 |
| 拍面/拍头 | 快带：球拍约与来球同高，拍面已前倾；正手挡：球拍高度在腰与胸之间较合适（单一来源）[BK-减力挡] | 球拍低于来球太多，像拉球一样从下往上 |
| 视线/头 | 看来球落台点和弹起方向 | 抬头看对手，丢了球 |
| 非持拍手 | 快带：随腰小幅右转，左手仍在腹前左侧，跟着身体走，不单独摆动 [PS-free-arm]；挡：基本不动，保持住位置 | 引拍时左臂松垂，转腰被"带停"；或左臂向后大摆，转体超出近台允许的时间 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 快带：右脚前掌内侧轻蹬；挡：脚已到位、站稳 | 边挥边往后退 |
| 膝 | 随蹬地轻微伸，不起跳 | 猛蹬站直，重心上冒 |
| 髋 | 快带：由右向左小幅转回，带动手臂 | 髋不转，纯手臂（来球晚时尤其容易，见第 2 节樊振东条） |
| 腰/躯干 | 正手挡也要转腰配合，重心从右脚移向左脚 [BK-挡球] | 身体僵住只伸手 |
| 肩 | 放松，跟随转体 | 肩发力上提 |
| 大臂/肘 | 肘基本不动，前臂绕肘转 [BK-支点] | 肘向上抬（抬肘）[CETV-纠错] |
| 前臂 | 快带：以前臂为主 [BK-快带]；方向参照正手攻球，由右侧向左前上方挥 [CETV-攻球]；对上旋要"向前，不是向上" [Hodges-36]；挡：前臂和手腕只稍向前送 [BK-挡球]；加力带：从稍大的引拍迎着来球挥过去 [ja-卓球]，挥幅比快带大（本卡推论） | 向上撩，球冒高出界 |
| 手腕 | 用手腕和前臂的小动作控制路线和落点 [BK-快带] | 甩腕，拍面每板不同 |
| 手指/握拍 | 触球前一刻自然收紧一点（快带、加力带）；减力挡保持松 | 一直死握 |
| 拍面/拍头 | 拍面前倾，拍头基本水平或稍高于手腕 | 拍头下垂（吊腕） |
| 视线/头 | 头稳，眼睛跟到触球 | 提前抬头看落点 |
| 非持拍手 | 快带、加力带：随髋、腰由右向左转，左肘向左后方轻收，带左侧一起转——是拉球里"右侧向前、左侧向后拉"[Hodges-3223] 的缩小版（幅度小是本卡推论）；挡、减力挡：留在腹前左侧不动，稳住上身 | 左臂垂落或向前伸：左侧不转，转体变小，只剩手臂去挥 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚稳定支撑，重心在两脚之间偏左移动中 | 重心后坐 [BK-挡球] |
| 膝 | 保持弯曲 | 膝伸直 |
| 髋 | 快带：转到大致正对来球方向 | 髋还朝右，球被"打晚" |
| 腰/躯干 | 前倾保持，不后仰 | 被来球顶得上体后仰 |
| 肩 | 放松 | 耸肩 |
| 大臂/肘 | 肘在身体右前方，大小臂成钝角，不夹死也不伸直 | 直臂击球（易伤）[BK-正手攻] |
| 前臂 | 快带：参照正手攻球，前臂快速内收发力 [CETV-攻球]；加力带：触球时仍在加速挥动，不像快带那样以借力为主（定性，无专门出处）；减力挡：前送"骤然停止"，或稍向后移 [BK-减力挡] | 减力挡时还在往前推，节奏变不了 |
| 手腕 | 快带：稍内转；挡：固定 | 手腕外展、拍面打开 |
| 手指/握拍 | 快带：瞬间捏紧；减力挡：放松，让拍子吃住球 | 减力挡握紧，球弹得远 |
| 拍面/拍头 | 角度、击球点、时间见第 4 节；加力带与快带一样要按来球旋转前倾，因为挥得更快，拍面稍开就更容易出界（定性，本卡推论） | 角度不随来球调整 |
| 视线/头 | 头在击球点后上方，基本不动 | 甩头 |
| 非持拍手 | 仍在身前左侧、不低于髋，和持拍手一起维持平衡 [ja-卓球] | 左臂掉下或向后甩开：上体失衡，被冲的来球顶歪 |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 快带：重心落到左脚；挡：重心随转腰由右脚稍移向左脚，幅度比快带小 [BK-挡球] | 打完脚还钉在原地；重心留在右脚或后坐 |
| 膝 | 保持弯曲，为下一板留弹性 | 直腿 |
| 髋 | 快带随转体自然停在正对球台附近 | 转过头，回不来 |
| 腰/躯干 | 前倾不变 | 打完直起腰 |
| 肩 | 立即放松 [BK-弧圈球] | 肩一直绷着 |
| 大臂/肘 | 肘回到身体右前方 | 肘跟着甩到身体左侧 |
| 前臂 | 快带：短，向左前方收住；正手攻球收到左前额 [BK-正手攻]，快带比它更短；加力带：随挥比快带长一些，因为是"挥过去"（振り抜く）[ja-卓球]（比较是本卡推论）；挡：几乎无随挥 | 习惯性在止点停住 [BK-正手攻] |
| 手腕 | 保持中立 | 打完手腕软塌 |
| 手指/握拍 | 立刻放松 | 继续攥紧 |
| 拍面/拍头 | 快带收拍高度大约在胸到额头之间；加力带收拍位置比快带远一些，拍面仍保持前倾（定性，本卡推论）；减力挡球拍停在击球点附近 | 收拍过低 = 往下压，或过高 = 往上撩 |
| 视线/头 | 看球的去向和对手的反应 | 低头看自己的拍子 |
| 非持拍手 | 快带：随转体自然停在身体左侧，幅度小；挡：基本不动 | 左臂甩到身后，身体转过头、回不来 |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 借动量回位：正手位击球后蹬右脚回中 [Hodges-3425] | 不回位，下一板中路追身吃亏 |
| 膝 | 回到微屈准备 | 站直歇一下 |
| 髋 | 回到正对球台 | 留在侧身状态 |
| 腰/躯干 | 前倾、收腹 | 后仰 |
| 肩 | 平、松 | 肩还在发力 |
| 大臂/肘 | 回到身前，肘向下 | 肘悬着 |
| 前臂 | 回到约与台面平行 | 垂下 |
| 手腕 | 自然 | 吊腕 |
| 手指/握拍 | 松握，必要时微调正/反手握 | 握法卡在正手位 |
| 拍面/拍头 | 每板都回到中立位，拍头指向预计来球方向，**练习里也要做** [Hodges-3731]。另一说：PingSkills 认为盲目复位可能有害，应跟踪来球，直接把拍移到下一板所需位置 [PS-reset]。两说并存，初学者先按 Hodges 练 | 练挡球时把拍子一直伸在正手位 |
| 视线/头 | 看对手引拍，判断下一板 | 看自己的回球看呆了 |
| 非持拍手 | 立刻回到腹前左侧的准备位，下一板随时能再配合转体 | 打完左臂垂下歇着：下一板转体变小、还原慢 |

## 4. 拍面角度、击球点、击球时间、触球部位

**拍面角度**（统一口径：拍面与台面的夹角，90° 为垂直，小于 90° 为前倾）[CETV-击球技巧]：
- 普通正手挡：拍面接近垂直 [BK-挡球]；来球上旋越强，拍面越要前倾（关拍）。挡很转的弧圈时，你的本能角度往往还不够，可能要瞄着球网甚至网底去挡 [Hodges-3445]。
- 拍面不够前倾时，来球的上旋会让球向上弹起，出界或变成对方的机会球 [ja-卓球]。
- 快带：拍面前倾，前倾程度随来球旋转调整。
- 减力挡：有资料说"一般保持与地面垂直；来球力量非常大，可稍后倾，接触球稍厚一些"，挡强烈上旋的前冲弧圈时"拍型稍前倾" [BK-减力挡]。注意这条词条讲的是推挡和长胶打法，横拍反胶正手对强上旋仍以前倾为主。
- 没有一个固定的角度，要按来球的旋转、速度和落点调整 [en-TT]。教学资料里的具体度数都是单一来源，本卡不给度数。
- 拍面角度看手部放大图，骨架测不出来（见第 10 节）。

**击球点**：在身体右侧前方，不能落到身体后方 [BK-弧圈球]；用身体"迎"到来球路线，不够球 [Hodges-3624]；正手挡球拍高度在腰与胸之间较合适（单一来源）[BK-减力挡]。

**击球时间**（五分法：上升前期→上升后期→高点期→下降前期→下降后期，与 `../fundamentals/racket-angle-timing-contact.md` 一致）[CETV-击球技巧]：
- 挡：上升期（百科原词，指"弹起后、达到最高点前" [BK-挡球]，即上升前期和上升后期）；英文维基说刚弹起就挡 [en-TT]，偏上升前期；日文资料写"上升期或高点" [ja-卓球]。
- 快带：上升后期或高点期 [BK-快带]。
- 加力带：英文维基的 counter-hit 是"刚弹起"（off the bounce）用短动作击球 [en-TT]；日文维基的反击建立在挡的基础上，挡是在上升期或高点触球 [ja-卓球]。加力带具体选哪一段，暂无可靠出处；counter-hit 更早、动作更短，和本卡"引拍稍大"的加力带不完全是一回事。
- 越晚击球越要用更大动作、越像反拉；越早越要靠拍形和借力。

**触球部位**（中上部、中部、后中部……）：
- 挡：球的中部 [BK-挡球]；减力挡：后中部，让作用力尽量通过球心 [BK-减力挡]。
- 快带：快带的出处没写触球部位。按近台对上旋的通则：离台越近、来球越强、越想发力，触球越靠上、越向前 [Hodges-36]，所以快带一般触球中上部。
- 加力带：暂无可靠出处写触球部位；按同一通则，比快带更发力，触球应不低于中上部（本卡推论）。

## 5. 发力：顺序、方向、摩擦与撞击

- **借力为主**：挡和快带的速度主要来自来球。拍面稍向下，即使挥拍很弱也能借对方球威回出快球，这时回球几乎不转，或只带一点挥拍产生的旋转 [ja-卓球]。
- **顺序**：快带、加力带是缩短版的正手攻、拉：右脚轻蹬 → 髋、腰由右向左小幅转 → 前臂绕肘向左前收 → 手腕稳定。挡几乎只有"脚到位 + 前臂手腕小送"。注意：近端到远端顺序的研究证据来自拉球，快带、挡本身没有关节顺序的研究。
- **方向**：快带、加力带向左前方，以向前为主、略向上（对上旋"向前，不是向上" [Hodges-36]；左前上方参照正手攻球 [CETV-攻球]）；挡向前；减力挡在触球时停止前送或稍后收 [BK-减力挡]。
- **摩擦与撞击**：
  - 挡：以撞为主。挡转弧圈时至少给一点"轻撞"（light punch），这样旋转对拍子的影响小一些 [Hodges-3445]。
  - 快带：由拉球演变而来 [BK-快带]，比挡多一些摩擦成分，但仍以借力撞击为主。研究没有给过它的摩擦与撞击比例。
  - 加力带："自己的力加上去" [ja-卓球]，撞击和摩擦都增加；再往上就成了反拉，摩擦为主 [BK-弧圈球]。
- **减力的力学**：后收削弱来球反弹力，回球力量轻、落点短、球速下降 [BK-减力挡]。（该词条还说"对方越发力，挡过去的球下沉越明显"，那是针对推挡和长胶的说法，反胶正手不适用。）同时要保证"吃"上球，让球有足够的前进速度过网 [BK-减力挡]。
- **合力**：先熟练借力，再慢慢加主动发力，找到不同旋转强度下要加多少力 [BK-借力]。

## 6. 面对不同来球的调整

**选哪种回法（带、挡还是反拉）：**
- 高水平选手在正手位几乎对所有上旋球都反拉，但离台太近、什么都反拉，会被又快又深的弧圈打穿；退一步再反拉，又怕慢而转、落在身前的弧圈。Hodges 的建议：找一个能舒服反拉大多数上旋球的距离，同时练好"反射式挡球"，专门对付打到正手的很凶的球；也可以先挡一板，退半步再反拉下一板；慢球毫不犹豫地反拉或扣 [Hodges-3003]。
- 反过来，只会挡、不会对弱弧圈反拉或扣杀，同样是弱点 [Hodges-3003]。
- 中国两面攻的思路：坚持近台，用快带顶住，再找机会近台反拉或中等力量扣杀 [CETV-两面攻]。
- 离台已经远、来不及前迎：改用反拉或鱼跃、放高球，见 `../techniques/lob-and-fish.md`。

**按来球调整：**

| 来球 | 怎么调 |
|---|---|
| 慢而转的弧圈（多来自拉下旋，旋转与速度之比更高）[Hodges-3001] | 拍面更前倾，加轻撞 [Hodges-3445]；站近时直接反拉或扣更好 [Hodges-3003]；PingSkills 给的三种回法是软挡、撞、反拉 [PS-counter-spinny] |
| 快而冲的前冲弧圈 | 动作最短，以挡为主，上升期迎前；这类球常用减力挡 [BK-减力挡] |
| 半高、质量一般的上旋 | 加力带或扣杀，见 `../techniques/forehand-smash.md` |
| 侧旋弧圈 | 球离拍时会向侧面偏，拍面要稍朝相反方向；侧旋判断见 `../fundamentals/spin.md` |
| 平击、扣杀 | 拍面接近垂直，以挡为主；先练挡中等力量的扣杀，再过渡到前冲弧圈 [BK-减力挡] |
| 正手大角度 | 向侧前方迎上截球 [Hodges-3568]；来球偏晚时先保证转髋，不只伸手（见第 2 节樊振东条） |
| 追身（中路） | 先让位，再决定用正手还是反手，见 `../techniques/transitions.md` |
| 对方退台等你的快球 | 突然减力挡，"重—轻—重"变节奏 [Hodges-3619] |

**线路变化**：大多数人正手挡只挡斜线。想挡直线，手腕稍向后翘，让拍面朝直线，同样借对方的速度和旋转把球弹回去 [Hodges-3226]。

## 8. 常见错误：表现 → 原因 → 纠正

1. **回球冒高、出界** → 拍面不够前倾，来球上旋把球弹高 [ja-卓球]；没有按对方弧圈的旋转调整 [Hodges-3445] → 再关一点拍面，瞄网甚至网底；给一点轻撞；用"发下旋—搓—拉—挡"练（第 9 节）。
2. **挡下网** → 拍面过度前倾 [BK-挡球]，或击球太晚、球已下落 → 多球强化拍面控制；按口令在上升期击球 [BK-挡球]。
3. **够球、手臂伸直** → 脚不动 → 先迎到来球路线上，在身体右侧前方挡 [Hodges-3624]；直臂击球还容易受伤 [BK-正手攻]。
4. **夹肘 / 拖肘** → 大臂贴死身体，或大臂拖到身后 → 放松肩部，加大上臂与身体的距离 [CETV-纠错]；左手托住右肘、保持约两拳宽做徒手挥拍，或腋下夹软物练习（单一来源）[BK-正手攻]。
5. **抬肘、肘上浮** → 肩紧张 [PSQ-floating] → 放松肩、肘压低；击球时肘、肩向后下方 [CETV-纠错]。
6. **吊腕（手腕下垂，拍与前臂成直角）** → 握法或手腕习惯 → 手腕内旋、拍柄向左 [CETV-纠错]。
7. **引拍过大、击球点落到身体后面** → 把快带当拉球打 → 引拍只到身体侧前方，动作紧凑，"以空间换时间" [BK-快带]。
8. **重心后坐、被顶退** → 来球判断慢，击球晚 → 徒手挥拍结合步法移动练习 [BK-挡球]；上体保持前倾。
9. **来球稍晚就只剩手** → 髋转不过来（樊振东论文点出的同类问题）[FZD-Jin2026] → 先练"先转髋再出手"的慢动作，再多球加速。
10. **只会挡、被压着打** 或 **什么都想反拉、近台被打穿** → 选择不对 → 按第 6 节的分工练 [Hodges-3003]。
11. **减力挡不过网 / 没有减速** → 后收过多、没"吃"上球；或触球时仍在前推 → 控制后收幅度，触球后中部 [BK-减力挡]；先挡中等力量的扣杀，再挡前冲弧圈 [BK-减力挡]。
12. **只会挡斜线** → 热身只练斜线 → 让同伴往正手直线拉，专门练手腕后翘挡直线 [Hodges-3226]。
13. **握拍太紧、手感僵** → 预判到快球就攥紧 → 握到别人能从背后抽走拍子的程度 [Hodges-2271]。
14. **挡完不还原** → 练习里养成的习惯 → 每板回中立位 [Hodges-3731]。
15. **太早退台** → 嫌时间不够 → 动作缩短，站在一臂远内；练习时在身后放障碍物提醒 [Hodges-3217]。
16. **左臂垂落、乱甩** → 只想着持拍手 → 准备时左臂弯曲放在腹前左侧 [CETV-姿势]，随转体小幅一起动，不刻意做大动作 [PS-free-arm]；拍视频看 `free_arm_height_level`（第 10 节）。

## 9. 练习方法（入门 → 进阶）

1. **徒手模仿**：对镜子做"准备—小引拍—前臂向左前收—还原"，检查肘的位置和拍面 [CETV-纠错]。
2. **定点挡**：同伴正手攻斜线，你正手挡。先挡中等力量的攻球，再过渡到拉球 [BK-减力挡]。连续板数逐步加长（PingSkills 给正手攻球定的目标是连续 100 板 [PS-counterhit]，挡球可参照）。
3. **定点快带**：同伴正手连续拉加转或前冲到你正手位，你快带斜线；熟练后快带直线（手腕后翘）[Hodges-3226]。
4. **挡转弧圈专项**：同伴手持一筐球："他发下旋—你搓—他拉—你挡"，挡完不打完这一分，马上下一球 [Hodges-3445]。逐步挡得更凶，最后改成反拉或扣 [Hodges-3445]。
5. **多球冲击**：多球连续供前冲弧圈到正手位，练"反射式挡球" [Hodges-3003]；减力挡也先用多球提高密度 [BK-减力挡]。
6. **挡—退—拉**：第一板快挡，退半步，第二板反拉 [Hodges-3003]。
7. **变节奏**：对方连续进攻，你"重带—减力挡—加力带"交替 [Hodges-3619]。
8. **两面攻顶住转攻**：一人连续拉正手和中路，你快带顶住，抓到半高球就反拉或中等力量扣杀，然后连续进攻 [CETV-两面攻]。
9. **全程还原**：上面所有练习，每板都回中立位，不许把拍子一直放在正手位 [Hodges-3731]。PingSkills 有不同看法（跟踪来球、直接移到下一板所需位置）[PS-reset]，见 3.6；两说并存，初学者先按 Hodges 练。

更多练法汇总见 `../training/drills.md`，错误速查见 `../training/errors-index.md`。

## 10. 视频检查要点

**机位**：主机位在**侧面**，站在持拍手（右）那一侧、镜头垂直于球员面对的方向，全身入画，能看到台面边缘；辅机位在**正面或斜前 45°**，看转体、重心左右转移和收拍位置 [见 `../analysis/recording-guide.md`]。用 120/240 帧慢动作；慢动作导出的文件要用 `--capture-fps` 校正，否则 `backswing_ms` `forward_ms` `follow_ms` 全错。每段只拍一种：例如"正手快带斜线 8 板"。

**注意**：挡和减力挡动作很小，自动分板可能漏掉，或报 `NO_STROKES`；这时看 timeline 图人工定出各板时刻，再用 `--strokes` 重跑（见 `../analysis/analysis-protocol.md` 第 6 步），结果在 `measured/` 目录。先看 `side_guess`，确认分到的是正手；`quality.reliable=false` 或关节在 `quality.low_visibility_parts` 里的数字一律不用。

| 阶段（关键帧） | 看什么 | 对应指标 |
|---|---|---|
| 准备 ready | 膝微屈、上体前倾、肘向下、拍在身前 | `knee_angle_deg.playing/other.ready`、`stance_width_ratio` |
| 引拍结束 backswing_end | 球拍是否只到身体侧前方（快带）或几乎没后引（挡）；肘是否留在体前；重心是否在右脚 | `backswing_ms`、`elbow_angle_deg.backswing_end`、`weight_shift.backswing_end`、`trunk_lean_deg.backswing_end`、`shoulder_width_ratio.backswing_end`（正面机位） |
| 前挥中段 mid_forward | 方向是向左前还是向上撩；肘有没有抬起来 | `swing_path.up/horiz/angle_deg`（快带、挡应比拉球平）、`forward_ms` |
| 击球 contact | 击球点在身体右前方还是身后；有没有伸直手臂去够；上体有没有后仰 | `contact_forward_m`（正值越大越靠前）、`contact_lateral_m`、`contact_height_level`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`trunk_lean_deg.contact`、`knee_angle_deg.playing/other.contact` |
| 随挥结束 finish | 快带收拍是否短、在胸到额头之间；减力挡是否停在击球点附近 | `follow_ms`、`elbow_angle_deg.finish`、`finish_height_level`、`weight_shift.finish`、`weight_shift.delta` |
| 还原 recovery | 是否回到身前中立位 | `recovery_dist`（越小越好） |
| 全程 | 头稳不稳；非持拍手：各关键帧里左臂是否弯曲在身前左侧、随转体小幅动，击球帧左手腕是否掉到髋以下；转体 | `head_motion`、`free_arm_height_level`（取击球帧，0 = 髋、1 = 肩，小于 0 即低于髋）、`shoulder_turn_deg` `hip_turn_deg` `x_factor_deg`（单机位低可信）、`peak_hand_speed`、`sequence_ms.hip/shoulder/elbow` 与 `sequence_order_ok`（帧率 ≥100 才算） |

**拍面角度必须看手部放大图**：自动分板时看 `stroke_NN_zoom.jpg`（击球前后各 2 帧）和 `stroke_NN_contact_raw.jpg`；用 `--strokes` 人工定板后，对应文件是 `measured_NN_zoom.jpg`、`measured_NN_contact_raw.jpg`。看：拍面前倾是否够、是否吊腕、减力挡时拍子是否停住或后收。骨架模型测不出拍面角度和握拍。

**读数提醒**：
- `weight_shift.delta` 在快带里应为正（重心右→左）；挡的 delta 应为小的正值（重心随转腰由右脚稍移向左脚 [BK-挡球]），明显为负（重心后坐或留在右脚）是问题；判断时要分技术。
- `peak_hand_speed` 单位是躯干长度/秒，不能和第 7 节的 m/s 比，只做同一人前后对比。
- `free_arm_height_level` 只有击球帧一个值；其他阶段的左臂位置看关键帧图。它小于 0，同时 `shoulder_turn_deg` 偏小，多半是左臂垂落让转体变小（定性，见 3.3）。
- 同一段视频里各板 `contact_forward_m`、`swing_path.angle_deg` 波动大，说明击球点和挥拍方向不稳定。

## 11. 自查清单

- [ ] 我能说出挡、减力挡、快带、加力带、反拉各在什么情况下用。
- [ ] 准备时膝微屈、上体前倾、肘向下、拍在身前、握拍松。
- [ ] 来球到正手先动脚，在身体右侧前方击球，不伸直手臂去够。
- [ ] 快带引拍只到身体侧前方，在上升后期或高点期击球；挡在上升期击球。
- [ ] 对强上旋会主动关拍面，回球不冒高。
- [ ] 快带向左前方挥，以向前为主，不向上撩。
- [ ] 来球稍晚时，仍然先转髋，不只用手。
- [ ] 减力挡触球时停止前送或稍后收，回球轻、短、节奏变慢，并且能过网。
- [ ] 正手挡也有转腰，重心由右脚稍移向左脚，不后坐。
- [ ] 正手能挡斜线，也能挡直线。
- [ ] 左臂全程弯曲在身前左侧，随转体一起动，不垂下、不乱甩。
- [ ] 每板都回中立位，练习时也一样。
- [ ] 面对慢而转的弧圈敢反拉或扣，不只会挡。
- [ ] 侧面慢动作视频里，击球点在髋前方，收拍短，头稳。
