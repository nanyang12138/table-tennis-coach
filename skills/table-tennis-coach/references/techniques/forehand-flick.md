# 正手台内挑打与台内进攻（Forehand Flick / Flip）

适用：接发球和对方摆短时，用正手主动处理台内短球（第二跳不出台）和半出台球｜难度：中高（正手比反手难）｜相关卡片：`../techniques/backhand-banana-flick.md` `../techniques/backhand-flick.md` `../techniques/short-touch.md` `../techniques/push.md` `../techniques/long-push.md` `../techniques/forehand-loop-vs-backspin.md` `../techniques/receive.md` `../techniques/footwork.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/spin.md`

> 全文按右手横拍写；左手持拍者左右互换。直拍正手挑见 `../techniques/penhold.md`。
> 出处缩写：`LH:N` = Larry Hodges 文章 https://www.tabletenniscoaching.com/node/N ；`BK-词条` = 百度百科词条（可编辑百科，可信度中等）；完整链接见文末。
> **注意 BK-快点**：该词条描述的是**反手位**快点（"主要应用于接对手发的反手位短球或摆短过来的反手短球"），正手是否同样适用，由本卡按原理推断；正手快点优先引 BK-正手快点。
> **手腕术语**：本卡的"外展"按百科用法，指手腕向后打开、使拍面后仰（BK-正手快点；PingSkills Forehand Flick 说 "open your wrist back"）；"内收"指触球时手腕向前收（BK-接发球）。全文统一按此理解。

## 1. 定义与用途

**挑打（flick，也叫 flip）**：在台内把短球直接打成带上旋或较平的进攻球。台内没有引拍空间，引拍被压缩成很小的手腕、前臂动作（英文维基「Table tennis」；日文维基「卓球」的フリック条目：几乎不引拍的极小动作）。用途：抢先上手、形成连续进攻优势，挑对方空档、逼对方在跑动中回球（BK-挑打）。Hodges 提醒：**挑打不是全力进攻，而是"缴械"对方发球（"disarm an opponent's serve"）、逼出弱回球**，隐蔽和落点比速度重要（LH:80）。

本卡覆盖的正手台内进攻手段：

| 手段 | 做什么 | 何时用 | 出处 |
|---|---|---|---|
| 挑打·暴挑 | 以自身发力为主、出手集中，威胁大，可直接得分 | 见下方"挑打总的使用时机" | BK-挑打 |
| 挑打·翻挑 | 以控制为主，威胁性相对较小 | 本卡建议（无出处）：来球低、转，只求先上手 | BK-挑打 |
| 台内快点（quick tap） | 几乎不引拍，手腕手指弹击（BK-快点，反手位）；向前撞击成分比挑打多（BK-正手快点） | 抢节奏、抢角度（BK-快点）；BK-正手快点说主要用于台内下旋 | BK-快点、BK-正手快点 |
| 台内拉 / 挑拉（over-the-table loop） | 稍伸进台内，用拉球动作制造上旋 | 半出台球（第二跳正好在端线附近） | LH:3723、PingSkills Two Ways to Return a Half-Long Serve |
| 带侧旋挑（侧拐挑） | 手腕在触球时转动/后翘，改变出球方向或抵消来球侧旋 | 挑直线、接侧旋短球 | PingSkills Forehand Flick、LH:33 |
| 晃撇 | **属于搓的变化**：侧身位正手搓侧旋、斜线，打出左侧下旋，落台外拐 | 与"侧身挑直线"配合，让对方不敢轻易侧身 | BK-接发球 |

**挑打总的使用时机**：对方短球控制、回球不太低、高度上有进攻空间时；百科建议业余爱好者先在"下旋程度不高""弧线偏高"两个条件下挑，成功率较高；不能为挑而挑（BK-挑打）。

说明："侧拐挑"这个叫法本次没有找到可靠定义，也没有出处把它和"晃撇"等同。本卡按唯一找到的定义（BK-接发球）把晃撇写成搓类，带侧旋的挑单列。

**和快点、挑打的区别**：快点更突出"快"和"突然"，向前撞击成分多；挑打更注重稳定和控制（BK-正手快点）。

**和反手拧拉怎么选**（详见 `../techniques/backhand-banana-flick.md`）：

| 比较项 | 正手挑 | 反手拧拉 |
|---|---|---|
| 拍速空间 | 正手在台内很难挥出足够拍速（PingSkills Attacking Short Serves） | 很多顶尖选手因此用反手侧旋挑（同上） |
| 难度 | Hodges：反手挑通常比正手挑容易（LH:3129） | 需要大量练习，年长者手臂可能吃不消（LH:3621） |
| 覆盖 | 正手位大角短球伸手最顺，挑直线/斜线都方便 | 现代顶尖选手常用反手到正手位接短球，Hodges 点名包括马龙（LH:3650）；但用反手接正手位短球后，反手位可能出现大空档（BK-台内球） |
| 正手拧 | 横拍正手拧拉因握拍原因难度非常大，未能普及（BK-台内球） | — |

**实用选择**：背景是 Hodges 说如今多数顶尖选手接短球偏用反手、接长球偏用正手（LH:3723）。本卡建议：球在正手位大角、离身体远，或来不及移位换反手时用正手；球在中路/反手位、想要更强旋转时用反手拧。正手挑仍要练："To attack short serves to the forehand, you will need to develop a forehand flip"（要进攻发到正手位的短球，就得练出正手挑，LH:80）。

## 2. 三位标杆怎么做

**马龙**
- 单场统计（2020 世界杯半决赛对张本智和，Edges & Nets 分析博客，非官方，仅此一场）：张本全场挑打 50 次、失误 7 次；马龙只挑 12 次、0 失误；马龙挑打的直接得分多是"控制好、落点好的慢球"。注意：统计没区分正手和反手。可以借鉴的是**少挑但挑得稳、靠落点不靠力量**，和 Hodges 的建议一致。
- 同一篇单场统计：前三板马龙最想要的是用正手对长球、尤其**半出台球**起板；尝试这类起板的分他赢 68%，其余的分只赢 47%（Edges & Nets，分析博客，只有一场，不能推广为生涯数据）。对应本卡的台内拉/半出台处理。
- 比赛报道中多次出现"接发球摆短→正手抢拉"的得分套路（央视网 2017-06-18、2018-06-03，单场描述）；也会直接用拧拉、反手翻挑上手（央视网 2017-06-04"接发球直接拧拉得分"、2021-07-29"马龙反手翻挑命中"）——这两项都是反手技术。
- 读者在 PingSkills 提问说马龙用正手接樊振东的右侧旋发球（提问者称是摆短）；PingSkills 教练回答：他触球时把拍面明显转向右来抵消旋转（"he does change the angle very much to face the right on contact"），用正手"可能"是因为角度更好。拍面对侧旋的调整原理与挑相同。
- 央视网 2014-03-22 亚洲杯决赛报道原文："第六局比赛的开局，樊振东找到了马龙正手短球的漏洞，偷袭得分，随后马龙通过发球的变化，迫使樊振东改变回球策略"。原文没说清是马龙发球还是接球环节，单场描述，不能据此认定马龙接正手短球有弱点。
- Hodges 称马龙等顶尖选手会用反手接正手位短球（LH:3650，仅此一家）。
- 百科转引论文《高水平男子乒乓球运动员台内球技术特征分析》："马龙的过渡控制型台内球技术相对单一但控制能力强，反手拧拉使用较多"（BK-台内球；百科转引论文，未读原文，不专指正手）。

**张继科**
- 正手挑打、正手台内拉的个人特点：暂无可靠出处。
- 百科转引同一篇论文："张继科台内球争抢积极凶狠，主要使用摆短和劈长，反手台内拧拉是核心技术"（BK-台内球；百科转引论文，未读原文，不专指正手）。
- 他的台内进攻主武器是反手拧拉：他本人说看到拧拉后觉得"能阻止对方第三板"，自己主动研究（《卓球レポート》2019，日本蝴蝶公司刊物）。
- 2008 年媒体评价其"台内处理还不够细腻"（搜狐 2008，只代表当时）。

**樊振东**
- 正手挑打的个人特点：暂无可靠出处。
- 论文统计：接发球第二板主动上手明显更多用反手而不是正手；反手拧拉使用率显著高于其他技术（Jin & Ma 2026，40 场比赛统计）。
- 刘国梁评价其"台内前三板更加细腻"（新京报转述，央视网 2021-07-30）。

## 3. 动作分解

**上步与退出（台内进攻的一半）**：右手持拍者，正手位短球**上右脚**；反手位用反手挑可上持拍同侧脚；侧身位上左脚、右脚适当跟上（BK-接发球）。上步前常先用左脚小垫步调整，再右脚上步（BK-正手快点、BK-挑打）。挑完**立即**退回正常准备位置，练习时把"进—出"当成动作的一部分（LH:3129、PingSkills Moving In for Short Balls）。退得回来的关键是脚下保持弹性、用碎步微调（BK-台内球）。步法总论见 `../techniques/footwork.md`。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 接发球站位离台约一小步（BK-台内球）；两脚平行、比肩略宽，右手持拍者一般右脚稍前，便于上步接短球；前脚掌着地、脚跟提起（BK-接发球） | 脚跟踩实，判断短球后迈不出去 |
| 膝 | 两膝微屈（BK-接发球）、有弹性；对方抛球/出手时可轻微小跳或上身抬起再起动（樊振东接发时有此动作：PingSkills 教练答问 Analysis of movements on return of serve；LH:3491） | 直腿站，起动慢 |
| 髋 | 髋略前屈，臀部不后坐，朝向球台 | 坐得太低，上步时重心跟不上 |
| 腰/躯干 | 上体稍前倾（BK-接发球） | 上体后仰，离台太远 |
| 肩 | 放松、平 | 耸肩、紧张 |
| 大臂/肘 | 肘在体前，大小臂约成钝角 | 肘夹死在身侧 |
| 前臂 | 置于体前，略高于台面 | 前臂垂到台面以下 |
| 手腕 | 自然、放松，不提前翘 | 提前用力锁腕 |
| 手指/握拍 | 横拍握得稍虚，保持手腕灵活（BK-正手快点）；握法见 `../fundamentals/grip.md` | 捏死拍 |
| 拍面/拍头 | 手位较高，不低于台面（BK-台内球）；拍放在正反手之间 | 拍放太低，接短球要先抬手 |
| 视线/头 | 盯对方抛球和触球，判断长短、旋转（BK-接发球） | 只看球不看对方动作 |

### 3.2 引拍（与上步同时）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 球将过网时右脚向来球处上步，插到台下（BK-接发球；LH:3129）；脚跟先着地再过渡到全脚掌（BK-正手快点）；距离不够先左脚垫步 | 不上步只伸手够球（LH:144） |
| 膝 | 上步后重心低压（BK-挑打·林高远要点）；右膝弯曲前顶，重心压在前脚掌（BK-侧拧，原文讲正手位短球的上步：重心"压在前脚掌或两脚之间"） | 右腿伸直，重心留在左脚 |
| 髋 | 随右脚一起前移，重心"完全跟上去"（BK-台内球） | 臀部掉在后面 |
| 腰/躯干 | 上体前探到球的后上方，不需要大幅转腰（台内没有空间） | 弯腰过度，头低于来球太多、看不到弧线 |
| 肩 | 右肩随上步送向球；左手抬起保持平衡（LH:3129） | 左手垂下或背在身后，上体晃 |
| 大臂/肘 | 手臂比平时更伸展（LH:33），但肘仍保留弯曲 | 手臂伸得过直（BK-台内球），失去发力空间 |
| 前臂 | 伸进台内，引拍很短（LH:33）；快点几乎不引拍（BK-快点） | 习惯性大引拍（BK-快点列为首要错误） |
| 手腕 | 起动时手腕向后打开，即"外展"（PingSkills Forehand Flick；BK-正手快点）；挑直线时腕和前臂再多带回一点（LH:3129） | 手腕不后引，只能用手臂推 |
| 手指/握拍 | 放松（BK-正手快点：引拍时肌肉放松） | 引拍时就握紧 |
| 拍面/拍头 | 拍头偏低（LH:3129）；按旋转预置拍面：对下旋手腕外展使拍面稍后仰（BK-正手快点） | 拍面固定一个角度对所有球 |
| 视线/头 | 跟住球的弹起，判断最高点 | 上步时低头看脚 |

右脚上步与手臂入台要同步，不能脚到了手还没到（BK-正手快点）。

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚踏稳后出手（"移动—停—击球"，PingSkills Move, Stop and Hit in Forehand Practice，原课讲正手步法） | 脚还在空中就挥拍 |
| 膝 | 由低向上轻微伸展，带重心向前上（BK-正手快点：重心先低、击球瞬间再起来；BK-挑打·马琳要点：蹬地使重心向前上） | 膝不动，全靠手 |
| 髋 | 借上步向前的惯性辅助发力（BK-挑打） | 髋后撤 |
| 腰/躯干 | 稳定，小幅前送 | 大转腰，拍迟到 |
| 肩 | 稳，不大幅转动；暴挑时肩前顶、手臂有意滞后蓄力（BK-挑打·马琳要点） | 肩带着拍横扫 |
| 大臂/肘 | 肘为支点，基本不动 | 大臂大摆（BK-快点列为错误） |
| 前臂 | 向前上（对下旋）或向前（对不转/上旋）加速；前臂前送（BK-正手快点） | 前臂只向前推、不加速 |
| 手腕 | 由后向前甩出，主要发力来源之一；保持放松才能摩擦（BK-挑打） | 手腕僵直 |
| 手指/握拍 | 引拍时放松，触球瞬间快速握紧（BK-正手快点） | 一直握紧，球感差 |
| 拍面/拍头 | 对下旋由后仰迅速向前压（BK-正手快点）；对上旋/不转拍面稍前倾（BK-正手快点） | 拍面一直后仰，回球高 |
| 视线/头 | 头稳，眼睛盯到触球（BK-接发球：注视来球直到完成还击） | 抬头看对方 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心前移到右脚（前脚）一侧（本卡建议） | 重心仍在左脚，身体离球远 |
| 膝 | 右膝弯曲支撑 | 右膝伸直锁死 |
| 髋 | 在右脚上方，不后坐 | 臀部后坐 |
| 腰/躯干 | 上体在球的后上方，身体离球较近、给手臂手腕留发力空间（BK-挑打·许昕要点） | 身体离球远，手臂够球 |
| 肩 | 平稳 | 右肩下沉过多 |
| 大臂/肘 | 肘不锁死 | 手臂完全伸直 |
| 前臂 | 主要发力段之一（BK-挑打；LH:33） | 前臂不动只抖手腕 |
| 手腕 | 突然、集中加速（BK-正手快点）；BK-接发球写作正手"手腕有一突然的微小内收"（即向前收） | 手腕早发力，触球时已减速 |
| 手指/握拍 | 握紧，力量传到球上（BK-正手快点） | 松垮，拍面被来球打歪 |
| 拍面/拍头 | 角度按第 4 节；暴挑可用拍头部位在高点期触球增长力臂（BK-挑打·许昕要点） | 拍面错配旋转：下网或冒高 |
| 视线/头 | 看触球点，头不前冲 | 触球时转头看落点 |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚开始准备蹬回 | 右脚粘地 |
| 膝 | 保持弯曲，便于蹬回 | 起身站直 |
| 髋 | 不继续前冲 | 身体扑到台上 |
| 腰/躯干 | 稳住，准备后撤 | 上体继续前倾，回不来 |
| 肩 | 放松 | 肩随挥甩出 |
| 大臂/肘 | 肘基本不动 | 大臂跟着大幅前送 |
| 前臂 | 短促收住；方向朝目标（斜线或直线） | 大幅随挥，回位慢 |
| 手腕 | 快点"触球后立即收拍"（BK-快点）；挑打腕部顺势收 | 腕继续上翻，回球偏高 |
| 手指/握拍 | 随即放松 | 一直紧握，下一板僵 |
| 拍面/拍头 | 收在体前、约头部以下高度 | 拍收到头顶以上（暴挑例外） |
| 视线/头 | 跟随回球，看对方动作 | 欣赏自己的球 |

（3.5 各格除标注外为本卡建议。）

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地后撤，立即回到正常准备位置（LH:3129、PingSkills Moving In for Short Balls）；碎步微调（BK-台内球） | 挑完站在台前不动 |
| 膝 | 弯曲、有弹性 | 站直 |
| 髋 | 回到两脚之间 | 重心仍压在右脚 |
| 腰/躯干 | 恢复稍前倾准备姿势 | 后仰 |
| 肩 | 放松 | 紧张 |
| 大臂/肘 | 回到体前 | 手臂伸在台上 |
| 前臂 | 准备下一板（快撕/反带或正手） | 前臂下垂 |
| 手腕 | 回到中立 | 腕仍翘着 |
| 手指/握拍 | 放松，准备正反手转换 | 保持正手握法用力 |
| 拍面/拍头 | 回到体前中位；挑后对方回球快，需要快撕、反带能力衔接（BK-挑打） | 拍落到腰下 |
| 视线/头 | 盯对方击球 | 看自己的落点 |

**各变体与上面基本挑打的差别**（未列出的部位同上）：

## 4. 拍面角度、击球点、击球时间、触球部位

拍面角度口径：**拍面与台面的夹角**，90° 为垂直，小于 90° 前倾，大于 90° 后仰（CETV-击球技巧）。详见 `../fundamentals/racket-angle-timing-contact.md`。

| 来球 | 拍面 | 触球部位 | 挥拍方向 | 出处 |
|---|---|---|---|---|
| 重下旋短球 | **大幅打开（后仰）**，比平时打开得多 | 球的下方偏后，从后下方刷 | 带上旋的向上刷 | LH:3611 |
| 中/轻下旋 | 稍后仰 | 中下部 | 前上，略带摩擦 | BK-正手快点、BK-挑打 |
| 不转 | 稍前倾或接近垂直 | 偏中上部 | 更向前 | LH:3129、BK-正手快点 |
| 上旋/侧上旋 | 拍面关一些（前倾） | 中上部 | 向前、可较平地打穿 | PingSkills Forehand Flick、LH:33 |
| 快点·对下旋 | 稍后仰 | 摩擦中下部 | 向前上 | BK-正手快点 |
| 快点·对不转/上旋 | 稍前倾 | 中上部 | 向前 | BK-正手快点；BK-快点（反手位）写"拍面稍立（约 60–70 度）"、打中上部（单一来源） |

**击球点**：在身体右前方、台内，击球点靠前（BK-台内球）；身体离球较近，用脚把球放进击球区而不是伸手够。
**击球时间**：一般在**高点期**（PingSkills Forehand Flick；LH:3129；BK-接发球"挑接"）；为抢对方节奏也可上升期（LH:3129；LH:80"very quick off the bounce"）；快点说法不一：BK-快点（反手位）写"上升期"，BK-正手快点写"高点期或上升后期"。结论：挑打以高点期为基准，快点可更早，取决于来球高低和你的目的。
**"平"还是"带上旋"（两家有分歧）**：PingSkills 教正手挑"平而向前、像小扣杀"；Hodges 主张以带上旋为主、像"小弧圈"，平挑只作变化（LH:3129）。两家**一致**的是：来球下旋越多越要摩擦，来球上旋或不转可以更平（PingSkills 教练答问 Flick / Flip in detail）。本卡按这一共识写。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：垫步/上步（身体向前的惯性）→ 膝由低向上、重心前上 → 前臂 → 手腕（爆发）。正手挑"主要靠手腕和前臂"（LH:33）；"手腕发力占比很高"（BK-挑打）。台内不靠转腰，腿的作用是把身体送到位并提供向前上的惯性。
- **方向**：对下旋向前上，下旋越重越向上；对不转/上旋向前。
- **摩擦与撞击**：快点向前撞击的成分比挑打多（BK-正手快点）；但用反胶时仍要多带摩擦以提高上台率，撞击多、突然性强是正胶、生胶等颗粒胶的特点（同上）。正手快点多见于直拍正胶快攻打法（同上）。挑打"略带摩擦"（BK-挑打），对下旋越重越以摩擦为主；BK-接发球的挑接写作"以前臂发力撞击球为主……适当给球一点摩擦，以保证准确性"。
- **力量**：除非来球高，很少一板挑死（LH:3129）；硬挑容易失误（LH:80）。暴挑以自身发力为主、出手集中，翻挑以控制为主（BK-挑打）。
- **借力**：对重下旋，打开拍面后来球下旋可以转成回球的上旋，Hodges 说这样挑重下旋"often easier"，往往比挑不转还容易（LH:3611）。
- **台内拉（半出台）**：第二跳正好在端线附近也够拉，"只要稍微伸进台内"（LH:3723）；可以让球过来、用更大的动作打（PingSkills Two Ways to Return a Half-Long Serve）。发力细节见 `../techniques/forehand-loop-vs-backspin.md`。

## 6. 面对不同来球的调整

| 情况 | 调整 |
|---|---|
| 下旋不强、弧线偏高 | 最适合挑；业余球员先在这两种条件下用（BK-挑打），可暴挑。球够高、下旋少时，拍从稍高的位置起动，快速挥过让胶皮咬住球（"Start with your bat a little higher and swing through fast so the rubber grips and lifts the ball"，PingSkills Attacking Short Serves） |
| 低而重下旋 | 拍面大幅打开，从后下方向上刷（LH:3611）。Hodges 主张三种接法（摆短、搓长、挑）都练、不要只会搓，否则被对手看穿（LH:3611）；百度百科"挑打"则建议业余者只在下旋不强、弧线偏高时挑（BK-挑打）。两种说法不同，按自己的水平选 |
| 不转 | 拍面稍关、偏向球的上部、更向前；Hodges 承认自己挑不转一直不好，被对手抓住（LH:3129），要专门练 |
| 短上旋/侧上旋 | 果断、快而平地打穿（PingSkills Returning Short Topspin Serves）；若摆短，要从球后面向下压而不是从下面托 |
| 右侧旋（如对方反手发球，球向接球者右侧拐） | 正手伸进台内时拍面天然朝左，需要有意把拍面转向右（LH:80；第 2 节马龙正手接右侧旋的例子同理）；BK-接发球：拍面向右偏斜，击球偏左 |
| 左侧旋（正手钟摆，向左拐） | 拍面略向左偏斜，击球偏右（BK-接发球）；转手腕抵消侧旋（PingSkills Forehand Flick） |
| 向外拐、离身体越来越远的侧旋 | 向球上步，不要伸手够；拍保持较高（LH:144） |
| 半出台 | 重下旋多用摆短（靠近第一跳出手）；侧旋、不转、上旋可挑，在接近最高点触球；判断能出台就拉（PingSkills Reading Half-Long Serves）。第二跳在端线上也够拉（LH:3723）；BK-接发球："能拉接，不要搓撇"，判断不清时有意识地"等"长球 |
| 高球、出界风险小 | 可以挑杀，转入扣杀动作（`../techniques/forehand-smash.md`） |
| 线路 | 斜线可攻大角；挑直线或中路时把前臂和手腕多带回一点（LH:3129），或触球时手腕后翘（LH:33）；把方向藏到最后一刻（LH:80）；对方侧身位发球时可挑其斜线正手位（BK-挑打） |
| 对方站位近、等短球 | 落点优先于速度（LH:80）；挑完马上退回准备反攻 |

晃撇（搓类变化）：侧身位用正手，在来球最高点触球后中下部，手腕略外展，向左侧前下方摩擦，回出左侧下旋、落台外拐；与侧身挑直线配合使用（BK-接发球）。分解见第 3 节小表，搓的基本动作见 `../techniques/push.md`。

## 7. 关键数据参考

- **关节角度、拍速、时长**：本次检索没有找到正手挑打的同行评审运动学数据（本项目在 Europe PMC 检索：只找到反手拧/弹后接快挡的拍速研究，且没给可用于本卡的数值）。所以本卡**不给**肘角、腕角、拍速范围，只给定性描述。
- **拍面角度**：快点"约 60–70 度"仅一处百科（BK-快点，讲的是反手位快点），量法不明，仅作参考。
- **马龙单场统计**（Edges & Nets，2020 世界杯半决赛一场，分析博客非官方，不能推广为生涯数据）：挑打 12 次 0 失误，对手 50 次 7 失误；正手对长球/半出台起板的分赢 68%，其余的分赢 47%。
- **半出台定义**：第二跳（如果让它跳）落在接球方端线附近："around the edge or just off the end"（LH:29）；"at or just off the end-line"（LH:3723）。
- **拍摄帧率**：按已发表的正手拉最大拍速约 13–15 m/s（Bańkosz & Winiarski 2018）推算，30 fps 两帧之间球拍约移动 0.43–0.5 m（推算，非实测；挑打拍速更低），几乎抓不到触球帧；拍挑打至少用 120 fps 慢动作，见 `../analysis/recording-guide.md`。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 挑下网 | 重下旋没打开拍面（LH:3611）；拍面一直平；击球太晚球已下落 | 读旋转后大幅打开拍面向上刷；在高点期前出手 |
| 挑出界/冒高 | 对上旋/不转仍用后仰拍面向上刷；随挥向上翻 | 拍面关一点、更向前；随挥短 |
| 动作慢、错过最佳击球点 | 引拍过大；大臂或前臂大摆；判断到出手节奏拖（BK-快点） | 默念"无引拍、快弹击"（BK-快点）；定点短球只练小动作 |
| 手伸得很直，够着打 | 没上步或上步不够；臀部掉在后面（BK-台内球；LH:144） | 先脚后手，右脚插到台下，重心完全跟上 |
| 回球没威胁、被对方反撕 | 为挑而挑，来球质量不适合；只会一条线（BK-挑打；LH:3129） | 初学先在下旋弱或球高时挑（BK-挑打），重下旋另外专练（LH:3611）；斜线、直线、中路都练；藏线路 |
| 挑完被对方打回来接不住 | 没还原，人留在台前（LH:3129） | 练"进—挑—出"一体；挑后衔接快撕、反带 |
| 侧旋来球挑偏 | 拍面没按侧旋转向（LH:80） | 右侧旋拍面转右、左侧旋转左；按第 9 节第 8 条单练一种侧旋再混合 |
| 挑得用力但老失误 | 想一板打死（LH:80） | 以控制和落点为主，先用中等力量把稳定的挑练熟，再逐步加力 |
| 手腕僵、没摩擦 | 握拍太紧、手腕锁死 | 握稍虚，触球瞬间才握紧（BK-正手快点）；林高远要点：手腕放松才能摩擦（BK-挑打） |
| 上步时上错脚、身体别扭 | 正手位上了左脚 | 正手位上右脚、侧身位上左脚（BK-接发球） |
| 手脚脱节 | 脚到了手还没进台，或手先伸出去 | 右脚上步与手臂入台同步（BK-正手快点） |
| 腕/肘酸痛 | 全靠手腕硬甩、练习量骤增 | 让前臂、腿参与；逐步加量，见 `../training/physical-and-injury.md` |

## 9. 练习方法（入门 → 进阶）

1. **徒手**：对镜做"左脚垫步→右脚上步→小引拍挑→蹬回"连贯动作，体会先脚后手、挑完马上退。
2. **定点轻下旋**：同伴或多球把轻下旋短球送到正手位，只挑斜线，先求命中率（原 BK-快点练法是反手位"先命中、再练角度"，这里换到正手位练）。
3. **Hodges 十步进阶（LH:3129，多球最好）**：①短正手轻下旋→挑斜线；②短正手重下旋→斜线；③短正手不转→斜线；④轻下旋→挑直线；⑤轻下旋→挑对方中路；（每板后都要退回准备位置）⑥正手短球混合旋转→挑全台；⑦正手短球与反手长球交替；⑧正手短与反手长随机；⑨随机后再接两板随机上旋；⑩比赛：双方只能发短球。
4. **重下旋专练**：同伴反复发低、短、重下旋，你只练挑，不打完这一分（LH:3611）。
5. **不定点**：短球随机到正手位不同位置，用半步调整位置但保持小动作（原 BK-快点练法是随机发反手位短球，这里换到正手位练）。
6. **快点专练**：定点快点，杜绝引拍和手臂大摆；一发现动作变大立即停下重做（原 BK-快点练法是反手位，这里换到正手位练）。
7. **半出台判断**：同伴混发短球和半出台球，短的挑或摆，出台的拉（PingSkills Reading Half-Long Serves）。
8. **侧旋短球**：多球或发球练习，先单练右侧旋短球（拍面转右），再单练左侧旋（拍面转左），最后混合（LH:80、BK-接发球）。
9. **晃撇配合**：侧身位晃撇与侧身挑直线交替练（BK-接发球）；两者准备动作尽量做得一样（本卡建议）。
10. **挑后衔接**：挑完接一板快撕/反带或正手（BK-挑打），再自由打。
11. **接发球实战**：先反复接同一种难发球，再加变化，最后比赛中用（PingSkills How to Practice Receiving）。与摆短、劈长混用，见 `../techniques/receive.md`。

## 10. 视频检查要点

**机位**：主机位用侧面（站在挑打者右侧，略高于球台），看上步、膝、躯干前倾和手臂前伸；补一个斜前 45° 看拍面和右脚插入台下（`../analysis/recording-guide.md`）。手机慢动作 120/240 fps，导出后用 `--capture-fps` 校正。台内动作小，脚本可能找不到挥拍（`NO_STROKES`），此时用 `--start/--end` 截取或 `--strokes` 指定。

| 阶段 | 关键帧看什么 | 对应指标（脚本输出） |
|---|---|---|
| 准备 | 站位离台约一小步、膝微屈、拍不低于台面 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 引拍/上步 | 右脚是否插到台下；重心是否前移到右脚一侧；手臂入台与上步是否同步；引拍是否很小 | `weight_shift.backswing_end`（台内挑重心应靠近 0＝持拍侧右脚，与正手拉台外球相反）、`knee_min_deg.playing`、`trunk_lean_deg.backswing_end`、`backswing_ms`（应很短） |
| 迎球 | 肘是否为支点、大臂是否大摆 | `elbow_angle_deg.backswing_end`→`.contact` 变化、`elbow_body_gap_m`、`forward_ms`、`peak_hand_speed` |
| 击球瞬间 | 击球点在身体右前、台内；手臂是否伸得过直；头是否稳 | `contact_forward_m`、`contact_height_level`、`elbow_angle_deg.contact`（接近 180° 说明伸直了）、`trunk_lean_deg.contact`、`head_motion`、`free_arm_height_level`（左手是否抬起平衡） |
| 随挥 | 挥拍方向（下旋应更向上，不转/上旋更向前）；收拍是否短 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`、`follow_ms` |
| 还原 | 是否马上退回 | `weight_shift.finish`、`recovery_dist` |
| 整体 | 发力顺序、识别正反手、数据可信度 | `sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`（台内动作小，此项参考价值低）、`side_guess`（应为正手）、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

台内拉和挑打同拍对比时，台内拉的 `backswing_ms` 应更长、`swing_path.up` 应更大（本卡推断，用于区分自己是否真的"拉"了）。

**拍面角度和手腕**：骨架模型测不出拍面，也测不准前臂旋前旋后（单机位误差很大，Shrestha 2026）。必须看击球前后的**手部放大图**（`stroke_NN_zoom.jpg`）目测：下旋来球时拍面是否打开、触球瞬间手腕是否由后向前甩、拍头是否偏低；侧旋来球时拍面是否转向抵消侧旋。`quality.reliable` 为假或手腕在 `low_visibility_parts` 里时，不要下结论，按 `../analysis/recording-guide.md` 重拍。

## 11. 自查清单

- [ ] 判断出短球后，先动脚：正手位上右脚、侧身位上左脚，必要时左脚先垫步
- [ ] 右脚插到台下，重心前移跟上，臀部没有掉在后面
- [ ] 手臂伸进台内但肘没锁死；左手抬起保持平衡
- [ ] 引拍很小，拍头偏低，手腕向后打开
- [ ] 按旋转定拍面：重下旋大幅打开向上刷，不转/上旋关拍面向前
- [ ] 接侧旋短球时会按旋转方向转拍面（右侧旋转右、左侧旋转左）
- [ ] 一般在高点期触球；快点可更早
- [ ] 主要靠前臂和手腕，触球瞬间才握紧
- [ ] 随挥短，方向对准目标；能挑斜线、直线、中路，并把方向藏到最后
- [ ] 挑完立即退回准备位置，能接住对方反撕/反带
- [ ] 会读旋转：重下旋知道打开拍面向上刷，没把握时也能用摆短或劈长变化
- [ ] 会用晃撇和侧身挑直线配合
- [ ] 知道什么时候用正手挑、什么时候用反手拧拉
- [ ] 半出台球会判断：出台就拉，不出台按旋转挑或摆
