# 正手拉上旋：前冲、反拉、连续拉、发力冲（Forehand Topspin against Topspin: Loop Drive, Counter-loop, Kill Loop）

适用场景：来球是出台的上旋或不转长球（对方的弧圈、攻球、挡球、推挡），近台到远台都会用｜难度：中级 → 高级｜相关卡片：`../techniques/forehand-loop-vs-backspin.md` `../techniques/forehand-counter-block.md` `../techniques/forehand-drive.md` `../techniques/forehand-smash.md` `../techniques/forehand-sidespin-loop.md` `../techniques/backhand-loop-vs-topspin.md` `../techniques/lob-and-fish.md` `../techniques/footwork.md` `../techniques/transitions.md`

> 全文按右手持拍写，左手持拍者左右互换。拍面角度用"拍面与台面的夹角"口径：90° 为垂直，小于 90° 为前倾（中国教育电视台课程的定义）。本卡的通用原理（发力链、旋转、击球时间五分法）见 `../fundamentals/power-and-body.md`、`../fundamentals/racket-angle-timing-contact.md`、`../fundamentals/spin.md`。

## 1. 定义与用途

正手拉上旋（forehand topspin against topspin）指用正手、以摩擦为主兼带撞击，把对方的上旋或不转长球拉成强上旋回过去。它是现代横拍进攻型选手相持中的主要得分手段。

**最核心的一句话：向前，不是向上。** 美国教练 Larry Hodges 说，对拉（counterloop）里 90% 的问题都能用"Stroke forward, not up!"这四个词概括。原因是多数人先学拉下旋，养成了向上拉的习惯，带到拉上旋里就会拉高、拉出界。来球本身带上旋，碰到球拍时会往上跳，所以拍面要更前倾、挥拍要更向前，而且要用自己的力量盖过来球的旋转，不能只把拍子"放上去"把球引回去（Hodges《Counterlooping》）。

本卡包含 7 种用法：

| 名称 | 什么时候用 | 和本卡基准动作（第 3 节）比 |
|---|---|---|
| 正手前冲弧圈（fast loop / loop drive），主动拉上旋 | 对方挡、推、攻过来的出台球，我方主动加速 | 上升后期或高点期击球，触球中上部，拍面更前倾，发力更向前（人民网、湖北经济学院） |
| 正手反拉 / 对拉（counter-loop） | 对方拉弧圈过来，我方也用弧圈回 | 按击球时间分四类：防守型、稳健型、进攻型、上升期（见第 6 节） |
| 正手连续拉（continuous looping） | 同一位置或移动中连拉两板以上 | 动作幅度收小，借随挥回位，重点在衔接 |
| 正手发力冲 / 杀板（kill loop） | 半高球、慢球、对方回球质量差 | 让球"吃透海绵碰到底板"，只打弱球或判断完全准确的球（要领见第 6 节） |
| 侧身爆冲（pivot / step-around forehand） | 反手位来球，侧身用正手 | 先用侧身步到位，右脚落地就开始前挥 |
| 中远台拉 / 被迫离台反拉（forehand topspin away from the table） | 被压到离台 1 米左右或更远 | 击球更晚、触球更靠后、更向上，弧线更高 |
| 速度与旋转变化（varying speed and spin） | 同一动作里拉出快慢、转与不转 | 挥拍更竖、摩擦更薄 → 更转；挥拍更平 → 更快 |

和相邻技术的分界：近台借力、小动作的"快带"见 `../techniques/forehand-counter-block.md`；约肩高以上的高球用扣杀，见 `../techniques/forehand-smash.md`；拉下旋见 `../techniques/forehand-loop-vs-backspin.md`；以侧旋为主的拐弧圈见 `../techniques/forehand-sidespin-loop.md`；离台 2 米以上的高吊、放高球、鱼跃见 `../techniques/lob-and-fish.md`。

## 2. 三位标杆怎么做（马龙 / 张继科 / 樊振东；只写有出处的）

本次检索没有找到马龙、张继科正手的同行评审运动学测量数据；樊振东只有一项定性研究。以下是教练观察、媒体评论、单场分析，外加一项基于比赛录像的研究和本人回忆；**没有任何角度或速度数字**。

**马龙（Ma Long）**
- 转体方式（教练看视频得出的观察）：Hodges 看马龙正手拉的慢动作后指出，马龙绕"一根穿过头顶的竖轴"转体，头只略微前移，击球点几乎在身体正侧方；腿、尤其是膝在带动转体（Hodges，2020-03-09）。他还指出，马龙拉球时左右两侧身体都参与（右侧向前转、左侧向后拉），身体完全不前冲，收拍时回到出发位置，所以能马上打下一板（Hodges，2020-11-16）。
- 相持中正手的地位：Khaleej Times 评论文章说"马龙正手非常强，那一侧的相持大多是他赢"，并说他有一种弧线更高、侧旋很强的正手上旋变化，常把樊振东调出位置；他还会不时离台退一步，给自己留出打变化的空间（评论，作者不是教练）。新浪体育 2016 年里约决赛评论写道："以往张继科的反手占优，马龙的正手有优势……马龙的相持有优势，失误比张继科要少"。
- 侧身正手（单场分析）：Edges & Nets 分析 2020 年世界杯半决赛对张本智和时说，马龙"持续攻张本的中路肘部，常用侧身正手弧圈"；同一篇也指出，因为他爱侧身，正手大角度常常空着。这只是一场比赛的观察。

**张继科（Zhang Jike）**
- 搜狐体育 2008 年评论："保持了衔接快速、反拉反带速度快等特长以外，明显增加了正手的抢拉抢冲的比例"。
- 本人回忆 2011 年世乒赛半决赛对波尔："有信心所有球都能用正手打，移动从容到会稍早到位"（日本蝴蝶公司《卓球レポート》转载）。《卓球王国》2025 年也用"关键时刻全台正手的步法"概括他。
- 《卓球レポート》称 2013 年巴黎世乒赛半决赛体现了他"关键分的强力正手弧圈"。
- 反例：新浪体育评 2016 年里约决赛，张继科"正手对拉又拉不过马龙"。

**樊振东（Fan Zhendong）**
- 卡塔尔 DOHA Stadium Plus（2016）称他以"爆发式步法和正手弧圈"著称；Butterfly 官方说他的正反手弧圈"靠出色的身体素质"。
- 一项基于 40 场比赛的研究（Jin & Ma 2026）统计：他主动上手后，正手直线和斜线进攻的得分率都高于 70%，常用正手施压得分。同一研究指出的不足是："相持中正手保护不够；来球稍晚时不能主动转髋，导致失误"。同一研究对 5 场比赛做的定性生物力学比较里，他的正手与对手"没有显著差异"。研究对象是比赛录像，不是实验室测量。
- 央视网 2020 年报道："樊振东坚定通过正手高质量进攻寻求突破"。

**业余球员能学什么**：马龙"绕竖轴转、头不前冲、在身体侧面击球、打完就回位"这几条，有教练观察作依据，业余球员可以直接对照；樊振东"来球晚了转不动髋就失误"，正好说明击球点不能被球挤到身后。张继科小时候由父亲在家里小院练步法和体能（蛙跳、单腿跳、交叉步、并步、跨跳），记者也感慨他"腿部肌肉太发达了"（新浪转载《乒乓世界》2010，链接见参考来源），详见 `../players/zhang-jike.md`。三人的整体对比见 `../players/comparison.md`。

## 3. 动作分解

基准动作：中台（离台约 50–100 cm，即中近台到中远台）对一板中等速度的上旋长球做稳健型反拉或主动拉。近台、远台和其他来球的差别见第 6 节。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚比肩稍宽，左脚略前；前脚掌（偏内侧）着地，脚跟微离地；判断出来球方向后**先动脚、后动手**，到位并站稳后再击球 | 两脚太窄，重心转移不出来；脚跟踩实，起动慢 |
| 膝 | 微屈、略内扣，像随时要起跳 | 直腿站立，蹬地没有余量 |
| 髋 | 略向后坐，臀部不翘不塌 | 髋部僵直，转髋启动慢 |
| 腰/躯干 | 上体略前倾、收腹，重心在两脚之间 | 上体后仰，来球一快就往后躲 |
| 肩 | 放松、两肩基本水平；左臂自然抬在体前，帮助保持平衡 | 耸肩、肩部发紧（"肘上浮"的根源，见第 8 节） |
| 大臂/肘 | 肘部自然下垂，和身体之间留出空隙 | 肘夹死在肋旁，或外翻抬起 |
| 前臂 | 自然平举在体前 | 前臂下垂，拍子放得太低 |
| 手腕 | 放松，保持自然；不要明显下垂 | 手腕"耷拉"下来，拍面不稳，容易擦边、带出多余侧旋 |
| 手指/握拍 | 横拍像握手；打正手时食指可稍上移；握得松，别人能把拍子从你手里抽动 | 握死，手臂发硬 |
| 拍面/拍头 | 拍在体前、腹部高度，拍面略前倾 | 拍放在身体右侧太远处，转正反手来不及 |
| 视线/头 | 盯住对方击球动作和拍面，读出来球的旋转、速度、落点 | 只看球不看对方的拍，判断晚半拍 |

### 3.2 引拍（backswing）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到右脚，右脚内侧蹬住地面；需要移动时边移动边引拍 | 先引拍再移动，或到位后才开始引拍（停顿） |
| 膝 | 右膝屈曲加深，储存蹬地的力量 | 膝不弯，只靠手臂向后拉 |
| 髋 | 右髋略向下坐，并随身体向右后转 | 髋不转，只转肩 |
| 腰/躯干 | 腰向右转，转到感觉重心落到右脚即可 | 腰转过头，成"掷铁饼式"，回不来 |
| 肩 | 右肩随转体向后；比拉下旋时右肩下沉得少 | 右肩压得过低，形成向上拉的路线 |
| 大臂/肘 | 大臂随转体自然向后，肘略弯、不伸直；**不要单独把肘向后拉** | 靠"拉肘"引拍，前臂翘起，拍子到了肩后 |
| 前臂 | 自然放低，使拍子位于来球后方、略低于来球 | 前臂抬高或沉得太低（太低就只能向上拉） |
| 手腕 | 放松，可略向后引，留出击球时顺势带一下的余地；来球越快，手腕动作越小 | 手腕向后折得很多，触球时控制不住拍面 |
| 手指/握拍 | 保持放松 | 引拍时就攥紧 |
| 拍面/拍头 | 拍面保持前倾；拍头略向下、向后 | 拍面打开（后仰），一挥就拉高 |
| 视线/头 | 头随转体略转，眼睛不离开球 | 头跟着大幅转动，丢球 |

引拍和前挥要连成一个动作。Hodges 的原话是："先引拍、停住、再向前，是坏习惯。"（《Stepping Around the Backhand Corner》）这句话的语境是侧身步：引拍到位以后停住、再向前挥。转体时拍子先停在胸前高度、随后才下沉，是另一种现象，不要套用这句话。

### 3.3 迎球挥拍（forward swing）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地，重心开始由右脚移向左脚 | 脚不蹬地，重心留在右脚上 |
| 膝 | 右膝由屈到伸，带动髋部转动；腿是每一板的起点 | 膝始终僵着，下肢不参与 |
| 髋 | 向左转、挺髋；髋带腰，不是腰带髋 | 髋没转，躯干单独扭 |
| 腰/躯干 | 绕身体竖轴转动，上体不向前扑 | 身体向前冲，打完失去平衡 |
| 肩 | 右肩向前转；左肩向后打开，左臂向体侧回收，左右两侧一起参与 | 只转右侧，左半身不动 |
| 大臂/肘 | 大臂由右后向左前方挥动，肩内旋发力；肘保持低，绕肘做"小弧形"挥动 | 肘先抬起来（"肘上浮"）；手臂直线向前推 |
| 前臂 | 由大臂带动后加速"收小臂"；收的时机要和触球对准 | 收得过早（力已用完才碰到球）或过晚（来不及发力），都会"吃不住球" |
| 手腕 | 基本稳定，跟随前臂 | 主动大幅甩腕，拍面乱 |
| 手指/握拍 | 保持放松，让手臂像橡皮筋一样甩出去 | 全身用死力，动作抽搐 |
| 拍面/拍头 | 拍面前倾；挥拍路线**以向前为主、略向上** | 路线以向上为主，拉对上旋时偏高、出界 |
| 视线/头 | 头稳定，只略微前移，眼睛跟球到拍上 | 抬头看落点，头先于球拍向前 |

### 3.4 击球瞬间（contact）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心正从右脚转向左脚；双脚仍抓地 | 已经跳起或单脚离地 |
| 膝 | 仍保持弯曲 | 膝完全伸直，整个人站高 |
| 髋 | 正在转动之中，不能等转完了再触球 | 髋已转完，只剩手臂在打 |
| 腰/躯干 | 转体中触球；上体略前倾的角度基本不变 | 上体后仰（来球快时最常见） |
| 肩 | 右肩向前上方转出 | 右肩仍落在后面（击球点太晚） |
| 大臂/肘 | 肘既不完全伸直也不完全折叠；肘高低于肩 | 手臂伸直去够球，或肘抬到与肩同高 |
| 前臂 | 收小臂达到最快 | 前臂已经减速 |
| 手腕 | 稳住拍面；主动拉前冲时手腕可向内、向前略转一下 | 手腕后折或下垂，拍面晃动 |
| 手指/握拍 | 触球时手指自然握实，过后马上放松 | 一直死握 |
| 拍面/拍头 | 拍面前倾，比拉下旋时明显更前倾；摩擦球的中上部到上部、略偏后，也可略偏球的外侧（远离自己的一侧） | 拍面太竖，球被"撞"出去拉不住；太前倾，摩擦太薄，球"飞碟"式下网 |
| 视线/头 | 头稳，眼睛看着触球 | 头和上体一起前冲 |

击球点在身体右侧、偏前一点，接近身体正侧方。不要太靠前去够，也不能落到身体后方。

### 3.5 随挥（follow-through）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落到左脚，右脚可顺势跟半步 | 重心停在右脚，或整个人向前扑出去 |
| 膝 | 左膝承重、微屈 | 左腿直挺挺地顶住 |
| 髋 | 转到大致正对球台 | 髋转过头，背对球台 |
| 腰/躯干 | 转体自然停止，身体回到中轴附近 | 上体继续向前倒 |
| 肩 | 右肩转到前方，随后立即放松 | 肩部持续发紧 |
| 大臂/肘 | 手臂收向左前上方，肘自然弯曲 | 手臂伸直甩到左侧（横扫） |
| 前臂 | 收至头前、额头附近；PingSkills 给攻球（drive）选手的建议是收拍时拍子碰到眉毛，这样肘会自然弯起来 | 收拍太低（PingSkills 列出的正手拉三个常见错误之一），或收到头顶后方（拉得太往上） |
| 手腕 | 顺势放松 | 手腕僵直 |
| 手指/握拍 | 放松 | 继续握紧 |
| 拍面/拍头 | 拍面仍前倾，拍头指向左前上方 | 拍面翻开朝上 |
| 视线/头 | 眼睛跟着球看向对方 | 头甩到一边 |

### 3.6 还原（recovery）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 借随挥的惯性回位：在正手位拉完蹬右脚回位；侧身拉完重心在左脚，顺势蹬回 | 打完原地欣赏，或回位方向不对 |
| 膝 | 重新微屈，准备下一次起动 | 站直了休息 |
| 髋 | 回到准备时的朝向 | 停在转体终点 |
| 腰/躯干 | 上体回到略前倾 | 上体仍偏向左侧 |
| 肩 | 迅速放松 | 肩部持续紧张，下一板更紧 |
| 大臂/肘 | 肘回到体前，与身体留出空隙 | 手臂停在左上方 |
| 前臂 | 把拍子带回体前 | 拍子垂在身体左侧 |
| 手腕 | 回到自然位置 | 仍维持随挥角度 |
| 手指/握拍 | 放松；需要时微调为正反手兼顾的握法 | 一直握在正手偏的位置，反手来不及 |
| 拍面/拍头 | 回到体前中间位置 | 拍面停在随挥终点 |
| 视线/头 | 看对方的击球准备 | 低头看自己的拍子 |

对方击球时你应该已经站稳：Hodges 的说法是，"位置略偏但站稳"好过"还在移动中"。至于是否每板都要回到固定的中立位，教练意见不一：Hodges 主张每板都回中立位；PingSkills 认为与其机械复位，不如跟踪来球，把拍直接移到下一板需要的位置。

## 4. 拍面角度、击球点、击球时间、触球部位

| 用法 | 拍面角度 | 击球点 | 击球时间 | 触球部位 |
|---|---|---|---|---|
| 主动拉前冲 | 明显前倾，比拉加转更前倾 | 身体右侧略偏前 | 上升后期或高点期 | 中上部 |
| 稳健型反拉 | 前倾 | 身体右侧，离台稍远 | 高点之后、球落到台面高度以下之前 | 中上部，略偏后 |
| 进攻型反拉 / 发力冲 | 更前倾 | 身体右侧 | 尽量接近高点 | 上部偏后 |
| 上升期反拉（贴台） | 最前倾，拍举得较高 | 身前近台 | 球刚弹起、到高点之前 | 几乎是正上部 |
| 防守型反拉（远台） | 前倾程度较小 | 身体右侧，较低（约膝高） | 下降后期 | 偏后，比上面几种更靠后 |

击球时间与五分法（`../fundamentals/racket-angle-timing-contact.md`）的对应：上升期反拉 ≈ 上升前期（到上升后期）；进攻型 ≈ 高点期；稳健型 ≈ 下降前期（Hodges 说的"高点之后、球落到台面高度以下之前"）；防守型 ≈ 下降后期（约膝高）（按描述对应，原资料未用五分法）。

- 拍面角度：教学资料给出的前冲拍面度数互相矛盾（一处约 80°，另一处的 60° 找不到原出处），所以本卡不给度数，只给规律：来球越转、越快，拍面越前倾。Iino 和 Kojima（2009）发现，面对不同旋转的来球（该研究用的是轻、重两种下旋），选手调整的主要是击球时的拍面角度，而不是挥拍路线的倾斜度。对上旋来球，Hodges 主张挥拍方向要随离台距离、来球速度和旋转调整（《Counterlooping》；见第 5 节"方向"），拍面角度也跟着调。
- 击球点：太靠前会转不回来、发不上力，还要伸手去够，身体失去平衡，这是 Hodges 认为最常见的毛病；落到身后则发不出力（樊振东的不足也在这里，见第 2 节）。直线与斜线可以用触球早晚来控制（PingSkills）；Hodges 的具体建议是，对拉时想打直线，就把球放晚一点再打。
- 触球部位：Hodges 主张对拉时摩擦球的上部偏后，并略偏球的外侧，带一点侧旋。这样更顺手，也避免和来球上旋正面相撞。
- 球落在身前、下坠的软弧圈：要么上前，要么几乎摩擦球的正上部，并且**忍住向上提的冲动**（Hodges）。

## 5. 发力：顺序、方向、摩擦与撞击

**顺序（近端到远端）**：蹬地 → 转髋、挺髋 → 转腰 → 肩、大臂 → 收前臂 → 手腕顺势。中文教学写作"右脚蹬地、挺髋、转腰、收小臂"（湖北经济学院），"腿、腰、上臂、前臂依次进行动量传递"（人民网）。英文教学说法一致：从腿开始，经髋腰、肩、手臂到手腕平滑衔接（Hodges、PingSkills）。研究也有支持：持拍侧骨盆的转动与击球时**水平方向**的拍速正相关（Iino 2018）；高水平选手下躯干转动对拍速的贡献更大，肩内旋力矩更大，躯干的能量传到上臂更快（Iino & Kojima 2009、2011）。注意：这三项研究的来球都是下旋。对上旋挥拍以向前为主，所以转髋、转腰带来的水平拍速尤其重要（推论）。

**方向**：对上旋，主要向前、略向上。离台越近、来球越快越转、自己越想发力，触球就越靠上、挥拍越向前；离台越远、来球越慢越弱、自己想拉得越柔，触球就越靠后、越向上（Hodges）。

**左右两侧一起转**：右侧向前转的同时，左侧向后"拉"，围绕身体中轴转一个圈；不要只转右半身（Hodges 以马龙为例）。

**摩擦与撞击**："先打后摩，又打又摩，以摩为主"（《乒乓世界》，经百度百科转引）。Hodges 按球吃进胶皮的深度把上旋触球分成几档：
- 只擦胶皮：慢而转，主要用于对付重下旋。
- 中等吃进海绵：最稳，力量平分给速度和旋转。
- 深吃海绵：强力弧圈。
- 吃透海绵碰到底板：杀板，只打弱球。
- 平击撞透海绵：扣杀、平攻、挡球。

对拉上旋时，通常用"中等"到"深吃海绵"。想拉得更快，挥拍要更快，触球要稍平一些，但仍然要有摩擦（PingSkills）。想拉得更转，挥拍更竖、摩擦更薄（PingSkills）。

**加速穿过球**：不要想着"打到球"，要想着让拍子加速穿过球；要平滑地加速，不要"用死力"（Hodges）。研究发现，高水平组和中等组击球瞬间的拍速并没有显著差别，高水平选手拍速-时间曲线的最大斜率更大（加速更猛），加速所用时间也趋于更短（Iino & Kojima 2009，来球为下旋）。

**手腕和肘**：PingSkills 认为手腕在正手中作用小，但放松的手腕仍能加一点速度；Hodges 建议引拍时手腕略向后，尤其在来球较慢时顺势甩过球。肘的用法有两派：肘一直弯着、基本不动（常被称为"欧洲式"），或者手臂先较直、触球时收肘（常被称为"中国式"）。PingSkills 的回答是"两种都对，都出过冠军"。

## 6. 面对不同来球的调整

**按来球**

| 来球 | 调整 |
|---|---|
| 对方加转弧圈（弧线高、转） | 拍面更前倾，触球更靠上；不要退台太多去等它下落。接高吊弧圈应在球刚弹起时迎前（百度百科） |
| 对方前冲弧圈（快、低） | 引拍更小、更早，拍举得较高；离台稍退半步，做稳健型反拉；被压得太紧就改为快带或挡，见 `../techniques/forehand-counter-block.md` |
| 对方挡球、推挡（快、弱上旋） | 主动拉前冲，上升后期或高点期击球；可以发力冲 |
| 软、短、在身前下坠的弧圈 | 上前；或几乎摩擦球的正上部；忍住不要上提 |
| 不转长球 | 比拉上旋时挥拍略向上一点、拍面略立；比拉下旋时更向前 |
| 带侧旋的弧圈 | 按来球侧旋的方向微调拍面的左右朝向，抵消侧旋；也可以用拐弧圈回，见 `../techniques/forehand-sidespin-loop.md` |
| 半高球、机会球 | 发力冲或杀板；约肩高以上改扣杀 |
| 拉完下旋后的第二板（上旋） | 拍面立刻关小、挥拍改为向前；第二板最容易出界（PingSkills《The Forehand After Your Opening Topspin》） |
| 追身球（中路，打持拍手肘部） | 中路是正反手交界点，要及早决定用正手还是反手（PingSkills《Conquer the Crossover Point》）。定了正手：快球来不及动脚，就靠宽站位、屈膝，髋和上身向左让开；慢球用脚移到位，打完整一板（PingSkills《How to Handle Balls Aimed at Your Middle》）。让位是为了把击球点放回身体右侧；被挤时引拍收短，拍面保持前倾、挥拍向前，以快带为主；不要夹肘、后仰躲球，否则拍面打开、球拉高（推论）。马龙曾持续攻张本肘部（单场，第 2 节）。要领见 `../techniques/transitions.md` 3.2、`../techniques/footwork.md` 3.12 |
| 扑正手（正手大角、离身体很远） | 先动脚：近用并步，远用交叉步，交叉步回位难，要练停稳（PingSkills《Shuffle or Crossover for a Wide Forehand?》）；向侧前方迎上截球，别横着追（Hodges 讲挡球；用于拉球为推论）。到位后右脚蹬住、转髋再挥，击球点仍在身体右侧，不能被带到身后：樊振东的不足就是"来球稍晚时不能主动转髋"，论文建议他加强正手大角保护（Jin & Ma 2026）。实在够不到才伸手，此时动作收小、拍面保持前倾，用稳健型反拉回球、弧线略高（推论）。侧身后正手大角最空（张本打马龙，第 2 节）。要领见 `../techniques/transitions.md` 3.3、`../techniques/footwork.md` 3.2、3.6 |

**按站位：近台 / 中台 / 远台**

距离划分参考扬州市职业大学的教学资料：近台为离台 30–50 cm 以内，中近台 50–70 cm，中远台 70–100 cm，远台 1 米以外。

| | 近台 | 中台（中近台、中远台） | 远台 |
|---|---|---|---|
| 对应的反拉类型 | 上升期、进攻型 | 稳健型（最常用） | 防守型 |
| 引拍 | 短，拍举得较高，主要靠前臂加转腰 | 中等幅度，腿、髋、腰都参与 | 大，重心更低，主要靠蹬腿和转体 |
| 击球时间 | 上升前期到高点期 | 下降前期（落到台面高度以前） | 下降后期，约膝高 |
| 触球 / 方向 | 几乎正上部，向前 | 上部偏后，向前略向上 | 更靠后，更向上，弧线高（可过网很高） |
| 身体 | 重心略高；髋屈曲小 | 标准 | 屈膝更深；全身发力，旋转为主 |
| 风险 | 需要预判，只对较弱的弧圈用 | — | 球慢，给对方时间；要拉深、拉转 |

近台与远台动作幅度的差别，有一项未经同行评审的预印本给出了方向一致的观察：近台拉时拍速最快时球拍位置更高，髋屈曲更小（Winiarski 等，2026 预印本）。被迫离台时仍可以继续进攻（PingSkills《Forehand Topspin Away from the Table》），但离台再远、只能把球托高时，就进入"放高球 / 鱼跃"的范畴，见 `../techniques/lob-and-fish.md`。

**同一动作里的速度与旋转变化**：挥拍更竖、摩擦更薄 → 更转更慢；挥拍更平、吃球更厚 → 更快（PingSkills《Varying Forehand Topspin Speed and Spin》）。Hodges 说的慢转弧圈（slow, spinny loop）主要用来对付下旋（《The Slow, Spinny Loop》）；在对拉中把它当作变化时，要求同样是全力挥拍、薄擦，力量几乎都转成旋转，不是软球。

**发力冲 / 杀板（kill loop）**：
- 触球：Hodges 的描述是拍面仍带角度（有摩擦），但力量大到把球压透海绵碰到底板，撞击成分比普通前冲明显更多（《Types of Topspin Contact》）。
- 什么时候用：只打弱球；或者偶尔对较难的球用，但前提是站位完美、对来球（尤其是旋转）判断完全准确（同上）。
- 击球时间：尽量接近高点期（第 4 节表格）；主动前冲的击球时间，人民网、湖北经济学院写的是上升后期或高点期。
- 和扣杀的分界：约肩高以上的高球改用扣杀，见 `../techniques/forehand-smash.md`。
- 引拍幅度、重心、站位：没有找到专讲杀板的出处，按第 3 节基准动作做，靠更快的挥拍加速（第 5 节"加速穿过球"）发力，不要为发力而前扑。

**连续拉**：连续多板时动作幅度自然收小。研究中三板组合拉的各关节活动范围比单板小，选手"时间少，就缩小了动作幅度"（Bańkosz & Winiarski 2025）。要领：每板借随挥回位；第二板以后引拍更短；靠步法把球放进同一个击球区，而不是用手去够（Hodges）。

**侧身爆冲**：
1. 左脚先向左迈一小步。
2. 蹬左脚跳转，右脚绕到足够远的位置，免得击球时太挤。
3. 转肩，使两肩至少与端线平行，重心落在右脚。
4. 右脚一落地就开始前挥（Hodges《Stepping Around the Backhand Corner》）。

要侧就侧到底。侧一半，身体会向左歪，打完更难回位（Hodges，2025）。拉完以后重心在左脚，顺势蹬回。侧身后正手大角会空出来，见上表"扑正手"。

**器材**：对拉需要黏性或摩擦好的反胶（Hodges）。胶皮、海绵硬度对动作的影响见 `../fundamentals/equipment-and-technique.md`。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 拉上旋总是拉高、出界 | 把拉下旋的向上路线带了过来；拍面不够前倾 | 默念"向前，不是向上"；拍面关小；对着挡球练，收拍高度定在额头前 |
| **肘上浮**（floating elbow）：前挥时肘先抬起、手腕下垂 | 肩部紧张，肩转不动，肘只能向上走；人站得离球太近 | 先放松肩，再有意识地把肘压低；动作适当放大，与球保持距离；要在训练中反复练很多次，比赛里才能改过来（PingSkills） |
| 手腕下垂，球带出多余侧旋、常擦边 | 手腕过度放松、"耷拉" | 手腕略抬起、打开，让拍面对正来球（PingSkills） |
| 击球点太靠前，伸手够球 | 步法没到位；转体前手臂先走 | 等球进入身体侧面再打，转体中触球；靠脚步调整距离 |
| 身体向前冲，打完失去平衡 | 用上体压球，而不是绕竖轴转 | 想象头顶有一根竖杆，绕它转；打完回到出发位置 |
| 触球太晚，球被挤到身后 | 判断慢、引拍晚，或退台太多 | 提早引拍；对弧圈不要随便退台 |
| 只用手臂，球没劲 | 下肢和髋没参与；左半身不动 | 先徒手练"蹬—转髋—转腰"；左臂向后收，带动转体 |
| 腰转过大（掷铁饼式） | 以为转得越多越有力 | 转到重心落到右脚即可 |
| 靠"拉肘"向后引拍 | 大臂单独向后抽 | 有意识地放下前臂，让转体带动大臂引拍 |
| 拍面过于前倾、摩擦太薄，球"飞碟"式下网 | 过分追求旋转 | 稍立拍面，吃进海绵；对上旋以"中等吃进海绵"为主 |
| 收拍太低，球下网 | 不敢向上；挥拍路线太平 | "finishing the stroke too low"是 PingSkills 列出的正手拉常见错误；收拍到头前、额头附近（PingSkills 对攻球选手的建议是拍子碰到眉毛） |
| 只是"放拍挡回"，回球软 | 怕失误，被来球旋转顶着走 | 用自己的力量盖过来球的旋转，加速穿过球 |
| "吃不住球" | 收小臂过早（身体的力已用完）或过晚（来不及发力） | 多球练"转体带收臂"的时机，听触球声是否一致 |
| 侧身只侧一半 | 怕回不来 | 侧到位，打完顺势蹬回 |
| 打完原地不动 | 没把还原当成动作的一部分 | 把随挥接回位练成一个动作；对方击球时你要已经站稳 |
| 肩、手臂越打越紧 | 用全力"抽"球 | 不用全力，做平滑的加速；每板打完马上放松肩 |

更多错误的归类见 `../training/errors-index.md`。

## 9. 练习方法（入门 → 进阶）

1. **徒手挥拍（shadow）**：对镜子或手机，按第 3 节逐阶段做，重点看肘是否压低、头是否前冲、收拍高度。Hodges 建议初学者每天正反手攻、拉各做 100 次徒手练习。
2. **多球定点**：喂球者喂中等速度的上旋或不转长球到正手位，先练稳定的路线和收拍高度，再逐步加快喂球节奏。
3. **拉对挡（topspin against block）**：同伴正手或反手挡，你在正手位连续拉斜线。Hodges 的标准是：能连续打 20 板，再进入下一阶段。
4. **连续拉多球**：喂球者连续喂 5–8 个上旋到同一点或两点，要求每板借随挥回位、引拍逐板收小，靠步法把球放进同一击球区。看视频时对比各板的 `backswing_ms`、`recovery_dist`，判断节奏是否稳定。
5. **一板拉下旋接连续拉**：同伴先搓（或喂）一个下旋，你拉起后转入拉对挡。专练第二板"拍面关小、挥拍向前"的转换。
6. **两点对一点 / 推拉结合**：同伴把球分到你的正手位和中路，你都用正手拉，练小步调整和还原。
7. **侧身练习（Falkenberg，两反一正）**：同伴依次把球送到你的反手位、反手位、正手位；你用反手、侧身正手、扑正手大角度三板一组循环。练"侧到底、右脚落地就挥拍、顺势回位"。
8. **对拉（loop to loop）**：先斜线中台稳健型对拉，再练直线；然后一人前冲、一人退台反拉，体会近、中、远台的动作差别。
9. **速度与旋转变化**：同一线路交替拉"慢而转"和"快而冲"，对方不知道下一板是哪种。
10. **随机与计分**：全台随机落点，你按来球选择反拉、前冲或杀板；把对拉练习变成 11 分制的计分比赛。
11. **发力冲 / 杀板**：多球喂半高球，练"吃透海绵碰到底板"的发力（要领见第 6 节）；比赛中只对弱球使用，或在站位完美、判断完全准确时偶尔用。

训练量和伤病预防见 `../training/drills.md`、`../training/physical-and-injury.md`。

## 10. 视频检查要点

**机位**：主机位放在持拍手一侧（右侧）的正侧面，镜头大致与端线平行、对着身体，拍全身（含双脚和拍头）。补拍机位：正面（球台对面）或斜前 45°，看转体、重心左右转移、收拍位置。使用 120/240 fps 慢动作；30 fps 两帧之间球拍可能移动 0.4 m 以上（按 13–15 m/s 的拍速推算），抓不到击球瞬间。如果是手机慢动作导出的视频，要用 `--capture-fps` 填入真实的拍摄帧率。详见 `../analysis/recording-guide.md`。

**单机位的局限**：侧面拍摄时，膝、髋屈曲和肘屈伸这类在成像平面内的动作比较可信；躯干和骨盆的转动、肩内旋、前臂旋转都离开了成像平面，单机位不可靠，快速前挥阶段误差最大。所以 `shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg` 只适合看趋势、做同一人前后对比，不能和论文数值比较。先看 `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`；不可靠就照 `../analysis/recording-guide.md` 重拍。

**拍面角度只能看手部放大图**（`stroke_NN_zoom.jpg`，击球前后各 2 帧）。在图上看：
- 拍面相对台面是否明显前倾，是否比自己拉下旋时更前倾；
- 手腕是否下垂（肘上浮常伴随手腕下垂）；
- 触球前后拍面是否稳定。

骨架模型测不出拍面和握拍。

**判读要点**：
- `swing_path.angle_deg` 拿来和同一人拉下旋的数值比，拉上旋应明显更平；不设绝对阈值。
- `contact_forward_m` 偏大，说明击球点太靠前；明显偏小，说明球被挤到了身后（正负方向以 `../analysis/metrics-reference.md` 的定义为准）。
- 肘上浮的判断：看分解图里击球前肘相对肩的高度，并结合 `elbow_body_gap_m` 和手部放大图。
- 连续拉时，比较各板的 `backswing_ms` 和 `recovery_dist` 是否越来越乱。

## 11. 自查清单

- [ ] 我拉上旋时想的是"向前"，而不是"向上"
- [ ] 拍面比拉下旋时更前倾；来球越快越转，拍面越前倾
- [ ] 准备时两脚比肩稍宽、屈膝、前脚掌着地，先动脚后动手
- [ ] 引拍时重心落到右脚，转腰不过头，没有单独拉肘
- [ ] 前挥从蹬地、转髋开始，左右两侧身体一起转
- [ ] 肘保持低，没有上浮；手腕没有下垂
- [ ] 击球点在身体右侧、接近正侧方，不太靠前，也不在身后
- [ ] 头和上体不前冲，打完回到出发位置
- [ ] 收拍在头前、额头附近，不太低也不甩到头后
- [ ] 能分清近台、中台、远台三种反拉，知道各自的击球时间
- [ ] 拉完下旋后的第二板，能立刻改成向前的挥拍
- [ ] 侧身时侧到底，右脚落地就挥拍，打完顺势回位
- [ ] 能在同一动作里拉出快慢、转与不转的变化
- [ ] 杀板只打弱球；对方击球时我已经站稳
- [ ] 打完每一板肩都能马上放松
