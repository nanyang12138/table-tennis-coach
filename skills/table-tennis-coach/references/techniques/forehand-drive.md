# 正手攻球（Forehand Drive / Counterhit）

适用场景：近台对上旋、不转的出台球快速回击；中台对上旋球主动发力；侧身用正手抢攻；扣杀、拉球的基础动作｜难度：入门（近台快攻）→ 中级（中台攻、侧身攻、变线、上升期）→ 进阶（突击、滑板式变线）｜相关卡片：`../fundamentals/grip.md` `../fundamentals/ready-stance.md` `../fundamentals/power-and-body.md` `../fundamentals/racket-angle-timing-contact.md` `forehand-counter-block.md` `forehand-smash.md` `forehand-loop-vs-topspin.md` `forehand-loop-vs-backspin.md` `forehand-flick.md` `footwork.md` `penhold.md`

> 全文按右手持拍写；左手持拍者左右互换（左脚↔右脚、向左前上↔向右前上、斜线/直线方向镜像）。拍面角度统一用"拍面与台面的夹角"：90° 为垂直，小于 90° 为前倾，大于 90° 为后仰（[CETV-击球技巧]）。

## 1. 定义与用途

**正手攻球**：用正手、以撞击为主、略带摩擦，把上旋或不转的来球快速打回去。百度百科把它称为"近台快抽"，并写明"本文所讲的正手攻球是指近台快攻，以攻不旋和上旋为主"（[BK-正手攻]）。英文维基对 hit / speed drive 的描述是：拍面大致垂直于挥拍方向，力量主要变成速度、旋转较少（[enwiki-TT]）。PingSkills 把 forehand counterhit 也叫 forehand drive，作为学正手拉（topspin/loop）的基础课（[PS-counterhit]）。

**用途**：保持回合、施加压力、为更强的进攻（扣杀）创造机会（[enwiki-TT]）；与落点变化结合可调动对方，为扣杀创造条件（[BK-正手攻]）。

**分类（按站位和用途）**
- 近台正手快攻：离台约 40–50 cm，动作小、出手快，以借力为主（[BK-正手攻]、[BK-攻球]）。
- 中台（中远台）正手攻球：离台约 1 m，动作较大，以自己发力为主（[BK-正手攻]，单一来源）。站位距离的划分：近台 30–50 cm、中近台 50–70 cm、中远台 70–100 cm、远台 1 m 以外（[扬州职大]）。
- 侧身正手攻：在反手位让开身体、用正手攻（[BK-正手攻]），步法见 `footwork.md` 第 3.7 节侧身步。
- 正手快点：近网短球（台内或刚出台）用正手小动作快点，见第 6 节和 `forehand-flick.md`。

**术语说明**
- "抽球""快抽""拉抽""扫抽"：中文资料对攻球的叫法。中文维基说"抽球"一般指不依赖旋转的快攻，和靠摩擦的"拉球"（弧圈）不同（[zhwiki-弧圈球]）；百度百科"攻球"条目把动作类型列为快抽、拉抽、扫抽、扣杀（[BK-攻球]）。这几个叫法没有找到权威的逐项定义。
- 平击 / ミート打ち：日文维基的"ミート打ち"指主要由正胶选手使用、像扣杀一样强力弹击带旋转来球的打法，拍子挥得紧凑，"不擦球"，所以旋转少、单板威力不算最大，但击球点早，对方来不及反应（[jawiki-卓球]）。中文"平击"一词常被这样使用，但没有找到中文权威定义。反胶横拍选手的近台攻球仍应"有擦有打"（[BK-正手攻]）。日文的"フォアハンドロング"（正手攻）也写明是不刻意加转、略带上撩、会带一点上旋的基础挥拍（[jawiki-卓球]）。
- 突击：中文维基把"正手挑打、突击"列在"台内接发球或回球"下（括注"常形成出台对攻"）（[zhwiki-乒乓球]），CETV 在搓攻、拉攻战术里也写"突击或扣杀"（[CETV-战术]），但**没有找到"突击"的权威定义**。本卡用作工作定义：对不太高、下旋不强或不转的机会球（冒高的搓球、半出台球），突然加力、以撞击为主的进攻。和扣杀的界限：扣杀用于大约肩高或更高的球（[PS-smash]），突击针对的球更低、旋转更难判断，所以拍面更保守，力量控制在中等——CETV 接发球抢攻写"用快点、快攻或中等力量突击"，并提醒"一般不可过凶"（[CETV-接抢]）。

**和正手拉球的区别**

| 项目 | 正手攻球 | 正手拉球（弧圈） |
|---|---|---|
| 触球 | 撞击为主、略带摩擦（[BK-正手攻]） | 薄擦为主，制造强上旋（[zhwiki-弧圈球]） |
| 拍面 | 稍前倾，约 80°（[CETV-攻球]） | 对上旋更前倾，对下旋更立；见拉球卡 |
| 挥拍方向 | 向左前上方，向前为主 | 更多向上（拉下旋）或向前（拉上旋） |
| 引拍 | 小，约与台面齐高（[CETV-攻球]） | 更大、更低；PingSkills：拉下旋是在攻球基础上"加长动作、加入摩擦"（[PS-topspin-vs-backspin]） |
| 来球 | 上旋、不转 | 上旋、下旋都可以 |
| 业余选择 | 年长或体能一般者可多攻、多挡，对精英以下的对手也能赢（[LH-3505]） | 现代比赛中多数情况更好的选择，但要求体能（[LH-3505]） |

## 2. 三位标杆怎么做（马龙 / 张继科 / 樊振东；只写有出处的）

先说明：三人都是现代弧圈结合快攻打法。**没有找到专门分析他们"正手攻球（平击）"动作的可靠出处**，下面只写跟正手进攻共通的、有出处的观察；他们的正手拉球见拉球卡和 `../players/` 下的档案。

**马龙**
- 击球点在身体侧面、绕竖轴转体：美国教练 Larry Hodges 建议正手不要在身体太靠前的地方触球，而是在身体侧面、右腿旁触球，"想象一根竖杆穿过头顶，绕着它转"，并以马龙的视频为例，写明"这对拉球和普通攻球（regular drives）都适用"（[LH-2415]）。这是教练看视频的观察，不是测量。
- 2013 年央视网评论说马龙"以速度见长"，但大赛中整体穿透力（旋转加力量）不够（[CCTV-2013-05-21]）。说明光有速度不够，要配合旋转和力量。
- 2020 年世界杯对张本智和一场，张本专打马龙正手大角；博客作者认为因为马龙有侧身习惯，他的正手位常常特别空（[EN-2020WC]，单场博客分析）。业余球员练侧身攻时同样要练侧身后扑正手（第 9 节）。

**张继科**
- 2011 年世乒赛半决赛对波尔，他本人说当时"有信心所有球都能用正手打"，移动从容到会"稍早到位"（[TR-014392]，《卓球レポート》转载的本人原话）。卓球王国也用"关键时刻全台正手的步法"形容他（[卓球王国-2025]）。编者理解（非出处原话）：正手覆盖面靠步法提前到位，不是靠手够。
- 正手攻球本身的动作细节：暂无可靠出处。

**樊振东**
- 一篇分析 40 场比赛的论文统计：他主动时常用正手施压，正手直线、斜线进攻得分率都高于 70%；同时指出相持中正手大角度保护不够，"来球稍晚时不能主动转髋，导致失误"（[Jin-Ma-2026]）。论文统计的是"正手进攻"，没有区分攻和拉；这是论文作者的解读，不是教练组评价。
- 对业余球员的启示（有出处的部分）：来球晚、转髋不到位是精英也会出的错，见第 8 节"只用手臂"。

## 3. 动作分解

以近台正手快攻为基准；中台（中远台）攻、侧身攻与它的差别集中写在 3.7 节，来球调整见第 6 节。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 近台中偏右站位，左脚稍前，身体斜对球台（[CETV-攻球]）；两脚与肩同宽或稍宽，前脚掌着地、脚跟微离地（[CETV-姿势]）。熟练后近台快攻可两脚接近平行（见 3.2） | 初学者完全平行站或前后站太开，又控制不了拍面，易出左边线（[BK-正手攻]） |
| 膝 | 两膝自然弯曲（[BK-正手攻]） | 直腿站立，无法蹬地 |
| 髋 | 稍向后坐，与膝配合降低重心 | 髋顶前，重心落在脚跟 |
| 腰/躯干 | 上体略前倾、收腹（[CETV-姿势]）；右肩略沉（[BK-正手攻]） | 弯腰驼背或上身直立 |
| 肩 | 放松，整条手臂像橡皮筋一样松（[LH-51]）；紧张时下颌和肩最先发紧（[LH-51]） | 耸肩，后面会抬肘 |
| 大臂/肘 | 横拍肘部向下（[CETV-姿势]）；上臂离开身体，有教学资料给"上体与大臂夹角一拳宽"（[BK-正手攻]，单一来源） | 夹肘（大臂贴死身体）或肘外张 |
| 前臂 | 自然弯曲，大致平举；大小臂约成钝角（有资料给约 120°，单一来源，见第 7 节） | 大小臂夹死或伸直 |
| 手腕 | 自然放松（[CETV-姿势]） | 手腕上翘或下垂 |
| 手指/握拍 | 横拍握手式；正手攻时食指稍向上移（[CETV-握拍]）；握拍放松，别人能轻易从手里把拍抽出来（见 `../fundamentals/ready-stance.md`） | 死握，前臂僵 |
| 拍面/拍头 | 球拍置于腹前，"拍半横状"（[CETV-攻球]），拍面稍前倾。注：通用准备姿势拍头可朝上（[CETV-姿势]）；判断正手攻球准备是否到位，看拍子是否已置于腹前、成拍半横状（[CETV-攻球]） | 攻球引拍前拍面朝前（手腕内旋过多），没有转成拍半横状 |
| 视线/头 | 两眼注视来球（[CETV-姿势]） | 盯着对方人而不看球 |
| 非持拍手（free arm） | 左臂自然弯曲，放在身体左侧、腹前左侧（[CETV-姿势]；[扬州职大]）。作用：非持拍手通过躯干与持拍手联动，调整击球时全身的平衡（[jawiki-卓球]）；从入门第一个技术就固定这个位置。细节见 `../fundamentals/ready-stance.md` | 左臂垂在体侧、插腰或贴死身体，后面转体时左半身不参与 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到右脚。来球慢或离台时右脚后撤，引拍更容易、击球区更大；近台快速对攻时右脚可以不后撤，两脚近平行，靠转髋转腰引拍（[LH-3484]） | 近台对快球仍每板后撤右脚，被逼退台 |
| 膝 | 右膝稍多屈，像压弹簧 | 引拍时站直 |
| 髋 | 随腰向右转 | 髋不动只转肩 |
| 腰/躯干 | 腰部右转带动引拍（[BK-正手攻]）；中台攻时腰髋转动更大（[BK-正手攻]） | 腰不转，只拉手臂（BK 错误 17"没有后引和横摆"） |
| 肩 | 右肩随转体后移、略沉 | 右肩抬高 |
| 大臂/肘 | **以肘关节为轴**引拍，不要把整个肘部连同大臂往后拉，否则形成肘高、肩高的"架肘"（[BK-正手攻]） | 拖肘（大臂往体后拖）、架肘 |
| 前臂 | 前臂横摆引至身体右侧后方（[BK-正手攻]）；引拍约与台面齐高，前臂与台面基本平行（[CETV-攻球]） | 引得太高（举拍）或太低（变成拉） |
| 手腕 | 保持相对固定（[BK-正手攻]） | 手腕先内收下摆，击球时再上摆，稳定性下降（BK 错误 13） |
| 手指/握拍 | 保持放松 | 引拍时握紧 |
| 拍面/拍头 | 顺来球路线略向右侧引拍，拍面与台面约 80°（[CETV-攻球]） | 拍面后仰（容易打出界） |
| 视线/头 | 头基本不动，看球的弹起 | 头随身体大幅后仰 |
| 非持拍手 | 保持弯曲，跟着腰一起向右转，不单独动作（它通过躯干和持拍手联动，[jawiki-卓球]） | 腰转了左臂留在原处或垂下，转体幅度变小 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚前掌内侧蹬地（[BK-正手攻]） | 脚下不发力，只有上肢动（BK 错误 22） |
| 膝 | 右膝随蹬地伸展 | 膝不动 |
| 髋 | 髋关节向前（向左）转动（[BK-正手攻]）；重心移动时"右脚内扣，左脚外旋，腰髋配合转动"（[BK-正手攻]） | 髋转动晚于手臂 |
| 腰/躯干 | 腰向左转，"转腰横摆"（[BK-正手攻]）；绕穿过头顶的竖轴转，身体不前冲（[LH-2415]） | 上身前扑，头冲向球 |
| 肩 | 右肩随转体向前；肩、肘不要抬起，击球时"肘肩向后下方"（[CETV-纠错]） | 抬肘抬臂 |
| 大臂/肘 | 上臂带动前臂（[BK-正手攻]） | 只摆小臂（力量不足）或只摆大臂（动作慢） |
| 前臂 | 向左前上方挥，呈半圆形（[BK-正手攻]）；"以前臂快速内收发力配合手腕内转沿球体做弧线挥动"（[CETV-攻球]） | 直接朝前或直接朝上挥（BK 错误 15） |
| 手腕 | 随前臂转动，不做上下甩动 | 甩腕，拍面不稳 |
| 手指/握拍 | 仍放松，准备击球瞬间收紧 | 全程紧握 |
| 拍面/拍头 | 拍面保持稍前倾，迎向来球 | 中途翻转拍面 |
| 视线/头 | 盯住球直到击球 | 提前抬头看落点 |
| 非持拍手 | 左侧一起参与转体：右侧向前、向左转的同时，左侧（左肩带左臂）向后、向左"拉"（[LH-3223]）。Hodges 这条讲的是正手拉，但"绕竖轴转体"他写明对普通攻球同样适用（[LH-2415]），本卡据此借用 | 只转右半边、左臂不动：Hodges 指出这样既限制力量，又破坏平衡（[LH-3223]） |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心由右脚移到左脚（[BK-正手攻]）；侧身攻同样边转体边把重心从右脚移向左脚，身体保持侧向、把身体让开，手臂以向前发力为主（[BK-正手攻]） | 重心停在中间或在右脚上不动（BK 错误 21） |
| 膝 | 两膝仍保持弯曲，不站起来 | 击球时整个人站直 |
| 髋 | 髋已转向左前 | 髋还没转完手已击球 |
| 腰/躯干 | 在转体过程中触球（[LH-2415]） | 转体已停、只靠手臂 |
| 肩 | 放松，不耸 | 用力时耸肩 |
| 大臂/肘 | 肘保持在身体右前方，不外张 | 抬肘：拍面朝下、打球上部，攻球下网（[BK-正手攻]） |
| 前臂 | 触球瞬间前臂迅速收缩，向前上方出手（[BK-正手攻]） | 前臂停顿 |
| 手腕 | 相对固定，可借手腕微调拍面方向控制落点（[BK-正手攻]） | 翻腕：拍面后仰时打上旋来球易出界（[BK-正手攻]） |
| 手指/握拍 | 瞬间收紧 | 一直死握或一直很松 |
| 拍面/拍头 | 稍前倾，击球中上部（[CETV-攻球]）；拍头大致横向，不竖起 | 拍头竖起、拍面朝前（[BK-正手攻]） |
| 视线/头 | 头稳定，眼看击球点 | 头左右晃 |
| 非持拍手 | 仍弯曲抬着，在身体左侧随转体后收，没有掉下去 | 左臂掉到髋以下：往往说明平衡和转体配合差（本项目定性判读口径，见 `../analysis/metrics-reference.md`） |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落在左脚；侧身攻打完重心也多在左脚，顺势蹬左脚回位（[LH-3425]） | 重心回到右脚 |
| 膝 | 左膝承重、保持弯曲 | 左膝锁直 |
| 髋 | 转向正对来球方向或略过 | 过度转体失衡 |
| 腰/躯干 | 顺势完成左转 | 腰停住、手单独随挥 |
| 肩 | 右肩到身体前方 | 肩高耸 |
| 大臂/肘 | 肘自然弯曲，大小臂夹角比引拍时更小（有资料说攻后小于 90°，单一来源） | 直臂随挥（主要靠肩，易伤肘，[BK-正手攻]） |
| 前臂 | 球拍继续向左前上方挥至左前额（[BK-正手攻]） | 挥到一半就停（BK 错误 15） |
| 手腕 | 不额外甩 | 收拍时翻腕 |
| 手指/握拍 | 重新放松 | 保持紧握 |
| 拍面/拍头 | 拍头指向左前上方 | 拍子落到腹前（向下打） |
| 视线/头 | 看球飞向对方台面 | 低头 |
| 非持拍手 | 随转体收在身体左侧，帮身体绕竖轴转完后停在原地。Hodges 用马龙正手拉视频说明：两侧身体一起转，身体完全不向前移，在起始位置结束、保持平衡，马上能打下一板（[LH-3223]） | 左臂乱甩或前伸，身体跟着前冲、失衡 |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 马上回到准备姿势（[BK-正手攻]）；正手位进攻后可蹬右脚借动量回位（[LH-3425]） | 打完停在原地欣赏 |
| 膝 | 恢复微屈、两膝弹性 | 膝锁直 |
| 髋 | 回正 | 髋停在左转位置 |
| 腰/躯干 | 回到略前倾 | 上身后仰 |
| 肩 | 放松 | 持续紧张 |
| 大臂/肘 | 回到体侧右前 | 肘留在左前额高度 |
| 前臂 | 回到腹前略偏右 | 停在止点（BK 错误 16"习惯性停留"） |
| 手腕 | 放松，回到中性 | 收拍后手腕仍翻着或紧绷，下一板拍形不对 |
| 手指/握拍 | 回到中性握法 | 握法变了没还原 |
| 拍面/拍头 | 回到腹前、拍半横状 | 拍子垂到体侧 |
| 视线/头 | 看对方击球动作，判断下一板 | 看自己的球落台 |
| 非持拍手 | 随身体回正，回到身体左侧、腹前左侧的准备位置（[CETV-姿势]；[扬州职大]） | 左臂停在体后或垂下，下一板转体又少了左半边 |

注：是否每板都回固定中立位，教练意见不同：Hodges 主张回中立位，PingSkills 主张跟踪来球、直接把拍移到下一板需要的位置（见 `../fundamentals/ready-stance.md`）。

### 3.7 中台（中远台）攻、侧身攻与近台快攻的差别

没列出的部位与 3.1–3.6 相同。

| 部位 / 项目 | 近台快攻 | 中台攻 | 侧身攻 |
|---|---|---|---|
| 站位 | 离台约 40–50 cm，左脚稍前（[BK-正手攻]） | 离台约 1 m，左脚稍前、右脚稍后（[BK-正手攻]） | 左脚在前、右脚在后，身体基本保持侧向，把身体让开（[BK-正手攻]）；步法见 `footwork.md` 第 3.7 节 |
| 腰髋 / 引拍 | 以肘为轴、前臂横摆，引拍约与台面齐高（[BK-正手攻]、[CETV-攻球]） | 腰髋向右转动更大，手臂引拍至身体右后方，幅度更大（[BK-正手攻]） | 侧身移动中完成引拍，右脚一落地就开始前挥（[LH-42]） |
| 拍面 | 稍前倾，约 80°（[CETV-攻球]） | 接近垂直（[BK-正手攻]） | 直板中台侧身攻写"接近垂直"（[BK-正手攻]）；离台近时按近台快攻 |
| 击球时间 / 部位 | 高点期 → 上升期，中上部（[BK-正手攻]、[CETV-攻球]） | 下降前期，击球中部（[BK-正手攻]） | 中台侧身攻同样下降前期、击球中部（[BK-正手攻]） |
| 摩擦与撞击 | 以击打为主（[BK-正手攻]） | 以击打为主，略带向上摩擦（[BK-正手攻]） | 以向前发力为主（[BK-正手攻]） |
| 手臂 | 前臂快速收缩为主（[BK-正手攻]） | 上臂带动前臂向左前上方加速挥动（[BK-正手攻]） | 手臂向前发力，注意身体侧向位置和发力方向（[BK-正手攻]） |
| 重心 / 力量 | 以借力为主、强调肘部稳定（[BK-攻球]） | 腰髋向左转、重心由右脚移至左脚，"重心转动要大，用力要明显"，以自己发力为主（[BK-正手攻]、[BK-攻球]） | 重心从右脚移向左脚，打完重心多在左脚，蹬左脚回位（[LH-3425]） |

为什么这样分：离台越远，球到你手里时速度越低、借不到力，只能靠更大的转体和重心移动自己发力；拍面立起来、略带向上摩擦，是为了让球有足够弧线过网。这条原理是编者归纳，各项要领本身有出处。

## 4. 拍面角度、击球点、击球时间、触球部位

- **拍面角度**：近台快攻拍面稍前倾，约 80°（[CETV-攻球]；[BK-正手攻] 同）。中台攻拍面"接近垂直"（[BK-正手攻]）。前倾过度或后仰都会失误（[BK-正手攻]）。线路由拍面朝向和触球早晚共同决定，见第 6 节。
- **击球点**：三个出处说法不一致。百度百科写球反弹到胸前或腹前的"正前方一肘远"、与网齐高（[BK-正手攻]）；CETV 写"身体右前方一前臂距离处"（[CETV-攻球]）；Hodges 明确说不要在身体前方太远处触球，要更靠身体侧面、右腿旁（[LH-2415]）。本卡取 CETV 和 Hodges 的"右前侧、偏侧面"，理由是这样便于绕竖轴转体发力（[LH-2415]）；三者一致的只有：不贴身、不伸直手去够。击球点相对身体要固定，靠脚步把球放进击球区（[PS-hitting-zone]）。
- **击球时间**：CETV 写"上升期"（[CETV-攻球]）；百度百科主张**初学先打高点期**，命中率高，熟练后再打上升期，"难度要大，但速度更快，更主动"（[BK-正手攻]）。Hodges 的正反手快攻练习也说"大多数球打在高点，可以开始尝试一些上升期"（[LH-3515]）。中台攻在下降前期（[BK-正手攻]）。也别抢得太早，仓促触球会破坏节奏、平衡和控制（[PS-stop-rushing]）。
- **触球部位**：近台快攻击球中上部（[CETV-攻球]），百度百科写"后中上部"；击球后上部或后中下部都算错误（[BK-正手攻]）。中台攻击球中部（[BK-正手攻]）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：从腿的重心转移开始，然后髋和腰、肩、手臂、手腕，平滑地依次进行（[LH-3698]）。中文资料同样写"后脚前掌内侧蹬地蹬腿，转腰横摆……重心由后脚转到前脚"（[BK-正手攻]）。正手拉球的生物力学研究显示骨盆和下躯干转动对拍速贡献大（见 `../fundamentals/power-and-body.md`）；攻球没有专门测量，只能作旁证。
- **手臂内部**：大臂带动小臂协调用力，视情况以小臂或大臂为主（[BK-正手攻]）；击球瞬间前臂快速收缩（[BK-正手攻]）、"前臂快速内收"（[CETV-攻球]）。手腕在正手中的作用比反手小（[PS-wrist]），学动作时手腕基本保持直（[PS-wrist-learn]）。
- **方向**：向左前上方（[CETV-攻球]），以向前为主；不是直线向前，也不是直线向上（[BK-正手攻]）。
- **借力与发力**：近台攻球以借对方来球的力为主、强调肘部稳定；中远台靠蹬地转腰主动发力（[BK-攻球]）。
- **加速**：想着"加速穿过球"，而不是"碰到球"（[LH-3478]）；不要每块肌肉都用尽全力，否则动作变成抽搐式、失去控制（[LH-3698]）。
- **摩擦与撞击**：攻球"有擦有打，但近台快攻不是以摩擦为主，而是以击打为主"（[BK-正手攻]）；中台攻"以击打为主，略带向上摩擦"（[BK-正手攻]）。原理：平击把球向前推，快而薄的摩擦才产生大量旋转（[PS-reading-spin]）。没有找到摩擦与撞击比例的可靠数字，本卡不给百分比。

## 6. 面对不同来球的调整

- **上旋来球**：拍面适当前倾、击中上部，调节向前的力量（[BK-接发球]）；拍形后仰或翻腕时，攻上旋来球容易出界（[BK-正手攻]）。来球上旋越强、越想发力，触球越靠上、越向前——这条出自正手拉上旋的教学（[LH-36]），对攻球同样是"多盖住球"的方向。
- **不转来球**：上旋来球碰拍会向上跳，所以要多"盖住"球（closing the racket，[enwiki-TT]）；不转球没有这股上跳，拍面要比攻上旋时稍立一点、向前上的成分多一点，否则易下网。旁证：[BK-正手快点] 对不转球写"稍前倾拍面、击中上部"，但那是台内快点的要领，对出台不转球只能作参考。
- **下旋来球**：正手攻球不适合强下旋球。对加转下旋要用提拉/拉球（[BK-接发球]），见 `forehand-loop-vs-backspin.md`。下旋不强、球冒高或半出台时才用"突击"（定义见第 1 节）：拍面比攻上旋时立一些、向前上的成分多一些，力量控制在中等，接发球抢攻"一般不可过凶"（[BK-接发球]）。
- **侧旋来球**：接左侧上旋，拍面稍前倾并略向左偏斜，击球偏右中上部；接右侧上旋则拍面向右偏斜、击球偏左中上部（[BK-接发球]）。
- **快球、反挡、近台对攻**：缩小引拍，右脚不后撤，两脚近平行、只转髋腰（[LH-3484]），见 `forehand-counter-block.md`。
- **慢球、高一点的球、被逼离台**：右脚后撤，引拍加大，在下降前期击球中部，以自己发力为主（[BK-正手攻]、[LH-3484]），即中台攻。
- **肩高以上的高球**：改用扣杀（[PS-smash]），见 `forehand-smash.md`。
- **近网短球（台内或刚出台）**：正手快点——右方来球右脚上步、上体前俯，上臂带前臂前伸迎球，对上旋或不转球用稍前倾拍面击中上部，在高点期出手（[BK-正手快点]）。"快点"另一种用法专指处理台内短球的手腕手指弹击（[BK-快点]），细节见 `forehand-flick.md`。
- **侧身攻**：左脚在前、右脚在后，身体保持侧向，"把身体让开，手臂向前发力为主"，要特别注意身体侧向位置和发力方向（[BK-正手攻]）。步法：左脚先小步，再蹬左脚跳转，右脚绕到足够远，肩至少与端线平行，重心在右脚，右脚落地即开始前挥（[LH-42]、[LH-3139]）；击球中重心移向左脚，打完重心多在左脚，顺势蹬左脚回位（[LH-3425]）。侧身要侧到底，侧一半更失衡、更难回位（[LH-3658]）。中台侧身攻的要领见 3.7 节；步法详见 `footwork.md` 第 3.7 节侧身步。
- **线路（斜线、直线、中路）**：五条基本线路是右方斜线、右方直线、左方斜线、左方直线、中路直线（追身）（[CETV-击球技巧]）。有出处的：PingSkills 主张用触球早晚而不是用手拨来改变斜线和直线（"the timing of contact can change the direction of the shot"，[PS-down-the-line]，原课讲拉球）。编者经验（无出处）：斜线距离长、相对安全；直线距离比斜线短，弧线要更低、更容易出界；打直线触球通常比斜线稍晚。侧身位（以对方右手持拍为前提）：侧身斜线打对方反手，侧身直线打对方正手（[BK-正手攻] 的分类）。
- **"滑板"**：民间常把"引拍和前挥像打斜线、触球前一刻用手腕/拍面方向改打直线"（假斜线真直线）这类变线叫"滑板"。**这个说法没有找到权威定义**。百度百科里"滑板"只出现在错误一节，指拍面方向错误造成的"无意滑板""滑板球"（[BK-正手攻]）。练变线伪装之前，先能稳定地有意打斜线和直线。

## 8. 常见错误：表现 → 原因 → 纠正

1. **不敢挥拍、中途停顿** → 怕失误 → 徒手模仿把拍挥够（[CETV-纠错]）；限时挥拍纠正停顿（[BK-正手攻]）。
2. **夹肘 / 拖肘**（大臂贴死身体 / 大臂往体后拖）→ 击球点太近、发不上力 → 放松肩部、加大上臂与身体距离（[CETV-纠错]）；左手托住右肘，肘离上体约两拳挥拍（[BK-正手攻]；这是限制性练法，正式击球时左手不托肘，位置见 3.1–3.6 的"非持拍手"行）。
3. **抬肘、架肘（肘上浮）** → 肩紧张（[PSQ-floating-elbow]）、引拍时整个肘往后拉（[BK-正手攻]）→ 拍面朝下、打球上部、下网 → 强调击球时"肘肩向后下方"（[CETV-纠错]）；放松肩、压肘；同时检查是否两脚平站（[BK-正手攻]）。
4. **手腕下垂、球拍与前臂垂直（吊板）** → 握拍手腕位置不对 → 强调手腕内旋、拍柄向左，徒手模仿（[CETV-纠错]）。
5. **拍头竖起、拍面朝前**（横拍手腕内旋过多）→ 漏球、掉球 → 暂时把食指移到拍前弯曲、用食指中指夹住拍肩来限制转腕，纠正后再还原握法（[BK-正手攻]，"矫枉过正法"）。
6. **甩腕** → 想用手腕加力 → 拍面不稳 → 手腕相对固定（[BK-正手攻]）；用绳子限制手腕上下摆动（[BK-正手攻]）。
7. **直臂打球** → 以为手臂越长越有力 → 动作慢、肘易伤 → 腋下夹软物挥拍，迫使用肘屈伸（[BK-正手攻]）。
8. **只用手臂、腰不转** → 引拍不转腰，击球时身体落后于手臂 → 力量小、不协调；樊振东的比赛分析也指出来球晚时转髋不足会导致失误（[Jin-Ma-2026]）→ 在身体侧面触球、绕竖轴转（[LH-2415]）；背后放物体，转腰让球拍后移碰到它（[BK-正手攻]）。
9. **重心不转移 / 转移后不还原** → 站死在一只脚上 → 教练在身后轻推帮助重心前移（[BK-正手攻]）；"移动—停—击球"节奏（[PS-leg-work]）。
10. **摩擦多于撞击（把攻打成拉）** → 习惯拉球 → 球慢、弧线高 → 站近台攻台内不出台的快球，逼自己"改摩为打"（[BK-正手攻]）。
11. **拍面后仰、翻腕** → 想把球"兜"起来 → 上旋来球出界（[BK-正手攻]）→ 引拍就保持稍前倾，击球中上部。
12. **击球时机错**（不在球反弹到网高时击球，过早或过迟；[BK-正手攻] 错误 4）→ 判断不准、没形成固定节奏 → 初学固定打高点期；多球由供网高球到半高球、高球，专门纠正时机（[BK-正手攻]）。
13. **判断落点不准、引拍不到位** → 先接平击发球练习，再做连续推挡球练习（[CETV-纠错]）。
14. **站位错误、出左边线** → 平行站或前后站又不会调拍面 → 地上画斜线，脚尖站在线后形成半侧位（[BK-正手攻]，百科写与端线成 45°，单一来源）。
15. **近台快攻每板后撤右脚** → 早期学法的习惯 → 被逼退台 → 近台、来球急时两脚近平行，只转髋腰（[LH-3484]），需要一定柔韧性。
16. **击球后停在止点、还原慢** → 欣赏自己的球 → 球拍挥到左前额后马上还原（[BK-正手攻]）。
17. **非持拍手垂下不动** → 把正手当成只有右半边的动作 → 力量受限、失去平衡（[LH-3223]）→ 准备时左臂弯曲放在腹前左侧（[扬州职大]），徒手挥拍时有意让左侧向后"拉"、与右侧同时转（[LH-3223]）。

更多错误的跨卡索引见 `../training/errors-index.md`。

## 9. 练习方法（入门 → 进阶）

1. **徒手挥拍**：体会挥臂、腰部扭转和重心转换（[CETV-纠错]）；照镜子或在墙上画一条弧线顺着挥（[BK-正手攻]）。新手每天正、反手攻各 100 次影子练习（[LH-54]）。
2. **自抛自攻**：站近台中偏右，在右角端线附近自抛自攻对方右边斜线，体会前臂内收发力和击球点（[CETV-纠错]）。
3. **一发一攻**：一人发球一人攻，打一板重新发（[扬州职大]）；一人自抛自攻，另一人用挡球回击（[CETV-纠错]）。
4. **多球**：供球先定点，再变落点让练习者移动中攻，最后不规律落点（[扬州职大]）。初学供网高球，再到半高球、高球（[BK-正手攻]）。
5. **推攻 / 挡攻对练**：一人正手攻，一人推挡回击（[CETV-纠错]）；先定点定线路，再有规律变落点，最后无规律（[扬州职大]）。
6. **对攻**：先 1/2 台右方斜线对攻，再直线对攻，过渡到 2/3 台移动中对攻（[扬州职大]）；目标连续 100 板，再挑战 1000 板（[PS-counterhit]）。
7. **击球时间进阶**：对攻稳定后，从高点期改打上升期（[BK-正手攻]）；正反手左右交替快攻，多在高点、部分上升期（[LH-3515]）。
8. **侧身攻**：侧身正手对攻（[扬州职大]）；推挡侧身攻、侧身攻后扑正手（[CETV-战术]）。步法练法见 `footwork.md`。
9. **两点打一点 / 一点攻两点**：两点打一点的左推右攻及两面攻（[扬州职大]）；一人一点攻两点，另一人两点推挡一点（[CETV-纠错]）；推挡变线正手打回头（[扬州职大]）。
10. **突击与变线**：多球喂下旋不强的冒高球练突击；同一引拍分别打斜线、直线，再练隐蔽变线（编者建议，无出处；旁证：CETV 搓攻写"搓球结合突击或扣杀"[CETV-战术]，扬州职大有"推挡变线正手打回头"[扬州职大]）。
11. **随机化**：先正反手两点随机，再全台随机（[LH-480]）；按 Hodges 从定点到随机、再到比赛的步骤推进（[LH-22]）。

完整训练计划见 `../training/drills.md`。

## 10. 视频检查要点

拍摄方法详见 `../analysis/recording-guide.md`，指标含义见 `../analysis/metrics-reference.md`。

- **机位**：主机位在持拍手一侧拍侧面全身（设计规定"正手从侧面拍"），镜头与台面同高或略高，画面包括双脚和球拍随挥的最高点。另加正面（球台对面）或斜前 45° 机位看转体、重心左右转移和收拍位置（见 `../analysis/recording-guide.md`）。用手机慢动作 120/240 帧，导出后用 `--capture-fps` 填真实拍摄帧率。推算（非文献结论）：正手拉研究中最大拍速约 13–15 m/s（[B2018]），按这个量级，30 fps 两帧之间球拍要走约 0.4–0.5 m，几乎拍不到击球瞬间；攻球拍速没有测量数据，只作数量级参考。
- **误差须知**：单机位 2D 只能看趋势，快速前挥阶段误差最大（[Cao2026]）；躯干/骨盆转动、前臂旋前旋后属于离开画面平面的转动，单机位不可靠（[Shrestha2026]）。所以 `shoulder_turn_deg` `hip_turn_deg` `x_factor_deg` 只能作参考，先看 `quality.reliable` 和 `quality.low_visibility_parts`。
- **看哪张图**：各阶段看 `stroke_NN_sheet.jpg`（精确测量后是 `measured_NN_sheet.jpg`），连续动作和球的轨迹看 `*_NN_strip.jpg`，拍面看 `*_NN_zoom.jpg` 和 `stroke_NN_contact_raw.jpg`（见 `../analysis/analysis-protocol.md`）。

| 阶段 | 关键帧里看什么 | 对应指标 |
|---|---|---|
| 准备 | 站位宽度、左脚是否稍前、膝是否弯、球拍在腹前 | `stance_width_ratio` `knee_angle_deg.{playing,other}.ready` `side_guess` |
| 引拍结束 | 是否转腰、重心是否到右脚、肘是否架起或拖到体后、引拍高度约与台面齐 | `backswing_ms` `elbow_angle_deg.backswing_end` `weight_shift.backswing_end` `shoulder_width_ratio.backswing_end` `trunk_lean_deg.backswing_end` `knee_angle_deg.playing.backswing_end` |
| 迎球挥拍 | 髋、肩、肘是否依次启动；挥拍向左前上方，不直向前或直向上 | `sequence_ms.{hip,shoulder,elbow}` `sequence_order_ok` `forward_ms` `swing_path.{up,horiz,angle_deg}` `peak_hand_speed` |
| 击球瞬间 | 击球点在身体右前侧、不贴身也不伸直；高度约在腰到胸之间；肘没有外张；头稳定；左臂仍弯曲抬着、没掉到髋以下。看 strip 图里球的轨迹，判断是在上升期、高点期还是下降期击球；看不到球就写看不到（无指标，靠看图） | `contact_forward_m` `contact_lateral_m` `contact_height_level` `elbow_angle_deg.contact` `elbow_body_gap_m` `head_motion` `trunk_lean_deg.contact` `free_arm_height_level` |
| 随挥 | 拍子挥到左前额附近；重心到左脚；没有直臂 | `finish_height_level` `elbow_angle_deg.finish` `weight_shift.{finish,delta}` `follow_ms` |
| 还原 | 是否马上回到准备位、有没有停在止点；左臂是否回到身体左侧（左臂靠看图，无专门指标） | `recovery_dist` |

- **拍面角度**：骨架模型测不出来，必须看 `*_NN_zoom.jpg` 手部放大图（触球前后各 2 帧）和 `stroke_NN_contact_raw.jpg`：拍面应稍前倾（拍面上沿比下沿更靠球网方向），拍头大致横向；拍头竖起、拍面后仰或吊板都要指出是哪一板、哪一帧。
- **判读方向（不设阈值）**：`swing_path.angle_deg` 应比同一人拉下旋时更平、更向前；`weight_shift.delta` 应为正（重心从持拍侧脚移向另一脚）；`sequence_order_ok` 为否、或 `sequence_ms` 显示肘先于髋，说明只用手臂（`sequence_ms`、`sequence_order_ok` 只在帧率 ≥100 时才有，低帧率视频不判发力顺序）。近台快攻右脚不后撤时 `weight_shift` 幅度会小，这是正常的（[LH-3484]）。同一人前后对比比和论文数字比更有意义。

## 11. 自查清单

- [ ] 近台站位，离台约 40–50 cm，左脚稍前（或近台快攻时两脚近平行），膝弯、前脚掌着地
- [ ] 引拍以肘为轴、靠转腰，引拍高度约与台面齐，没有架肘、拖肘
- [ ] 拍面稍前倾（约 80°），拍头大致横向，没有吊板、竖板
- [ ] 击球点在身体右前侧，不贴身、不伸直手够；与网齐高附近
- [ ] 初学打高点期，熟练后能稳定打上升期
- [ ] 击球中上部，以撞击为主、略带摩擦
- [ ] 发力顺序：蹬右脚 → 转髋转腰 → 大臂带前臂 → 前臂快速收缩；手腕相对固定
- [ ] 挥拍方向向左前上方，随挥到左前额，不停在止点
- [ ] 重心从右脚到左脚，打完马上还原
- [ ] 非持拍手弯曲放在身体左侧，挥拍时左侧向后"拉"，击球时不掉到髋以下，打完随身体还原
- [ ] 能有意打斜线、直线、中路，侧身攻时身体让开、侧到底
- [ ] 遇强下旋改用拉球，遇肩高以上的球改用扣杀，遇冒高的弱下旋才突击
- [ ] 能在定点对攻中连续 100 板
