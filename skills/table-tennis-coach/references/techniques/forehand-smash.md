# 正手扣杀与突击（Forehand Smash / Kill & Forehand Sudden Attack）

适用场景：对方回出约肩高或更高的球（半高球、高球、放高球），或台内/半出台略冒高的下旋、不转机会球，或相持中的出台长下旋（削球、劈长）｜难度：中级（杀放高球、突击下旋偏进阶）｜相关卡片：[正手攻球](../techniques/forehand-drive.md) · [正手拉上旋](../techniques/forehand-loop-vs-topspin.md) · [正手拉下旋](../techniques/forehand-loop-vs-backspin.md) · [正手挑打](../techniques/forehand-flick.md) · [放高球与鱼跃](../techniques/lob-and-fish.md) · [发力与身体](../fundamentals/power-and-body.md) · [拍面·时间·部位](../fundamentals/racket-angle-timing-contact.md) · [步法](../techniques/footwork.md)

> 全文按右手持拍写，左手持拍者左右互换。

## 1. 定义与用途

- **扣杀（smash / kill）**：对方回球弹得过高或离网太近时，用尽可能快的加速把球打出最大速度的进攻技术（英文维基："when the opponent has returned a ball that bounces too high or too close to the net … rapid acceleration to impart as much speed on the ball as possible"）。百度百科技术图解（引《乒乓世界》）：力量重、球速快、动作幅度较大，以撞击为主；通常先用别的技术取得主动，对方回出半高球时使用，是比赛中重要的得分手段之一。词条"技术要点"段概括为**"以撞击为主、摩擦为辅"**。
- 本卡分三种情况：
  1. **扣半高球**：近台，来球比网高出一截但不算很高，在上升期或高点期快打。
  2. **扣高球 / 杀放高球**：对方退台放高球（lob），球弹得很高很深，要先判断旋转和落点，再在略高于眼的位置扣。
  3. **正手突击（sudden attack）**：在以拉、搓为主的回合里突然发力打一板，主要对付下旋。分两种：
     - **台内/半出台冒高的下旋或不转球**：上步突然发力，打完常形成出台对攻（中文维基把"正手挑打、突击"列为台内回球技术，注"常形成出台对攻"）。发力要领参考百度百科"正手快点"条对"突击下旋球"的描述和 PingSkills 的"近网高下旋怎么打"。
     - **相持中的出台长下旋（削球、劈长）**：以拉为主，看准机会突然发力打一板。扬州职大课程的拉攻战术写"拉中突击""稳拉为主，伺机突击""拉吊结合，伺机突击"（拉攻是对付削球的主要战术），搓攻战术写"搓中突击"；中国教育电视台拉攻战术（快攻对付削球的主要战术）写"遇到机会球时要大胆扣杀或突击""拉、扣的力量要有较大的悬殊"，搓攻战术写用"低突、快点或拉攻"展开攻势，遇到机会球扣杀。
     - 突击和扣杀的分界（多高、多转算哪一种）没找到权威出处。本卡的概括（非出处原话）：来球还不够高、不能放心扣，又有下旋时用突击，动作比扣杀小（百度百科"正手快点"：动作幅度小）。
- 和相邻技术的分工：低于肩、深的球用[拉](../techniques/forehand-loop-vs-topspin.md)；中等高度的连续对攻用[正手攻球](../techniques/forehand-drive.md)；台内会弹两跳的短球用[挑打](../techniques/forehand-flick.md)（PingSkills 说它"像一板小扣杀"）。反手位来了高球，PingSkills 建议尽量侧身换正手扣，不用反手扣。

## 2. 三位标杆怎么做

**先说结论：本次调研没有找到专门描述马龙、张继科、樊振东扣杀或突击动作细节的可靠出处。** 下面只列有出处、又和本卡相关的事实，不要把它们当成"标杆扣杀动作"。

- **马龙**：扣杀、突击的动作细节——暂无可靠出处。
  - 正手共性（出自正手拉球视频，不是扣杀）：美国教练 Larry Hodges 以马龙正手视频为例，说他绕一根"穿过头顶的竖轴"转体，头只稍前移，击球点几乎在身体正侧方（[Hodges, node/3147](https://www.tabletenniscoaching.com/node/3147)）。（推论：扣杀同样靠转体发力，可作参考；Hodges 原文讲的是正手拉球。）
  - 起板选择（单场统计）：分析博客 Edges & Nets 统计 2020 年世界杯半决赛对张本：马龙前三板最想要的是用正手打长球、尤其是半出台球的起板，这类分他赢了 68%，其余分只赢 47%（[Edges & Nets 存档](https://web.archive.org/web/20210616170515/https://edgesandnets.com/2021/06/16/how-harimoto-built-a-3-1-lead-and-ma-long-came-back-at-the-2020-world-cup/)）。原文没有区分起板用的是拉还是打，只能说明"半出台球要主动用正手上手"。
- **张继科**：扣杀、突击——暂无可靠出处。现有资料只说他关键分的正手弧圈有威力（《卓球レポート》2020-06-05，[链接](https://www.butterfly.co.jp/takurepo/other/detail/014476.html)），那是弧圈，不是扣杀。
- **樊振东**：
  - 央视网 2024-08-16 报道巴黎奥运转播 AI 的测量：男单决赛中他打出的一记球转速 146.48 转/秒，和卡尔伯格的 146.6 转/秒是本届仅有的两个超过 146 转的球，"全是扣杀的制胜球"；男选手平均转速 66.7 转/秒（[央视网](https://sports.cctv.com/2024/08/16/ARTIlud2yPVvzKS0wKyrZzyR240816.shtml)）。这是转播系统对单次击球的峰值。原文没说这两板球的旋转方向和击球动作。媒体说的"扣杀"可能包括发力弧圈，所以这个转速不能当作平击扣杀的参考。
  - 同文：他在男团决赛对莫雷高德时打出本届最快球速 19.3864 米/秒。**原文没说那一球是扣杀**，不要写成"扣杀球速纪录"。
  - 论文统计（2021–2023 年 40 场）：最后一板不变线时，他正手打直线、斜线的得分率都高于 70%；正手变斜线的得分率最低，作者认为原因之一是来球稍晚时他没法主动转髋（Jin & Ma 2026，[Frontiers, DOI 10.3389/fbioe.2026.1763704](https://doi.org/10.3389/fbioe.2026.1763704)）。这是作者对比赛的解读，不是教练组评价；原文统计的是"进攻"，没有单独区分扣杀。
- **业余怎么用**：照本卡第 3–5 节的通用要领练；看三人比赛录像时，重点看机会球出现时他们"先到位、再出手"的节奏，不要去猜他们的角度和力量比例。更多见 [马龙](../players/ma-long.md)、[张继科](../players/zhang-jike.md)、[樊振东](../players/fan-zhendong.md)。

## 3. 动作分解

以"扣高球/半高球"为主线写；"突击"与之不同的地方写在每个表下面。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 一看到高球就动：判断高度、长短、旋转后，**趁球在空中的时间移动、侧身到位**（PingSkills）。左脚稍前；站位远近按来球长短定（百度百科）。扣半高球两脚站得较宽（百度百科）。杀放高球：深的往后退，上旋高球别站太近（落台会往前窜），侧旋高球往拐的那一侧移（Hodges） | 以为机会球"志在必得"不动脚，球弹起来才发现位置不对，只能抡臂硬打（百度百科"专家指导"） |
| 膝 | 微屈、有弹性，随时能蹬 | 直腿站着等球，没法调整，也没有蹬地力量 |
| 髋 | 随侧身向右后转，侧对球台 | 正对球台站着打高球，转体空间没了 |
| 腰/躯干 | 上体略前倾、收腹（基本姿势）；扣高球时上体不必像拉下旋那样压低 | 弯腰含胸等高球，之后只能往上够 |
| 肩 | 放松；杀高球时准备让右肩抬高（Hodges） | 耸肩、肩紧 |
| 大臂/肘 | 手臂自然弯曲（百度百科），肘离开身体 | 夹肘贴身 |
| 前臂 | 随转体准备后拉 | 前臂先动、身体不动 |
| 手腕 | 自然，不勾不翘 | 手腕下垂 |
| 手指/握拍 | 握松，松到别人从后面能把拍抽走（Hodges 自测法）；横拍正手时食指可稍上移（中国教育电视台） | 一看是机会球就攥死拍子 |
| 拍面/拍头 | 拍面稍前倾（百度百科）；**拍子提早举高到约肩高**（PingSkills） | 拍子还停在拉球的低位，打出来像拉 |
| 视线/头 | 盯球；对方放高球时看他的摩擦动作和球的弯曲，判断旋转（PingSkills、Hodges） | 只看球高不高，不读旋转 |
| 非持拍手（free arm） | 左臂自然弯曲，放在身体左侧、腹前（中国教育电视台："非持拍手臂自然弯屈于身体左侧"；详见 [准备姿势](../fundamentals/ready-stance.md)）；侧身时跟着身体一起转。作用是平衡、配合上体转动，不用刻意做大动作（PingSkills"非持拍手"课） | 垂在身侧或插在腰上：侧身时左肩"漏"，人站不稳 |

突击：站近台，看到台内或半出台冒高的下旋，右脚上步到位（同正手快点：右方来球右脚上步）；重心放低，拍面准备稍开。对出台长下旋（削球、劈长），站位按拉球的位置，先拉，看准机会再突击。

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到右脚（后脚）。杀高球可先把重量放在右脚，为后面向前转移做准备（Hodges） | 重心在两脚之间不动，后面无从转移 |
| 膝 | 右膝屈、承重，像压紧的弹簧 | 右腿伸直 |
| 髋 | 随腰髋转动向右后转（百度百科："随腰、髋的转动，整个手臂后拉"） | 髋不转，只往后拉手 |
| 腰/躯干 | 向右转，肩线跟着转过来；上体保持直，不后仰 | 上体后仰，重心落到后跟 |
| 肩 | 持拍侧肩不下沉；扣高球时右肩可以略抬（Hodges） | 像拉下旋那样沉肩 |
| 大臂/肘 | 整个手臂后拉；肘不要往上浮（Hodges 练习要求"keep the elbow down"） | 抬肘、肘外张，手臂发力路线变形 |
| 前臂 | 拉到身体右后方，拍高约肩高（PingSkills、百度百科） | 从腰以下低位起拍 |
| 手腕 | 基本中立。PingSkills 认为正手上手腕作用小，先把手腕保持直 | 手腕后屈很多，触球时拍面不可控 |
| 手指/握拍 | 继续放松，触球前各部分肌肉都要放松（百度百科） | 引拍时已用力握紧 |
| 拍面/拍头 | 拍面稍前倾，拍头指向身体右后方 | 拍面后仰（对上旋高球会飞） |
| 引拍幅度 | 适当加大，便于加速；但要按来球调整（百度百科：引拍太小或击球点离身体太近都影响力量） | 引拍很大，赶不上球 |
| 视线/头 | 头稳定，盯球 | 转体时头也跟着大幅转 |
| 非持拍手 | 随身体右转，左臂**抬起**（肘弯着）伸向身体左前方、大致指向来球，和后拉的右臂一起把上体转成侧对球台，左侧身体也就为下一步"向后拉"做好了准备。程度：抬起、不垂、不僵，不必抬得很高。"指向来球、帮助瞄准"是常见的教学提示，暂无可靠出处，只作参考；有出处的是它帮助平衡和上体转动（PingSkills） | 左臂垂下或贴身：右转转不够，侧身不到位；左臂伸得笔直发僵，或甩得很大把身体带歪 |

突击：引拍幅度比扣杀小，手腕可微微外展让拍面稍后仰；肌肉放松（百度百科"正手快点"）。

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地，重心从右脚向左脚转移（Hodges、PingSkills） | 脚不蹬，原地甩手 |
| 膝 | 右膝蹬伸，把力往上传 | 膝一直弯着不蹬 |
| 髋 | 髋先向左转（百度百科："借腰、髋的左转及腿的蹬力，带动手臂向前迎球"） | 髋和手同时转，甚至手先动 |
| 腰/躯干 | 紧跟髋转，躯干绕竖轴转，不向左歪倒 | 身体往左倒或往后仰 |
| 肩 | 肩线跟着转；杀高球时右肩保持高位（Hodges，Smashing Lobs）；扣挡回来的半高球也要抬肩（Hodges LH:50） | 肩先于髋转出去；沿用拉下旋的沉肩，扣出底线 |
| 大臂/肘 | 大臂带动前臂一起加速（百度百科） | 大臂不动，只甩前臂 |
| 前臂 | 被身体带出后，在最后一段猛"甩"——Hodges 认为这一甩是扣杀速度的关键，弱扣通常缺的就是它；可以把腿、髋、腰、肩想成"把前臂带起来"的手段 | 前臂一路匀速推出去 |
| 手腕 | 相对固定，不额外翻 | 手腕乱抖，拍面不稳 |
| 手指/握拍 | 仍然松；接近触球时握实 | 全程攥死 |
| 拍面/拍头 | 保持前倾，对准球的中上部；上旋或不转来球，拍子走在球的上方（百度百科） | 拍面打开，球飞出界 |
| 视线/头 | 头尽量不动，眼睛跟球到拍 | 抬头看对方或看落点 |
| 非持拍手 | 髋、腰一开始左转，左臂就弯着**向左后方收**，把左侧身体往后"拉"，和右侧向前转同时进行。Hodges 讲正手拉时说：右手持拍者右侧向前转的同时左侧要向后"拉"，只转右侧会限制力量、破坏平衡（Hodges LH:3223）；扣杀同样靠转体发力，本卡按同一要求写（本卡推论） | 左臂停在原地或垂下：只有右半边身体在转，转不动，球没力量；左臂猛甩到身后，身体被带歪、拍面不稳 |

突击：动作要突然、集中——引拍时放松，击球瞬间快速收紧握拍，把力量一下送到球上（百度百科"正手快点"说它与突击下旋球的发力相似）。

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心正在由右脚移到左脚，脚下站稳 | 两脚离地乱跳（跳杀见第 6 节，非必要不用） |
| 膝 | 右膝基本蹬直，左膝承接 | 双膝都直，身体僵 |
| 髋 | 髋已基本转到对着出球方向 | 髋转过头，拍子被带到身后 |
| 腰/躯干 | 躯干稳定，不后仰 | 后仰着打，球飞高 |
| 肩 | 肩已转到位，持拍侧肩不下沉 | 肩一沉，拍面跟着翻 |
| 大臂/肘 | 扣高球：手臂几乎伸直，击球点在持拍手头部的右斜前方（百度百科）。扣半高球：手臂保留一定弯度 | 肘夹死，只剩肩在动 |
| 前臂 | 快速收缩发力（百度百科："以前臂快速收缩为主"） | 前臂提前停住 |
| 手腕 | 固定，支撑拍面 | 触球时才翻腕找角度 |
| 手指/握拍 | 握实 | 握得松散，球拍被撞歪 |
| 拍面/拍头 | 拍面前倾，撞击为主；让球吃透海绵、碰到底板，发出响亮清脆的"啪"声，每板声音应该差不多（Hodges） | 声音时响时闷，说明触球不一致 |
| 视线/头 | 头稳定，看着球拍碰球 | 触球前就抬头 |
| 非持拍手 | 已收到身体左侧，手臂仍弯着、抬着（手不掉到髋以下），和右臂一起稳住转体 | 触球时左手已掉到髋以下：左肩塌，身体往左歪，转体提前泄掉 |

突击：击球点在台内或刚出台处，时间多为高点期或上升后期；对下旋拍面由稍开迅速压向前，撞击中带摩擦（用反胶时更要带摩擦，百度百科"正手快点"）。

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落到左脚；杀高球时右脚可顺势离地，同时右肩被抬高（Hodges） | 重心还压在右脚 |
| 膝 | 左膝稳住，承接重心 | 左膝软，身体前扑 |
| 髋 | 顺势转完 | 刹车太早 |
| 腰/躯干 | 随转体收住，不前扑、不歪 | 打完身体歪到一边 |
| 肩 | 放松下来 | 一直耸着 |
| 大臂/肘 | 顺着发力方向自然向左前方挥出 | 挥向正上方（变成拉）或直接朝下砸 |
| 前臂 | 甩完自然减速 | 刻意停住，前臂发僵 |
| 手腕 | 放松 | 打完翻腕 |
| 手指/握拍 | 恢复松握 | 一直攥着 |
| 拍面/拍头 | 拍子收在身体左前方，高度一般不会像拉弧圈那样高 | 收到头上方（发力向上了） |
| 视线/头 | 看清球去向，准备下一板 | 看着球欣赏 |
| 非持拍手 | 留在身体左侧、仍抬着，帮身体收住、站稳；杀高球右脚离地时更要靠它保持平衡（PingSkills：非持拍手帮助平衡） | 打完左臂垂下或乱甩，身体晃一步才站稳 |

突击：动作幅度小（百度百科"正手快点"），收拍短，不像扣高球那样挥得很远；收得短才来得及接下一板。

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 马上回到能起动的位置。Hodges 建议正手进攻后蹬右脚借势回位；PingSkills 认为不必机械回固定中立位，而是按来球把拍子和人移到下一板需要的位置，两种说法都有 | 以为一板必死，站着不动 |
| 膝 | 重新微屈，随时能蹬 | 直腿站着 |
| 髋 | 从左转的位置回到大致对着来球方向 | 髋还转在左侧，下一板正手来不及侧身 |
| 腰/躯干 | 上体回到略前倾的准备姿势 | 打完上体前扑或后仰着不动 |
| 肩 | 放松下来，两肩回到大致水平 | 右肩还抬着或耸着 |
| 大臂/肘 | 手臂收回体前，自然弯曲，肘离开身体 | 手臂还伸在左前方 |
| 前臂 | 收回，拍子回到体前 | 前臂还停在收拍位置 |
| 手腕 | 回到中立，不勾不翘 | 手腕还保持在击球时的角度 |
| 手指/握拍 | 恢复松握（松到别人从后面能把拍抽走，Hodges LH:2271） | 打完还攥着拍子 |
| 拍面/拍头 | 拍子回到体前；对方擅长放高球时，拍子准备在较高位置 | 拍子垂下 |
| 视线/头 | 盯对方击球：好的放高球会一板接一板回来（Hodges） | 低头 |
| 非持拍手 | 回到身体左侧、自然弯曲的准备位置 | 一直垂着，下一板侧身、转体又不到位 |

突击：打完马上还原，准备出台对攻（中文维基："常形成出台对攻"）；拍子回到体前，准备接对方的出台回球，不要站着看。

## 4. 拍面角度、击球点、击球时间、触球部位

- **拍面角度**（中国教育电视台的定义：拍面与台面的夹角，90° 为垂直，小于 90° 为前倾）：
  - 上旋、不转的高球：拍面明显前倾，球拍在来球上方压过去（百度百科）。
  - 很高的球：可以几乎正面直击（Hodges LH:3419："where you can hit the ball straight on"）。
  - 下旋高球：拍面**稍开**一点，抵消下旋，否则会被拉下网（PingSkills）。
  - 扣杀专用的拍面角度数值本次没有找到可靠出处，这里只写定性描述。
- **击球点**：
  - 高度：约肩高或更高才考虑扣（PingSkills 的简单标准）；杀放高球在略高于眼处击球（Hodges）；扣很高的球时，击球点在持拍手头部右斜前方，手臂几乎伸直（百度百科）。
  - 前后/远近：在身体右前方，留出手臂伸展的空间；离身体太近会削弱力量（百度百科）。
- **击球时间**（教育电视台五分法：上升期→上升后期→高点期→下降前期→下降后期）：
  - 扣半高球：上升期（百度百科）或高点期。
  - 扣高球：高点期，位置合适时可上升期；"击球前多等球"（百度百科）。
  - 杀放高球：上升时或下降时都行；没打稳之前先练下降期；短的高球在上升期打，角度更大（Hodges）。落台即打（right off the bounce）很难，只适合高手（Hodges）。
  - 突击：高点期或上升后期（百度百科"正手快点"）。
- **触球部位**：
  - 上旋、不转来球：打中上部（百度百科）。
  - 下旋高球：拍面稍开，触点往球的后中部移（按 PingSkills"拍面稍开"推出来的）。
  - 触球深度：撞击要吃透海绵、碰到底板（Hodges）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：腿 → 髋 → 腰 → 肩 → 前臂，依次连贯，同时重心从后脚移到前脚（Hodges LH:3419；PingSkills"加大扣杀力量"课也说靠转体和后脚到前脚的重心转移）。最后的前臂甩是速度来源。百度百科也强调：只用手臂，杀伤力有限而且动作不稳定。
- **力量大小**：不要用全力。Hodges 说用力过猛会变成抽搐式动作，既失去控制，也打不出力量（因为肌肉没按顺序用上）。百度百科"专家指导"也写了抡圆了胳膊拼死力的后果：动作僵硬变形，丢掉机会球。
- **方向**，两家说法不同，要分情况：
  - 百度百科：扣半高球向前下方发力；技术图解写向左前下方发力（右手）；扣高球"从后向前"。
  - Hodges：除非球很高，扣杀仍要带一点上旋，触球是略向上的"拍打"，打上旋球也一样。
  - 理解（本卡推论，非出处原话）：击球点明显高过网、又离网近时，可以平打甚至向前下；击球点离网远或高度一般时，平直向前、略带向上摩擦更保险。拿不准时按后者打。
- **摩擦与撞击**：撞击为主、摩擦为辅（百度百科"技术要点"段）。
  - 带少量上旋能让球下坠上台，这是安全余量。
  - 侧旋扣只在对方是很强的放高球选手、什么都能救回来时偶尔用，因为它会降低自己的稳定性（PingSkills、Hodges）。
  - 不要带削、带下旋扣：Hodges 认为对深球会伤稳定性，PingSkills 也不推荐。
- **突击的发力**：引拍放松，击球瞬间突然收紧、集中发力，以前臂和手腕的爆发为主，身体配合（百度百科"正手快点"）。来球下旋重时多带摩擦。

## 6. 面对不同来球的调整

| 来球 | 先判断 | 怎么调 |
|---|---|---|
| 低于肩的球、深的球 | 扣下去过网余量小 | **别扣，先拉上旋过渡**，等更高或更短的机会（PingSkills）；想"打得狠"就用快速弧圈（PingSkills 问答） |
| 约肩高的球 | 不低，但未必是好扣杀球 | 可以继续拉上旋，等更好的机会；高度不是唯一标准（PingSkills） |
| 高上旋球（弧圈冒高、上旋高球） | 落台后往前窜 | 别站太近；拍子在球上方，拍面前倾多 |
| 高下旋球（搓高、削高） | 下旋会把球拉下网 | 拍面稍开，或加一点上旋把球提起来；同时看深度：**离网近又高就扣，深而低就拉**（PingSkills） |
| 近网冒高的下旋（发球后搓回来常见） | 看着好打，但下旋仍在 | 侧身用正手；稍开拍面或带上旋（PingSkills） |
| 台内/半出台略冒高的下旋或不转 | 能否上步到位 | 用突击：上右脚，高点期，撞击中带摩擦；不冒高就改用挑、搓或拉 |
| 出台的长下旋（削球、劈长） | 下旋强弱和高度 | 高的按"高下旋球"一行处理；不够高时以拉为主，看准机会再突击（扬州职大"稳拉为主，伺机突击"；见[正手拉下旋](../techniques/forehand-loop-vs-backspin.md)）；突击时拍面稍开、带一点向上（PingSkills 高下旋课）。具体角度没有出处，只写定性 |
| 侧旋高球 | 看对方的摩擦方向和球在空中的弯 | 移到球拐过去的那一侧，然后**用你平时的扣法**（PingSkills） |
| 又高又深的放高球 | 读旋转和深度 | 后退；在略高于眼处扣，先练下降期（Hodges）；等球落到肩高再打会退得很远，很难打出力量（PingSkills 问答） |
| 短的放高球 | 落点短，能抢到角度 | 上升期扣，直接打大角度得分（Hodges） |
| 对方放高球质量很好 | 一板很难打死 | 不必一板打死：保持大力，多压反手或中路，逼出弱的、短的、转得少的高球再打死；打死之前少打他的正手，免得被反攻（Hodges）。也可以变化扣杀的速度和深度（PingSkills）；偶尔放短作变化（PingSkills 专门教；Hodges 认为通常成功率低） |
| 推挡、挡回的半高球 | 来球快、弧线高 | 肩要抬起来扣（Hodges LH:50），站位保持近台 |
| 跳杀、抬腿扣 | — | 跳起来能把击球点抬高、离台更近，但影响节奏，很多人认为不是好方法（Hodges）；PingSkills 也提醒早打和跳打的风险。业余先别学 |

## 8. 常见错误：表现 → 原因 → 纠正

1. **机会球打丢、动作变形** → 没移动、没调重心就出手，再拼命抡臂（百度百科） → 球一冒高先动脚、侧身、举拍，到位后用顺畅、不过猛的力。
2. **低球硬扣下网** → 高度不够还平打（PingSkills） → 低于肩先拉上旋，见第 6 节。
3. **扣高下旋下网** → 拍面没开，被下旋拉下去（PingSkills） → 拍面稍开或带点上旋，先多球专练。
4. **扣出来像拉、球不够快** → 起拍太低、摩擦太多（PingSkills 问答） → 拍子先举到约肩高，平一些撞出去。
5. **扣杀出界、飞高** → 拍面后仰、身体后仰，或很平地打一个不够高的球 → 拍面前倾，留一点上旋，躯干不后仰。
6. **球速慢** → 缺最后的前臂甩，或只用手臂（Hodges、百度百科） → 做离网近的自拍自扣练习，强调前臂甩；再加上蹬转。
7. **抬肘、肘上浮** → 肩紧张（PingSkills 问答对正手的分析） → 放松肩，练习时注意肘压低（Hodges）。
8. **击球点离身体太近** → 判断晚、步法不到位（百度百科） → 先退半步、侧身，留出伸臂空间。
9. **被上旋高球顶住** → 站太近（Hodges） → 读到上旋就后退一点。
10. **硬要一板打死好高球** → 对好的放高球硬求一板打死，成功率低（Hodges：low percentage） → 压反手或中路连续扣，等出现弱球再打死。
11. **带削、带侧切扣** → 习惯性带削或带侧切（Hodges 称为 bad habit；对深球伤稳定性） → 回到平直略带上旋的扣法；侧旋扣只作偶尔的变化。
12. **击球声时响时闷** → 每板触球不一样（Hodges） → 练到每板都是同样清脆的响声。
13. **扣完站着看** → 以为得分了 → 立刻还原，准备对方再放高球。
14. **反手位高球用反手硬扣** → 懒得移动 → 侧身用正手扣（PingSkills）。
15. **拉完下旋紧接着扣挡回球，球出底线** → 沿用拉下旋时的沉右肩，扣的时候带了向上的力（Hodges LH:50） → 扣挡回球时右肩保持抬起，拍子在球上方。
16. **从拉球转成扣杀时肩发紧** → 扣杀的起拍高度和拉球不同，换板时肩容易紧张（PingSkills 问答 forehand-smash-technique） → 做第 9 节第 6 条的"一低一高"交替练习，换扣杀时有意放松肩。
17. **左臂垂着不动，扣得没力** → 只转右半边身体，左侧没往后"拉"（Hodges LH:3223 讲正手拉的同一问题） → 引拍时左臂抬起、伸向左前方，挥拍时弯着向左后方收，击球后仍抬着站稳。

## 9. 练习方法（入门 → 进阶）

1. **徒手挥拍**（入门）：对镜做"侧身、举拍到肩高、蹬转、前臂甩、收拍左前方"。**做到**：每次起拍都在肩高附近，重心有明显的右脚到左脚转移。中国教育电视台的攻球练习步骤也是从徒手模仿开始。
2. **近网自拍自扣**（Hodges）：拿一筐球站在球台侧面靠近网的地方，自己把球拍到台上弹高，用前臂甩扣，肘压低；熟练后逐步离网远一些，并把球拍得弹低一点（Hodges）。球再低时通常改拉弧圈更好（Hodges："against lower balls it's usually better to loop"）。**做到**：每板都是同样的清脆声。Hodges 说做对了，你能全速扣杀还能照常说话，说明身体是放松的。
3. **多球定点扣半高球**：PingSkills 建议先用多球找扣杀的规律和感觉。供球者在对面发同一落点的半高球（上旋、不转）。**做到**：连续多板上台、声音一致后，再加力、再变线。
4. **多球扣高下旋、近网高球**：供球者送高下旋，有深有浅。**做到**：按深浅判断"扣还是拉"，用开拍面或带上旋的方法扣过网。
5. **多球突击**：
   - 台内：供台内/半出台略高的下旋，练上右脚、高点期突击；再混入不冒高的球，逼自己选挑或搓。**做到**：连续 10 个冒高下旋里至少 7 个突击上台，不冒高的球没有一个硬突。
   - 出台：供出台长下旋（模仿削球、劈长），练"拉两板再突击一板"（扬州职大"拉中突击"）。**做到**：每组"拉、拉、突"连续 5 组不失误，突击那板明显比拉的两板快。
6. **高度混合判断练习**（PingSkills 问答 forehand-smash-technique）：先一低一高交替——低的拉上旋、高的扣（"one ball lower that you topspin and the next ball high which you smash"），再改成几个低球后随机出一个高球。换成扣杀时有意放松肩，该问答说很多人这时肩会发紧。**做到**：低的拉、高的扣，判断错的次数越来越少。
7. **组合练习**：结合[拉攻](../techniques/forehand-loop-vs-backspin.md)和搓攻战术——"拉中路杀两角，或拉两角杀中路"（扬州职大课程）；"搓中突击"；推挡里突然加力推中路，再正手或侧身扣（中国教育电视台推攻战术）。**做到**：每种组合连续 5 组，扣或突击那板上台，并落在事先说好的线路上。
8. **杀放高球**（进阶）：陪练退台放高球，你练读旋转、退步、在略高于眼处扣，先打下降期，再打上升期；按 Hodges 的思路连续压反手或中路，等弱球再打死。也可以练抬右肩、右脚离地的动作。**做到**：连续压反手或中路 5 板不失误，再找短球打死。
9. **比赛式**：发球 → 对方搓或挡出机会 → 扣 → 还原再打一板。练"扣完还要准备下一板"的习惯。**做到**：10 个回合里机会球都上台，而且每次都还原到能接下一板的位置（对方回过来能碰到）。

更多练法见 [drills.md](../training/drills.md)；肩部负荷大，注意热身和恢复，见 [physical-and-injury.md](../training/physical-and-injury.md)。

  - **准备**：是否侧身、两脚是否较宽 → `stance_width_ratio`、`knee_angle_deg.{playing,other}.ready`。
  - **引拍结束**：拍和手是否已在约肩高；重心是否在右脚；右膝是否弯曲承重 → `weight_shift.backswing_end`、`knee_angle_deg.playing.backswing_end`、`elbow_angle_deg.backswing_end`、`trunk_lean_deg.backswing_end`。
  - **迎球挥拍**：是否髋先、肩再、肘最后 → `sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`；转体幅度 → `shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`。单机位测转动不可靠（离开成像平面的转动误差大），只看趋势或同一人前后对比。
  - **击球**：
    - `contact_height_level`（0=髋，1=肩）：扣高球应在 1 附近或更高；明显低于 1 还在平扣，说明该拉不该扣。突击的击球点本来就低，不按这条判断。
    - `contact_forward_m`、`contact_lateral_m`、`elbow_body_gap_m`：击球点是否在身体右前方、手臂是否有伸展空间。
    - `elbow_angle_deg.contact`：扣高球时手臂应接近伸直（只看方向，不对照具体度数）。
    - `head_motion`：头是否稳。
  - **随挥**：
    - `swing_path.{up,horiz,angle_deg}`：扣杀路径应以向前为主，比自己拉弧圈时平；`up` 很大说明打成了拉。
    - `finish_height_level`：收拍过头说明发力向上了。
    - `weight_shift.{finish,delta}`：`delta` 应大于 0，即重心从持拍侧脚移到另一脚。
  - **还原**：`recovery_dist`，以及下一板前人是否已回到可起动的姿势。
  - **节奏**：`backswing_ms`、`forward_ms`、`follow_ms`、`peak_hand_speed`。只和自己的正手攻、拉比较（扣杀的手速峰值应更高），不和论文数字比。快速前挥阶段的角度误差本来就最大。
  - 非持拍手：`free_arm_height_level` 取的是击球帧左手腕的高度，左手掉到髋以下，说明左臂垂下、没参与转体（标准动作见第 3.2–3.5 节"非持拍手"一行）。引拍结束时左臂是否抬起、跟着侧身，脚本没有对应指标，只能看关键帧图。
  - 其他：`trunk_lean_deg.contact`（是否后仰）、`side_guess` 应为正手。
- **拍面角度**：骨架测不出，只能看击球前后的手部放大图 `stroke_NN_zoom.jpg` 和 `stroke_NN_contact_raw.jpg`。
  - 上旋、不转高球：拍面应明显前倾。
  - 下旋高球：拍面稍开。
  - 拍面后仰着扣上旋球，是出界的直接原因。
- 指标含义见 [metrics-reference.md](../analysis/metrics-reference.md)。

## 11. 自查清单

- [ ] 球低于肩就先拉，只在约肩高以上、或近网冒高时才扣
- [ ] 看到机会球先动脚、侧身，趁球在空中把拍举到约肩高
- [ ] 杀放高球前先读旋转和深度：上旋别站太近，侧旋往拐的方向移，深球后退
- [ ] 重心从右脚到左脚，髋 → 肩 → 大臂 → 前臂依次发力，最后前臂甩
- [ ] 左臂引拍时抬起伸向左前方，挥拍时向后收带动转体，击球后不垂下
- [ ] 不用全力，手臂和握拍到触球前都是松的
- [ ] 上旋/不转高球拍面前倾、压在球上方；下旋高球拍面稍开
- [ ] 击球点在身体右前方，扣高球时手臂接近伸直
- [ ] 除非球很高，扣杀带一点上旋；不带削、少带侧旋
- [ ] 每板击球声音一样清脆
- [ ] 好的高球不硬求一板打死，压反手或中路等弱球
- [ ] 突击：上右脚、高点期、放松后瞬间收紧发力；出台长下旋以拉为主，看准机会再突击
- [ ] 拉完下旋扣挡回球时右肩抬起，不沿用拉球的沉肩
- [ ] 扣完立刻还原，准备下一板
