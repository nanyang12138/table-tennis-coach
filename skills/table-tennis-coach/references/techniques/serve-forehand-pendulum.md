# 正手侧旋发球（钟摆式，Forehand Pendulum Serve）

适用：发球轮的主力发球，最常从反手位侧身发；可发左侧上、左侧下、纯侧、纯下旋、上旋、不转，以及短、半出台、急长｜难度：入门可学，做到"同动作多旋转"属中高级｜相关卡片：`../techniques/serve-basics-and-rules.md` `../techniques/serve-reverse-pendulum.md` `../techniques/serve-fast-long-and-high-toss.md` `../techniques/serve-hook-and-squat.md` `../techniques/serve-backhand.md` `../techniques/receive.md` `../techniques/forehand-loop-vs-backspin.md` `../fundamentals/spin.md` `../fundamentals/grip.md` `../fundamentals/racket-angle-timing-contact.md`

> 全文按右手横拍写；左手持拍者左右互换。直拍发球见 `../techniques/penhold.md`。
> 出处缩写：`LH:N` = Larry Hodges（美国乒协认证国家级教练）文章 https://www.tabletenniscoaching.com/node/N ；`PS` = PingSkills 课程/教练问答；`ETT` = Expert Table Tennis；`CETV` = 中国教育电视台《乒乓球——发球方式》；`BK` = 百度百科（可编辑百科，可信度中等）。完整链接见文末。

## 1. 定义与用途

**钟摆式发球**：正手发球，拍头朝下，球拍在身体前方**从右向左**挥过球（LH:144）。主体旋转是**左侧旋**（俯视时球顺时针转，BK-侧旋球）：球飞行中向发球者的右侧、即接发球者的左侧（反手外侧）拐；接发球者被动一挡，球会向他的右侧弹（CETV）。

为什么人人都发它：Hodges 称它是"世界上最普遍的发球"，从纯下旋、侧下、纯侧、侧上到上旋都能用同一个动作做出来，转与不转的组合也容易做（LH:144）；PingSkills 也称它是最流行的发球（PS Pendulum Serve）。

**本卡覆盖的变化**：

| 变化 | 旋转 | 典型落点与用途 |
|---|---|---|
| 左侧下旋 | 侧旋+下旋 | 短或半出台，限制对方拉，逼搓 |
| 左侧上旋 | 侧旋+上旋 | 短球骗对方搓冒高；长球发对方反手，逼对方用反手上手，进入相持 |
| 纯侧旋 | 主要侧旋 | 与侧上、侧下交替，扰乱判断 |
| 不转（float / no-spin） | 几乎不转 | 用加转动作发，对方按下旋搓会冒高 |
| 纯下旋（加转短下旋，俗称"砍""搓"式） | 强下旋 | 最容易发短，最难被直接拉 |
| 上旋 | 主要上旋 | 少用，作变化 |
| 侧旋急长 | 侧旋/侧上，常带侧拐（corkscrew，旋转轴指向对方，落台后跳得厉害，LH:144） | 偶尔偷袭对方反手大角或中路 |

**优点**：侧旋向接发者反手外侧拐，反手接、反手打直线都别扭，发球者可以几乎放弃那条直线；适合"发球→正手抢拉"的打法（LH:144）。**弱点**：这种侧旋用正手较好拉；而且大家都见惯了（LH:144）。所以必须配合逆钟摆（正手逆旋转发球，reverse pendulum，`../techniques/serve-reverse-pendulum.md`；下文统称"逆钟摆"）或反手发球，否则旋转方向是"公开的"（LH:3688）。

## 2. 三位标杆怎么做

只写有出处的内容；比赛中的单场描述只当"那场比赛的例子"。

**马龙（Ma Long）**
- 央视网（转《羊城晚报》2020-08-17）：2020 年队内模拟赛按奥运标准判罚，马龙"使用自己擅长的正手发球手法，结果被裁判直接判罚发球遮挡丢分"，之后改用反手发球。报道只说正手发球是他"擅长"的，没写是哪种正手发球。（另：钟摆发球过去最容易遮挡触球，见 LH:144 和"规则要点"，这不是该报道的说法。）
- PingSkills 教练答问（马龙、张继科、水谷隼发球的区别）：三人发球原理相同；马龙收拍时手和手腕停的位置不同，但触球非常相似。教练让提问者参考钟摆发球的原理课。
- PingSkills 教练答问（Why elbow while serving）：提问者注意到马龙、陈玘发球时肘抬得很高；教练解释"肘抬高是为了把拍抬高"，旋转靠前臂和手腕产生，"整个发球中肘基本不动"。
- PingSkills 网友提问里转述过一段马龙的钟摆发球教学视频：开始时重心在左腿、身体和手臂放低；抛球后摆臂，发短球时身体轻微前送，发长球时明显前送。这是网友的二手转述，原视频未核实；教练的回答只强调"发球时身体要低，便于移动到下一板"。
- 高抛：央视网 2017-06-18 写到樊振东"面对马龙的高抛发球也无计可施"；Edges and Nets 分析 2020 世界杯半决赛，马龙暂停后全部改发高抛，扭转了比赛（单场，分析博客）。两处都没写挥拍方向，详见 `../techniques/serve-fast-long-and-high-toss.md`。
- "马龙主要发正手钟摆""招牌发球是 X"之类的说法：**暂无可靠出处**。

**张继科（Zhang Jike）**
- PingSkills 教练答问（Zhang Jike's Serve）："钟摆和逆钟摆都发得很好"，靠手腕制造很强的旋转，落点控制很好。另一则答问（Zhang Jike serve）说他"大多发钟摆发球"。英文维基则说他常用逆钟摆短球发两个角，但该句标有 [citation needed]。几处说法不一致，都不是统计，只能说"两种都用"。
- 《乒乓世界》2010（新浪转载，父亲口述）：2010 年对马龙的决胜局，他"发马龙一个正手小三角不转球，马龙回高了，他直接爆拧了"。这是"不转发球→对方冒高→第三板抢攻"的实例；没写是哪种挥拍方式。

**樊振东（Fan Zhendong）**
- 关于他的正手钟摆发球的技术特点：**暂无可靠出处**。能查到的只有：关键分用逆钟摆得分（央视网 2017-12-17 称"逆旋转发球"，见 `../techniques/serve-reverse-pendulum.md`）；2021 年奥运模拟赛林诗栋一直处理不好他发到正手的短球（Edges and Nets，单场，没写发球种类）。

**业余可以学的共同点**：肘抬高并保持稳定、靠前臂和手腕甩出拍速、薄擦、落点控制。三人的个人细节（收拍位置等）不必模仿。三人档案见 `../players/ma-long.md` `../players/zhang-jike.md` `../players/fan-zhendong.md`。

## 3. 动作分解

整体节奏：静止持球 → 近乎垂直抛起 → 球下落时引拍到位 → 球落到接近台面高度时快速擦球 → 短促随挥（可反向） → 立即还原。各阶段都要放松；全程要快，否则对方看得清触球（LH:28）。

### 3.1 站位与准备

| 部位 | 做什么、做到什么程度、为什么 |
|---|---|
| 脚/步法 | 站在**反手位**（Hodges："stand over towards your backhand corner"，LH:31）；CETV 写"一般站在中线偏左或侧身发球"。左脚在前、右脚在后，身体侧对球台，离端线留出挥拍空间。右脚在后是为了发完能蹬地还原（PS 答问 Ready position after pendulum serve）。站得太正，右侧没有挥拍空间，只能横推。 |
| 膝 | 屈膝、重心放低。PS：身体放低，发完更容易移动到下一板。直腿站，发完起动慢。 |
| 髋 | 髋随侧身略向右后转，臀部微后坐，为挥拍时髋部小幅回转留出余地。 |
| 腰/躯干 | 上体前倾、**收腹**（CETV 要点①）。腰挺直后仰会把击球点抬高。 |
| 肩 | 左肩对着球台方向，右肩放松、不耸。 |
| 大臂/肘 | 大臂外展，**肘抬高**。肘高"能把拍抬高"（PS 答问 Why elbow while serving）；把动作集中到前臂和手腕，拍速更快（PS 答问 Pendulum Serve: Elbow）。后一则答问还说，肘高能让触球点高到足以让球弹过网；所以本卡说的"触球尽量低"，是指在能稳定过网的前提下尽量低。肘掉下来，就只能用大臂带拍，拍速慢。 |
| 前臂 | 放松，自然下垂，拍头朝下。 |
| 手腕 | 放松、可以自由屈伸，不锁死。 |
| 手指/握拍 | 换成**发球握法**：食指沿拍面往下移（有人几乎放到拍面正中，指向拍头），拇指放在对侧，压在拍柄与拍面交接处，"这样能解放手腕"（LH:31）；PS 的示范是把另外三指松松地放在拍柄后面，同样为了手腕更自由，发完再握回正常握法（PS Serving Grip）。PS 不建议两指放在拍背面，这会限制手腕。握死了手腕甩不动，转不起来。握法总论见 `../fundamentals/grip.md`。 |
| 拍面/拍头 | 拍放在身体右侧，台面以上，拍头朝下。 |
| 视线/头 | 看清对方站位（离台远近、偏哪边），先定好要发的落点和旋转，再看球。 |
| 不执拍手 | 球**静止**放在**张开的手掌**上，手掌静止；手在台面以上，球在端线后（ITTF 2.6.1、2.6.4；HMO17 10.2.2）。 |

### 3.2 抛球

| 部位 | 要领 |
|---|---|
| 脚/膝 | 不动或轻微下沉；不要边抛边走动。 |
| 髋/躯干 | 保持侧身，随抛球略向右后转，进入引拍。 |
| 肩 | 放松，不随抛球耸起。耸肩会带紧大臂，手腕跟着僵。 |
| 大臂/肘 | 肘已在高位，保持不动（PS 答问 Why elbow while serving："keep the elbow quite still"）。 |
| 前臂 | 放松下垂，等球下落；不要跟着球往上抬。 |
| 手腕 | 放松，此时还不要翘腕；翘早了会僵住，也容易提前暴露动作。 |
| 手指/握拍 | 保持发球握法（LH:31；PS Serving Grip），不要中途调整。 |
| 拍面/拍头 | 拍头朝下，留在身体右侧、台面以上。抛球时拍不要乱动，以免提前暴露要发的旋转。 |
| 不执拍手 | 手掌张开，**近乎垂直**向上抛，离开手掌后至少上升 16 cm，不得使球旋转（ITTF 2.6.2）；不能把手先放到台面以下再一路扫上来抛（HMO17 10.2.2）。**抛出后左臂立即移开**，不能留在球和球网之间（ITTF 2.6.5）。 |
| 高度 | 低抛（略高于规则最低值）时球落得慢，触球前最后一刻有更多动作空间来伪装；高抛时球落得快，可以借速度加转，但更难控制（LH:144）。先用低抛练熟（LH:31）。 |
| 视线/头 | 盯球，头稳住。 |
| 常见问题 | 抛斜（往身后或往台里抛）：落点每次不同，只能伸手去够，动作变形；也可能被判"不近乎垂直"。 |

### 3.3 引拍

| 部位 | 要领 |
|---|---|
| 脚 | 重心在两脚之间或略偏右脚。 |
| 膝 | 保持屈膝，随球下落可再降一点，让击球点低。 |
| 髋/腰 | 随引拍向右后小幅转动，为挥拍积累一点回转。 |
| 肩 | 右肩略后引；左肩不要前探挡住球。 |
| 大臂/肘 | 肘保持高位、几乎不动（PS 答问），只作支点。 |
| 前臂 | 向右上方摆开，拍从身体右侧被"提起"。 |
| 手腕 | 向后（向右）充分翘起，预先拉开。手腕不预先拉开，触球时就没有甩的距离。 |
| 手指 | 仍放松。 |
| 拍面/拍头 | 引拍时各种旋转的拍面保持一致（拍头朝下、拍面略开）；拍面角度在触球前最后一刻才变（PS 发球伪装课；LH:28 半圆挥拍）。引拍时拍面就不一样，等于提前告诉对方旋转。 |
| 视线 | 盯球下落。 |

### 3.4 触球

| 部位 | 要领 |
|---|---|
| 脚/膝 | 屈膝保持低位，重心稳定；发长球时身体前送多一些（见第 5 节）。 |
| 髋/腰/躯干 | 收腹，髋和肩小幅向左回转带动手臂；BK-侧旋球说"发力以腰髋带动手臂为主"（单一来源），Hodges 写高抛发球要"用肩转进球里"（LH:31）。躯干只是小幅回转，不要大幅转体，否则击球点不稳。 |
| 肩 | 放松，配合躯干回转。 |
| 大臂/肘 | 肘在高位、基本稳定（PS）。 |
| 前臂 | 由右向左快速摆动。**尽量加大由右向左挥动的幅度和弧线**，侧旋更强（CETV 要点②）。 |
| 手腕 | 触球前一刻爆发甩腕。Hodges：发球开始时以肘为转轴，快触球时以腕为转轴（LH:3393）；放松后自然甩出，不要刻意用力来回甩（ETT 加转发球）。左侧上旋：触球瞬间"手腕快速内收"（CETV）。 |
| 手指 | 触球瞬间才收紧，帮助控制拍面。 |
| 拍面/拍头 | 按旋转选拍面（见第 4 节）。用**拍头附近**擦球最转，靠**拍柄**处触球几乎不转（LH:3393、LH:27）。 |
| 击球点 | 球**下落**时击球（ITTF 2.6.3），在台面以上、端线之后（ITTF 2.6.4）；尽量低（见第 4 节）；不可远离身体（CETV 要点①），在身体右前方。 |
| 视线/头 | 盯住触球，头不晃。 |

### 3.5 随挥

| 部位 | 要领 |
|---|---|
| 脚/膝 | 保持屈膝、低重心，右脚准备蹬地（PS 答问 Ready position after pendulum serve）。随挥时站直，还原就慢一拍。 |
| 髋 | 随躯干小幅回正，不继续大转；转过头，重心偏左，回不到准备位置。 |
| 肩 | 放松，不往前送；肩一送，球容易长、高。 |
| 前臂/手腕 | 短促，拍在身体左前方很快停住或改向。**伪装**：触球后可以立刻反向夸张收拍，例如发侧下旋时往上、往侧面收，发侧上旋时往下、往侧面收；要用小半圆一甩而过，不要停住再反向（LH:336）。也可以触球后把拍往外拉，装作发逆钟摆（LH:3448）。 |
| 大臂/肘 | 肘不要大幅前送；大臂一动，球就容易长、高。 |
| 躯干 | 回到侧身中立，准备转入还原。 |
| 手指/握拍 | 触球后手指放松，准备换回正常握法（PS Serving Grip）。 |
| 拍面/拍头 | 两种做法选一种：各种旋转收拍时拍面朝向、拍头位置都一样；或按 LH:336 有意反向（见上面"前臂/手腕"）。侧下顺势往下收、侧上顺势往上收，对方一看收拍就知道旋转。 |
| 视线 | 看球的第一落点和对方的接发动作。 |
| 尺度 | 收拍幅度每次相近：转与不转、侧上与侧下的收拍一样（PS 发球伪装课）。 |

### 3.6 还原与衔接

| 部位 | 要领 |
|---|---|
| 脚/步法 | 发完立即蹬右脚回到准备位置，左脚只需小调整；PS："随挥之后直接进入准备姿势，几乎是一个动作。"怕对方回反手位深球就稍微离台一点；对方回短球时只用右脚快速上步、退回（PS 答问 Ready position after pendulum serve）。发完原地站着看，第三板就来不及。 |
| 膝 | 保持屈膝，便于起动。PS 教练："be low ... easier to move into position for the next ball"（PS 答问 Weight Transfer on Pendulum Serve）。 |
| 髋/腰/躯干 | 由侧身转回面对球台的准备姿势。还停在侧身，正手位来球够不到。 |
| 肩/大臂/肘/前臂 | 回到身前准备位置，前臂抬起；拍还垂在身体左下方，第三板来不及引拍。 |
| 手腕 | 回到中立，不再保持发球时的翘腕。 |
| 手指/握拍 | 手指放回正常握法（PS Serving Grip）。 |
| 拍面/拍头 | 拍头由朝下转回准备姿势的朝向，拍在身前。 |
| 视线/头 | 看对方接发的触球和来球线路。心里先有第三板：发什么球、对方可能怎么接、自己怎么打（CETV-发抢；LH:24）。侧下短球常被搓回来，准备拉下旋；长的上旋/侧上常被反手攻回，准备侧身或反手相持。接发与第三板见 `../techniques/receive.md` `../techniques/forehand-loop-vs-backspin.md`。 |

## 4. 拍面角度、击球点、击球时间、触球部位

拍面角度按 CETV 的定义：拍面与台面的夹角，90° 为垂直，大于 90° 为后仰（打开）。骨架模型测不出拍面，只能看手部放大图（第 10 节）。

| 旋转 | 拍面 | 球上的触球部位 | 摩擦方向 | 出处 |
|---|---|---|---|---|
| 纯侧旋 | 较垂直，以侧向摩擦为主 | 球后部与左侧之间 | 由右向左，同时**向前**擦球侧面，不要横擦球的背面 | LH:31；BK-侧旋球；ETT 侧旋发球 |
| 左侧下旋 | 稍后仰。BK-侧旋球写"拍面角度需调整至约 45 度并向下切球"，没说怎么量；从"向下切"看是拍面后仰，大致相当于本卡口径的 135°（单一来源，转述孙颖莎教学视频） | 球的中下部 | 向左下方，同时向前 | CETV 要点④；BK-侧旋球 |
| 左侧上旋 | 较立，触球时拍面向上翻 | 球的正中或中上 | 向左上方，手腕快速内收 | CETV 要点③；LH:31 |
| 纯下旋 | **完全打开**，起止都接近与台面平行 | 球的底部（像"舀"球） | 向前擦球底部，不往下砍 | ETT 重下旋发球；LH:3639 |
| 上旋 | 较立偏前倾 | 球的上部 | 向上、向前 | LH:31；LH:28 |
| 不转 | 后仰减小、拍面较直立 | 用**靠拍柄**的部位触球 | 增加向前推送 | CETV 转与不转；LH:27；乒乓网下旋发球 |
| 侧旋/侧上急长 | 较立 | 球的后部偏侧上 | 撞击成分比短球多、挥拍更快，向前发力；触球点低，第一跳贴近本方端线 | CETV 奔球要点；PS 直线急长；LH:71 |

- **拍上的位置**：拍头附近线速度最快，转得最多；靠拍柄处慢，同样的动作几乎不转。Hodges 明确说，原因是离手腕的远近，不是接触时间的长短（LH:27）。
- **击球时间**：规则只允许在球从最高点下落时击球（HMO17 10.4.1）。实践中要让球落得低，在接近台面高度时触球；高抛同样"尽量低，略高于台面"（LH:31）。
- **击球高度**：触球点越低，球在对方台面弹得越低；尽量在略高于台面处触球（LH:31、LH:32；ETT："在肚脐高度而不是胸口高度触球"），前提是能稳定过网（见 3.1 大臂/肘）。发奔球时 CETV 写"击球点与网同高或稍低于网"。
- **离身体远近**：贴近身体，不可远离身体（CETV 要点①）。BK-侧旋球写"最佳触球点约距身体 15 厘米"；CETV 讲高抛发球时也写"在近腰的中右处（15厘米）为好"（高抛语境）。两处都是粗略参考。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：下肢稳住、屈膝保持低位 → 髋和躯干小幅向左回转 → 肩带动大臂（肘作为稳定支点）→ 前臂由右向左加速 → 手腕最后甩出 → 触球瞬间手指收紧。BK「逆旋转发球」词条把这个顺序概括为"用腰带臂，用臂带腕"。这里套用到钟摆发球是一个类比，没有找到专讲钟摆发球的出处。
- **拍速从哪来**：主要来自放松的前臂和手腕"鞭打"（ETT；LH:31："手腕、手臂、肩全程放松"）；肘基本不动（PS）。身体的作用是低重心、稳定和小幅转动，不是大力转体。
- **摩擦为主**：旋转来自"全速加速，再只轻轻擦球"，不是撞击（LH:24）。球吃进海绵越深，球越快、越不转、越难短；要用胶皮表层擦（ETT）。
- **方向要向前**：擦球的同时拍要向前，与球要去的方向一致；横着擦或往下擦球背面，球又弹又不转（ETT）。
- **短与长**：短球靠薄擦加转、手腕为主；CETV："击球时，手腕的力量大于前臂的力量"。长球摩擦里撞击成分多一些，挥拍更快，第一落点靠近本方端线（CETV 奔球要点；PS 直线急长）。
- **重下旋的入门顺序**：先锁住手腕、只用肘带前臂发力；熟练后再加手腕（ETT 重下旋发球）。

## 6. 面对不同情况的调整

| 情况 | 调整 |
|---|---|
| 想发**短**（对方台面跳两次，LH:30） | 擦得更薄、更转；触球点放低；第一落点靠近网（Hodges 的短下旋练习："两边都落在靠网处"，LH:30）；CETV 同时提醒第一落点"不要离网太近"，可以按"网是镜子"来理解：本方第一跳离网多远，对方那边就离网多远（ETT）。 |
| 想发**半出台**（tweeny） | 第二跳正好落在对方端线附近，让对方拿不准出不出台（LH:583；ETT"瞄准端线"）。 |
| 想发**侧旋急长** | 第一落点尽量靠近本方端线，放开手打（PS 直线急长）；击球点低；斜线最长、可以更快（LH:71）。长的钟摆发球常带侧拐（corkscrew，见第 1 节）。详见 `../techniques/serve-fast-long-and-high-toss.md`。 |
| 发不转急长 | 球落台两次会带上一点上旋，要"死"就在触球时略向下，加一点点下旋抵消（LH:29）。 |
| 落点选择 | 三个目标：正手大角、反手大角、中路（对方正反手转换点，常在执拍手肘附近）（LH:24、LH:71）。侧旋往对方"拐出去"的那一侧发更难接，对初中级对手可发大角（LH:144）。 |
| 接发者是**左手** | 本卡的落点建议默认对方是右手。左手者的正手、反手位置正好相反，"往外拐""往里拐"的落点要对调。你看过去球台右侧（对方的左侧）是右手者的反手、却是左手者的正手；钟摆球仍往这一侧拐，所以发到右手者反手大角是往外拐，对左手者就是往他**正手外侧**拐。表里的"发对方反手""发正手短""中路（执拍手肘附近）"都要按对方持拍手重新找位置；原样照搬，会把球送到对方擅长的位置。 |
| 对方爱侧身用正手抢拉 | 发对方正手位或长球要谨慎：这种侧旋正手较好拉（LH:144）。多发短下旋、不转，偶尔快长偷袭。 |
| 对方反手强、站位偏反手 | 改发正手短；或从中路、正手位发（换站位本身就是变化，LH:3617）。 |
| 对方摆短好 | 短下旋的缺点是高水平对手能摆短（LH:23）；改用侧上、不转、半出台。 |
| 高抛 | 动作同低抛，但抛球要单独练到能落在固定位置；触球尽量低（LH:31）。 |
| 紧张、关键分 | 有研究发现，焦虑时发球的拍面角没有显著变化，但动作变快（Ngo 2017，9 名大学水平球员）。关键分优先发自己最稳的那一套。 |

## 规则要点

规则全文与裁判解释见 `../techniques/serve-basics-and-rules.md`。下面只列钟摆发球最容易出问题的地方。

1. **持球**：球静止放在张开的手掌上，手在台面以上，球在端线之后（ITTF 2.6.1、2.6.4；HMO17 10.2）。不能握球、不能捏着球加旋转（HMO17 10.2.1）。
2. **抛球**：近乎垂直向上，离开手掌后至少上升 16 cm（ITTF 2.6.2）。裁判手册把"近乎垂直"解释为偏离垂直只能有几度（HMO17 10.3.1）；抛得越高，同样的水平偏移越容易被判"不垂直"。16 cm 只是"略高于网高 15.25 cm"的参照，不等于"抛过网高就合法"（HMO17 10.3.2）。
3. **击球**：球从最高点下落后才能击球，击球时球在台面以上、端线之后（HMO17 10.4.1）。
4. **不得遮挡**：从发球开始到击球，球不能被发球员的身体或穿戴物挡住；抛球后不执拍手臂必须移出"球与球网之间的空间"（ITTF 2.6.4、2.6.5）。钟摆发球是侧身发，左肩、左臂、头最容易挡住球。Hodges 指出，钟摆发球流行的一个历史原因就是它过去最容易遮挡触球，现在已不合法（LH:144）。马龙 2020 年模拟赛就因正手发球被判遮挡丢分（央视网 2020-08-17）。
5. **判罚**：让裁判相信发球合法是发球员的责任（ITTF 2.6.6）。只有"拿不准"时每场可警告一次；明显违例不会先警告，直接判失分（HMO17 10.6.1–10.6.2）。在不合法边缘发球，风险由发球员自己承担（HMO17 10.5.3）。
6. **藏拍与遮挡**：规则只要求球不被遮挡，不要求接发者整个发球过程都看得见球拍；可以在发球开始时把拍藏在身后（HMO17 10.5.2）。但球从开始到被击中都不能被身体或穿戴物挡住（ITTF 2.6.4；遮挡发球 2002 年起禁止，Jin & Ma 2026）。

## 旋转变化与伪装

**原则**：起始站位、引拍、收拍都相同，只改变触球（PS 发球伪装课）。另外，改变旋转的"量"可能比改变旋转的"种类"更有效（PS Variation of Spin）。

1. **半圆挥拍定旋转**：拍走一个"先下、再横、后上"的半圆，在下行段触球得下旋，在横向段触球得侧旋，在上行段触球得上旋（LH:28）。挥拍要快，让对方看不清是在哪一段触的球。发侧下、侧上比纯下、纯上更骗人（LH:28）。ETT 的说法是："手腕的一点变化就能把下旋变成上旋"。
2. **拍头与拍柄（转与不转，heavy no-spin）**：同一个动作，用拍头附近擦球是转的，用靠拍柄处触球是不转的；发不转时也要像加满下旋那样"用力切进去"（LH:27）。不转球的威力来自"有旋转的威胁"，必须先有真正转的球（LH:583）。CETV 的做法是触球瞬间减小拍面后仰、增加前推。乒乓网的说法是动作相似，靠触球瞬间手指和手腕的精细控制来区分（乒乓网下旋发球）。
3. **拍中间作转轴**：触球前把转动轴移到拍面中间，这时拍头向下、靠拍柄处向上；拍头触球得下旋，拍柄侧触球得上旋或侧旋（LH:3393）。这招难度高，需要教练或高手当面帮助。
4. **反向收拍**：触球后立即反向，用夸张的小半圆收拍（LH:336）；也可以突然停顿、出现"顿挫"动作（LH:31，高抛）。
5. **双重动作**：钟摆触球后立刻把拍往外拉，像要发逆钟摆；或者摆出逆钟摆的架势，向外挥时"放空"，回拉时再用钟摆触球（LH:3448）。
6. **配套发球**：钟摆可以在最后一刻改成逆钟摆（LH:144）。会正反两种侧旋，对方才不能从动作上直接读出旋转方向（LH:3688）。
7. **抛高变化**：高抛和低抛混用，扰乱对方对节奏和旋转量的判断（LH:31）。
8. **落点与长短**：同一个动作发短、半出台、急长（PS 急长课；LH:71："用和其他发球相同的总体动作发急长"）。

**纯下旋（加转短下旋，ghost serve）要点**：拍面完全打开，尽全力加速，只在球底部轻擦，感觉"球差点过不了网"。做到这样，球不但很转，还可能在对方台面停住甚至往回跳（LH:3639）；PS 把这种往回跳的发球称作"马琳鬼球"（Ma Lin Ghost Serve）。**利弊**：短下旋有球台挡着，对方拉不起来，常见的回球是搓长；缺点是高水平对手能摆短或挑打（LH:23；ETT："最容易发短的发球"）。

**上旋、侧上旋与不转（float）**：职业比赛里纯上旋是最少见的发球，多数是带侧旋的上旋或下旋（英文维基 Table tennis）。一般原理：侧上、上旋短球让对方误判成下旋去搓，回球就会冒高。球员例子：2021 年中国奥运模拟赛，马龙发正手短上旋，周启豪判断错误、回球冒高（Edges and Nets 2021-05-06，单场观察；原文没写挥拍方式）。长的上旋/侧上钟摆发对方反手，对方多半只能打出发球方应付得了的反手进攻，进入相持（ETT，作者个人经验）。但这种侧旋正手较好拉（LH:144），对方能侧身用正手抢攻时，发长到反手有风险；对方侧身太早，可突然发正手直线快长（LH:29）。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 球弹得高、旋转弱 | 横擦或往下擦球的**背面** | 向前擦球的侧面（侧旋）或底部（下旋）（ETT） |
| 想发短却总出台 | 擦得不够薄；触球点太高（LH:583）；往下砍（ETT） | 更薄、更快；让球落得更低；第一落点前移靠网 |
| 下旋不转 | 为求稳放慢挥拍 | 全速加速、只擦一点（LH:3639）；离台对地毯练到球能往回滚（ETT；PS） |
| 不转球一看就看出来 | 动作变慢、变小 | 用同样的加转动作、用拍柄处触球（LH:27） |
| 旋转被一眼读出 | 侧上往上收、侧下往下收；引拍不一样 | 同起手、同收拍，或反向收拍（PS；LH:336） |
| 只会一种侧旋方向 | 只练钟摆 | 加练逆钟摆或反手发球（LH:3688） |
| 手腕甩不动 | 握拍太紧、手指位置不对 | 换发球握法，全程放松（LH:31；PS） |
| 大臂大摆、肘乱动 | 用大臂代替前臂和手腕 | 肘抬高并固定作支点（PS） |
| 击球点离身体远、向前够球 | 抛球不准、没收腹 | 练抛球落点；收腹，击球点贴近身体（CETV） |
| 被判遮挡 | 左臂留在前面、侧身过度、头挡住球 | 抛完左臂立即移开；用正面机位自查（规则要点） |
| 被判抛球不合法 | 抛不够 16 cm、斜抛、手从台下扫上来 | 先单独练抛球（ITTF 2.6；HMO17） |
| 急长下网或太慢 | 第一落点离本方端线远；往下打 | 第一跳贴近本方端线，让球落低后向前打（PS；ETT 快发） |
| 发完被抢攻、来不及 | 发完站着看 | 随挥直接进入准备姿势，右脚蹬地还原（PS） |
| 高抛乱 | 抛球没练好就上高抛 | 先低抛练熟，再单独练抛球（LH:31） |

错误总表见 `../training/errors-index.md`。

## 9. 练习方法（入门 → 进阶）

1. **徒手与握拍**（入门）：徒手做站位、抛球、引拍、挥拍的完整动作；练发球握法和发完换回正常握法（扬州职大"徒手作发球前的预备姿势"；PS Serving Grip）。
2. **离台练擦球**（入门）：不上台，只练薄、快的摩擦；下旋发到地毯上，看球能不能往回滚（PS 改进发球课；ETT 重下旋发球）。
3. **一筐球上台**（入门）：多球练习，按 LH:30 的顺序：先练短下旋（拍面打开擦球底部，球刚好过网，两边第一跳都靠网，触球点略高于台面）→ 再加侧旋成侧下 → 最后练侧上（拍同时向侧、向上，一开始容易冒高出台）（LH:30；PS 钟摆课教的是下旋、侧旋、上旋之间的变化）。每种连续发 20 个，统计成功数（仿 PS 逆钟摆课的 20 球挑战）。
4. **长短控制**（中级）：在对方台面放目标，练短（跳两次）、半出台（第二跳压端线）、急长（第一跳贴本方端线）。ETT 提到中国队曾用 A4 纸作发球目标。
5. **落点**（中级）：正手大角、反手大角、中路，三点轮换（LH:24；PS Variation of Placement）。
6. **同动作多旋转**（进阶）：同伴接发前先报出判断的旋转；练转与不转（拍头/拍柄）、侧上与侧下（半圆不同段）、反向收拍（LH:27、28、336）。
7. **双重动作与逆钟摆配套**（进阶）：LH:3448；`../techniques/serve-reverse-pendulum.md`。
8. **发球+还原+第三板**（进阶）：每发一个球都回到准备姿势并做一次影子挥拍（PS）；再上台练发球抢攻，先固定对方回球线路，再放开（CETV-发抢；扬州职大"练一至二套质量高的特长发球"）。
9. **高抛**（进阶）：单独练抛球落点，再加挥拍（LH:31）。

更多练法见 `../training/drills.md`。

## 10. 视频检查要点

**机位**（详见 `../analysis/recording-guide.md`）：
- **侧面**（首选）：拍全身，看屈膝、收腹、肘高、击球点高度、离身体远近、抛球高度。
- **正面**（补拍）：看是否遮挡、抛完左臂是否移开、挥拍方向和收拍是否暴露旋转。
- 用 120/240 fps 慢动作，导出后用 `--capture-fps` 校正。发球动作小、手速峰值低，脚本可能报 `NO_STROKES`。先用 `--start/--end` 截出单个发球；仍报 `NO_STROKES` 时，用 `--timeline 起 止` 出逐帧图，找到准备、引拍结束、触球、随挥结束、还原五个时刻（秒），再按 `--strokes "ready,backswing_end,contact,finish,recovery"` 的顺序填入，例如 `--strokes "3.10,3.34,3.52,3.70,4.05"`（见 `../analysis/metrics-reference.md`）。
- 脚本不追踪球，抛球高度、垂直度和落点只能逐帧目测。

| 阶段 | 最佳机位 | 关键帧看什么 | 对应指标 |
|---|---|---|---|
| 站位与准备 | 侧面；侧对程度看正面 | 是否侧身、屈膝、肘是否抬高 | `stance_width_ratio`、`knee_angle_deg.{playing,other}.ready`、`shoulder_width_ratio.backswing_end`（正面机位下用来核对身体侧对程度，解读见 `../analysis/metrics-reference.md`） |
| 抛球 | 正面看垂直度、左臂；侧面看高度 | 球是否静止在掌上、是否近乎垂直、抛完左臂是否移开 | `free_arm_height_level`（抛完后应下降、移开）；抛球本身靠目测 |
| 引拍 | 侧面 | 手腕是否预先翘起、肘是否高而稳、躯干前倾 | `elbow_angle_deg.backswing_end`、`trunk_lean_deg.backswing_end`、`backswing_ms`、`knee_min_deg.{playing,other}` |
| 触球 | 侧面（`contact_height_level`、`knee_*`、`contact_forward_m`）；正面看遮挡 | 击球点高度（低）、离身体远近、头是否稳 | `contact_height_level`（0＝髋高，1＝肩高；钟摆发球应明显低于肩，接近或低于髋）、`contact_forward_m`、`contact_lateral_m`、`elbow_body_gap_m`、`elbow_angle_deg.contact`、`trunk_lean_deg.contact`、`head_motion`、`peak_hand_speed`、`forward_ms` |
| 随挥 | 正面 | 挥拍方向是否暴露旋转（侧下应偏横向下、侧上偏横向上）、收拍是否短、各种旋转的收拍是否一致 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`、`follow_ms`、`elbow_angle_deg.finish` |
| 还原与衔接 | 侧面或正面 | 是否立刻回到准备位置 | `weight_shift.{backswing_end,finish,delta}`（0＝右脚，1＝左脚；发长球时前送通常更明显，但只有二手转述，仅供参考）、`recovery_dist` |
| 整体 | 两个机位分别跑 | 身体是否参与、顺序是否合理、数据是否可信 | `hip_turn_deg`、`shoulder_turn_deg`、`x_factor_deg`、`sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`（发球动作小，此项参考价值低）、`side_guess`（应为正手）、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

**拍面与手腕**：骨架模型测不出拍面和握法，必须看**手部放大图**（`stroke_NN_zoom.jpg`，触球前后各 2 帧）和 `stroke_NN_contact_raw.jpg` 目测：拍头是否朝下、拍面打开多少（下旋应接近与台面平行）、触球在拍头还是靠拍柄、触球前手腕是否有甩动。同一组视频里把转与不转、侧上与侧下的放大图并排比较，看动作是否一样。`quality.reliable` 为假，或手腕出现在 `low_visibility_parts` 里时，不下结论，按拍摄指南重拍。

## 11. 自查清单

- [ ] 站在反手位侧身，左脚前、右脚后，屈膝放低，收腹
- [ ] 换成发球握法，手腕放松；发完换回正常握法
- [ ] 球静止在张开的手掌上，手在台面以上，球在端线后
- [ ] 近乎垂直抛起，离手后至少 16 cm；抛完左臂立即移开，不遮挡
- [ ] 球下落后、在接近台面的低位触球，击球点贴近身体
- [ ] 肘抬高且基本不动，前臂由右向左加速，手腕最后甩出
- [ ] 擦球时拍同时向前；用拍头附近薄擦
- [ ] 侧下、侧上、纯侧、纯下、不转的拍面和触球部位都清楚
- [ ] 短球能跳两次，半出台能压端线，急长第一跳贴本方端线
- [ ] 转与不转、侧上与侧下的起手和收拍看不出区别
- [ ] 至少还有一种反方向侧旋发球（逆钟摆或反手发球）作配套
- [ ] 发完一个动作接上还原，心里有第三板
