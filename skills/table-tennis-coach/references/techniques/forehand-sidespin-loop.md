# 正手侧旋弧圈：左拐与右拐（Forehand Sidespin Loop: Hook and Fade）

适用场景：相持中把对方拉出位置、做下一板的铺垫；被调到正手大角时把球"绕"回来；接侧旋长发球、对拉时避开来球旋转｜难度：高级（必须先把直线上旋拉稳）｜相关卡片：`../techniques/forehand-loop-vs-topspin.md` `../techniques/forehand-loop-vs-backspin.md` `../techniques/forehand-counter-block.md` `../techniques/backhand-block.md` `../techniques/receive.md` `../techniques/footwork.md` `../techniques/serve-reverse-pendulum.md` `../fundamentals/spin.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/power-and-body.md`

> 全文按右手持拍、**击球者视角**（站在自己这一端看向对方）来写，左手持拍者左右互换。拍面角度用"拍面与台面的夹角"口径：90° 为垂直，小于 90° 为前倾（中国教育电视台课程的定义）。

## 1. 定义与用途

正手侧旋弧圈（forehand sidespin loop / sidespin topspin）是在正手弧圈的上旋里加上明显的侧旋，让球在空中横向拐弯、碰到对方球拍后向侧面弹。人民网（转苏州世乒赛官网）的说法是：准备姿势和全身用力方法与加转弧圈相似，区别在击球时"摩擦球的偏右面，拍形稍前倾，手臂自右外侧向左前上方（近似于弧形）发力"；击球右中部或右中上部拉出侧上旋。

**两种侧旋弧圈。** PingSkills 课程把正手侧旋上旋分为两种：拍头下垂的 hook 和拍头上翘的 fade；手臂动作和普通弧圈一样，只改手腕和拍面角度，不要横着扫过身体。本卡这样称呼它们：

| 本卡叫法 | 拍头 | 触球部位 | 击球者看球往哪拐 | 英文 | 日文 | 球碰到对方拍后 |
|---|---|---|---|---|---|---|
| **左拐弧圈（下垂型）** | 下垂 | 球的外侧（远离身体的右侧） | 向左 | hook / hooking sidespin loop | カーブドライブ（日文维基："左回転"，"飛球は左側へ曲がる"） | 向击球者的右侧弹（即对方的左侧） |
| **右拐弧圈（上翘型）** | 上翘，手腕后翘 | 球的内侧（靠近身体的左侧） | 向右 | fade；Hodges 称 inside-out loop | シュートドライブ（"右回転"，"右側へ曲がる"） | 向击球者的左侧弹（即对方的右侧） |

出处链：hook 的"拍头下垂、触球远侧"见 Hodges《Hooking Sidespin Loops》；"触球右侧（外侧）→ 弧圈往左拐，触球左侧（内侧）→ 往右拐（inside-out）"见 Hodges《Looping Spin Serves》；两种日文弧圈的拐向和"碰对方拍后的弹向"见日文维基「卓球」。把 hook 对到カーブ、fade 对到シュート，是本卡按上述来源写明的旋转方向逐一对上的，**没有哪份来源直接说过二者等同**。

**关于"外拐、内勾"等叫法。** 中文口语里的"外拐/内拐/内勾"和 hook/fade、カーブ/シュート 之间的对应，本项目调研**没有找到权威出处**，不同教练用法可能正好相反。"左侧旋/右侧旋"也一样：Hodges 按"球的右侧向远离你的方向转"叫 right sidespin，按这个定义下垂型是 right sidespin，日文却叫它"左回転"。所以本卡一律写"拍头怎么放、摩擦球的哪一侧、击球者看球往哪拐"，听别人说"外拐/内勾"时先问清是哪种拐向。

**用途（各条均有出处）：**
- **调动对手**：用侧旋把站在中间的对手拉到大角外，并让他更难挡（PingSkills）。左拐弧圈打到对方正手大角，球继续往边线外拐，对方很难攻你空出来的反手位，回球多半回到你的正手（Hodges）。
- **做铺垫**：侧旋打乱对方的节奏，并逼他把球回到你的正手，适合做下一板的铺垫（Hodges）。
- **被调到正手大角时**：只要需要伸手够球，最好把拍子放到球的外侧，带着上旋和侧旋"勾"回去（Hodges）。
- **对拉中**：稍微触球外侧带点侧旋，既顺手，又不用和来球的上旋正面硬碰（Hodges《Counterlooping》）。
- **拉侧旋发球**：根据来球拐向调整触球在球的内侧或外侧，顺势拉出侧旋（Hodges《Looping Spin Serves》，见第 6 节）。
- **藏线路**：先摆出往左打的架势，最后一刻打球的内侧打到右边（inside-out），对方容易判断错（Hodges 2020-10-12 每周技巧）。
- **绕网**：极宽的正手球可以从网柱外绕过去（PingSkills《Around the Net Forehand Topspin》：选够宽的球，加侧旋）。历史上匈牙利的约尼尔（Jonyer）常用直臂、拍头几乎垂直朝下拉出近乎纯侧旋的弧圈，甚至绕网，规则因此改为网柱伸出台外（Hodges）。

**代价**：侧旋弧圈的容错比纯上旋小，先把直线上旋练可靠再练它（PingSkills）。Hodges 也说大多数弧圈本来就带一点侧旋，因为手臂从肩部向下斜，拍头自然下垂；本卡讲的是**有意加大、并能控制方向**的侧旋。

## 2. 三位标杆怎么做（马龙 / 张继科 / 樊振东；只写有出处的）

- **马龙**：Khaleej Times 2021-08-05 评论东京奥运会男单决赛时写道，马龙正手"弧线更高的上旋变化带有很强的侧旋，常把樊振东调出位置"，还能把看似够不着的球"hook"成正手制胜球。这是一位评论作者的观察，单一来源，没有讲动作细节，也没写具体拐向（英文评论里的 hook 未必等于本卡的左拐）。可借鉴的是用法：**用高弧线加侧旋调动对手**。本卡推断，"把够不着的球 hook 回来"与 Hodges 说的"被调到正手大角时把拍放到球外侧勾回"是同一种用法，但原文没写动作和拐向。更多见 `../players/ma-long.md`。
- **张继科**：关于他正手侧旋弧圈的特点，**暂无可靠出处**。他常被提到的"拧"是反手台内技术（《卓球レポート》2019-03-07〈水谷隼に聞く 24 チキータがすごい選手〉：张继科把チキータ（拧拉）发展成进攻支柱），见 `../techniques/backhand-banana-flick.md`，不要混为一谈。
- **樊振东**：关于他正手侧旋弧圈的动作细节，**暂无可靠出处**。PingSkills 有一篇教练问答（"Forehand Topspin Fade shot"）顺带一句说马龙和樊振东都擅长从反手位侧身拉出打到对方反手大角、继续往台外拐的侧旋正手，但没有给比赛或视频证据；这篇问答对挥拍的描述（收拍横过身体到左肩）也和 PingSkills 课程本身"别横扫身体"的说法不一致。所以本卡只采用其中"侧身位用右拐弧圈打对方反手大角"这个用法，不采用它对动作的描述。

## 3. 动作分解

基准：下面每个阶段都以 `../techniques/forehand-loop-vs-topspin.md`（拉上旋）和 `../techniques/forehand-loop-vs-backspin.md`（拉下旋）的正手弧圈为底，**只写侧旋弧圈要变的地方和容易做歪的地方**。原则是：身体和手臂跟普通弧圈一样，变化集中在手腕、拍头和触球部位（PingSkills）。

**非持拍手（free arm，左臂）**放在各表最后一行。要求：**左臂的动作和你拉直线弧圈时一样**，拉左拐、右拐都不为侧旋单独改左臂。
- **依据**：日文维基「卓球」说，非持拍手通过躯干与持拍手联动，原则上在各种打法里用同样的方式和位置，用来调整击球时的全身平衡（"基本的に各種打法と同じような手の使い方と位置取りを行う"）。Hodges《Use Both Sides of the Body When Forehand Looping》：右手持拍者拉正手时，右侧向前转，左侧要同时向后"拉"；只转右侧会限制力量、破坏平衡。PingSkills《How to Use Your Non-Playing Arm in Table Tennis》：用非持拍手支持平衡和上身转动，但不要刻意做大动作，拍视频检查它在做什么。
- **为什么拉侧旋时更要一样**（本卡推断，没有找到专讲侧旋弧圈左臂的来源）：侧旋弧圈靠"前段和直线弧圈一样、最后一刻才变"来藏线路（Hodges 2020-10-12）。左臂动作比手腕大，对手更容易看到，左臂提前和平时不一样（提前收紧、甩开或换位置），就等于提前给了线索。侧旋只改手腕和拍面，转体不变，左右两侧"一拉一送"的配合也就不用变。
- **做错了会怎样**：左臂垂下不动，转体变小、只剩手臂发力，球软、身体失衡（Hodges）；左臂猛向后甩、带着肩水平转，容易变成第 8 节第 1 条的横扫。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 与普通正手弧圈相同：两脚略宽于肩，右脚稍后，前脚掌着地，随时能向右跨出或侧身 | 还没击球就站成侧身或大开步，对方提前看出线路 |
| 膝 | 微屈，有弹性 | 直腿站，后面来不及到位，只能用手找球 |
| 髋 | 放松微坐，便于向右转 | 髋僵，转不动 |
| 腰/躯干 | 上身略前倾，与普通弧圈相同 | 后仰，重心在脚跟 |
| 肩 | 放松、基本水平 | 耸肩；肩紧会引起"肘上浮"（PingSkills 问答） |
| 大臂/肘 | 自然放在体侧前方 | 肘贴死在身上 |
| 前臂 | 拍在体前，略高于台面 | 拍放得太低 |
| 手腕 | 中立，不要提前下压或后翘 | 准备时就把腕压下或翘起，等于告诉对方要拉侧旋 |
| 手指/握拍 | 正常横拍握法，握松；不必为侧旋改握法，拍面变化靠手腕和手指在后面阶段完成 | 握得死紧，手腕动不了 |
| 拍面/拍头 | 拍头朝前偏右，拍面中立 | — |
| 视线/头 | 看对方拍面和挥拍方向，判断来球的旋转和落点 | 只看球不看对方拍，判断慢 |
| 非持拍手（左臂） | 自然弯曲，放在身体左侧、腹前左侧（中国教育电视台《攻球技巧》；扬州职大），放松，见 `../fundamentals/ready-stance.md` 2.7；准备拉直线、左拐、右拐时位置都一样 | 垂在身侧或插腰，后面转体时左半身不参与；准备拉侧旋时左臂位置和平时不同，等于暴露意图 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落到右脚（人民网：加转弧圈准备时重心约在右脚）。左拐弧圈多用在正手大角：右脚先向右跨，身体到位后再引拍；实在够不到时允许伸手，但要把拍放到球外侧（Hodges）。右拐弧圈多在侧身位：右脚后撤、身体打开，提早到位（PingSkills 问答） | 不移步，站在原地用手臂去够 |
| 膝 | 右膝屈得更深，蓄力 | 膝不屈，只能靠手臂 |
| 髋 | 右髋向后转并下坐 | 髋不转，后面只能用手臂横扫 |
| 腰/躯干 | 向右转，幅度与普通弧圈相同；不要为了加侧旋多转 | 转得过大成"掷铁饼"式（百度百科"弧圈球"列出的错误） |
| 肩 | 右肩略低于左肩，与普通弧圈相同 | 右肩沉得过多，拉侧上旋来球时容易出界长（Hodges，接侧旋发球） |
| 大臂/肘 | 与普通弧圈相同，靠转体带手臂后引 | 靠拉肘向后引拍（百度百科） |
| 前臂 | 放松、自然下垂 | 前臂绷紧 |
| 手腕 | 左拐：手腕放松下沉，让拍头低于手；右拐：手腕向后翘（Hodges 2020-11-23："有意把手腕往后翘，打球的内侧"）。尽量晚一点变，最好在引拍末段到前挥中完成（Hodges：最后一刻打球内侧改线） | 一开始就把手腕定型，线路暴露 |
| 手指/握拍 | 拇指、食指保持对拍面的微调能力 | 手指死握 |
| 拍面/拍头 | 拍面稍前倾（人民网）；拍低于来球（拉下旋时尤其要低） | 拍面过于前倾、摩擦太薄 |
| 视线/头 | 头稳，盯住来球，判断球会落在身体侧前方哪个位置 | 引拍时头跟着转走 |
| 非持拍手（左臂） | 保持弯曲抬起，随腰髋右转一起移到体前，幅度与直线弧圈相同（本卡按"左臂随躯干转动"归纳）。左拐在正手大角伸手够球时，左臂仍要抬着，帮身体稳住平衡（日文维基：非持拍手调整全身平衡） | 左臂留在左侧不动或垂下，上身转不过去；右拐、左拐时左臂各有一套动作，与直线弧圈不同，对方能提前看出 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地，重心开始向左脚转移（人民网） | 脚不蹬，重心留在右脚 |
| 膝 | 右膝蹬伸 | 膝一直弯着，只用手臂 |
| 髋 | 向左前方转（湖北经济学院：蹬地、挺髋、转腰、收小臂） | 髋先停住，手臂单独甩 |
| 腰/躯干 | 转腰带动手臂，方向是**向目标的前上方**，不是横向 | 腰带着手臂横扫，球偏出侧边或软 |
| 肩 | 右肩向前上方转 | 右肩水平向左拉，形成横扫 |
| 大臂/肘 | 上臂带前臂向前上方加速（人民网），肘不上浮 | 抬肘、手腕下垂并发力（"肘上浮"，PingSkills 问答） |
| 前臂 | 两种拐法的前臂方向都和普通弧圈相同，仍向前上方（PingSkills：手臂动作同普通弧圈，只改手腕和拍面角度）。左拐：拍头下垂，拍面自然落在球的外侧（人民网把这一板描述为"自右外侧向左前上方（近似于弧形）"发力）；右拐：手腕保持后翘，拍面自然落在球的内侧（左侧）（Hodges 2020-11-23） | 为了拐而让前臂或整条手臂横向甩出去，变成横扫 |
| 手腕 | 保持引拍末的角度：左拐拍头一直下垂，右拐手腕一直后翘，直到触球 | 中途手腕回正，侧旋没了；或手腕抢先甩，"吃不住球" |
| 手指/握拍 | 保持松握，让手腕能动 | 越挥越紧 |
| 拍面/拍头 | 左拐：拍面朝左前，准备擦球右侧；右拐：拍面朝右前，准备擦球左侧 | 拍面角度和挥拍方向一起改，导致又横扫又打偏 |
| 视线/头 | 头稳定，眼睛盯击球点 | 提前抬头看对方 |
| 非持拍手（左臂） | 随左转向左后方"拉"，与右肩向前上方送出同时发生（Hodges node/3223）；方向和幅度与直线弧圈相同，不要为了让球拐弯而加大左拉 | 左臂垂下不动：转体变小、只剩手臂发力（Hodges：只转右侧会限制力量、破坏平衡）；左臂猛向后甩，带着肩水平转，变成横扫 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心正从右脚移向左脚 | 跳起或后仰着击球 |
| 膝 | 右膝基本蹬开 | — |
| 髋 | 髋还在向左前转，不提前停 | 髋先停，后面全靠手 |
| 腰/躯干 | 上身略前倾，保持稳定 | 上身后仰，球拉高 |
| 肩 | 右肩已转到前方 | — |
| 大臂/肘 | 肘与身体留出空间，不夹臂。约尼尔是直臂拉侧旋（Hodges），属个人风格，不必照学 | 肘夹在身上，挥不开；或手臂完全伸直还要发力 |
| 前臂 | 快速收前臂，方向同普通弧圈；左拐靠拍头下垂、右拐靠手腕后翘，让拍面落到球的外侧或内侧，不要靠前臂横向绕球 | 前臂停住，只剩手腕"拨"；或前臂横向绕球 |
| 手腕 | 左拐：拍头下垂（约尼尔拍头常常直指地面，拉出近乎纯侧旋，一般不必这么极端）；右拐：手腕后翘、拍头上翘 | 手腕下垂太多，打在拍边（PingSkills 问答：提问者的教练认为手腕下垂会带侧旋、容易打到拍边；PingSkills 回答确认下垂的手腕会带来多余侧旋） |
| 手指/握拍 | 用手指稳住拍面 | 手指松掉，拍面被球顶开 |
| 拍面/拍头 | 拍形稍前倾（人民网）。左拐：摩擦球的右中部或右中上部（人民网）；右拐：摩擦球的左侧（Hodges：触球靠近你的一侧），仍要包住上部带上旋 | 只擦侧面、不包上部，上旋太少，球不往下扎、容易出界长 |
| 视线/头 | 头不动，看清球拍接触球的那一侧 | 头跟着手臂甩 |
| 非持拍手（左臂） | 仍弯曲抬着、在向后拉，和右侧前送形成"一拉一送"（Hodges node/3223）；高度与直线弧圈相近 | 左手掉到髋以下：转体和平衡配合差（`../analysis/metrics-reference.md` 对 `free_arm_height_level` 的解读） |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心落到左脚（人民网） | 重心还在右脚 |
| 膝 | 左膝承重，保持弯曲，便于马上还原 | 两腿伸直站起来 |
| 髋 | 髋转到大致面对球台 | 髋转过头，身体背向球台 |
| 腰/躯干 | 随着转动自然停下 | 上身往左倒 |
| 肩 | 肩放松（百度百科：拉后手臂尤其是肩部要迅速放松还原） | 肩一直紧着 |
| 大臂/肘 | 手臂继续向目标前上方送出，收拍方向和普通弧圈一致（PingSkills：手臂动作同普通弧圈） | 收拍横过胸前到左腰或左肩以下——典型的"横扫" |
| 前臂 | 自然收回 | — |
| 手腕 | 回到中立 | 手腕一直保持翘/压，下一板来不及变 |
| 手指/握拍 | 放松 | — |
| 拍面/拍头 | 拍头随动作自然转回 | — |
| 视线/头 | 看球的拐向和对方怎么接 | 看自己的拍子 |
| 非持拍手（左臂） | 收回到身体左侧，配合重心落到左脚，帮身体转完后停稳。Hodges 用马龙正手拉视频说明：两侧身体一起转，身体不向前移，结束时保持平衡、马上能打下一板（node/3223） | 左臂继续甩到身后，身体被带歪、回位慢 |

## 4. 拍面角度、击球点、击球时间、触球部位

- **拍面角度**：拍形稍前倾（人民网）。没有找到有出处的侧旋弧圈具体度数，本卡不写数字。比较可靠的做法是：前后倾按来球决定（拉上旋更前倾，拉下旋相对立起来，见两张拉球卡），左右方向再按侧旋类型偏转——左拐时拍面转向左，右拐时转向右。
- **拍头**：左拐下垂，右拐上翘（PingSkills）。Hodges 解释为什么左拐更顺手：手臂从肩部向下斜、击球点低于肩，拍头本来就会下垂；想不带侧旋，几乎得刻意把拍头抬起来。本卡由此推断：右拐要**主动抬拍头、翘腕**，比左拐难（Hodges 没有直接比较二者难度）。
- **触球部位**：左拐摩擦球的右中部或右中上部（人民网），Hodges 的说法是"球的远侧"；右拐摩擦球的左侧（靠近身体一侧）。两种都要**同时包住球的上部**，保留足够的上旋。
- **击球点**：在身体右侧前方，不能落到身体后方（百度百科"弧圈球"）。左拐的球通常稍偏右外、离身体远一点，拍才能放到球外侧；右拐的球要稍靠近身体或让得晚一点，拍才能放到球内侧。
- **击球时间**：按来球类型选，与普通弧圈相同（拉上旋见 `../techniques/forehand-loop-vs-topspin.md`，拉下旋见 `../techniques/forehand-loop-vs-backspin.md`）。两条有出处的微调：对拉时想往直线走，可以稍晚一点击球来对准，或者翘腕打 inside-out（Hodges 2020-11-23）；PingSkills 问答说侧身位的右拐弧圈在"刚过最高点"击球（单一来源）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：与普通弧圈完全相同：腿蹬地→髋/腰转→肩→上臂→前臂→手腕，平滑依次（Hodges；人民网"腿、腰、上臂、前臂依次进行动量传递"）。侧旋只改最后一节（手腕和拍面），前面各环节不变。
- **方向**：整体挥拍方向仍然是向**目标的前上方**。人民网说左拐的手臂"自右外侧向左前上方（近似于弧形）"发力，PingSkills 则强调"别横扫身体"。本卡的理解：两者并不矛盾，弧形来自拍头下垂、拍面落在球外侧时拍面走出的小弧，前臂方向仍同普通弧圈，不是肩膀带着整条手臂水平扫过胸前。判断标准：收拍位置和你拉直线弧圈时差不多。
- **摩擦与撞击**：仍是"先打后摩，又打又摩，以摩为主"（百度百科引《乒乓世界》）。侧旋弧圈的摩擦更偏球的侧面。PingSkills 说它"容错更小"，但没给原因。可能原因之一（本卡解释）：拍速有一部分变成了侧旋，上旋和向前的量就少了，弧线下扎变弱；另外球会横向拐弯，瞄准和触球部位的允许偏差都更小。所以加侧旋时要**保住上旋**，不要为了拐而把球擦"平"。
- **侧旋多少**：Hodges 转述美国男队教练 Seemiller 的说法，普通正手弧圈大约带 15% 侧旋（教练估计，不是测量值）。有意加侧旋时也不要追求约尼尔式的纯侧旋，那需要特殊的直臂打法（Hodges）。

## 6. 面对不同来球的调整

**相持中（来球是上旋）**
- 对方挡/拉到你**正手大角**：最适合左拐。拍放到球外侧，拉回对方正手大角，让球继续往边线外拐，逼他回到你的正手（Hodges）。
- 对方站在中间：用侧旋把他拉出台角（PingSkills）。
- 对拉/反拉：稍微触球外侧，带点侧旋，避免与来球上旋正面相撞（Hodges《Counterlooping》）。想反拉直线时，晚一点击球或翘腕打 inside-out（Hodges 2020-11-23）。
- **侧身位**：右拐弧圈打对方反手大角，球继续往台外拐（PingSkills 问答，见第 2 节的可靠度说明）。
- 极宽的正手球：PingSkills：选够宽的球并加侧旋，可以从网柱外绕过去。为什么合法（ITTF Handbook 2022）：网柱外缘在边线外 15.25 cm（2.2.2）；2.7.1 只要求回球直接或触及球网装置后落到对方台区；2.10.1.5 只把"从网中穿过、从球网与网柱之间或球网与台面之间穿过"判为失分。所以从网柱外侧绕过、落到对方台区就是合法还击。（Handbook 2022 的 2.5 定义里没有"从球网装置上方或旁边绕过"这一条，本卡核对过原文。）

**拉下旋（对方搓长、劈长、长下旋发球）**
- 先保证"向上摩擦够、能过网"，侧旋只是附加。动作基础见 `../techniques/forehand-loop-vs-backspin.md`。
- 人民网另说，触球中下部、以向内向前发力为主时，往往拉出侧下旋弧圈（与百度百科同源，单一来源，本卡不展开）。
- 专门讲"拉下旋时加侧旋"的可靠来源很少。本卡建议（无出处）：先在正手大角的下旋球上练左拐（拍头本来就下垂，最顺手）；右拐拉下旋要同时抬拍头、包球的左下侧往上带，难度最高，等左拐稳定后再练。

**接侧旋长发球**（Hodges《Looping Spin Serves》）
- 先预判拐向并提前站到位，不要等球拐了才反应。右手对手的反手发球往你的右边拐；正手发球（拍头朝下）往你的左边拐。
- 球往你右边拐：碰拍后会往左跳，触球要偏**内侧（球的左侧）**，甚至可以 inside-out 拉成右拐。球往你左边拐：触球偏**外侧（球的右侧）**，弧圈可能往左拐。
- 拉侧上旋长发球时，右肩不要沉得太多，否则容易出界长；对上旋、侧旋发球，主要向前发力，对下旋才多向上（Hodges《How To Return Different Serves》）。

**如何应对对方的侧旋弧圈**
- **认清三件事**：侧旋球在空中横着拐，落台后只有轻微侧拐，碰到球拍后向侧面弹（Hodges《Everything You Ever Wanted to Know About Spin》）。看对方拍头：拍头下垂、拍面在球外侧是左拐；拍头上翘、手腕后翘是右拐。再盯住飞行中的拐向（PingSkills《How to Handle Sidespin During a Rally》）。
- **对方左拐弧圈**（从你这边看，球往右拐，也就是往你的正手边线外拐）：碰你的拍后往你的左边弹（日文维基：弹向击球者的右侧，也就是你的左侧）。挡或反拉时，拍面瞄准目标偏右一点，或者触球偏内侧（球的左侧）（Hodges 对"往你右边拐"的球的调整原则）。球往边线外跑时，**上步去追，不要伸手够**，拍保持相对高；够球时拍会自然往下掉，容易把球托出端线（Hodges《Strengths and Weaknesses of the Four Major Serves》，原文讲的是同旋向的发球）。
- **对方右拐弧圈**（球往你的反手方向拐）：碰拍后往你的右边弹。瞄准偏左，或触球偏外侧（球的右侧）。
- **线路选择**：对方左拐弧圈打到你正手、继续往边线外拐时，回直线（对方反手）是横着穿过旋转，比较好控制；回斜线要多用力压住旋转，类似拉下旋（Hodges，同上，原文讲的是同旋向的发球）。
- **两种应对思路**：只调拍面角度、把球控回去；或者主动摩擦，用自己的旋转盖过对方的侧旋（PingSkills）。侧旋弧圈同时带强上旋，挡球的基础仍是拍面前倾、往下压（PingSkills 问答：重上旋要压着挡），见 `../techniques/forehand-counter-block.md`、`../techniques/backhand-block.md`。
- **心理**：对方有一板"看着往一边、实际去另一边"的怪球时，先让自己多见几次，适应后才能在比赛里"自动"反应（Hodges 每周技巧 2016-11-21《Getting "In the Zone" by Adapting to Your Opponent》）。

## 8. 常见错误：表现 → 原因 → 纠正

1. **球软、偏出侧边，身体被带着转过头** → 用肩膀带整条手臂横扫，以为这样才能拉出侧旋 → 手臂按普通弧圈挥向前上方，只改手腕和拍面（PingSkills）；用"收拍位置与直线弧圈相同"来检查。
2. **球从侧边出界**（左拐从你看的左边出，右拐从右边出） → 瞄准时没算上拐弯 → 左拐瞄得偏右、右拐瞄得偏左；先打大目标（半张台），确认每次拐多少再收小。
3. **打在拍边、声音发闷** → 手腕下垂太多、拍头太低（PingSkills 问答：提问者的教练认为手腕下垂会带侧旋、容易打到拍边；PingSkills 回答确认下垂的手腕会带来多余侧旋） → 拍头下垂用手腕"放"，不要整个手腕塌下去；先在多球中找到稳定的触球位置。
4. **球出界长、不往下扎** → 只擦侧面不包上部，上旋不够；或者拉侧上旋来球时右肩沉得太多（Hodges） → 触球点保持在右中上部（人民网），右肩不要过分下沉，对上旋来球向前多于向上。
5. **线路被对方提前看穿** → 准备或引拍初段就把手腕压下/翘起、身体提前侧过去，或左臂的位置、动作和平时不同 → 前段动作（包括左臂）和普通弧圈保持一致，最后一刻再变（Hodges 2020-10-12）。
6. **被调到正手大角时一拉就下网或出界** → 不移步，靠伸手够，拍子越够越低 → 先跨步，跨不到再把拍放到球外侧勾回（Hodges）。
7. **右拐弧圈拉不出、反而变左拐** → 拍头没抬起来，手臂自然下斜带出了左拐（原理见 Hodges node/36，右拐的结论是本卡推断） → 引拍末段翘腕、抬拍头，触球左侧；先在高一点的来球上练。
8. **拉侧旋来球方向乱跑** → 没根据来球侧旋调整触球位置 → 往你右边拐的球打内侧，往你左边拐的球打外侧（Hodges）。
9. **一练侧旋，直线弧圈也变差** → 太早练侧旋，基本动作还没定型 → 先保证直线上旋稳定（PingSkills），侧旋只占练习的一小部分。
10. **接对方侧旋弧圈总往一边出界** → 没预判碰拍后的侧弹；伸手够往边线外拐的球 → 按第 6 节调整瞄准，上步追，拍保持高（Hodges）。
11. **一拉侧旋左臂就垂下，拉完站不稳** → 注意力全在手腕上，只用右半边身体 → 左臂按直线弧圈做：准备时弯曲在腹前左侧，迎球时向左后"拉"，和右侧一起转（Hodges node/3223）；先徒手挥拍找感觉（本卡建议）。

## 9. 练习方法（入门 → 进阶）

下面每步的"过关"是本卡建议的定性标准（无出处），达到了再进下一步；某一步明显变差就退回上一步。

1. **前提检查**：拉上旋、拉下旋的直线弧圈都已稳定（PingSkills：先把直线上旋练可靠）。过关：多球和相持里直线弧圈能连续多板上台，落点基本可控。
2. **徒手模仿**：对镜子或对着手机，同一个挥拍只改手腕：直线、左拐（拍头下垂）、右拐（翘腕抬拍头）交替做，确认三种的收拍位置一样（练"不横扫"）。过关：从正面或斜前 45° 回看录像，三种挥拍的收拍位置分不出差别。
3. **多球·左拐**：陪练喂正手大角的上旋球，你把拍放到球外侧，拉回对方正手大角，看球是否继续往边线外拐（Hodges 的用法）。过关：连续多板上台，且拐向一致。
4. **多球·右拐**：喂反手位的球，侧身用正手翘腕打球内侧，拉向对方反手大角（PingSkills 问答的练法：先慢速，重点感觉擦球侧面，再追求拐弯，最后瞄大角）。左拐过关后再开始；可以先在高一点的来球上练。过关：高球上稳定上台、拐向一致后，再降到正常高度，同样稳定。
5. **多球·拉下旋加侧旋**：喂正手位长下旋，先练左拐，要求先过网上台，再要求拐向。过关：不再因加侧旋而明显多下网，拐向清楚。
6. **固定线路相持**：对方挡你的正手，你按"两板直线弧圈、一板侧旋"的节奏练，对比两种球的手感和对方的回球。侧旋板只占一小部分，直线弧圈仍是主体（呼应第 8 节第 9 条）。过关：加入侧旋板后，直线弧圈的质量不下降，侧旋板也能稳定上台。
7. **接发球**：请陪练发长的正手、反手侧旋发球，按第 6 节调整内外侧触球（Hodges《Looping Spin Serves》）；先反复接同一种难接的发球，再加入变化（PingSkills《How to Practice Receiving》）。过关：同一种发球能稳定拉上台后，再加入变化。
8. **对拉中带侧旋**：中台对拉时稍微触球外侧，体会"不和来球硬碰"（Hodges）。过关：带侧旋后对拉回合不比直线对拉短。
9. **对抗侧旋弧圈**：让陪练拉左拐、右拐弧圈到你的正反手，你练挡和反拉，按第 6 节瞄准和上步。过关：先固定一种拐向挡稳，再让陪练左右拐混合。
10. **实战**：用在 Hodges 说的场景（被调到正手大角、需要铺垫）和 PingSkills 说的场景（对手站在中间）。从极宽的正手位绕网也是一种选择（PingSkills：选够宽的球并加侧旋）。过关：比赛中用侧旋得分或逼出机会球，而不是主要靠它失误送分。

更多通用练法见 `../training/drills.md`。

## 10. 视频检查要点

**机位**（总体要求见 `../analysis/recording-guide.md`）：
- **机位 A（主机位）**：正手一侧的正侧面，拍全身，120/240 帧慢动作；导出后帧率变了要用 `--capture-fps` 校正。用来看发力链和下表的骨架指标。
- **机位 B**：站在击球者身后偏高处，看向对方台面。用来目测挥拍是向前上方还是横扫、球往哪边拐、落在哪里。脚本不追踪球和球拍，**拐向只能靠这个机位目测**。
- **手部放大图**：拍面和拍头角度骨架测不出来，必须看 `stroke_NN_zoom.jpg` / `measured_NN_zoom.jpg`（击球前后各 2 帧）及对应的 `_contact_raw.jpg`，以确认后的 `measured_` 为准：拍头下垂还是上翘，拍子在球的外侧还是内侧，是否擦到拍边。

**逐阶段看什么**（指标名见 `../analysis/metrics-reference.md`；最可靠的用法是和**你自己拉直线弧圈的同机位视频**比，因为侧旋弧圈的身体动作应该和直线弧圈基本一样）：

| 阶段 | 关键帧里看什么 | 对应指标 |
|---|---|---|
| 准备 | 站位宽度和屈膝与平时一样；手腕没有提前定型（看放大图）；左臂弯曲在腹前左侧，位置与直线弧圈相同（目测，脚本没有准备帧的左臂指标） | `stance_width_ratio`、`knee_angle_deg.{playing,other}.ready` |
| 引拍末 | 转体幅度与直线弧圈接近，没有"掷铁饼"；重心在右脚；右肩没有过度下沉 | `shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`（侧面单机位下属"低可信"，转体幅度以机位 B 或正面补拍目测为主）、`weight_shift.backswing_end`、`trunk_lean_deg.backswing_end`、`knee_angle_deg.{playing,other}.backswing_end`、`elbow_angle_deg.backswing_end` |
| 迎球挥拍 | 髋→肩→肘依次启动；是否横扫主要靠机位 B，或按 recording-guide 补拍正面/斜前 45°，目测挥拍是否横过胸前。`swing_path` 只作参考：看 `swing_path.angle_deg` 是否比直线弧圈明显变小（向上的成分少了）；`horiz` 是向前和左右合在一起的水平位移，分不出向前送还是横向扫，不能拿它判断横扫。左臂是否随转体向左后拉、幅度是否和直线弧圈一样，用机位 B 或正面目测 | `sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`、`swing_path.{up,horiz,angle_deg}`、`forward_ms`、`peak_hand_speed` |
| 击球瞬间 | 击球点在身体右侧前方；左拐时击球点稍偏外，右拐稍靠近身体；肘没有夹死；头稳；放大图里拍头方向和触球侧对不对；左手没有掉到髋以下，高度与直线弧圈相近 | `contact_height_level`、`contact_forward_m`、`contact_lateral_m`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`head_motion`、`trunk_lean_deg.contact`、`knee_angle_deg.{playing,other}.contact`、`free_arm_height_level` |
| 随挥 | 收拍高度与直线弧圈相近；收拍位置是否横过胸前、低低地扫到左腰，要用机位 B 或正面/斜前 45° 判断（侧面看不清左右）；重心移到左脚；左臂收在身体左侧，没有甩到身后 | `finish_height_level`、`elbow_angle_deg.finish`、`weight_shift.{finish,delta}`、`follow_ms` |
| 还原 | 从大角拉完后有没有回位 | `recovery_dist` |
| 全程 | 脚本判断为正手；画面质量是否可信 | `side_guess`、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

注意：本卡建议，若 `peak_hand_speed` 比同机位直线弧圈明显下降，可能是在"控"侧旋，回看 zoom 图和挥拍路线确认；`quality.reliable` 为假时，只报告能看清的部分，并说明怎么重拍。

## 11. 自查清单

- [ ] 我的直线正手弧圈（拉上旋、拉下旋）已经稳定，才开始练侧旋。
- [ ] 我能说清这一板是左拐还是右拐：拍头下垂/上翘、摩擦球的右侧/左侧、从我这边看往左/往右拐。
- [ ] 侧旋弧圈和直线弧圈的身体动作、收拍位置基本一样，没有横扫。
- [ ] 手腕和拍面的变化在引拍末段到前挥中完成，准备阶段看不出来。
- [ ] 拉侧旋时左臂和拉直线弧圈一样：准备时弯曲在腹前左侧，迎球时向左后拉，击球时没有掉到髋以下。
- [ ] 触球时仍包住球的上部，球有明显的下扎，不是又平又飘。
- [ ] 瞄准时算上了拐弯，没有频繁从侧边出界。
- [ ] 被调到正手大角时先跨步，再把拍放到球外侧勾回。
- [ ] 拉侧旋长发球时，按拐向调整内外侧触球，右肩不过分下沉。
- [ ] 拉完侧旋后，我会预判回球往哪边弹（左拐→多回到我的正手）。
- [ ] 接对方侧旋弧圈：先认拍头和拐向，瞄准时抵消侧弹，上步不够球。
- [ ] 听到"外拐、内勾"这类叫法时，我会先确认对方指的是哪种拐向。
