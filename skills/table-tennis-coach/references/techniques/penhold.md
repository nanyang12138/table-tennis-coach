## 1. 直拍是什么，和横拍差在哪

- **定义**：拇指和食指在拍前侧握住拍柄，其余三指在拍背；名字来自握笔（[英文维基 握法与打法](https://en.wikipedia.org/wiki/Table_tennis_grips_and_playing_styles)）。规则不规定握法（[英文维基 Table tennis](https://en.wikipedia.org/wiki/Table_tennis)）。
- **优点**：正手、传统反手都用同一面，出手快；正手攻斜线、直线时拍面变化小，对手不易判断（[扬州职大《乒乓球运动》](https://tyxy.yzpc.edu.cn/2022/1114/c937a50138/page.htm)）。没有横拍那种身体中路的正反手"交界点"，中路球可以把正手像钟摆一样向下摆过去处理（英文维基）。
- **缺点**：反手攻球受身体阻碍，较难掌握；防守照顾面积小（扬州职大）。
- **研究对照**：上海体育学院中国乒乓球学院 27 名国家一、二级男运动员（9 名直拍）的测试：正手回击上旋和下旋，两种握法的球速、拍速**没有显著差别**；反手则横拍更快，作者认为原因是直拍反手的肩、肘、前臂动作幅度更小，球拍纵轴与前臂纵轴不够在一条线上（[Xia 等 2020，J Sports Sci Med](https://pmc.ncbi.nlm.nih.gov/articles/PMC7675628/)）。摘要没有说明直拍组反手是用正面还是反面打。
- **对你的意义**：直拍正手的身体发力可以照横拍高手学；反手要么靠推挡把速度、落点做出来，要么学横打把肩肘前臂的动作打开（第 4–6 节）。
- 已经用顺手的握法一般不要改（[PingSkills](https://www.pingskills.com/tutorials/table-tennis-strokes-further-learning/switch-from-penhold-to-shakehand)）。

## 2. 直拍握法（中式、日式、横打调整）

### 2.1 中式直拍（Chinese penhold）
- **手指**：拇指第一指节压拍左肩，食指第二指节压拍右肩，两指在拍前呈钳形，拍柄贴住虎口；中指、无名指、小指在拍背自然弯曲、叠在一起，用中指第一指节托住拍背（[CETV 握拍](http://www.centv.cn/p/480438.html)；[CETV 进攻方法](http://www.centv.cn/p/480439.html)；英文维基）。
- **钳形大小**：两指间距各资料给的数字不一致，只记住**"钳形适中"**。
  - 大钳：食指压得更外，背后三指伸开托拍；中远台正手攻、扣杀有力，但手腕不灵，台内球、推挡、追身球差（CETV 进攻方法；[百科·直板握法](https://baike.baidu.com/item/直板握法/2094427)）。
  - 中钳：钳形适中，背后三指半伸半曲；百科认为最适合横打，因为既能控制拍形，背面又留出足够击球面积。
  - 小钳：两指几乎贴近（俗称"吊拍"），背后三指弯曲叠托；手腕最灵活，但拍形不易固定（百科·直板握法；CETV 进攻方法第三种握法同理）。
- **快攻型与弧圈型**：快攻型拇指、食指呈钳形，另外三指弯曲贴在拍背上端；弧圈型基本相同，但拇指和食指形成一个小环，背后三指自然重叠，中指第一指关节顶在拍柄延长线上（CETV 握拍）。
- **支点**：拍柄背面贴虎口的食指根部是手指用力的"支点"（[百科·乒乓球支点](https://baike.baidu.com/item/乒乓球支点/68123970)）。握得松紧合适、支点稳定，拍形才稳。

### 2.2 日式（日韩式）直拍（Japanese/Korean penhold）
- 背后三指在拍背**伸开**；常用方头拍，拍柄上有一块突出的软木，食指勾住软木控制方向（[英文维基 Table tennis](https://en.wikipedia.org/wiki/Table_tennis)；英文维基 握法与打法）。
- 通常只用一面击球，很多人背面不贴胶皮；英文维基说这种握法让球拍与手、前臂对齐，正手特别快，但反手只适合挡和回球（百科性质，原文无引用）。

### 2.3 每类击球的手指用力（中式）
- **正手攻**：拇指与中指协调用力，食指相对放松，无名指微离中指、指尖轻托拍背，保持发力时拍稳（CETV 进攻方法）。
- **反手攻、推挡**：食指和中指协调用力，拇指相对放松（CETV 进攻方法）；百科·推挡球同样写"主要依靠食指用力，拇指相对放松，中指、无名指和小指在拍后顶住"。
- **用手腕发力时**（正反手）：以中指发力为主，拇指、食指稳定拍形并辅助（CETV 进攻方法）。
- **横打**：见 5.1。**发下蹲球**：食指移到拍背（第 8 节）。

## 3. 直拍正手：与横拍的差别

身体部分（脚、膝、髋、腰、重心交换）和横拍相同，照 `../techniques/forehand-drive.md`、`../techniques/forehand-loop-vs-backspin.md`、`../techniques/forehand-loop-vs-topspin.md`、`../techniques/forehand-smash.md` 做。下面只写不同处。

- **准备姿势（肘、拍头）**：直握拍的肘略向外张，球拍放在腹部右前方，手腕放松，**拍头指向右斜前方**；横拍则肘向下、拍头向上（[CETV 攻球技巧](http://www.centv.cn/p/480440.html)）。
- **站位（脚）**：直拍左推右攻一般左脚稍前，左脚大致在球台左边线的延长线上，离端线约 40 厘米（CETV 攻球技巧）；扬州职大给的范围是近台 30–40 厘米、偏左。
- **手指**：拇指与中指用力、食指放松（2.3）。
- **手腕与拍面**：
  - 不要"吊腕"——手腕下垂、拍头朝下（[百科·弧圈球](https://baike.baidu.com/item/弧圈球/221749) 练习提示："直握球拍者还应注意避免吊腕"）。
  - 手腕内收过多，直拍容易拍面斜向右侧、朝外或吊板，造成漏球、滑板和腕部损伤（[百科·正手攻球](https://baike.baidu.com/item/正手攻球/3579498)，出处《乒乓世界》等）。
  - 正手近台攻：拍面与台面约 80°，前臂与台面基本平行，上升期击中上部，击球点在身体右前方约一前臂距离（[CETV 正手攻球](http://www.centv.cn/p/480450.html)；这是通用要领，不分握法）。
- **直板正手拉弧圈的分解**（百科·弧圈球 技术图解）：
  1. 准备：左脚在前，收腹、含胸、屈膝，身体稍前倾，重心在两脚之间，右肩略沉。
  2. 引拍：腰髋右转，重心到右脚前脚掌，右膝屈得更深，前臂自然下垂，转腰带大臂、前臂向侧后引拍。
  3. 击球：以右脚为轴，腰带大臂左转；上身接近正对球台时迅速收前臂，向前上方挥，压住拍形，摩擦中上部。
  4. 随挥、还原：手臂顺势挥完，重心移到左脚，迅速还原。
- **研究里的差别**：正手时直拍组的球拍相对前臂处在内收、屈、更外旋的位置，挥拍时出现"球拍伸"方向的角速度（横拍组是"球拍屈"）；横拍组的肩外旋角度有更大的**趋势**（原文"tended to"，未达显著）。拍速、球速两组相同（Xia 等 2020）。论文的"球拍角"包含手腕和手与拍之间的动作，不等于单纯的腕关节角。**论文讨论部分的说法**：正手拍速主要来自肩（肩内旋、肩屈角速度最大）；前臂和手腕贡献较小（该文引 Iino & Kojima 2009）；直拍正手的球拍处在更外旋、更屈的位置，因而还更多利用球拍相对前臂的伸和内旋动作。**本卡推论（论文没有这么写）**：手腕在直拍正手里有作用，但不能代替肩和身体的发力。
- **直板正胶正手（"小上旋"）**：动作要领与反胶弧圈基本相同，但正胶摩擦系数小、触球面积小，摩擦太薄容易"打滑"，所以击球时要加强手腕转动、扩大接触面；动作更小，以前臂发力为主，弧线更低（[人民网 弧圈球技术动作](http://sports.people.com.cn/n/2015/0422/c395343-26887019.html)）。
- **横打握法对正手的影响**：英文维基认为，为横打调整的握法让手腕与手臂不在一线，正手比传统握法弱（无引用，只作提醒）。正反手之间如何换握，暂无可靠出处。

## 4. 直拍推挡（Push-block）

推挡是我国直拍快攻打法的基本技术，站位近、动作小、速度快、变化多，用来控制、调动对方，为正手攻和侧身抢攻创造机会；分为挡球、减力挡、快推、加力推、推挤和推下旋等（扬州职大）。横拍一般不大用推挡（[百科·推挡球](https://baike.baidu.com/item/推挡球/3579872)）。横拍的反手挡见 `../techniques/backhand-block.md`。

### 4.0 共同要领（各子技术都按这个底子做）
- **脚、膝**：两脚平行或右脚稍后，两膝微屈，离台约 40 厘米（百科·推挡球）。
- **腰/躯干**：收腹含胸（百科·推挡球）；挡球时保持躯干轴线稳定（百科·挡球）。加力推借右脚蹬地和转腰的力量；击球后用重心移动和腰的转动还原（百科·推挡球）。
- **髋、肩**：暂无专门出处；保持放松、不耸肩即可。
- **大臂、肘**：上臂和肘靠近身体右侧；肘离身体太远是典型错误（百科·推挡球）。
- **前臂**：与台面大致平行，向前伸向来球。
- **手腕**：外展，让拍柄靠近虎口，**不要吊板**（手腕下垂）（百科·推挡球）。
- **手指**：食指压拍、拇指放松，中指等三指在拍背顶住（2.3）。
- **拍、击球点**：球拍引到腹前；最佳击球点在腹前约一臂距离，高度与网相近（百科·推挡球，出处西北大学现代学院）。
- **视线**：盯来球落点，判断长短、旋转后再决定用哪种推。

### 4.1 挡球（Block，入门）
- 前臂与台面平行伸向来球；触球时前臂和手腕稍向前移动，借来球反弹力挡回；**拍面接近垂直**；**上升期击中部**；离台 40–50 厘米（[百科·挡球](https://baike.baidu.com/item/挡球/3579888)）。
- 为什么先学：动作框架最简单，打好了才能学快推、加力推。
- 做错会怎样（百科·挡球列的典型错误）：拍面过度前倾→下网（多球练手腕角度控制）；击球时机滞后（用节奏口令强化上升期击球）；重心后坐（徒手挥拍配合步法练）；吊腕→手腕外展、拍柄靠近虎口。

### 4.2 快推（Fast push）
- 最常用的推挡（百科·推挡球）。用于回击一般拉球、推挡和中等力量的攻球，推压两大角或打空档。
- **引拍**：肘靠近身体右侧，前臂与台面平行，拍后引到左腹前，拍面垂直（[百科·快推](https://baike.baidu.com/item/快推/3579945)）。
- **击球**：上升期；前臂和手腕迅速前伸，**食指用力、拇指放松使拍面稍前倾**，击中上部（百科·快推）。
- **前臂**：前推过程中完成外旋；转腕不要太大，关键在时机（百科·推挡球）。
- **随挥、还原**：手臂随势前送，迅速还原（百科·推挡球）。

### 4.3 加力推（Power push）
- 用于速度较慢、旋转较弱的上旋球，或力量较轻、弹起稍高于网的球；可迫使对方离台，与减力挡搭配前后调动（百科·推挡球）。
- **引拍（前臂、拍）**：前臂向后上方屈收幅度更大，拍位置稍高，加长用力距离（百科·推挡球）。
- **击球点、时间**：离身体稍远；上升后期或高点期，击中上部（[百科·加力推](https://baike.baidu.com/item/加力推/3579927)）。
- **发力顺序**：以手臂发力为主，借右脚蹬地和转腰，力量集中在击球一瞬（百科·推挡球）。
- **做错会怎样**：手臂前伸不够→用不上力。纠正：强调大臂和肘前送，小臂和手腕协调用力（百科·推挡球）。避免手腕过度翻转，保持以撞击为主（百科·加力推）。

### 4.4 减力挡（Soft block）
- 用于对方扣杀、前冲弧圈等速度快、冲力大的球，也常用来接加转弧圈；回球弧线低、落点短、力量轻；与加力推结合可前后调动（[百科·减力挡](https://baike.baidu.com/item/减力挡/3579909)）。
- **重心、前臂、拍面**：击球前重心略升高，前臂稍屈，拍保持合适的前倾（百科·减力挡；百科·推挡球）。
- **触球瞬间**：有意识地做手臂和手腕**后收**（或让球拍前移骤然停住）；按来球力量和上旋强度调节拍面角度和后移幅度（百科·减力挡；百科·推挡球）。
- **注意**：百科·减力挡里"球拍一般与地面垂直、力量大时稍后倾"和"反手挡拍在胸部高度"等说法，引自邓亚萍**长胶打法**的经验（该段原文开头就是"在长胶打法中"），反胶、正胶选手不适用，不要照搬。
- **做错会怎样**：后收不够、没有卸力→回球长、力量大，起不到减力挡的作用（百科·推挡球说减力挡要"削弱来球反弹力"）。

### 4.5 推下旋（Push with backspin）
- 用于上旋不强、力量不大的来球；回球较快、略带下旋、落点长、着台后下沉，易使对方推挡下网（[百科·推下旋](https://baike.baidu.com/item/推下旋/3579999)）。
- **动作**：要点同快推，区别是击球时前臂向前下方推出，同时**手腕用力向下做推切**（百科·推挡球）。
- **时间、部位、拍面**：**高点期或下降前期**，击**中部偏下**，拍面稍后仰（百科·推挡球；百科·推下旋另一处把时间写成"上升后期、高点期或下降前期"）。

### 4.6 挤推（Squeeze push）
- 也叫推挤、推拱下旋；是对付弧圈球的方法之一；弧线低、角度大、带侧下旋（[百科·挤推](https://baike.baidu.com/item/挤推/3580018)）。
- **引拍**：前臂上提，把拍引到身体前上方（百科·挤推）。
- **击球**：伸腕幅度较大；**上升期**击球的**左侧中上部**；手臂向**左前下方**挥（百科·挤推）。
- 历史：1970 年代以来我国近台快攻发展了加力推、减力挡和推挤弧圈球（扬州职大）。

### 4.7 侧推（只作术语）
- 常见中文术语，本次没有找到可打开的权威定义，不给动作要领；百科·推挡球的子类里另列了"拱推""快拨"。别把它和马琳的"侧切"混为一谈（侧切见百科·直板反手，只作术语）。

### 4.8 推挡对付弧圈：拍面
- **加转弧圈**：食指压拍，拍面前倾，与台面**约 50°**，在来球上升前期推压中上部。
- **前冲弧圈**：拍面前倾小一些，与台面**约 70°**。
- 以上两个数字**只有单一来源**（百科·推挡球，原出处荔枝网 2017，原页打不开），只当起点，按回球高低自己调：出界就再压，下网就立起来。
- 通用道理：加转弧圈向上的反弹更强，所以拍面要更前倾；前冲弧圈速度大、向前冲，拍面相对立起、借力挡。推攻战术对付弧圈类打法以近台为主，用快推和加、减力推挡控制落点（[CETV 推攻](http://www.centv.cn/p/480442.html)）。

## 5. 直拍横打（Reverse Penhold Backhand, RPB）

用拍子**反面**的胶皮打反手。反手技术（拉、抽、弹、拨、挑等）更丰富，反手位攻击力更强，能充分发挥前臂力量（[百科·直拍横打](https://baike.baidu.com/item/直拍横打/3579050)）。英文维基认为它解决了传统直拍反手的肩部力学问题，让反手可以拉、可以攻。

### 5.1 握法调整
- **拇指**：往里握深一点，适度用力压拍——拇指一压，正面向内转，反面才对准来球（百科·直拍横打；英文维基）。
- **食指**：略上移到拍边缘，稍放松（百科·直拍横打；英文维基"relax the index finger and bring it higher up"）。
- **背后三指**：中指、无名指、小指略微伸开，便于发力、稳定拍形；反面拉时三指上移靠近拍柄，腾出更多拍面（百科·直拍横打；百科·弧圈球）。
- **松紧**：不能太紧，否则影响拍形调节（百科·直拍横打）。
- **握法选择**：中钳最适合横打（2.1）。

### 5.2 发力方向（共同）
- 右手为例，身体从左向右发力；转腰辅助，伸展前臂和手腕，力量由下往上传，拍朝身体**右前上方**用力（百科·直拍横打）。
- 业余常见毛病是随意发力、不用腰控制手臂，手臂一晃就失去方向（百科·直拍横打）。

### 5.3 反面平挡、反面快拨（借力类，横打的入门）
- **反面平挡**：准备同快推；引拍时前臂稍内旋，手腕略屈，重心多放右脚；**拍头不要刻意下垂**；转腰带手臂自然前迎，上升期向前略向上击中上部；以前臂为主，**手腕相对固定**，借力（百科·直拍横打）。
- **反面快拨（拨）**：拍面稍前倾，引拍略低；上升期击中上部；以腰带前臂和手腕，向前略向上，稍带摩擦（百科·直拍横打）。
- **分解（百科·直拍横打 技术图解）**：左脚前、右脚稍后，重心中间偏左，前臂端起放松→腰左转带手臂引拍，前臂和手腕内收→向右转腰，手臂迎前，上升期向前上击球→击球瞬间前臂和手腕**外展**，触中上部。
- 横拍的拨、快带可参考 `../techniques/backhand-drive-punch.md`、`../techniques/backhand-block.md`。

### 5.4 反面拉（RPB loop）
- 用途：加转和前冲用于抢拉左大角的下旋长球，快撕用于相持对攻；动作要点与横拍反手拉相似、幅度较小（[百科·直拍反面拉球](https://baike.baidu.com/item/直拍反面拉球/3580144)，出处北大主页 2003）。所以动作框架可照 `../techniques/backhand-loop-vs-backspin.md`、`../techniques/backhand-loop-vs-topspin.md` 学，握法按 5.1。
- **脚**：两脚平行或左脚稍后；基本站位左脚在前时，决定反面拉长球要把左脚后撤半步。
- **膝、重心**：两膝微屈，重心较低；准备时重心在左脚，拉完移到右脚，再回到两脚之间。
- **肘、前臂、手腕**：拍引到腹部下方，肘略向前凸，手腕下垂内收，拍形前倾；球弹起后以肘为轴，前臂迅速向前上挥；击球瞬间手腕向右前上方转动。
- **时间、部位**：下降期（词条写"下降初期或下降后期"），摩擦中部或中上部。
- **下旋与不转**：拉下旋适当向上提拉；拉不转以向前为主。
- **腰**：腰部要有由下向上的弹性动作，只用手拉不稳（以上均出自百科·直拍反面拉球）。

### 5.5 拧（RPB flick/twist）、撕、弹
- **拧**：直拍横打的台内进攻分支（[百科·台内球](https://baike.baidu.com/item/台内球/68896300)）。中文维基写王皓"拧拉技术也相当娴熟"（[中文维基·王皓](https://zh.wikipedia.org/wiki/王皓_(乒乓球运动员))）。直拍拧的专门动作要领本次没找到可靠出处：手臂、腰、步法照横拍 `../techniques/backhand-banana-flick.md` 做，握法按 5.1。百科·侧拧给的分阶段练法（单一来源）是：原地体会手腕摩擦→加前臂→加腰部协调→结合步法移动中拧（[百科·侧拧弧圈技术](https://baike.baidu.com/item/侧拧弧圈技术/16716062)）。
- **快撕**：快撕是横打体系的组成部分（[百科·快撕](https://baike.baidu.com/item/快撕/7479847)）。王皓拧拉之后接哪一板，两处说法不一致：百科·快撕说拧拉起手、快撕衔接；百科·台内球说吴敬平让他把台内拧拉和下一板作为整体训练，用"快抽"取代了之前的"快撕"。动作见 `../techniques/backhand-tear.md`。
- **弹打**：王皓"能反面弹打、快拉，甚至远台反拉"（中文维基·王皓）；百科·反手弹打把刘国梁列为反手弹击的早期直拍代表人物（[百科·反手弹打](https://baike.baidu.com/item/反手弹打/6300134)；同词条也提到更早的郗恩庭用过大力推挡加反手弹击）。
- **伤病**：横打用腕较多，练习时间不宜过长，关节酸痛就休息，可戴护腕（百科·直拍横打）。

### 5.6 历史
- 英文维基：中国在 1990 年代发展出直拍用两面击球的技术，即 RPB（[英文维基 Table tennis](https://en.wikipedia.org/wiki/Table_tennis)）；通常认为刘国梁发明并推广，王皓是第一位真正掌握并普及它的高水平球员（英文维基 握法与打法）。
- 中文维基：刘国梁是"第一位在正式比赛中采取直拍横打技术并取得成功的乒乓球手"（[中文维基·刘国梁](https://zh.wikipedia.org/wiki/刘国梁)）。
- CETV：1992 年成都中国乒乓球大奖赛上，16 岁的刘国梁以"直拍横打"战胜瓦尔德内尔、金泽洙等（[CETV 中国乒乓球队发展史](http://www.centv.cn/p/480427.html)）。百科·直拍横打写的是"1990 年四川成都比赛"，年份不一致，以 CETV 为准但存疑。
- 百科·直拍横打：2000 年悉尼奥运会铜牌战，刘国梁一改推挡变线，大量使用横打击败佩尔森（单一来源）。

## 6. 直拍反手的三种做法

| 做法 | 是什么 | 代表人物（出处） | 适合谁 |
|---|---|---|---|
| 全推挡 | 正反手都用正面；反手靠挡、快推、加力推、减力挡等 | 蒋澎龙"推挡相持为主的快攻打法"（[中文维基·蔣澎龍](https://zh.wikipedia.org/wiki/蔣澎龍)） | 近台、反应快、正手跑动好；手腕不适合大量横打的人 |
| 推挡加横打 | 推挡为主，有机会或推不了的球用反面 | 刘国梁、马琳（[中文维基·乒乓球](https://zh.wikipedia.org/wiki/乒乓球)） | 已有推挡底子、想补反手进攻的人 |
| 全横打 | 反手几乎都用反面 | 王皓（中文维基·乒乓球）；英文维基说他除接短发球的反手搓外几乎都用反面 | 从头学、愿意花时间练反手的人 |

- **英文维基的三类**（握法与打法条目）：
  - **One-Sided（单面，传统直拍）**：中式、日式、韩式传统握法，正反手都用正面，反手像"倒过来的雨刷"在身前划过，适合挡和回球，但不利于快攻和拉上旋；靠强正手和大量步法弥补。列举柳承敏、金泽洙、吉田海伟。
  - **Two-Sided（两面，现代中式直拍）**：用 RPB 打反手，需调整握法（5.1）。英文维基还写马琳、许昕回球主要用传统反手，背面贴胶皮以便有机会时横打。
  - **Hybrid（混合）**：把挡（传统）与拉（横打）合在一起，列举马琳。
- 推挡加横打的结合在新规则下回合增多、相持变长时提高了相持能力和变化（百科·推挡球，出处知网论文《马琳、王皓的直拍横打与直拍推挡技术应用对比分析》）。
- 接长下旋：不会横打的可积极侧身用正手抢攻；会横打的可直接用反面拉（[百科·下旋球](https://baike.baidu.com/item/下旋球/4119725)）。

## 7. 直拍台内技术（搓、摆、劈、挑、快点）

身体部分（上步、重心跟上、还原）照 `../techniques/push.md`、`../techniques/short-touch.md`、`../techniques/long-push.md`、`../techniques/forehand-flick.md` 做；上台内球时重心要完全跟上，避免臀部留在后面、手臂伸得过直（百科·台内球）。

- **搓（Push）**：直板控拍以拇、食、中指为主。**拍面后仰和前倾要靠前臂内旋（后仰）、外旋（前倾）配合放松的手腕来调**，不要靠拇指、食指死压拍肩——那样手腕和前臂会紧张、发力不对、手臂负担大（[百科·搓球](https://baike.baidu.com/item/搓球/3579742)）。不少老球友习惯"抖腕"搓，是正胶留下的习惯，用反胶不必模仿（同词条）。英文维基说连全横打的王皓接短发球时的反手搓也用正面。
- **摆短（Short touch）**：上升初期触球，借来球的力量和旋转控制，而不是主动加力摩擦；前臂带手腕快速抖动（百科·摆短；同词条横板摆短部分写"前臂相对稳定，靠手腕的爆发力"，两说不一；许昕的说法是"主要靠前臂带动手腕抖动球拍"）；**手臂在台内迎球时近似与台面平行**（[百科·摆短](https://baike.baidu.com/item/摆短/3687925)）。
- **劈长（Long push）**：上身重心放低，前臂和手腕向怀中内收，拍面后仰角较小；正手位短球用"两步上、一步退"（左脚先向右前迈，右脚插入台下）；身体前倾、重心跟到前脚；上升后期或高点期；前臂带手腕突然加速，有"切、砍"的感觉，撞摩结合；板型较立，触后中部或中下部，触点稍偏来球右侧以避开旋转轴（[百科·劈长](https://baike.baidu.com/item/劈长/3697701)）。百科把马琳列为劈长代表（出处是网易转载的教学文章，未另行核实）。
- **挑（Flick）**：对直拍来说，**正手挑打威力最大**；横拍除正手外反手挑也有威力（[百科·挑打](https://baike.baidu.com/item/挑打/6623819)）。尽量在高点期用板头触球（同词条）。接台内下旋，直拍可积极侧身用正手挑；挑下旋困难时用正手晃撇到对方反手位控制（百科·下旋球）。
- **正手快点**：直板正胶快攻型常用；站位近台，右方来球右脚上步，中路或左方来球左脚上步；高点期或上升后期；对上旋、不转用稍前倾拍面击中上部，对下旋用稍后仰拍面摩擦中下部；**直拍要注重拇指与中指的调节，击球瞬间食指向前顶出、拇指向下压**来控制拍面（[百科·正手快点](https://baike.baidu.com/item/正手快点/3579672)）。
- **反手台内进攻**：传统做法是反手快点——左脚上步、重心左移，前臂伸向台内，拍头稍高、拍面前倾、手腕内收，最高点用前臂和手腕击中上部；下旋强则击中下部、向前上方发力（[百科·直板反手](https://baike.baidu.com/item/直板反手/6264038)）；横打做法是反面拧（5.5）。

## 8. 直拍发球的特点

- **手腕优势**：直拍因手腕活动更多，发球有天然优势（[PingSkills 发球握法](https://www.pingskills.com/tutorials/52-week-table-tennis-training-plan/service-grips)）。CETV 也说中式直拍的第一种握法手腕灵活，发球时能用手腕发出**动作相似而旋转、落点不同**的球（CETV 进攻方法）。英文维基说直拍更容易做出两个方向的侧旋并隐藏旋转（无引用；条目里的"270°"手腕活动范围没有出处，不要用）。
- **转与不转**：百科把正手发转与不转后抢攻称为直拍选手的"绝招"，理由是发侧旋容易被对方借转转入上旋相持，对直拍不利；而转与不转让对方最多控制或轻拉（[百科·发球抢攻](https://baike.baidu.com/item/发球抢攻/3580332)）。
- **发球抢攻**是我国直板快攻打法的"杀手锏"（扬州职大）。
- **下蹲发球要换握法**：横拍发下蹲球比直拍方便；直拍要把**食指移到拍背**（[CETV 发球方式](http://www.centv.cn/p/480441.html)）。发完要利落站起，以防被抢攻（同页）。动作见 `../techniques/serve-hook-and-squat.md`。
- 发球时具体怎么松开背后三指，本次没找到可靠出处；原则是让手腕放松、触球瞬间再握紧（通用发力道理，见 `../techniques/serve-forehand-pendulum.md`）。

## 9. 直拍打法类型

- **英文维基四类**（握法与打法条目，"Penhold playing styles"）：
  - **直拍正手弧圈（Forehand looper）**：以正手弧圈为主，靠出色步法用正手覆盖大部分球台，尽量贴近球台。列举郭跃华、刘南奎、吕林、金泽洙、阎森、柳承敏、马琳、许昕。
  - **两面拉（Two-sided looper）**：基本都是现代中式直拍，用 RPB 拉出侧上旋混合的弧圈。列举王皓、Félix Lebrun（小勒布伦）、邱党、薛飞。
  - **近台快攻/反击（Counter driver）**：贴近球台，把对方上旋挡、打回去，改变节奏，伺机正手扣杀。列举蒋澎龙、文贤晶；对方放高球时马琳也用这种打法。
  - **正胶快攻（Short pips hitter）**：通常只一面贴正胶，台上、球刚弹起就平打，受对方旋转影响小，球快但不太稳。列举刘国梁、江嘉良、田崎俊雄、杨影、何智文等。
- **中文常用说法**：直拍左推右攻（蒋澎龙、柳承敏、杨影）、直拍横打弧圈结合快攻（马琳、王皓、李静、许昕）（CETV 攻球技巧）；刘国梁"右手直拍两面近台快攻型"（中文维基·刘国梁）；王皓"右手中国式直拍弧圈结合两面快攻"（中文维基·王皓）。
- **更正**：蒋澎龙是"右手日式直板**反胶**快弧打法"、"推挡相持为主"（中文维基·蔣澎龍），英文维基把他归为 counter driver，**不是**正胶快攻。正胶快攻的代表应看刘国梁等（百科·直拍横打也说刘国梁是"传统的直板正胶左推右攻嫁接了横打"）。

## 三位标杆（只写有出处的）

- **三人都是右手横拍**：马龙"右手横板弧圈结合快攻"（[央视网 2013-05-14](http://sports.cntv.cn/2013/05/14/ARTI1368541155329503.shtml)）；张继科右手、Classic（横拍）（[ITTF 旧版资料存档](https://web.archive.org/web/20170111090326/http://www.old.ittf.com/biography/biography_web_details.asp?Player_ID=110553)）；樊振东 Grip Shakehand、Hand Right（[东京奥运官方资料存档](https://web.archive.org/web/20210730141139/https://olympics.com/tokyo-2020/olympic-games/en/results/table-tennis/athlete-profile-n1321133-fan-zhendong.htm)）。所以他们没有直拍技术可直接模仿。

- **与直拍的交集（有出处的事实，不代表技术传承）**：樊振东的主管教练是直拍横打代表王皓（[央视网 2021-07-24](https://2020.cctv.com/2021/07/24/ARTIkPItsFvJAzLQdMQs8Cfl210724.shtml)）；2016 年报道说他由王皓和马琳指导（[DOHA Stadium Plus 存档](https://web.archive.org/web/20180902084250/http://dohastadiumplusqatar.com/contentpage.aspx?article=I-havent-reached-my-best-Fan-)）。至于三人具体哪项技术受直拍影响：暂无可靠出处。
- **直拍可参考的人物**：刘国梁（推挡加横打、正胶近台快攻）、马琳（推挡加横打/混合）、王皓（全横打）、许昕（正手弧圈为主）、蒋澎龙（日式直拍、推挡相持）、柳承敏（传统单面）——出处见第 5、6、9 节。

## 常见错误 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 推挡、正手时拍头朝下（吊板/吊腕） | 手腕下垂、内收 | 手腕外展，拍柄靠近虎口（百科·推挡球）；正手拍头指向右斜前方（CETV 攻球技巧） |
| 推挡时肘甩开 | 大臂离身体 | 大臂与肘略靠近身体右侧（百科·推挡球） |
| 推挡回球高或下网 | 击球太早或太晚；拍面不匹配 | 上升期击球，控制好前倾（百科·推挡球）；对弧圈按 4.8 调 |
| 加力推没力 | 手臂前伸不够、只用手腕 | 大臂和肘前送，加右脚蹬地、转腰（百科·推挡球） |
| 减力挡挡不住或回球长 | 触球时没有后收 | 重心略升、触球瞬间手臂手腕后收（百科·减力挡） |
| 推完还原慢 | 不用重心和转腰 | 结合重心移动和腰的转动还原（百科·推挡球） |
| 横打反面对不准来球 | 握法没调整：食指死压、拇指不压 | 按 5.1：拇指握深压拍，食指上移放松，背后三指伸开 |
| 横打动作大但不稳 | 只用手、不用腰控制 | 腰带手臂，力量由下往上（百科·直拍横打） |
| 反面平挡拍头下垂 | 刻意下垂拍头 | 拍头不刻意下垂，手腕相对固定（百科·直拍横打） |
| 搓球拍形不稳、前臂发紧 | 靠拇食指死压拍肩调拍形 | 用前臂内外旋加放松的手腕调（百科·搓球） |
| 正手拍面朝外、漏球滑板 | 手腕内收过多 | 手腕不内收，拍面朝前（百科·正手攻球） |
| 手腕、肘酸痛 | 横打用腕太多、练太久 | 缩短单次练习，酸痛就停，可戴护腕（百科·直拍横打） |

## 练习方法

- **推挡**（扬州职大；百科·推挡球）：徒手模仿→对墙推→自抛自推→陪练供到反手位连续推→推中线，再推直线和斜线→一点推两点或不同落点→推攻结合（陪练攻、你推；先定点，再有规律变化，最后不定点）。
- **加力推、减力挡**：在快推稳定后，陪练连续供中等力量的球，按"快推—加力推—减力挡"轮换；减力挡先挡中等力量的扣杀，再过渡到前冲弧圈，可以用多球提高密度（百科·减力挡）。
- **推下旋、挤推**：在陪练轻拉或快推的来球上练，每组只练一种，先求落点长、弧线低，再求变化。
- **左推右攻组合**（CETV 推攻）：左推右攻→推挡侧身攻→推挡、侧身攻后扑正手；推挡一般压对方反手，再突然变正手创造进攻机会。
- **横打**（以下顺序按动作难度排，是建议不是出处）：反面平挡→反面快拨（借力、手腕固定）→加转腰→多球反面拉下旋长球→相持中快撕→台内拧（百科·侧拧的四阶段可参照）→推挡与横打结合。
- **正手**：CETV 的教学步骤——徒手模仿→自抛自攻→一攻一挡→一人攻一人推→一点攻两点→对攻斜线、中路直线（[CETV 易犯错误](http://www.centv.cn/p/480451.html)）。
- **台内**（顺序按难度排，是建议；上步出自百科·正手快点）：徒手模仿上步（右方来球上右脚，中路或左方来球上左脚）→多球定点摆短→摆短与劈长交替→加正手挑和快点的上步；每球后还原。
- **发球**（扬州职大发球练习步骤；CETV 发球方式；百科·发球抢攻）：徒手做预备姿势，练下蹲发球的换握（食指移到拍背）→台前多球发下蹲球，发完利落站起→用同一手法发转与不转→发球后衔接抢攻。

## 视频检查要点

**机位**
- 推挡、横打：正面（球台对面）或持拍侧斜前 45°，全身入画；正手：侧面（`../analysis/recording-guide.md`）。
- 台内技术（搓、摆、劈、挑、快点）：侧面、略高于球台，备选斜前 45°；看触球帧放大图里的拍面后仰程度、食指与拇指位置，以及上的是哪只脚（recording-guide.md）。
- 发球：侧面；看放大图里下蹲发球时食指是否移到拍背；备选正面，看是否遮挡（recording-guide.md）。
- 用 120/240 帧慢动作；文件帧率与拍摄帧率不同时加 `--capture-fps`。
- **哪一面击球、手指位置、是否吊板、拍面角度，骨架测不出来，只能看 `stroke_NN_zoom.jpg` 手部放大图（击球前后各 2 帧）和 `stroke_NN_contact_raw.jpg` 击球帧原图**；手动测量时为 `measured/measured_NN_zoom.jpg`、`measured/measured_NN_contact_raw.jpg`。脚本把推挡和横打都判成反手，只有放大图能区分。
- 挡、快推手速低、动作短，可能分不出板（NO_STROKES 警告），这时按 `../analysis/analysis-protocol.md` 处理。

**各阶段看什么、对应哪个指标**（指标说明见 `../analysis/metrics-reference.md`）

| 阶段 | 关键帧里看什么 | 指标 |
|---|---|---|
| 识别 | 正手还是反手；反手要再看放大图是正面推还是反面打 | `side_guess`、`contact_lateral_m` |
| 准备 | 站位宽度、膝微屈；直拍正手肘略外张、拍在腹部右前方 | `stance_width_ratio`、`knee_angle_deg.playing.ready`、`knee_angle_deg.other.ready` |
| 引拍 | 推挡：短，肘贴身；加力推：拍位置更高；横打：腰左转、前臂内收；反面拉：拍到腹下 | `backswing_ms`、`elbow_angle_deg.backswing_end`、`shoulder_width_ratio.backswing_end`、`shoulder_turn_deg`、`hip_turn_deg`、`x_factor_deg`（单机位转动只作提示） |
| 击球瞬间 | 击球点在腹前约一臂、网高附近（推挡）；肘是否离身体太远 | `contact_forward_m`、`contact_height_level`、`elbow_body_gap_m`、`elbow_angle_deg.contact`、`trunk_lean_deg.contact`、`knee_angle_deg.playing.contact`、`knee_angle_deg.other.contact` |
| 击球瞬间（放大图） | 用哪一面；拇指、食指位置（横打拇指压、食指上移）；是否吊板；拍面前倾程度；减力挡是否后收；推下旋是否向下推切；台内球拍面后仰程度；下蹲发球食指是否在拍背 | 只能目测 zoom 图和 contact_raw 图 |
| 随挥 | 快推平而短；推下旋、挤推向前下；反面拉向前上；正手拉向左前上 | `follow_ms`、`swing_path.up`、`swing_path.horiz`、`swing_path.angle_deg`、`finish_height_level`、`elbow_angle_deg.finish` |
| 重心 | 正手由右脚到左脚（`delta` 为正）；反面拉由左脚到右脚（`delta` 为负）；推挡移动通常很小 | `weight_shift.backswing_end`、`weight_shift.finish`、`weight_shift.delta`、`knee_min_deg.playing`、`knee_min_deg.other` |
| 发力顺序 | 加力推、横打、正手是否先腰后手 | `forward_ms`、`peak_hand_speed`、`sequence_ms.hip`、`sequence_ms.shoulder`、`sequence_ms.elbow`、`sequence_order_ok` |
| 还原、平衡 | 拍是否回到身前；头是否乱晃；非持拍手是否保持平衡 | `recovery_dist`、`head_motion`、`free_arm_height_level` |
| 可信度 | 数据能不能信 | `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`；正面机位的肘角、膝角误差大 |

## 自查清单

- [ ] 我知道自己是中钳、大钳还是小钳，钳形适中，食指根部支点稳定。
- [ ] 正手时拇指、中指用力，食指放松；推挡时食指、中指用力，拇指放松。
- [ ] 准备时拍头指向右斜前方，正手和推挡都不吊板。
- [ ] 快推：肘贴身体右侧，前臂与台面平行，上升期击中上部，食指压出前倾。
- [ ] 加力推有更高的引拍、右脚蹬地和转腰；减力挡在触球瞬间有后收。
- [ ] 推下旋向前下推切、击中部偏下；挤推向左前下方挥、击左侧中上部。
- [ ] 对弧圈：加转压得更前倾，前冲稍立起（数字只是单一来源的起点）。
- [ ] 横打时拇指握深压拍、食指上移放松、背后三指伸开；用腰带手，力量向右前上方。
- [ ] 我清楚自己的反手属于全推挡、推挡加横打还是全横打，练习按这个分配。
- [ ] 搓球用前臂内外旋调拍形，不靠手指死压拍肩。
- [ ] 正手快点时击球瞬间食指向前顶、拇指向下压控制拍面，右方来球上右脚、中左方来球上左脚；挑打尽量在高点期用板头触球。
- [ ] 发下蹲球时把食指移到拍背；发球多用转与不转的变化。
- [ ] 视频里用手部放大图确认了击球面、手指位置和拍面。
