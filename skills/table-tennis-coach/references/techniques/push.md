# 搓球（Push）

适用：近台回击下旋、不转的短球和半出台球（接发球、对搓、搓中起板之前）｜难度：入门技术，搓出质量（转、低、快、变）是中高级｜相关卡片：`../techniques/short-touch.md` `../techniques/long-push.md` `../techniques/chop.md` `../techniques/forehand-flick.md` `../techniques/backhand-banana-flick.md` `../techniques/forehand-loop-vs-backspin.md` `../techniques/backhand-loop-vs-backspin.md` `../techniques/backhand-block.md` `../techniques/receive.md` `../techniques/footwork.md` `../techniques/tactics.md` `../fundamentals/spin.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/grip.md`

> 全文按右手横拍写；左手持拍者左右互换。直拍搓球见 `../techniques/penhold.md`。
> 出处缩写：`LH:N` = Larry Hodges（美国乒协名人堂教练）文章 https://www.tabletenniscoaching.com/node/N ；`PS` = PingSkills 教学网站；`BK` = 百度百科「搓球」词条，`BK-接发球` = 百度百科「接发球」词条（可编辑百科，可信度中等）；`CETV` = 中国教育电视台乒乓球课程页。完整链接见文末。
> 拍面角度沿用 CETV 定义：拍面与台面的夹角，90° 为垂直，大于 90° 为后仰（拍面朝上打开）。

## 1. 定义与用途

**搓球（push）**：近台用后仰的拍面，从球的中下部向前下方摩擦，回出带下旋的球。BK：上臂前伸、拍面稍后仰，把球拍向前下方送出，摩擦球的中下部；特点是"动作小，弧线低，落点活，旋转变化多"。英文维基「Table tennis」：拍面切到球的下部，使球带下旋、较慢地飘到对方台面。日文维基「卓球」把它叫ツッツキ（拍面稍朝上，向前"戳"球底部）。

**本卡覆盖的种类**（BK；扬州职大课程资料同样分为慢搓、快搓、搓不转、搓侧旋）：

| 种类 | 一句话 | 何时用 |
|---|---|---|
| 慢搓（加转） | 动作较大，下降期击球，回球慢但旋转强（BK） | 来球旋转强、线路稍长；对搓中变节奏 |
| 快搓 | 动作小，上升期借力搓回，回球快（BK） | 接发球、近网下旋；抢时间、逼对方仓促起板 |
| 搓转与不转 | 用相似动作搓出加转或不转（BK） | 让对方判断错拍形而冒高或下网 |
| 侧旋搓（搓偏） | 下旋中加侧旋，让球往一侧拐：反手侧旋搓（LH:76）；正手侧旋搓"晃撇"（BK-接发球） | 偶尔变化，不宜多用 |

相邻技术分卡写：搓短、第二跳不出台的**摆短（short push）**见 `../techniques/short-touch.md`；以撞击、速度为主的**劈长**和搓长落点要求见 `../techniques/long-push.md`；远台的大幅度**削球（chop）**见 `../techniques/chop.md`。BK 还提到用不同性能胶皮"倒拍"搓，只适用于两面胶皮不同的球员，本卡不展开。

**三个容易混的名词（不要互相等同）**：
- **侧旋搓**：对下旋或不转的**短球**，在搓的同时加侧旋（LH:76；PS 课程 *Is the Sidespin Push Worth the Risk?*）；正手侧身位的侧旋搓 BK 叫"晃撇"（BK-接发球）。本卡第 6 节写要领。
- **侧切**：中文维基「乒乓球」把"正、反手侧切"列在**出台**接发球或回球技术里，但没有动作说明；本次没找到可靠的动作要领出处，所以本卡不写它的做法，也不把它当成侧旋搓。
- **削挡 / 搓挡（chop block）**：对**上旋**来球，在挡的同时向下切出下旋（PS *When and How to Use a Chop Block*）；长胶选手的削挡是近台防守，拍子往下刷、动作短、手腕放松（PS *Long Pimple Chop Block*）。英文维基术语表写它"带侧旋和下旋"。对付的是上旋而不是下旋，和搓球不是一回事；PingSkills 教练认为比赛中大约五十次才值得用一次（见第 7 节）。另外，Hodges 把台内接短上旋/侧上旋时竖拍下切也叫 chop-block（"half block, half push"，LH:80；"a push with closed racket"，LH:33），本卡第 4、6 节的"竖拍下切"就是这一板；它不是开拍面的搓。

**作用**：CETV「搓攻」把搓球的要求概括为"转、低、快、变"，用来控制对方、寻找机会再起板，并说搓攻是各种打法"都不可缺少的辅助战术"。Hodges：一板重搓"有时就足以拿掉对方的进攻"（LH:3117）。

**限度（必须知道）**：
- 英文维基：对高水平对手，搓球"可能是最差的选择"，因为对方会直接拉。BK：过多搓球必然导致对方先进攻的被动局面，应"加强搓中抢攻、减少依赖搓球得分"。
- Hodges：短下旋发球最容易的接法是搓长，"也是最快惹麻烦的方式"；搓长要出于战术选择，而不是因为别的不会（LH:80）。高水平最常见的接发球是摆短（LH:80）。
- 但不要因此不练搓：Hodges 发现只会挑打接发的人，长期练不出搓球手感，也练不出防守；建议先练好搓长，再练摆短（LH:3702）。

## 2. 三位标杆怎么做（只写有出处的）

**马龙**
- 一场比赛的统计（2020 世界杯半决赛对张本智和，Edges & Nets 分析博客，非官方，仅此一场）：张本"在摆短对抗中赢不了马龙"，于是更多挑打——张本挑 50 次、失误 7 次，马龙只挑 12 次、0 失误。同一分析：马龙前三板最想要的，是对方发球或**搓球**出长球、尤其半出台时用正手起板，起板的分赢了 68%，其余的分只赢 47%。这说明了搓球的限度：搓得不够短、不够低，就是送给对方起板。
- PingSkills 教练答问：提问者说某段视频里马龙几乎全用正手搓接樊振东的发球，并把其中一个发球称为 right sidespin；教练指出，马龙**触球瞬间把拍面明显转向右侧**来抵消这个侧旋，并推测他用正手是因为角度更好（单段视频，教练口头分析；只说明这一个发球，不是"接侧旋都转向右"，通用规则见第 4 节）。
- 央视网比赛报道：接发球摆短后正手抢拉得分（2017 日本公开赛、2018 中国公开赛，单场描述）——这是"搓攻"的典型路线。
- 2015 年被问到技术上最大的不同，他说除了发球，"还包括一些反手拧，还有短球上也跟过去有一些变化"（央视网 2015-02-05）。原话没具体说搓球怎么变。
- 慢搓、快搓的具体动作细节、"劈长是马龙特点"：暂无可靠出处。

**张继科**
- 本人原话（《卓球レポート》2019，日本蝴蝶公司刊物）：10～15 年前接发球以搓（ツッツキ）为主；看到拧拉后，觉得它"能阻止对方的第三板"，于是自己主动研究。（他的说法反映了接发球从搓转向拧的变化，这是本人一家之言，不是统计。）
- 2008 年（20 岁）媒体评价他"台内处理还不够细腻"（搜狐体育 2008-03-22，只代表当时）。
- 搓球的个人动作特点：暂无可靠出处。英文维基"常用反手到正手位接重下旋和搓球"一说没有出处，不采用。

**樊振东**
- 论文（Jin & Ma 2026，40 场比赛统计）只比较了第二板的进攻技术：反手发起进攻明显多于正手，反手拧拉在进攻技术中使用率最高；搓、摆短在接发球中占多少比例，论文没有统计，暂无可靠出处。
- 刘国梁评价他"台内前三板更加细腻"（新京报转述，央视网 2021-07-30）。
- 央视网 2019-07-21："接发球劈长得手"——只能说明他会用劈长，不能说是特长。
- 搓球的个人动作特点：暂无可靠出处。

**业余怎么借鉴**：搓的目标不是"搓得赢"，而是让对方起板难受、自己有机会先上手（马龙一场比赛的统计见上；张继科、樊振东的搓球使用习惯暂无可靠出处）。

## 3. 动作分解

**先看这里**
- 用得多的一侧：BK 说搓球"一般在左半台使用较多"；正手搓用于正手位短球。有提问者说某段视频里马龙几乎都用正手搓接发（单段视频，见第 2 节）。
- 上步：短球无论正手位还是反手位，右手持拍者都**上右脚**，打完马上退回（PS *Moving In for Short Balls*；LH:33）；Hodges 补充，反手位上左脚也可以，便于补正手位（LH:33）。
- 拍面怎么开：用前臂旋转加放松的手腕调拍形，不要用手指压拍（BK 这段原本说的是直板，原理可借鉴）。横拍的方向（本卡推论，非引文）：正手前臂外旋、反手前臂内旋使拍面后仰。
- 击球点：正手搓在身体右前方，反手搓在身体正前方（腹前）；都在体前，不要等球到身侧（BK"球拍在体前"）。
- 3.1–3.6 写正反手共同的要领；正手、反手不同的地方集中在 **3.7 对照表**。

**慢搓与快搓对照**（全部出自 BK，击球时间另见 LH:3641）

| 项目 | 慢搓 | 快搓 |
|---|---|---|
| 用途 | 来球旋转较强、线路稍长；对搓中变节奏 | 接发球、削过来的近网下旋、半出台短球；抢节奏、缩短对方准备时间 |
| 站位和重心 | 近台，右脚稍前，持拍手臂自然弯曲 | 站位近台，身体重心前移，身体靠近来球 |
| 引拍幅度 | 动作幅度大 | 引拍幅度小 |
| 击球时间 | 下降期（控制最好、最易加转，LH:3641） | 上升期（逼迫对方、角度大，LH:3641） |
| 拍面 | 后仰，按来球控制后仰角度 | 拍形稍后仰；击球时拍面"稍横立"，避免出界或回球过高 |
| 手腕 | 前臂用力为主，转腕动作不宜过大 | 手腕固定 |
| 发力方向 | 向前下方；搓加转"在向下用力的同时，应增加前送的幅度" | 前臂主动前伸，插向球的中下部 |
| 借力还是自己发力 | 下降期击球，注意减力、卸力 | 一般借来球的前进力；"若来球下旋弱可用力下切" |
| 回球 | 速度慢，旋转强 | 速度快 |

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 两脚略宽于肩、前脚掌着地，随时能上步；站位不要贴台，BK 建议以正常台距为准，用脚前后左右移动"迎前" | 搓着搓着越站越近，对方一变长或追身就来不及（BK） |
| 膝 | 微屈有弹性 | 直腿站，上步慢 |
| 髋 | 略前屈，正对球台 | 臀部后坐 |
| 腰/躯干 | 上体稍前倾，重心压低（BK 转述《国家队教学》：搓球时重心不能站得太高） | 站得太直，够球时只能弯腰 |
| 肩 | 放松 | 耸肩 |
| 大臂/肘 | 肘在体前、离身体不远 | 肘夹死在身侧或甩开 |
| 前臂 | 置于体前，略高于台面 | 前臂垂到台面以下 |
| 手腕 | 自然放松 | 先锁死 |
| 手指/握拍 | 握拍放松，稍虚（BK 转述《国家队教学》；PS 摆短课也要求放松握拍）；握法见 `../fundamentals/grip.md` | 捏死拍，触感差 |
| 拍面/拍头 | 拍放在正反手之间、台面以上 | 拍太低，抬手耽误时间 |
| 视线/头 | 看对方触球动作判断旋转：往球后下方、下部切是下旋；平着碰球主要给速度，擦得越快越薄旋转越多（PS *Reading Spin*） | 只盯球，不看对方拍 |

### 3.2 引拍（与上步同时完成）

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 判断是短球后右脚上步到台下，步子大小以"击球点在体前"为准 | 不动脚、伸手够球（LH:3727：侧倾去搓，重心压在一侧脚上，下一板来不及） |
| 膝 | 上步时前腿屈膝，承接重心 | 腿直着，上体前扑 |
| 髋 | 随上步向前移，不后坐 | 脚上去了髋没跟上 |
| 腰/躯干 | 稍前倾，不扭转；搓球基本不靠转腰发力 | 大幅转腰引拍 |
| 肩 | 平稳；正反手肩的朝向不同，见 3.7 | 抬肩 |
| 大臂/肘 | 大臂向前送，肘略屈 | 大臂往后拉 |
| 前臂 | 前臂提起，引拍到球的后上方；**引拍高度要在台面以上，大致与网同高**（BK）。慢搓引拍稍大，快搓引拍很小（BK） | 引拍低于台面，向上兜球（BK 特别纠正） |
| 手腕 | 慢搓、加转搓时手腕稍向后引（LH:3117）；快搓手腕基本固定（BK） | 快搓时也大幅勾腕，失控 |
| 手指/握拍 | 保持放松 | 引拍时握紧 |
| 拍面/拍头 | 拍面后仰，拍头朝前；BK 转述《国家队教学》（孙颖莎反手搓）：引拍时拍面相对立一点，触球瞬间再变平 | 一开始就把拍面放得很平，动作被看穿也缺少前送空间 |
| 视线/头 | 盯球的落点和弹起高度，决定上升期还是下降期击球 | 看对方站位分心 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 上步脚落地与触球大致同时，重心落在上步脚上 | 脚还在动就出手 |
| 膝 | 前膝屈，稳定支撑 | 膝内扣或晃动 |
| 髋 | 稳定，向前 | 髋向后拉 |
| 腰/躯干 | 稳定前倾，不起身 | 迎球时上体抬起，拍形跟着变 |
| 肩 | 放松，肩不参与大幅转动 | 用肩带臂"砍" |
| 大臂/肘 | 上臂前伸是动力之一（BK："上臂前伸和旋外的力量"） | 大臂不动，只靠前臂 |
| 前臂 | 由上向前下方挥；来球下旋越强越多向前，越不转越多向下（BK）；快搓时前臂主动前伸"插向"球的中下部（BK） | 只向下砍（下网）；只向前推（冒高或出界） |
| 手腕 | 加转搓时前臂带手腕一起加速（LH:3117；BK：搓加转时手腕爆发式用力） | 只甩手腕，腕臂脱节（BK） |
| 手指/握拍 | 保持虚握，临触球再稍收紧 | 全程捏死 |
| 拍面/拍头 | 按来球定后仰：下旋越强越平，不转来球拍稍竖（BK） | 不看来球，一个拍形搓到底 |
| 视线/头 | 头稳定，看球到拍 | 抬头看对方 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心在上步脚（右脚）上，但身体平衡、不侧倒（LH:3727） | 身体向侧倒 |
| 膝 | 屈膝稳住，不再下蹲或起立 | 触球时站起 |
| 髋 | 静止或微微前移 | 后坐 |
| 腰/躯干 | 前倾稳定 | 仰身 |
| 肩 | 放松 | 发紧 |
| 大臂/肘 | 肘略屈，不伸直锁死 | 手臂完全伸直够球（击球点太远，BK 列为常见错误） |
| 前臂 | 在加速中触球，加速要穿过触球（LH:3117） | 触球时已减速 |
| 手腕 | 加转：腕和前臂一起向前下方发力；不转：少用手腕（PS 不转搓课）；反胶初学者不必模仿正胶选手的大幅抖腕（BK） | 乱抖腕 |
| 手指/握拍 | 触球瞬间手指稍收紧 | 拍被球顶歪 |
| 拍面/拍头 | 后仰，摩擦球的中下部；重下旋拍面几乎朝天（PS 答问）。两件事分开：自己搓不转——触球略偏向前、少用手腕、换拍面上的触球位置（PS 不转搓课）；来球不转——拍面稍竖、多向下（BK） | 拍面后仰不够（BK 常见错误）——下网 |
| 视线/头 | 头静止，看到触球 | 提前抬头 |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心随球向前，然后准备蹬回 | 重心留在后脚 |
| 膝 | 保持屈 | 直膝 |
| 髋 | 跟随前送 | 停住 |
| 腰/躯干 | 稳定 | 跟着手起身 |
| 肩 | 放松 | 用肩拉回 |
| 大臂/肘 | 随前送略伸 | 立即缩回 |
| 前臂 | 击球后小臂**继续向前下方送**，不要碰到球就停（BK 常见错误"击球后动作停止"） | 一碰就收，球软、短、高 |
| 手腕 | 自然放松 | 收拍时向上翻腕 |
| 手指/握拍 | 放松 | 一直握紧 |
| 拍面/拍头 | 拍头指向出球方向，保持后仰；收拍高度不高于开始高度 | 拍头上翘 |
| 视线/头 | 看球飞向哪里、对方怎么动 | 低头看拍 |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 上步脚立即蹬回准备位置：PS 要求上步后马上退回，Hodges 说随挥的一部分就应把你带回位置（LH:3727） | 搓完留在台下，被对方拉追身或大角 |
| 膝 | 屈膝蹬回 | 站起再退 |
| 髋 | 回到中立 | 留在台内方向 |
| 腰/躯干 | 恢复稍前倾 | 直立 |
| 肩 | 放松 | 耸肩僵住 |
| 大臂/肘 | 收回体前 | 手臂留在台上 |
| 前臂 | 拍子回到正反手之间 | 拍子落在台面以下 |
| 手腕 | 回中立 | 手腕保持后仰下压姿势不回中立 |
| 手指/握拍 | 回到中性握法，准备下一板拉或挡 | 握拍还停在搓球的手型 |
| 拍面/拍头 | 拍面从后仰回到接近垂直、拍头回到体前中间，准备挡或反拉 | 一直保持搓球的后仰拍面，被拉过来后挡出界 |
| 视线/头 | 盯对方起板，先做好挡或反拉准备（LH:3445 的练法就是"搓—对方拉—你挡"） | 搓完就松懈 |

### 3.7 正手搓与反手搓逐阶段对照

标"定性"的是本卡的动作描述，没有找到专门出处；其余标出处。

| 项目 | 正手搓 | 反手搓 |
|---|---|---|
| 何时用 | 正手位短球、下旋 | 左半台，用得更多（BK"一般在左半台使用较多"） |
| 上步脚（3.2） | 右脚上到台下（PS；LH:33） | 多数也上右脚，回球更有力；上左脚便于随后右移补正手（LH:33） |
| 肩、躯干（3.1–3.4） | 右肩略前，上体稍向右侧对球（定性） | 两肩大致平行对台（定性） |
| 大臂/肘（3.2–3.4） | 肘在身体右前方，不夹死、不外甩（定性） | 肘在体前，前臂横在腹前（定性） |
| 引拍位置（3.2） | 拍在身体右前方、球的后上方，高度在台面以上、约网高（高度：BK） | 拍收到腹前、球的后上方，同样在台面以上、约网高（高度：BK） |
| 拍头朝向（3.2–3.4） | 拍头大致指向前方球网，拍面朝前上方（定性） | 拍头指向左前方，拍面朝前上方（定性） |
| 开拍面的前臂旋转（3.3–3.4） | 前臂外旋，拍面后仰（本卡推论） | 前臂内旋，拍面后仰（本卡推论） |
| 拍面左右方向（3.3–3.4） | 伸进台内时拍面自然偏左；接对方反手侧旋发球必须主动转向右（LH:80） | 手腕更灵活，左右方向较容易调（LH:80） |
| 击球点（3.4） | 身体右前方，体前（体前：BK） | 身体正前方（腹前） |
| 随挥方向（3.5） | 沿出球方向向前下方送，拍头指向目标、不上翘（定性；"继续前送"：BK） | 从腹前沿出球方向向前下方送，拍头指向目标（定性；"继续前送"：BK） |
| 还原（3.6） | 右脚蹬回，拍回体前中间（PS；LH:3727） | 同左；上左脚时更易向右补位（LH:33） |

## 4. 拍面角度、击球点、击球时间、触球部位

**拍面角度**（没有出处的度数不写；按后仰程度定性）：
- 一般搓球：拍面稍后仰（BK）。
- 来球下旋强：拍面更后仰（更平），增加向前的力量（BK）；极重下旋拍面几乎朝天，还不够就触球时略向上托一点，帮助过网（PS 答问 *Push heavy backspin serve*）。
- 来球不转：拍面稍竖，增加向下的力量（BK），要往下切，否则会按下旋的拍形把球托高（LH:3600）。
- 来球是短上旋/侧上旋：不要用搓的开拍面，拍面大致垂直，向下切（"一半挡、一半搓"），否则球会飞出端线或边线（LH:80；LH:3117）。
- 侧旋来球（按效果判断，不按"左/右侧旋"的叫法，中英文叫法未必一致）：先判断来球碰拍后会往哪边偏，拍面就预先朝反方向对准。LH:80 的例子：右手持拍者正手伸进台内接对方反手侧旋发球时，拍面自然偏左，必须主动转向右；反方向的侧旋用反手接也较别扭，但手腕灵活、较好调。旁证：PingSkills 答问里一个发球（提问者称为 right sidespin），马龙触球瞬间把拍面明显转向右（单段视频）。

**击球点**：体前，正手搓在身体右前方，反手搓在身体正前方（腹前）；不要离身体过远（BK 常见错误）。快搓更靠前，在台内上升期截球。

**击球时间**（LH:3641；与 BK 的慢搓/快搓分法一致）：
- 上升期（刚弹起）：最理想，能逼迫对方、角度大，离目标近反而好控制；缺点是自己也仓促。= 快搓。
- 下降期：控制最好、最容易加转；缺点是逼不住对方、角度小。= 慢搓。
- 高点期：**一般最差**，击球点高，回球容易弹高，给对方好拉的球。Hodges 也承认高点期过网余量大，有人用它打很凶的搓；劈长就在上升后期或高点期出手，靠较立的拍形加向下切来压低，见 `../techniques/long-push.md`；正手晃撇 BK 也说在最高点击球（第 6 节）。

**触球部位**：球的中下部（BK、CETV 的"中下部"）；下旋越强越往下部摩擦，不转球触点偏后、向下切。拍面上的触球位置：侧旋搓有人用拍的下部触球以便更早击球，用中部更好控制（LH:76）；转与不转可以靠换拍面触球位置来区分（PS 不转搓课）。

## 5. 发力：顺序、方向、摩擦与撞击

- **发力来源**：以上臂前伸和前臂为主（BK："利用上臂前伸和旋外的力量"；慢搓"前臂用力为主，转腕动作不宜过大"）。腿和躯干负责把身体送到位、稳住重心，搓球基本不靠转腰。
- **顺序**：上步、重心到位 → 大臂前送 → 前臂向前下方加速 →（加转时）手腕最后加速。腕和前臂必须一起用力，不能脱节（BK）。
- **方向**：由上向前下方（BK："将球拍向前下方送出"；"大部分是从上向下发力"）。来球下旋越强，越要向前；来球越不转，越要向下（BK）。
- **摩擦与撞击**：搓加转要薄擦——越薄，旋转越多，但需要额外用力才能搓深（LH:3117）；平着撞球只给速度，快而薄的擦才有旋转（PS *Reading Spin*）。快搓借来球的反弹力（BK："借来球的前进力"），下降期搓则要注意减力、卸力（BK）。
- **加转要点（LH:3117）**：① 用手腕，手腕先向后引；② 前臂加手腕平顺加速、加速穿过触球；③ 拍面相对打开、擦球；④ 胶皮要涩（spinny rubber 转更多）。
- BK 另说：用反胶的初学者只用手腕前挺加小臂的合力就足够转，不必模仿正胶选手的大幅抖腕。

## 6. 面对不同来球的调整

| 来球 | 调整 |
|---|---|
| 短、重下旋 | 拍面更后仰（极重时几乎朝天），向前多送；还过不了网就触球时略向上托（PS 答问；BK） |
| 短、不转 | 拍面稍竖，往下切，并靠自己摩擦制造下旋（LH:3600；BK）；也可以直接进攻（LH:3600） |
| 短、上旋或侧上旋 | 一般该挑或拧（见 `../techniques/forehand-flick.md` `../techniques/backhand-banana-flick.md`）；非要搓，拍面大致垂直向下切（LH:80；LH:3117；PS *Returning Short Topspin Serves*） |
| 侧下旋 | 拍面先按下旋后仰，再按"球碰拍后往哪边偏"把拍面朝反方向对准（第 4 节；LH:80）；正手接对方反手侧旋较别扭，有人按侧旋方向选正手或反手接（LH:80） |
| 半出台 | 能拉就拉（`../techniques/forehand-loop-vs-backspin.md`）；不能拉时快搓抢节奏、压落点（BK 把应对半出台短球列为快搓的用途） |
| 对方搓过来的重下旋长球 | 优先拉；搓回则要快、低、深、转、有角度（LH:80；LH:358） |
| 削球手的下旋 | 搓转与不转结合落点变化，可以摆脱被控制（BK） |

**快搓接发（quick chip，LH:3409）**：对方发短下旋或不转到中路、反手位时，刚弹起就快搓到对方反手大角外；可以快，也可以稍软、略向下压低弧线搓到反手角外侧。好处是基本封住对方正手抢攻；对方侧身后，下一次用同样的动作在最后一刻改搓正手。

**反手侧旋搓（搓偏，LH:76）**：
- 做法：拍从球的**右上方**开始；球一落台就搓（上升期），给对方的时间越少，越来不及适应侧旋；同时加下旋和侧旋。
- 原文的挥拍方向前后矛盾：先写触球时拍"从右向左"，后又写"向下并向侧（从左向右）"。本卡不规定方向，用效果检验：右手对右手时，应**搓到对方反手大角，球往对方反手方向拐**。
- 何时用：对方右手正手侧旋发球时，借它的侧旋搓回对方反手大角；左手对右手时，可搓到对方正手大角，往外拐更难受。
- 风险：下旋相对少，看懂的对手可以在上升期直接拉；不要多用（LH:76）。PingSkills 教练总体更倾向低、短、带下旋的普通搓（PS *Is the Sidespin Push Worth the Risk?*）。

**正手侧旋搓（晃撇，BK-接发球，单一来源）**：
- 何时用：一般在侧身位，用正手搓侧旋、斜线球接短球；和侧身挑直线配合，使对方不敢轻易侧身进行正手抢攻。BK 还说判断不准时"可轻轻地托一板或撇一板"。
- 要领：最好在来球最高点击球；拍触球的后中下部，手腕略外展，向左侧前下方摩擦，使球带左侧下旋，落台后向外拐，对方不容易对准球。
- 注意：BK 说在最高点击球，与 LH:3641"高点期一般最差"不同（高点期的例外见第 4 节）。只有这一个来源，先当变化手段试用，看回球是否偏高被拉。

**转与不转的隐蔽**：加转是前提，转与不转差别越大越有效（BK）。搓不转时改变拍面上的触球位置、少用手腕、触球略偏向前，并让两种动作看起来一样（PS 不转搓课）。对方习惯开拍面接下旋，不转搓会让他冒高（LH:17）。搓不转时注意回球弧线（BK）。

**长搓质量六要素（LH:358）**：快（刚弹起）、深、低、转、有角度、落点隐蔽。Hodges 记录，曾在中国队效力、后获四届美国男单冠军的教练程银华说：六项都做到，对方发球抢拉就会"散架"。做到四五项只能难住中级选手。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 下网 | 拍面后仰不够（BK） | 在下降期搓对方发来的下旋，体会拍面后仰前送（BK） |
| 前臂由上向下的动作不明显，球软、弧线高 | 引拍不够；引拍低于台面向上兜（BK） | 持拍模仿前臂和手腕先向上再向下切；引拍到网高附近（BK） |
| 球软、不转、不深 | 前臂前送不够，碰到球就停（BK） | 两人对练慢搓，体会击球后小臂继续前送（BK） |
| 击球部位不准、失误多 | 击球点离身体过远，重心偏后（BK） | 近台对练慢搓，下降期击准中下部（BK）；先动脚再出手 |
| 搓不转、失误多 | 滥用手腕，腕臂脱节（BK） | 手腕必须跟前臂一起发力（BK） |
| 接不转球冒高 | 按下旋的开拍面去搓（LH:3600） | 不转球拍面稍竖、往下切（BK；LH:3600） |
| 接短上旋/侧上旋出界 | 用搓的开拍面去碰上旋（LH:80） | 拍面大致垂直向下切，或改挑、拧（LH:80） |
| 回球偏高被拉 | 在高点期搓（LH:3641） | 改上升期或下降期 |
| 比赛中面对不同发球就冒高 | 平时只两人对搓练加转，只适应重下旋（LH:3117） | 让对方混发转、侧下、不转，你专练加转搓（LH:3117） |
| 吃旋转 | 不依来球旋转和高低长短调整（BK） | 下旋强拍面后仰、多向前；不转拍稍竖、多向下（BK），并加强判断 |
| 搓完下一板来不及 | 侧倾够球、重心压在一侧脚上（LH:3727）；越站越近（BK） | 用步法到位，搓完蹬回；保持正常台距 |
| 手臂紧、拍形不稳 | 靠拇指、食指压拍控拍形（BK，原文针对直板） | 用前臂旋转配合放松的手腕控拍形（BK；横拍方向见第 3 节开头） |
| 侧旋搓被直接拉死 | 下旋不够又用得太多（LH:76） | 只在对方没准备时偶尔用 |

## 9. 练习方法（入门 → 进阶）

每一步后面的"过关"是本卡给的定性标准，不是出处里的数字；做到了再进下一步。

1. **徒手模仿**：对镜或录像，从侧面和正面看起始位置、触球位置、收拍和还原（BK、扬州职大教学顺序；PS 单人练习）。过关：录像里引拍在台面以上、挥拍向前下方、收拍不上翘，正反手都能做出 3.7 的区别。
2. **自抛自搓**：自己把球抛到本方台面，搓过网（BK）。过关：大多数球能低平过网、落在对方台内，不冒高。
3. **多球喂下旋**：陪练发下旋，你搓回；先定点，再变旋转强弱和长短，模拟真实的搓（BK；PS *Match Drills with Multiball*）。过关：能连续把不同转速的下旋都搓回、不冒高不下网，再进第 4 步。
4. **两人对搓**：先中路直线，再斜线（BK）；再加入落点变化，正反手结合（PS *Training 101: Backhand and Forehand Push Drills*：先弹球搓、慢速对搓、连续性挑战、搓不同位置、只准搓的比赛打到 11 分）。Hodges 给初学者每节课排反手对搓、正手对搓各 5 分钟（LH:18）。过关：正反手都能稳定连续对搓，并能有意识地变落点、快慢搓交替。
5. **加转专项**：对方练发球，发重下旋、侧下旋、不转混合，你每球都搓加转（LH:3117）；不要两人互搓加转。过关：面对混合发球也能搓出明显下旋，对方回球明显变沉或下网。
6. **转与不转**：同一动作搓出加转和不转，让对方说出是哪种，或看他回球的高度验证。过关：对方经常判断错再进下一步。
7. **侧旋搓**：对方正手发侧旋短球到你反手，你用反手侧旋搓到他反手大角，检查拐向（LH:76）；会正手侧身的，再试晃撇（BK-接发球）。过关：球稳定往预定方向拐、不冒高；做不到就只把它当偶尔的变化。
8. **搓后衔接**：发下旋—对方搓—你拉—打完（LH:22 的第 7 步）；或发下旋—你搓—对方拉—你挡，不打完，马上下一球（LH:3445）；"摆短→搓长→拉"多球组合（PS）。过关：搓完能及时退回挡住对方起板，或抓住对方搓过来的长球先上手。
9. **比赛化**：练习赛里有意识地接发搓长，直到搓得好、也不怕对方拉（LH:3702）；找爱发短球抢拉的人，用加转、深、低、隐蔽的搓去赢他（LH:3117）。过关：比赛里搓长不再是"送分"，对方的抢拉质量明显下降。

## 10. 视频检查要点

**机位**：主机位用**侧面**（站在搓球者右侧，镜头略高于球台），看上步、前倾、手臂前送和挥拍方向；补拍**斜前 45°**看拍面后仰程度和右脚是否到位（`../analysis/recording-guide.md`）。手机慢动作 120/240 fps，导出后用 `--capture-fps` 校正。搓球动作小、速度慢，脚本可能找不到挥拍（`NO_STROKES`）；这时用 `--start/--end` 截取，或用 `--strokes` 手动给出各阶段时间。

| 阶段 | 关键帧看什么 | 对应指标 |
|---|---|---|
| 准备 | 屈膝、前倾、拍在台面以上；离台不太近 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 引拍/上步 | 右脚是否上到位、重心是否跟上；引拍是否在台面以上、幅度小 | `weight_shift.backswing_end`（上右脚后应接近 0，即持拍侧脚）、`knee_min_deg.playing`、`trunk_lean_deg.backswing_end`、`backswing_ms` |
| 迎球 | 是否向前下方挥、大臂是否前送、肘是否离身体太远 | `elbow_angle_deg.backswing_end` → `.contact`、`elbow_body_gap_m`、`forward_ms`、`peak_hand_speed`（只和自己比） |
| 击球瞬间 | 击球点在体前、手臂没有伸直锁死；头稳；正反手是否判断对 | `contact_forward_m`、`contact_lateral_m`、`contact_height_level`、`elbow_angle_deg.contact`（接近 180° 说明伸直了）、`trunk_lean_deg.contact`、`head_motion`、`side_guess` |
| 随挥 | 前臂是否继续前送；方向应向前、略向下，不应向上 | `swing_path.{up,horiz,angle_deg}`（搓球仰角应为负或接近 0；明显为正说明在往上兜）、`finish_height_level`、`follow_ms`（过短说明碰球就停）、`weight_shift.finish`（搓球时也应接近 0，重心在持拍侧上步脚上） |
| 还原 | 脚有没有退回，目测 `stroke_NN_sheet.jpg` 的还原帧和 `timeline_XX.jpg`（脚本不测脚步还原）；拍面是否从后仰回到接近垂直 | `recovery_dist` 只看手和拍有没有回到体前 |
| 整体 | 数据能不能用 | `free_arm_height_level`、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}`；`sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok` 对搓球参考价值低（动作小） |

**拍面角度必须看手部放大图**（`stroke_NN_zoom.jpg`、`stroke_NN_contact_raw.jpg`）：骨架模型测不出拍面。目测：触球前拍面是否后仰；对重下旋是否更平；对不转是否稍竖；是否在触球前大幅翻腕。`quality.reliable` 为假，或手腕在 `low_visibility_parts` 里时，不要下结论，按拍摄指南重拍。各指标的含义见 `../analysis/metrics-reference.md`。

## 11. 自查清单

- [ ] 判断出短下旋后先动脚：右脚上步，击球点在体前
- [ ] 引拍在台面以上、大约网高，不向上兜
- [ ] 拍面后仰程度随来球变：重下旋更平，不转稍竖，上旋不搓或竖拍下切
- [ ] 挥拍向前下方，前臂发力为主，手腕和前臂一起用力
- [ ] 击球后小臂继续前送，不碰球就停
- [ ] 快搓在上升期、慢搓在下降期，避免高点期搓
- [ ] 加转靠薄擦和加速穿过触球，不靠乱抖腕
- [ ] 能用同样的动作搓出转与不转
- [ ] 长搓做到快、深、低、转、有角度、落点隐蔽
- [ ] 正手搓击球点在右前方、前臂外旋开拍面；反手搓在腹前、前臂内旋开拍面
- [ ] 侧旋来球按"球往哪边偏"把拍面朝反方向对准，不按"左/右侧旋"的叫法死记
- [ ] 侧旋搓（反手搓偏、正手晃撇）只偶尔用，检查拐向是否如预期
- [ ] 搓完立即退回，准备挡或反拉对方的起板
- [ ] 知道什么时候不该搓：长球、半出台能拉就拉，短上旋该挑或拧
