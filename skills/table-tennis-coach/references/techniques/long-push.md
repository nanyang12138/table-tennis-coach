# 劈长（Long Push / Fast Long Push）

适用：接发球和台内相持中，把对方的短下旋、短不转球快速劈到我方对面端线附近的大角或追身｜难度：中（业余较易上手，但落点、伪装和衔接难）｜相关卡片：`../techniques/push.md` `../techniques/short-touch.md` `../techniques/forehand-flick.md` `../techniques/backhand-banana-flick.md` `../techniques/backhand-flick.md` `../techniques/receive.md` `../techniques/footwork.md` `../techniques/transitions.md` `../techniques/forehand-counter-block.md` `../techniques/backhand-block.md` `../fundamentals/racket-angle-timing-contact.md` `../fundamentals/spin.md`

> 全文按右手横拍写；左手持拍者左右互换。直拍劈长见 `../techniques/penhold.md`。
> 出处缩写：`LH:N` = Larry Hodges 文章 https://www.tabletenniscoaching.com/node/N ；`PS` = PingSkills 课程简介；`BK-词条` = 百度百科（可编辑百科，可信度中等）；`乒乓网-劈长` = 乒乓网《全民学乒乓横拍篇》第 45 集。完整链接见文末。
> 拍面角度沿用 CETV 定义：拍面与台面夹角，90° 为垂直，大于 90° 为后仰。本卡所有角度都只做定性描述。

## 1. 定义与用途

**劈长**：搓球（push）的一种，在台内把短球用"切、砍"的手法快速送到对方端线附近。特点是速度快、旋转强、线路长、出手凶狠（BK-劈长）。弧线两源说法不同：BK-劈长称"弧线低平"，乒乓网-劈长称"弧线长且顶""既长又上抬"；共同点是长、快、落到端线附近。中文维基把它和摆短、撇并列为台内接发球技术（"正、反手摆短、劈长（搓）、撇"）。

**用途**
- 接发球：处理短下旋、短不转发球，尤其是**弧线稍高但下旋不强**的球（乒乓网-劈长；BK-劈长）。
- 压缩对手的引拍时间：球快、落点深，对方来不及拉开引拍距离，上手质量下降甚至失误（BK-劈长）。
- 和摆短配合：劈长常与摆短组合使用，是使用率很高的一套接发球组合（BK-劈长）；两者如何互相配合见第 5 节"与摆短的伪装"。
- 发球抢攻轮：发短后对方回短，确实不好抢攻时，可先劈长到两大角，争取下一板再抢（BK-发球抢攻）。

**术语**：Hodges、PingSkills 的 push long / long push 本卡译作"长搓"，泛指把球搓长，不区分劈长和搓长；本卡引用它们时都按这个意思理解。

**定位提醒**：Hodges 说长搓（push long）是最容易的接短下旋方法，但要**为战术而选，不要因为别无选择才劈**（"Push long by choice, for tactical purposes"，LH:80）；对方如果一直拉你的劈长，就改挑或摆短（LH:33）。

**劈长与相邻技术的区别**

| 比较项 | 劈长 | 搓长 | 摆短 |
|---|---|---|---|
| 目的 | 速度、长度、压迫 | 旋转、稳定 | 控制弧线和落点，不让对方拉（BK-劈长） |
| 适用来球 | 弧线稍高、下旋不强的球（乒乓网-劈长） | 弱下旋球；旋转较强，但速度不及劈长（乒乓网-劈长） | 低、转、贴网的短球（BK-摆短） |
| 击球时间 | 上升后期或高点期，手感好可上升中期（乒乓网-劈长） | 资料未给出 | 上升期（BK-摆短） |
| 拍形 | 较立，比摆短更立（BK-劈长） | 动作与常规搓球相似（乒乓网-劈长） | 比劈长平（BK-劈长） |
| 发力 | 前臂带动手腕在触球瞬间突然加速，集中，撞击为主、撞摩结合（BK-劈长） | 摩擦为主，向前力量比常规搓多，动作相对平缓（乒乓网-劈长） | 前臂相对稳定，靠手腕把球"放"过去（BK-摆短） |
| 一句话 | "劈长以速度为先，搓长以旋转为先"（BK-劈长） | 同左 | 详见 `../techniques/short-touch.md` |

术语说明：表中"搓长"按乒乓网-劈长的用法（侧重旋转与稳定）。百度百科「接发球」里的"搓长"指"以速度和突然性取胜"的快搓底线长球，相当于本卡的劈长；Hodges 的 push long 也泛指长搓，不区分劈长和搓长（见上方"术语"）。

常规慢搓、快搓见 `../techniques/push.md`。

## 2. 三位标杆怎么做

**马龙**
- 劈长的个人特点：**暂无可靠出处**。
- 可确认的相关事实（是摆短，不是劈长）：接发球摆短后正手抢拉是他比赛中反复出现的得分套路（央视网 2017、2018 比赛报道）。劈长在他比赛中占多大分量，暂无可靠资料。

**张继科**
- 劈长的个人特点：**暂无可靠出处**。

**樊振东**
- 会在关键分使用：2019 年 T2 钻石赛半决赛对许昕，第四局赛点"接发球劈长得手"（央视网 2019-07-21，单场描述）。只能说明他会用、敢在关键分用，**不能说劈长是他的特长**。

**能学的是什么**：三人都没有可靠的劈长动作细节资料。本卡动作要领全部来自教学资料，不冒充"某某的动作"。

## 3. 动作分解

**正手劈长和反手劈长的整体差别**

| | 正手劈长 | 反手劈长 |
|---|---|---|
| 来球位置 | 正手位、中路偏右的短球 | 反手位、中路偏左的短球 |
| 上步 | "两步上一步退"：左脚先向右前迈，右脚插入台下（BK-劈长） | 上右脚发力更足但补正手慢；上左脚便于向右横移补正手（LH:33） |
| 挥拍方向 | 前臂和手腕向怀中内收（BK-劈长），即从右侧向左前下方"切" | 由身体左前方向前下方送出，以伸肘和前臂为主 |
| 触球部位 | 后中部或右侧中下部，接触点稍偏来球右侧（乒乓网-劈长） | 后中部或中下部 |
| 常用落点 | 劈到对方反手大角（BK-下旋球） | 劈到对方正手大角，尽量加转（BK-下旋球） |

说明：反手劈长没有找到专门的教学资料，下面反手一栏按搓球通用要领（BK-搓球、PS Backhand Push）和劈长的共同特点（较立、集中、撞击为主）写成。

### 3.1 准备

| 部位 | 正手劈长 | 反手劈长 | 常见偏差 |
|---|---|---|---|
| 脚/步法 | 接发球站位离台约一小步（BK-台内球）；两脚略宽于肩，前脚掌着地，随时能上步 | 同左 | 脚跟踩死，判断短球后迈不出去 |
| 膝 | 微屈、有弹性 | 同左 | 直腿站 |
| 髋 | 略前屈，朝向球台 | 同左 | 坐得太低或臀部后坐 |
| 腰/躯干 | 上体稍前倾 | 同左 | 上体后仰，离台太远 |
| 肩 | 放松、平 | 同左 | 耸肩、紧张 |
| 非持拍手 | 自然弯曲，放在腹前左侧（`../fundamentals/ready-stance.md` 2.7） | 同左 | 垂在身侧或背在身后，上步时身体容易晃 |
| 大臂/肘 | 肘在体前 | 同左 | 肘夹死在身侧 |
| 前臂 | 置于体前，略高于台面 | 同左 | 前臂垂到台面以下 |
| 手腕 | 放松，不提前锁死 | 同左 | 提前绷紧 |
| 手指/握拍 | 握稍虚，保留手腕灵活（握法见 `../fundamentals/grip.md`） | 同左 | 捏死拍 |
| 拍面/拍头 | 手位较高，不低于台面（BK-台内球）；拍放在正反手之间，**和准备摆短时完全一样** | 同左 | 拍放太低；一看要劈长就提前把拍摆开 |
| 视线/头 | 盯对方触球，判断长短、旋转强弱、弧线高低 | 同左 | 只看球不看对方拍 |

### 3.2 引拍（与上步同时完成）

| 部位 | 正手劈长 | 反手劈长 | 常见偏差 |
|---|---|---|---|
| 脚/步法 | 左脚先向右前迈，右脚插到台下（BK-劈长）；Hodges 主张所有短球都上右脚，够得最远；有人正手短球上左脚，正手站位舒服，但少了将近一英尺（约 30 厘米）够球距离，反手大角也空出来（LH:33） | 上右脚或上左脚都可以，各有利弊（LH:33，见上方"整体差别"表） | 不上步、伸手够球；上错脚，身体别扭 |
| 膝 | 右膝弯曲前顶，重心压低（BK-劈长："上身重心放低"） | 前脚膝前顶，重心压低（BK-搓球：重心"一定要压下来"） | 直腿弯腰 |
| 髋 | 随右脚前移，重心跟进到前脚（BK-劈长） | 随前脚前移 | 臀部留在后面 |
| 腰/躯干 | 上体前倾，与手臂、球拍形成一个整体（BK-劈长）；不需要大幅转腰 | 上体前倾，略含胸，正对来球 | 转腰引拍，动作变大 |
| 肩 | 右肩随上步送向来球 | 两肩基本平，右肩略前 | 右肩后撤拉大引拍 |
| 非持拍手 | 随右脚上步把左手抬起一些、略向左侧张开，平衡前探的上体（Hodges 对台内上步挑球的要求"left hand up some for balance"，LH:3129；劈长同样上步前探，照此做） | 同左；左手留在身体左侧，不挡在体前的挥拍路线上（通用要领） | 左手垂下，上步后上体左右晃，击球点跟着乱 |
| 大臂/肘 | 肘在身体右前方，手臂离身体近一些（BK-接发球对摆短的要求，劈长与摆短同手法，同样适用） | 肘在体前偏右，肘部略弯，为伸肘留空间 | 肘伸直、手臂过早伸进台内（BK-接发球对摆短的提醒） |
| 前臂 | 小幅上提到球的右后上方，引拍高度在台面以上（BK-搓球：大约与网同高） | 前臂收到腹前偏左上方，台面以上 | 引拍过大过高，节奏慢（乒乓网-劈长："动作幅度不宜大"） |
| 手腕 | 自然放松，略向后打开蓄力 | 略向内收（拍头指向左前）蓄力 | 手腕提前甩完 |
| 手指/握拍 | 保持虚握 | 同左 | 握紧，没有"抖"的余地 |
| 拍面/拍头 | 拍面稍后仰但较立，基本不做大幅调整（乒乓网-劈长："几乎没有大幅度调整板面"） | 同左；BK-搓球描述孙颖莎反手搓：引拍时拍面较立（一般搓球的描述，不是劈长专有） | 过早把拍面放得很平，暴露意图 |
| 视线/头 | 头随上步前移，眼睛盯球弹起 | 同左 | 抬头看对方站位，丢球 |

### 3.3 迎球挥拍

| 部位 | 正手劈长 | 反手劈长 | 常见偏差 |
|---|---|---|---|
| 脚/步法 | 右脚落地，重心踩实在右脚 | 前脚落地，重心踩实 | 脚还在移动就出手 |
| 膝 | 保持弯曲，不起身 | 同左 | 一出手就站直 |
| 髋 | 稳定，不再前冲 | 同左 | 髋部晃动，击球点乱 |
| 腰/躯干 | 前倾保持，躯干稳定作为"支架" | 同左 | 躯干前后晃 |
| 肩 | 稳定，不主动发力 | 同左 | 用肩抡 |
| 非持拍手 | 保持抬起、稳定，不跟着右手甩 | 同左 | 左手随挥拍乱摆，带动肩和躯干转动，拍面跟着变 |
| 大臂/肘 | 大臂基本固定，肘为支点 | 大臂略前送，开始伸肘 | 大臂大摆，动作大且慢 |
| 前臂 | 前臂向左前下方加速（BK-劈长："以前臂发力为主"） | 前臂向前下方加速 | 前臂速度均匀，没有"突然" |
| 手腕 | 跟随前臂，准备在触球瞬间抖动 | 同左 | 手腕先动、前臂不动，只靠手腕甩 |
| 手指/握拍 | 仍虚握 | 同左 | 过早握紧 |
| 拍面/拍头 | 拍面保持较立，对准球的右侧中下部 | 拍面保持较立，对准球的后中部偏下 | 迎球时拍面角度来回变 |
| 视线/头 | 头稳，盯球 | 同左 | 头跟着手动 |

### 3.4 击球瞬间

| 部位 | 正手劈长 | 反手劈长 | 常见偏差 |
|---|---|---|---|
| 脚/步法 | 重心在右脚，身体随动作向前跟出（BK-劈长） | 重心在前脚 | 重心向后坐，出球软 |
| 膝 | 弯曲稳定 | 同左 | 起身，拍面被带平 |
| 髋 | 稳定，随重心略向前送 | 同左 | 髋部上顶或后坐，带动拍面变化 |
| 腰/躯干 | 前倾，与手臂、球拍成一个整体（BK-劈长） | 同左 | 躯干后仰 |
| 肩 | 放松 | 同左 | 耸肩 |
| 非持拍手 | 仍抬在身体左侧，不低于髋；身体前探最多的这一刻也不碰球台 | 同左 | 左手掉到髋以下，平衡变差；扶台或撑台面：非执拍手触及比赛台面判对方得分（ITTF 规则 2.10.1.11） |
| 大臂/肘 | 肘不锁死 | 伸肘接近完成，但不完全锁死 | 手臂伸得笔直够球 |
| 前臂 | 前臂带动手腕突然加速，"切"或"砍"的感觉（BK-劈长） | 同左 | 推送而不是切 |
| 手腕 | 快速抖动（乒乓网-劈长："前臂带动手腕快速抖动"） | 同左；想加转可借前臂带手腕瞬间抖一下（BK-搓球） | 手腕僵硬，或手腕大甩、控制不住 |
| 手指/握拍 | 保持相对虚握、放松（BK-搓球），让手腕能快速抖动 | 同左 | 一直捏紧，手腕抖不起来 |
| 拍面/拍头 | 较立，接触后中部或右侧中下部，接触点稍偏来球右侧（乒乓网-劈长；BK-劈长） | 较立，接触后中部或中下部；BK-搓球描述孙颖莎反手搓：引拍时拍面较立、触球瞬间相对变平（一般搓球，不是劈长专有） | 拍面太平：冒高；太立：下网 |
| 视线/头 | 看到球离拍 | 同左 | 提前抬头看落点 |

### 3.5 随挥

| 部位 | 正手劈长 | 反手劈长 | 常见偏差 |
|---|---|---|---|
| 脚/步法 | 重心随动作向前跟出（BK-劈长），不再迈步 | 同左 | 收不住，冲进台下 |
| 膝 | 保持弯曲，前膝开始准备蹬地后撤 | 同左 | 随挥时站直，来不及蹬地后撤 |
| 髋 | 重心停在前脚上方，不再前冲 | 同左 | 髋继续前冲，重心压过前脚，退不回来 |
| 腰/躯干 | 保持前倾，随挥结束即起动还原 | 同左 | 随挥后起身看球 |
| 肩 | 放松，不跟着前送 | 同左 | 肩随手臂前探，身体被带进台内 |
| 非持拍手 | 留在体侧，配合前膝准备蹬地后撤 | 同左 | 左手随挥拍落下，重心收不住冲进台下 |
| 大臂/肘 | 大臂基本不动，肘仍在体前 | 肘随伸肘自然前送一点，不锁死 | 大臂跟着大幅前送，收不回来 |
| 前臂 | 沿出球方向短促前送，**击球后不要立刻停死**（BK-搓球纠错：前送力量不够、击球后动作停止是常见错误） | 同左 | 一碰即停，球短而软 |
| 手腕 | 抖完自然放松 | 同左 | 手腕继续翻转 |
| 手指/握拍 | 击球后放松回虚握，为下一板换拍形做准备 | 同左 | 一直捏紧，前臂僵、还原慢 |
| 拍面/拍头 | 指向目标方向，拍面仍后仰 | 同左 | 拍面翻成前倾（变成"拱"球） |
| 视线/头 | 跟球，同时看对方动作，判断下一板 | 同左 | 欣赏落点 |

随挥要"小而急促"（乒乓网-劈长）：随挥越长，还原越慢，对方的拉球就越容易抢在你前面。

### 3.6 还原（衔接准备）

| 部位 | 正手劈长 | 反手劈长 | 常见偏差 |
|---|---|---|---|
| 脚/步法 | 右脚蹬地退回（"一步退"，BK-劈长），回到能照顾全台的位置 | 上右脚的蹬右脚退回；上左脚的可以直接向右横移补正手（LH:33） | 人留在台前 |
| 膝 | 弯曲，准备迎接对方的拉球 | 同左 | 直腿站起 |
| 髋 | 随后撤回到两脚之间，略前屈对台 | 同左 | 臀部仍留在台下，退不出来 |
| 腰/躯干 | 上体保持微前倾，恢复对台姿势 | 同左 | 上体直起或后仰，接拉球时被顶 |
| 肩 | 放松、平，两肩对台 | 同左 | 右肩还探在台内 |
| 非持拍手 | 随右脚后撤收回腹前左侧，回到准备位置 | 同左 | 左手垂下或还停在台面上方，下一板转体不足、平衡差（`../fundamentals/ready-stance.md` 2.7） |
| 大臂/肘 | 肘回到体前，与身体保持自然距离 | 同左 | 肘夹死在身侧或仍伸在台内 |
| 前臂 | 抬到台面以上、体前 | 同左 | 手垂到台面以下，挡不及 |
| 手腕 | 放松，便于换成前倾拍形 | 同左 | 手腕还保持搓球时的后引角度 |
| 手指/握拍 | 握拍回到中立，虚握 | 同左 | 仍捏紧拍，换拍形慢 |
| 拍面/拍头 | 准备对付上旋（多半是拉下旋起来的加转弧圈）：拍面要能前倾 | 同左 | 还保持搓球的后仰拍面 |
| 视线/头 | 盯对方引拍判断线路 | 同左 | 只看自己的落点，不看对方引拍 |

还原到哪里有两种说法：Hodges 主张每板回中立位（LH:3731）；PingSkills 认为不应"盲目复位"，要跟着来球直接把拍放到下一板需要的位置（PS stop-coming-back-to-ready-position）。劈长后可以兼顾：先退出台下，再按自己的落点预判对方回球（见第 5 节末）。

## 4. 拍面角度、击球点、击球时间、触球部位

- **拍面角度**：后仰但"较立"，比摆短立（BK-劈长）；"几乎没有大幅度调整板面"（乒乓网-劈长）。具体角度：**没有可靠数字**，只按来球调（第 6 节）。
- **击球时间**（CETV 五分法：上升期→上升后期→最高点期→下降前期→下降后期）：上升后期或高点期；手感好可提前到上升中期（乒乓网用语，在五分法的上升期内、早于上升后期），球速更快（乒乓网-劈长）。比摆短晚一点（BK-劈长）。不要拖到下降期：球落下后只能慢搓，速度优势没了。
- **与 Hodges 的说法对照**：Hodges 认为一般搓球最差的击球时间是最高点，容易冒高（LH:3641）；他还说高水平选手长搓多在球刚弹起后快速出手（"push very quick off the bounce"，LH:80），比国内资料说的上升后期更早，手感好可以往前提。国内资料为什么认为高点期仍可劈长，没有找到解释；推测和较立的拍形、向下切有关（本卡推断，无直接出处；Hodges 对不转球要求"往下切"才不冒高，LH:3600）。如果你的劈长在高点打经常冒高，先把出手时间提前到上升后期。
- **击球点**：正手在身体右前方，台内、离身体不远；反手在身体正前方偏左。手臂不要伸直够球。
- **触球部位**：后中部或中下部；正手接触点稍偏来球右侧、切球的右侧中下部，"以避开球的旋转轴，减少失误"（乒乓网-劈长）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：脚先到位（上步、重心跟到前脚）→ 身体前倾与手臂、球拍"形成一个整体"→ 前臂加速 → 前臂带动手腕在触球瞬间突然加速、快速抖动（BK-劈长；乒乓网-劈长）。握拍全程相对虚握、放松（BK-搓球），手腕才抖得起来。腿和躯干负责"送位置"和稳定，主要发力在前臂和手腕。
- **方向**：下旋不强时以"由上向下"为主；下旋强时"由后上向前下"，向前成分多（BK-劈长）。
- **撞击与摩擦**：劈长"更强调撞击与速度"，撞摩结合（乒乓网-劈长；BK-劈长）；搓长侧重摩擦与旋转（乒乓网-劈长）。没有可靠的比例数字。实战还要**带足下旋**：Hodges 要求长搓"快、低、下旋足、到大角"（LH:80："push quick, low, with good backspin, to a wide angle"）；PingSkills 也说长搓要快，以调动对手，并带足下旋（PS When to Use a Fast, Long Push："the fast long push with heaps of backspin"）。纯撞没转的劈长，对方拉起来很轻松。
- **力量集中**：发力集中、突然（BK-劈长），引拍小、出手快。大引拍虽能加力，但会暴露意图、错过上升后期。

**落点与线路**
- **大角**：劈向对手端线两侧大角度（BK-劈长）。常用：正手位短球劈到对方反手大角；反手位短球劈到对方正手大角，尽量加转（BK-下旋球）。Hodges：落在大角、下旋足、够深的搓球比落在台中间的难拉（LH:35）。
- **追身**：劈向追身位（执拍手腋下），根据对手站位调动（BK-劈长）。对方站位偏一侧时，追身逼他让位。
- **深度**：据 Hodges 经验，长搓最好落在离端线约 6 英寸（约 15 厘米）以内；半深不深的搓球很容易被攻（LH:33、LH:35）。这是单一来源的经验值，不是标准。
- **变线**：对方开始预判你劈反手大角时，突然劈正手往往直接得分；劈对方正手大角后，你可以把他的回球挡到他反手，限制他连续正手进攻（LH:35）。

**与摆短的伪装**
- 原则：劈长和摆短出自**同一个准备姿势、同一个上步、同一个拍位**。BK-接发球称之为"搓长"（以速度和突然性取胜的快搓底线长球，即本卡的劈长），要求"手法要尽可能与摆短相似，以前臂发力为主，手腕的摆动不要过大"。
- 资料里两者的区别在最后一刻：摆短在上升期、轻、吸收来球力；劈长等到上升后期、拍形更立、前臂突然加速（BK-劈长；BK-摆短）。所以**引拍必须小**：引拍一大，对方立刻知道是长球。
- 出手时机差也会暴露意图：百度百科「摆短」提到高水平选手摆短也可以放到上升后期（该段原始出处未核实，仅作参考），这样摆短和劈长出手时机一致，伪装更好。初学者先保证同准备、同上步、同小引拍。
- 两者互相"养"：摆短把对方引到台前，他就怕深球（LH:33："leaving him vulnerable to a deep ball"）；反过来，偶尔突然劈长，又让你的每一板摆短更有效（PS Flick and Long Fast Push）。

**劈长后的衔接准备**
- 劈长后对方最可能的回球是**拉下旋起来的上旋球**（加转弧圈）。标准练法就是"发下旋—你搓—他拉—你挡"（LH:3445）。
- 预判线路：你劈了对方反手大角，就准备他的反手拉或侧身正手拉；劈了正手大角，准备他的正手斜线或直线。劈完立即退出台下（第 3.6 节），拍子回到台面以上。
- 对方拉得软、从反手角过来时，随时准备用快挡、反拉或扣杀打大角（LH:35）。挡加转弧圈要盖住拍面，见 `../techniques/backhand-block.md`、`../techniques/forehand-counter-block.md`；后续转换见 `../techniques/transitions.md`。
- 对方连续拉你的劈长，就别再劈：改挑或摆短（LH:33）。

## 6. 面对不同来球的调整

| 来球 | 怎么调 | 出处 |
|---|---|---|
| 下旋不强、弧线稍高 | 劈长最适合；拍形稍立，发力由上向下 | 乒乓网-劈长；BK-劈长 |
| 短不转球 | 可用劈长；拍形立，往下切，否则冒高 | BK-劈长；LH:3600、LH:3117 |
| 下旋强烈 | 拍形稍平（后仰幅度大），发力由后上向前下，前送多 | BK-劈长 |
| 极重下旋 | 拍面接近"朝天"，必要时触球时略向上托 | PingSkills 答问 push heavy backspin |
| 来球低、转、贴网 | 劈长时间不好抢，更适合摆短；硬劈容易下网 | BK-摆短；BK-劈长（劈长适合"稍高"的球） |
| 侧下旋 | 正手接触点稍偏来球右侧（乒乓网-劈长）；另按侧旋方向调拍面朝向，抵消侧拐（通用要领，无专门出处） | 乒乓网-劈长 |
| 短上旋、侧上旋 | 不宜劈：搓上旋或侧旋发球，球会从端线或边线飞出（LH:80："the ball will shoot off the end or side"）；优先挑打 | LH:80 |
| 出台长球 | 拉 | PS Effective Returns："topspin all long serves" |
| 半出台 | 能拉就拉；拉不起来、判断二跳不出台时按台内球处理 | 通用要领 |
| 错过上升期 | 快点做不了时可转为劈长 | BK-快点 |
| 正手位大角短球 | 正手劈长，上右脚 | BK-劈长 |
| 反手位短球 | 反手劈长，劈对方正手大角 | BK-下旋球 |
| 中路短球 | 横拍可用反手拧（BK-下旋球）；要劈长可劈追身或两角（BK-劈长） | BK-下旋球；BK-劈长 |

## 7. 关键数据参考

- **关节角度、拍速、时长**：本次检索没有找到搓球或劈长的同行评审运动学数据（本项目在 Europe PMC 的检索结果）。本卡**不给**肘角、腕角、拍速、拍面角度数字。
- **落点**：据 Hodges 经验，长搓落点离端线约 6 英寸（约 15 厘米）以内（LH:33、LH:35，单一来源）。
- **击球时间**：上升后期/高点期，手感好可上升中期（乒乓网-劈长）——这是定性分期，不是毫秒数。
- **视频测量误差**：单机位 MediaPipe 对前臂旋前旋后这类细小转动测量很差（RMSE 超过 30°，Shrestha 2026）。劈长主要靠前臂和手腕，骨架数据只能看大致姿势，拍面必须看放大图。
- **拍摄帧率**：动作小而快，用 120/240 fps 慢动作拍，导出后用 `--capture-fps` 校正（`../analysis/recording-guide.md`）。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 劈下网 | 来球下旋强还用很立的拍形；方向太向下 | 下旋强时拍形放平、向前下送（BK-劈长） |
| 劈出界或冒高 | 拍形太平；在下降期或高点偏晚击球；来球其实带上旋或侧旋（LH:80） | 拍形立、往下切（LH:3600）；提前到上升后期；先判断旋转 |
| 从边线飞出 | 来球带侧旋（或侧上旋）没判断出来，没按侧旋调拍面或接触点 | 先判断旋转，侧上旋不劈（LH:80）；侧下旋接触点偏来球右侧（乒乓网-劈长），按侧旋方向调拍面（通用要领） |
| 落点在台中间、半深 | 前送不够、击球后动作停住（BK-搓球纠错） | 前臂短促前送；用端线附近的目标练（第 9 节） |
| 被对方提前识破、轻松拉 | 引拍大；准备时就把拍面放平；只劈一条线 | 同摆短一样的准备和引拍；练大角、追身、变线（LH:35） |
| 球速慢、没压迫感 | 推送而不是切；没有"突然加速" | 前臂带手腕在触球瞬间突然加速（BK-劈长） |
| 劈得快但对方很好拉 | 纯撞没下旋 | 撞摩结合，保证下旋足（LH:80） |
| 手伸直够球、重心在后 | 没上步或上步不够；球点离身体过远（BK-搓球纠错） | 先脚后手，右脚插到台下，重心跟到前脚 |
| 动作大、节奏慢 | 引拍过大，大臂、肩参与 | 肘为支点，只用前臂和手腕；"小而急促"（乒乓网-劈长） |
| 劈完接不住对方的拉 | 不还原；拍面还是搓球拍面 | 劈完马上退；拍子回到台面以上，准备挡加转（LH:3445） |
| 一直劈长被对方连续抢拉 | 战术单一 | 改挑或摆短（LH:33）；多摆短，劈长作突然变化 |
| 手腕僵或乱甩 | 握拍太紧；全靠手腕 | 相对虚握、放松（BK-搓球）；前臂带手腕 |

更多错误索引见 `../training/errors-index.md`。

## 9. 练习方法（入门 → 进阶）

1. **徒手**：对镜做"左脚垫步→右脚上步→小引拍→切→蹬回"，体会先脚后手、引拍小、劈完马上退。
2. **自抛或定点多球**：同伴把弱下旋短球送到正手位，只劈对方反手大角；再从反手位劈对方正手大角。先求上台和低，再求速度（多球方法见 PS Match Drills with Multiball）。
3. **深度靶**：靶区放在对方端线内侧（可用毛巾或纸），靶的纵深据 Hodges 经验取约 6 英寸（约 15 厘米，LH:33、LH:35），只计落在靶区的球。
4. **线路**：斜线大角 → 直线大角 → 追身（执拍手腋下）→ 三点随机，每组固定一种。
5. **按旋转调拍形**：同伴混发弱下旋、强下旋、不转短球，你都劈长，体会拍形立和平的差别（BK-劈长）。不要两人对搓互练，那样只会适应同一种下旋（LH:3117）。
6. **摆短与劈长同手法**：同伴发短下旋，你用完全相同的上步和引拍，自己随机决定摆短还是劈长；同伴喊出他在你触球前猜到的是长还是短，猜对率越低越好。
7. **劈长后衔接**："发下旋—你劈长—他拉—你挡"，不打完这一分，马上下一球（LH:3445 的挡转练法）；熟练后改成打完。PingSkills 的组合："两板摆短后一板深搓对方攻""短下旋发球—长搓到正手—正手拉"（PS Playing Blockers；PS Match Routine Drills）。
8. **发球抢攻轮**：发短后对方回短，你练"劈长两大角—下一板抢攻"（BK-发球抢攻）。
9. **比赛**：接发球只许摆短和劈长，统计劈长直接得分、被对方抢攻得分各多少。

更多练习见 `../training/drills.md`。

## 10. 视频检查要点

**机位**：正手劈长从持拍侧（右侧）的侧面拍，略高于台面，看上步、膝、躯干前倾和前臂方向；反手劈长从正面或斜前 45° 拍。都补一个斜前 45° 机位看拍面和右脚是否插到台下（`../analysis/recording-guide.md`）。最好同时拍到球的落点，看深度和大角。手机 120/240 fps 慢动作，用 `--capture-fps` 校正。劈长动作小，脚本可能识别不到挥拍（`NO_STROKES`）。出现 `NO_STROKES` 时，按 `../analysis/metrics-reference.md` 处理：看 timeline 找到这一板，再用 `--strokes "ready,backswing_end,contact,finish,recovery"` 手动指定各阶段时间点；`--start/--end` 只用来缩短分析范围。指标的正负方向和含义以 `../analysis/metrics-reference.md` 为准。

| 阶段 | 关键帧看什么 | 对应指标（脚本输出） |
|---|---|---|
| 准备 | 站位离台约一小步，膝微屈，拍不低于台面；和摆短时的准备是否一样 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 引拍/上步 | 右脚是否插到台下；重心是否跟到前脚；引拍是否很小；是否转腰 | `weight_shift.backswing_end`（右脚上步时应偏向 0＝持拍侧脚）、`knee_min_deg.{playing,other}`、`trunk_lean_deg.backswing_end`、`backswing_ms`（应很短）、`shoulder_turn_deg`、`hip_turn_deg`（应很小） |
| 迎球 | 肘是否为支点，大臂是否大摆；前臂有无突然加速 | `elbow_angle_deg.backswing_end`→`.contact` 的变化、`elbow_body_gap_m`、`forward_ms`、`peak_hand_speed`（和自己的摆短比，劈长应明显更快） |
| 击球瞬间 | 击球点在身体前方、台内；手臂是否伸直够球；身体是否前倾；头是否稳；左手是否抬在身体左侧帮助平衡、没有扶台 | `contact_forward_m`、`contact_lateral_m`、`contact_height_level`、`elbow_angle_deg.contact`（接近 180° 说明伸直了）、`trunk_lean_deg.contact`、`head_motion`、`free_arm_height_level`（取击球帧；左手掉到髋以下多半说明平衡差，定性） |
| 随挥 | 挥拍方向以向前下为主，不应明显向上；随挥是否短；前臂是否一碰就停 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`、`follow_ms`、`elbow_angle_deg.finish` |
| 还原 | 是否马上退出台下；左手是否随后撤收回腹前左侧（目测，脚本的左手高度只取击球帧） | `weight_shift.{finish,delta}`、`recovery_dist` |
| 整体 | 正反手识别、发力顺序、数据可信度 | `side_guess`（与正手/反手劈长相符）、`sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`（动作小，参考价值低）、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

**拍面角度和手腕**：骨架模型测不出拍面，前臂旋前旋后也测不准（Shrestha 2026）。必须看击球前后的**手部放大图**（`stroke_NN_zoom.jpg`）目测：拍面是否"较立"、是否和来球旋转匹配；正手接触点是否在球的右侧中下部；触球瞬间手腕是否有快速抖动；随挥后拍面是否仍后仰。`quality.reliable` 为假，或手腕、手在 `low_visibility_parts` 里时，不下结论，按 `../analysis/recording-guide.md` 重拍。

**伪装检查**：把一板摆短和一板劈长的 `stroke_NN_sheet.jpg` 并排比较准备和引拍两格：两格看起来应几乎一样；`backswing_ms`、`elbow_angle_deg.backswing_end` 差别越小越好。

## 11. 自查清单

- [ ] 劈长是为战术选的（压对方的反手或正手大角、打乱节奏），不是因为不会别的
- [ ] 准备姿势、上步、拍位和摆短完全一样，对方看不出长短
- [ ] 正手位：左脚垫步、右脚插到台下，重心跟到右脚；反手位知道上右脚和上左脚各自的利弊
- [ ] 身体前倾，与手臂、球拍成一个整体；手臂没有伸直够球
- [ ] 上步时左手抬起保持平衡，击球时不低于髋，从不扶台
- [ ] 引拍小，在台面以上；肘为支点
- [ ] 在上升后期或高点期出手，不拖到下降期
- [ ] 拍形较立；来球下旋强时放平、向前下送；不转球时立、往下切
- [ ] 前臂带手腕在触球瞬间突然加速；握拍相对虚握、放松，手腕抖得起来
- [ ] 正手接触点在球的右侧中下部
- [ ] 既有速度也有下旋，落点深（靠近端线）
- [ ] 能劈斜线大角、直线大角和追身，并会根据对方的预判变线
- [ ] 劈完立即退出台下，拍子回到台面以上，准备挡或反拉加转弧圈
- [ ] 对方连续抢拉我的劈长时，会改用摆短或挑
- [ ] 上旋、侧上旋短球和出台长球不劈
