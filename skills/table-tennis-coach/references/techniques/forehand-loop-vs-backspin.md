# 正手拉下旋（Forehand Loop against Backspin）

适用场景：对方搓长、劈长、发长或半出台下旋、削球时由下旋转入进攻（起板）｜难度：中级→高级｜相关卡片：[正手拉上旋](../techniques/forehand-loop-vs-topspin.md)、[正手侧旋弧圈](../techniques/forehand-sidespin-loop.md)、[反手拉下旋](../techniques/backhand-loop-vs-backspin.md)、[搓球](../techniques/push.md)、[劈长](../techniques/long-push.md)、[削球](../techniques/chop.md)、[接发球](../techniques/receive.md)、[步法](../techniques/footwork.md)、[衔接](../techniques/transitions.md)、[战术](../techniques/tactics.md)、[直拍](../techniques/penhold.md)、[旋转原理](../fundamentals/spin.md)、[拍形/击球时间/部位](../fundamentals/racket-angle-timing-contact.md)

> 全文按右手持拍写，左手持拍者左右互换。方括号里的标记（如 [人民网]）对应文末"参考来源"。
>
> **直拍提示**：身体部分照本卡做。直拍正手与横拍的差别（准备时肘略外张、拍头指向右斜前方，拇指和中指用力，避免吊腕、手腕内收过多，正胶拉"小上旋"）见 [直拍](../techniques/penhold.md) 第 3 节。

## 1. 定义与用途

正手拉下旋就是用正手把对方的下旋球（backspin）摩擦成强烈上旋（topspin）回过去，是"先上手"最主要的手段。来球带下旋，碰拍后有往下走的趋势，所以动作要比拉上旋**起拍更低、更向上、拍面更开**；一旦拉成，对方要面对由自己的下旋"转换"来的上旋 [H3613]。

本卡覆盖的变化（按用途选，不是按水平选）：

| 变化 | 一句话特点 | 什么时候用 |
|---|---|---|
| 加转弧圈 / 高吊（heavy topspin loop） | 第一弧线高、慢，第二弧线下坠快，旋转最强 [BK弧圈] | 下旋重、来球低、位置不好；为下一板前冲创造机会 |
| 前冲弧圈（fast/drive loop） | 弧线低而长、速度快、落台前冲 [BK弧圈] | 下旋不太重、来球稍高或位置好；直接得分 |
| 慢转弧圈（slow spinny loop） | 力量几乎全变成旋转，慢、转、落点深 [H3587][H70] | 对重下旋，打乱对手挡和反拉；给自己回位时间 |
| 不转弧圈 / 假弧圈（no-spin loop） | 动作像加转，球却不太转；靠拍形和"推拉"做出，和下一行"假转"的区别见 6.8 [人民网] | 变化，让对方挡、反拉出界或冒高 |
| 假转弧圈（dummy loop） | 全幅度动作，但触球时有效摩擦少 [H66] | 同上，伪装更好 |
| "中国式"大力拉（overpower） | 大力吃进海绵，向前兼向上压过下旋 [H3613] | 体能好、训练多的球员；硬海绵更容易 |
| 拉半出台、拉长下旋、侧身拉、拉削球 | 见第 6 节 | 接发球、第三板、对搓、对削 |

侧旋弧圈单独见 [正手侧旋弧圈](../techniques/forehand-sidespin-loop.md)。

## 3. 动作分解

总原则：手臂放松、引拍低于来球、以身体转动带手臂、触球瞬间加速摩擦。下面的"加转"指高吊/加转弧圈，"前冲"指前冲弧圈；没注明的两者通用。

非持拍手（free arm，左臂）在各表最后一行。拉下旋引拍要压到右脚、转体幅度大，左臂的作用是让左右两侧身体一起转、稳住平衡：迎球时左侧向后"拉"、帮助转体 [H3223]，非持拍手垂下不动会转体变小、失去平衡（见 [发力与身体](../fundamentals/power-and-body.md) 2.1）。各阶段左臂的位置变化，除注明出处的，是本卡按"左臂随躯干转动"归纳的。

### 3.1 准备

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 左脚在前、右脚稍后，重心约在右脚 [人民网]；判断是正手长球后先用步法把球"放进"右侧击球区，再出手 | 不移步、伸手够球 |
| 膝 | 两膝微屈、内扣，前脚掌着地，脚跟略提 [BK弧圈] | 直腿站，后面无法下蹲 |
| 髋 | 微屈，髋放松，准备向右后转 | 髋僵 |
| 腰/躯干 | 上身略前倾，含胸收腹 [BK弧圈] | 后仰坐着等球 |
| 肩 | 放松，右肩略沉 [BK弧圈] | 耸肩 |
| 大臂/肘 | 自然放在体侧前方，肘不夹死也不外张 | 肘贴肋骨 |
| 前臂 | 放松，拍在身前中路 | 拍垂到身体右侧，回位慢 |
| 手腕 | 中立 | 提前下垂 |
| 手指/握拍 | 握松，见 [握拍](../fundamentals/grip.md) | 攥紧 |
| 拍面/拍头 | 拍在台面高度附近、身体前方 | 拍太高或太低 |
| 视线/头 | 看对方拍触球的方向和速度来判断旋转 [H79] | 只看球不看对方拍 |
| 非持拍手（左臂） | 自然弯曲，抬在体前偏左（腹前左侧）[CETV攻球][扬州职大]；放松，见 [准备姿势](../fundamentals/ready-stance.md) 2.7 | 垂在身侧或插腰：后面转体时左半身不参与 |

### 3.2 引拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到右脚（右脚前脚掌内侧）[人民网][BK弧圈]；侧身拉时右脚绕到足够远 [H42] | 重心留在左脚，拉不起来 |
| 膝 | 右膝屈曲加大，下旋越重屈得越多 [H3613][BK弧圈]；慢转弧圈要明显深蹲 [H70] | 只弯腰不屈膝 |
| 髋 | 右髋向右后"坐"下（引拍结束时持拍侧屈髋最多，见第 7 节 [B2020a]） | 髋不转、只摆手 |
| 腰/躯干 | 腰向右转，带动手臂向右后下方；转到重心能压到右脚即可，不要转成"掷铁饼" [BK弧圈] | 转腰过大 |
| 肩 | **右肩下沉**，拉重下旋时更要沉 [H50][H3613] | 肩平，像扣杀的肩位 |
| 大臂/肘 | 由腰带大臂向右后下展开，肘与前臂之间的夹角要打开，不要"拉肘向后" [BK弧圈] | 肘先往后拉、前臂没放下来 |
| 前臂 | 自然下垂（人民网写"手臂自然下垂伸直"[人民网]）；BK弧圈提醒手臂不能伸得太直、引拍不要过低 [BK弧圈]；研究中拉下旋引拍结束时肘屈曲约 27°（个体差异大）[B2020a]，即"接近伸直但不锁死" | 前臂夹在胸前；或手臂伸直锁死 |
| 手腕 | 中立或略后伸 [PS钩腕][BK弧圈]，不向内勾 | 腕内勾（钩手腕） |
| 手指/握拍 | 继续放松 | 攥紧拍柄 |
| 拍面/拍头 | 拍**低于来球** [BK提拉]，拍头朝下 [H3613]；起拍约在膝高或略高 [PS钩腕]；加转引得低，前冲比加转高一些但仍低于来球 [人民网][BK前冲] | 拍举得和球一样高去"打"下旋 |
| 视线/头 | 盯球的弹起与下落，判断击球时间；头稳定 | 头跟着手往后转 |
| 非持拍手（左臂） | 保持弯曲抬起，随腰髋右转一起向右移到体前，左肩跟着转进来 | 左臂留在左侧不动或垂下，上身转不过去，引拍只剩手臂往后拉 |

### 3.3 迎球挥拍

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚蹬地启动 [人民网]，力量由下往上传 | 脚没发力，只用手 |
| 膝 | 右膝开始蹬伸（"稍伸膝"[BK弧圈]）；慢转以向上蹬为主 [H70] | 一下子蹬直跳起来 |
| 髋 | 挺髋 [湖北经院]，髋向左转（本卡归纳） | 髋不动 |
| 腰/躯干 | 以竖轴为中心向左上转，不往前扑 [人民网][H3147] | 身体整体前冲 |
| 肩 | 右肩由低向前上转出，左侧身体同时向后"拉" [H3223] | 只转右边 |
| 大臂/肘 | 大臂带前臂，以肘为轴向**左前上方**挥出，轨迹是"小弧形"，不是直线 [BK弧圈] | 手臂直线前推 |
| 前臂 | 接近击球时迅速收缩、内旋 [BK弧圈]；收得太早、太晚都会"吃不住球" [BK弧圈] | 收臂时机不对 |
| 手腕 | 先保持稳定，触球前后才加速 | 过早甩腕 |
| 手指/握拍 | 仍放松，留给触球瞬间加力 | 全程紧握 |
| 拍面/拍头 | 加转：拍面接近垂直（"拍形成横立状"[BK弧圈]，PingSkills 认为最多开到垂直 [PS拍面选择]）；BK 的"提拉"教法（小动作、以小臂为主）说重下旋可稍后仰 [BK提拉]。初学以接近垂直为准，仍下网先改成更向上挥，再考虑稍后仰；前冲：拍面前倾 [人民网] | 拍面固定成攻上旋的前倾角 [BK提拉] |
| 视线/头 | 头稳定，只轻微前移 [H3147] | 低头、甩头 |
| 非持拍手（左臂） | 随左转向左后方"拉"，与右肩前送同时发生，帮助转体 [H3223] | 左臂垂下不动：转体变小、只剩右手发力 |

### 3.4 击球瞬间

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 右脚内侧蹬地，重心正在由右向左转移 [BK弧圈] | 重心已提前到左脚 |
| 膝 | 正在伸展；研究中持拍侧膝在击球时仍保持明显屈曲（第 7 节）[B2020a] | 击球前已站直 |
| 髋 | 转向前方 | 髋还在后面，手先到 |
| 腰/躯干 | 上身接近正对球台时击球 [BK弧圈]，躯干稳定 | 后仰"抬"球 |
| 肩 | 右肩向前上转动 | 肩停住，只剩手臂 |
| 大臂/肘 | 肘不完全伸直也不夹死 [BK弧圈][B2020a] | 手臂伸直僵打 |
| 前臂 | 快速收缩；正手拉时击球瞬间拍速与最大拍速几乎相同 [B2018] | 前臂松垮 |
| 手腕 | 熟练者可配合转腕加摩擦（"向前打击球后向上摩擦"[BK弧圈]；前冲时"手腕向内向前略为转动"[人民网]）；初学先保持腕基本稳定 [PS手腕] | 腕内勾或晃动 |
| 手指/握拍 | 食指适时压拍 [BK提拉]；手指抓紧球板 [BK前冲] | 一直松（拍面晃）或一直死紧 |
| 拍面/拍头 | 加转，两种来源分开看：人民网——下降初期摩擦中部或中上部 [人民网]；BK"提拉"教法——下旋越重，越击后中下方、拍面越后仰，摩擦大于撞击 [BK提拉]。前冲：触中上部 [人民网] | 摩擦太薄"飞碟"、打到拍边 [BK弧圈] |
| 视线/头 | 看着球碰拍 | 提前抬头看落点 |
| 非持拍手（左臂） | 仍弯曲抬着、在向后拉 [H3223]，和右侧前送形成"一拉一送" | 左手掉到髋以下或甩开，身体失衡 |

### 3.5 随挥

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 重心移到左脚 [人民网] | 重心停在右脚 |
| 膝 | 顺势伸展，不站直僵住 | 锁膝 |
| 髋 | 继续转到面向前方，力量送完再停 | 髋转到一半就停，力量没送出去 |
| 腰/躯干 | 绕竖轴转完，身体不前冲，结束时仍平衡 [H3223] | 身体扑出、失衡 |
| 肩 | 立即放松 [BK弧圈] | 肩紧，影响下一板 |
| 大臂/肘 | 向左前上方顺势收 | 收拍太低 |
| 前臂 | 收至额前/头侧 | 收到胸前就停 |
| 手腕 | 自然 | 腕向内勾到底 |
| 手指/握拍 | 放松 | 一直攥紧 |
| 拍面/拍头 | 收拍约在头高 [PS钩腕]；拉下旋"起得低、收得高"，下旋越重越竖直 [PS轻重下旋] | 收拍太低（三大错误之一）[PS三错误] |
| 视线/头 | 看回球，准备下一板 | 盯着自己的拍 |
| 非持拍手（左臂） | 收回到身体左侧，配合重心落到左脚，帮助身体在转完后停稳 | 左臂继续甩到身后，身体被带歪、回位慢 |

### 3.6 还原

| 部位 | 要领 | 常见偏差 |
|---|---|---|
| 脚/步法 | 用随挥的动量回位：正手位进攻后蹬右脚回；侧身后重心在左脚顺势蹬回 [H3425] | 打完原地看球 |
| 膝 | 回到微屈 | 站直 |
| 髋 | 回到面向球台的中立位，为下一板留出再次右转的余地 | 髋停在左转到底的位置，下一板来不及转 |
| 腰/躯干 | 回到略前倾 | 后仰 |
| 肩 | **准备抬起**：下一板常是对方的挡球，扣挡回来的球时右肩不要再沉 [H50] | 继续沉肩，下一板扣出界 |
| 大臂/肘 | 回到身前 | 手臂垂在身侧 |
| 前臂 | 拍从头侧收回到身前中路 | 拍停在头侧不收回 |
| 手腕 | 回到中立，不再下垂 | 仍保持拉下旋时的下垂 |
| 手指/握拍 | 放松，为反手留出换握时间 | 一直攥紧，反手来球来不及调整 |
| 拍面/拍头 | 准备下一板的上旋来球：拍面要前倾、动作更向前 [PS拍角][H36] | 还用拉下旋的开拍面去接挡球 |
| 视线/头 | 看对方拍，判断挡/反拉的方向 [H79] | 只看自己的球落点、不看对方拍 |
| 非持拍手（左臂） | 回到体前偏左、弯曲抬起，恢复准备姿势 [CETV攻球][扬州职大] | 停在身后或垂下，下一板又转不足 |

## 4. 拍面角度、击球点、击球时间、触球部位

**口径**：拍面角度＝拍面与台面的夹角，90° 为垂直，小于 90° 前倾，大于 90° 后仰 [CETV]。击球时间按上升期→上升后期→高点期→下降前期→下降后期五段划分 [CETV]。

**加转 vs 前冲对照**

| 项目 | 加转弧圈（高吊） | 前冲弧圈 |
|---|---|---|
| 拍形 | 接近垂直或略前倾 [BK弧圈]；PingSkills 认为最多开到垂直 [PS拍面选择]，BK"提拉"教法说重下旋可稍后仰 [BK提拉]，初学以垂直为限 | 前倾，比加转更前倾（教材数字互相矛盾，不给度数）[人民网][BK前冲] |
| 发力方向 | 更多向上，向前上方 [BK前冲][人民网] | 刻意向前，配合略向上 [BK前冲][BK弧圈] |
| 击球时间 | 高点期或下降前期 [BK弧圈]；人民网写下降初期 [人民网] | 上升后期或高点期 [人民网][湖北经院] |
| 触球部位 | 中部或中上部 [人民网]；"提拉"教法：下旋越重越击后中下方 [BK提拉] | 中上部 [人民网][湖北经院] |
| 站位/重心 | 稍远，重心低 | 更近台，重心稍高 [湖北经院][BK弧圈] |
| 引拍 | 低 | 比加转高一些，但仍低于来球 [人民网][BK前冲] |
| 落台声音 | 较闷 | 清脆 [BK前冲] |

**击球时间说法不统一**：拉强下旋可在下降期，爆冲提前到上升期 [BK弧圈]；提拉下旋在下降前期 [BK提拉]；拉前冲对强下旋要抢高点期或下降前期，甚至更早 [BK前冲]；慢转让球落到约膝高 [H70]。结论：**越想加转、下旋越重→越晚；越想速度→越早**。

**击球点**：身体右侧前方最好，只要在身体侧面即可，但**不能落到身体后方** [BK弧圈]；Hodges 建议更靠身体侧面（右腿旁），不要太靠前 [H2415]。离身体稍远便于手臂加速，但不要过远 [BK弧圈]。

**高手怎么调**：一项研究发现，面对不同旋转的下旋，高水平选手主要**调拍面角度**，而不是改挥拍路径的倾斜度 [IK2009]；教学网站则建议下旋越重挥拍越竖直 [PS轻重下旋]。两者不完全一致；业余球员初学时用更竖直的路径帮助过网，熟练后多靠拍面微调（这是本卡的建议，不是研究结论）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：蹬地 → 挺髋 → 转腰 → 收小臂 [湖北经院]；腿、腰、上臂、前臂依次传递 [人民网]。研究支持髋/骨盆转动对水平拍速的贡献 [I2018]，高水平选手下躯干转动贡献更大 [IK2009]。
- **方向**：加转更向上，前冲更向前（见第 4 节）。重下旋"多向上，兼向前，重点在上" [H3613]。
- **绕轴转，不前扑**：力量来自身体绕竖轴转动和左右两侧同时参与 [H3147][H3223]；击球太靠前会变成"只用手臂" [H2415]。
- **摩擦与撞击**："先打后摩，又打又摩，以摩为主"；向上发力时也要向前 [BK弧圈]。下旋越强，摩擦成分越大于撞击 [BK提拉]。前冲撞击成分更大，百度百科写作"以撞击为主结合摩擦" [BK前冲]。
- **吃进海绵的深浅**（Hodges 分档）：只擦胶皮（慢转）→中等吃进海绵（中等拉）→深吃海绵（强拉）→透到底板（杀板）[H3539]。"中国式"大力拉属于深吃海绵、向前兼向上压过下旋，需要体能，硬海绵更容易 [H3613]。
- **放松再加速**：手臂像橡皮筋一样放松 [H51]，力量集中在触球前后。研究里高手与中等水平击球时拍速没有显著差异，但高手加速所需时间趋于更短 [IK2009]——练的是"短促加速"，不是全程用力。
- **膝不好时的替代**：少屈膝，改为沉肩、拍放得更低，多用上身、手臂和手腕向上转出慢转 [H3613][H3587]。

## 6. 面对不同来球的调整

### 6.1 轻下旋 vs 重下旋
- 轻下旋：拍面可前倾些，击球早些，多向前，可以直接前冲 [BK前冲]。
- 重下旋：拍更低、拍头朝下、拍面开（接近垂直）、屈膝（尤其后腿）、沉右肩，**向上为主** [H3613]。仍下网就再抬高弧线，宁可出界 [H3613][H3501]。
- **不要用同一拍形和力量拉所有下旋** [BK提拉]。

### 6.2 长下旋（搓长、劈长、发长）
- **先判断长短**：确认球够长再拉；短了就改用挑打，不要硬拉 [H42]，见 [正手挑打](../techniques/forehand-flick.md)。
- **深而重的下旋**：拍放很低、拍头朝下、拍面开、屈后腿（右腿）、沉右肩，向上为主兼向前；下网就把弧线再抬高 [H3613]。这种球最容易因怕出界而拉下网，宁可出界 [H3501]。
- **瞄准更深的落点**：更高的过网弧线会让球落得更深，深球比落点短的球更难被反击；有人觉得直接瞄更深的落点更容易拉出够高的弧线 [H3634]。
- **让出空间**（本卡建议）：来球深、顶到身体时，先退半步或侧身让出击球空间，等球落到合适高度再拉。
- 可选慢转弧圈：落点要深，拉短了容易被攻 [H70][H3539]。

### 6.3 半出台下旋（第二跳在端线附近）
- 判断难点是长短：二跳就在端线上也足够长，可以拉，只需"稍微伸到台面上方" [H3723]。
- 两种处理：上前早触球搓/摆，或让球过来打一个更大的动作 [PS半出台1]；要一直留意够长的发球，用上旋进攻 [PS半出台2]。
- 拉半出台的动作调整（建议）：右脚上前到台下，引拍幅度小、以前臂和转腰为主，在高点期附近触球，避免拍碰台。马龙最想要的起板正是对半出台球 [EN2021]。
- 实在够不着、来球很低，可改用挑打/突击，见 [正手挑打](../techniques/forehand-flick.md)。

### 6.4 来球高低
- 来球偏高、下旋弱：前冲或直接扣 [BK弧圈]，见 [正手扣杀](../techniques/forehand-smash.md)。
- 来球很低：拍从更低处起，可以借鉴慢转的做法，让球再落一些 [H70，原文讲慢转]。

### 6.5 侧身拉下旋（侧身弧圈）
- 球在反手位、步法跟得上时用侧身正手拉，争取主动 [BK弧圈]。动作同正手拉，但要选对侧身时机、侧身到位，并调整引拍方向、出手角度和挥拍方向，**避免盲目侧身** [BK弧圈]。
- 步法：左脚小步→蹬转，右脚绕到足够远，肩至少与端线平行，重心在右脚；**右脚落地即开始前挥**；对方出手后再动 [H42]。要侧到底，侧一半更失衡 [H3658]。
- 风险：打得不好会空出正手位 [PS侧身]——马龙相持中的侧身习惯使正手大角度常特别空 [EN2021]；樊振东相持段侧身进攻打直线时，站位使击球距离偏短 [Jin2026]（两条都是相持中的统计，不专指拉下旋）。
- 步法细节见 [步法](../techniques/footwork.md)。

### 6.6 拉削球（攻削）
- **先读旋转**：只看对方触球瞬间拍的方向和速度 [H79]；削不转往往是触球点换到拍面别处、手腕动作少、触球更向前 [PS不转搓削]。削球手常在削加转后用相似手法削不转，诱你拉高 [CETV削攻]。
- **拉加转削**：按重下旋处理——拍更开、更向上、摩擦大于撞击 [BK提拉][H3613]。
- **拉不转削**：拍面压一些、触球更靠上、更向前，少往上提，否则冒高或出界（由慢转出界时的调整 [H3587] 和"下旋弱则少摩擦" [BK提拉] 推得）。
- 连续拉时，削球手削回来的球与搓球不同 [H2328]，每板都要重新判断。
- 战术：连续拉的能力加线路、落点、旋转、轻重变化；拉中突击、拉吊结合、拉搓结合 [扬州职大]；变换速度把削球手调前调后，不要每板都大力 [PS对削]。详见 [削球](../techniques/chop.md)、[战术](../techniques/tactics.md)。

### 6.7 从下旋转入进攻的衔接
- **起板时机**：发球抢拉（第三板）、接发球抢拉、对搓中突然转拉 [BK弧圈][扬州职大]。
- **第一板之后**：对方多半挡或反拉。下一板是上旋来球，要**马上换成拉/打上旋的拍形和方向**：拍面前倾、动作更向前 [PS拍角][H36]，右肩抬起扣挡球 [H50]。
- **手段**：拉加转→对方回高→前冲或扣杀；慢转→对方挡慢→再发力 [H70]。
- **回位**：靠随挥回位，打完保持平衡 [H3425]；肩部迅速放松，以利于连续拉和拉后扣杀 [BK弧圈]。见 [衔接](../techniques/transitions.md)、[正手拉上旋](../techniques/forehand-loop-vs-topspin.md)。

### 6.8 旋转变化
不转弧圈和假转弧圈目的相同（看着转、实际不转），做法不同：不转弧圈靠拍形稍后仰、手臂紧、向前推拉 [人民网]；假转靠触球前先甩腕或用靠拍柄处触球、动作做足 [H66]。
- **不转弧圈（假弧圈）**：在加转动作基础上，拍形稍后仰，触球中下部，手臂紧张些向前上方"推拉" [人民网]。**和加转怎么区分**：两者触球部位可以相近，差别在于加转快速薄擦、以摩擦为主；不转手臂绷紧、向前上"推拉"，撞击多、摩擦少 [人民网][BK提拉]。所以真想拉加转时，手臂要放松、薄擦，否则容易拉成不转（本卡建议）。
- **假转弧圈**：动作照做全，但触球前先甩腕（触球时拍头已经上翘），或用靠近拍柄的部位触球（加转用靠拍头处）；关键是动作要做足，收着做对方一眼就看出来 [H66]。
- **慢转弧圈**：不是软球，而是全力击球、力量几乎全转成旋转；让球落到约膝高，深屈膝，肩和拍头放低，蹬腿向上，薄擦，弧线稍高，**落点要深** [H3587][H70]。出界时不要减速，改为触球稍靠上、稍向前 [H3587]。

## 8. 常见错误：表现 → 原因 → 纠正

1. **下网远多于出界** → 怕出界、潜意识不敢往上拉；拍形太前倾 → 定规则"宁出界不下网"，抬高过网高度、瞄准更深的落点；录比赛统计下网/出界比例，目标是下网减少、出界可以暂时增加 [H3501][H3634][BK提拉]。
2. **"吃不住球"** → 收前臂过晚（爆发力没出来球已离拍）或过早（力量用完才触球）[BK弧圈] → 徒手练"转腰带臂、触球才收前臂"的节奏。
3. **钩手腕（腕向内勾、从低处勾到头顶以上）** → 手腕代替身体发力 → 膝高或略高起拍、拍面稍开、向上向前、收于头高；手腕中立或略上翘；近台练习限制大幅勾手，或沿腕背贴胶带提醒 [PS钩腕]。
4. **触球太晚、太平、收拍太低**（正手拉三大错误）[PS三错误] → 等球过来才动、套用打上旋的拍形和平的挥拍路径（本卡归纳）→ 提前到位、拍面开一些向上、收拍到头高。
5. **击球点太靠前、身体往前扑** → 用手臂代替转体 → 在身体侧面（右腿旁）触球，绕竖轴转 [H2415][H3147]。
6. **拉肘向后引拍** → 前臂没放下来 → 有意识让前臂下垂，配合脚和重心移动 [BK弧圈]。
7. **转腰过大（掷铁饼式）** → 影响向前发力 → 转到重心能压到右脚即可 [BK弧圈]。
8. **拍太前倾、摩擦太薄（"飞碟"、擦拍边）** → 套用拉上旋的拍形 → 拍面开到接近垂直，加大向上摩擦 [BK弧圈][BK提拉][PS拍面选择]。
9. **手臂直线前推，没有弧线** → 把拉当成攻球，只用手臂前推（本卡归纳）→ 以肘为轴向左前上方"小弧形"挥 [BK弧圈]。
10. **肩紧张、动作僵、肘上浮** → 常因肩紧 → 放松肩、压低肘 [BK弧圈][PS肘浮]。
11. **不沉右肩，重下旋拉不起；拉完扣挡球又出界** → 肩位没随来球换 → 拉下旋沉肩，扣挡球抬肩 [H50]。
12. **重心太高、拍高于球** → 不利于向上提拉 → 拍低于球，降低重心 [BK提拉]。
13. **所有下旋一个拍形** → 不判断旋转 → 先看对方拍，再选拍形和摩擦/撞击比例 [BK提拉][H79]。
14. **慢转拉成软而短的球** → 收着拉 → 全力但薄擦，落点要深 [H3587][H70]。
15. **侧身侧一半 / 盲目侧身** → 失衡、正手空当大 → 侧到底，右脚落地就挥拍 [H3658][H42][BK弧圈]。
16. **来球稍晚就转不动髋** → 来球稍晚、转髋不主动（论文对樊振东相持段的解读，不专指拉下旋）[Jin2026] → 提早判断、早移步，留出主动转髋的时间（本卡建议）。
17. **非持拍手垂下不动** → 只用右半身，转体小、拉完失衡 → 准备时左臂抬在体前，迎球时向左后"拉"，左右两侧一起转 [H3223]；可先徒手挥拍体会左臂向后拉（本卡建议）。

## 9. 练习方法（入门 → 进阶）

**入门**
1. 徒手模仿：对镜子或手机做完整动作，检查起拍约在膝高或略高、收拍到头高 [PS钩腕]；引拍不要过低 [BK弧圈]。
2. 多球，中路出台下旋，连续拉；从轻下旋开始，逐步加重，保持摩擦 [扬州职大][PS轻重下旋]。
3. 多球练"宁出界不下网"：只要求过网，出界不算错 [H3501]。

**中级**
4. 多球变长短、变旋转量，模拟真实搓球；组合"摆短→搓长→拉""短球挑→拉" [PS多球]。
5. 对搓中固定一方转拉 [扬州职大]。
6. 先拉固定落点，再拉不固定落点；1/2 台 → 2/3 台 → 全台 [扬州职大]。
7. 侧身拉：多球喂反手位下旋，练侧身步后正手拉，再回正手位 [H42]。

**进阶**
8. Hodges 三步：①多球；②发下旋（通常短）→对方搓长→拉→**打完这一分**，第一板可先拉固定点让对方挡好；按难度递进：搓一点 → 搓两点之一（需要移动）→ 搓正反手两大角之一（陪练开始伪装、快搓）→ 全台随机；③用同样的开局打计分比赛，高水平以"全台随机"为主 [H2328]。
9. 慢转专练：自己发下旋，对方回重搓，你全力慢转，力量全进旋转 [H3587]。
10. 对削连续拉（有削球陪练）：练加转削/不转削的判断与拍形切换 [扬州职大][CETV削攻]。
11. 拉扣结合、发球抢拉、接发球抢拉 [扬州职大]。

## 10. 视频检查要点

**机位**：首选侧面——站在持拍手一侧、镜头垂直于你面对的方向，全身入画；补拍正面或斜前 45°（看转体和重心左右移动）。用 120/240 帧慢动作；30 帧几乎拍不到触球那一下（见 [拍摄指南](../analysis/recording-guide.md)）。一段只拍一种：如"多球正手拉长下旋 8 板"。

| 阶段 | 关键帧里看什么 | 对应指标 |
|---|---|---|
| 准备 | 站位宽度、屈膝；左臂是否弯曲抬在体前偏左（看关键帧，脚本的 `free_arm_height_level` 取击球帧，不量准备帧） | `stance_width_ratio`（正面更准）、`knee_angle_deg.playing.ready`（侧面） |
| 引拍结束 | 右膝是否明显更屈、重心是否在右脚、右肩是否下沉、拍是否低于来球、躯干是否转出 | 侧面：`knee_angle_deg.playing.backswing_end`、`knee_min_deg.playing`、`trunk_lean_deg.backswing_end`、`elbow_angle_deg.backswing_end`；正面：`shoulder_width_ratio.backswing_end`（转体）、`weight_shift.backswing_end`（正面更准） |
| 迎球挥拍 | 是否先转髋再转肩再收前臂 | `sequence_ms.hip`、`sequence_ms.shoulder`、`sequence_ms.elbow`、`sequence_order_ok`、`hip_turn_deg`、`shoulder_turn_deg`、`x_factor_deg` |
| 击球瞬间 | 击球高度（拉下旋通常比攻球低，慢转约在膝高）、击球点在身体侧面还是太靠前、肘是否僵直；左手是否仍抬着、没掉到髋以下（掉下多半是转体和平衡配合差；是否在向后拉要看正面/斜前图） | `contact_height_level`、`contact_forward_m`、`contact_lateral_m`、`elbow_angle_deg.contact`、`elbow_body_gap_m`、`knee_angle_deg.playing.contact`、`free_arm_height_level`（击球帧左手腕高度） |
| 随挥 | 挥拍方向是否明显向上（加转、慢转更陡，前冲较平）、收拍是否到头高、重心是否移到左脚、头是否稳 | `swing_path.angle_deg`、`swing_path.up`、`swing_path.horiz`、`finish_height_level`、`weight_shift.finish`、`weight_shift.delta`（应为正；正面更准）、`head_motion`、`elbow_angle_deg.finish`；左臂是否收回体侧要看图 |
| 还原 | 手是否回到身前；步法是否借随挥回位要看图判断 | `recovery_dist`（只量手回到准备位置的距离） |
| 节奏 | 引拍、前挥、随挥时长；前挥越短、峰值越高，说明加速越集中（只做同一视频内比较） | `backswing_ms`、`forward_ms`、`follow_ms`、`peak_hand_speed` |
| 识别 | 是否识别为正手、数据是否可信 | `side_guess`、`quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable` |

**拍面角度必须看手部放大图**（击球前后各 2 帧）：骨架测不出拍面。看拍面是接近垂直、前倾还是后仰，拍头是否朝下，是否有勾腕。转体类指标（`hip_turn_deg`、`shoulder_turn_deg`、`x_factor_deg`）单机位不可靠，只作参考。所有数字只做同一机位前后对比和板与板之间的稳定性比较。

## 11. 自查清单

- [ ] 判断出下旋轻重和长短，再决定加转、前冲还是慢转
- [ ] 先移步，把球放到身体右侧，不伸手够球
- [ ] 重心压到右脚，右膝屈、右肩沉
- [ ] 拍低于来球，拍头朝下，拍面接近垂直（重下旋）或前倾（前冲）
- [ ] 前臂放下来，不拉肘、不勾腕
- [ ] 蹬地→挺髋→转腰→收小臂，触球才加速
- [ ] 在身体侧面触球，绕竖轴转，不往前扑
- [ ] 左臂抬在体前，迎球时向后拉、帮助转体，打完收回体侧
- [ ] 向上为主兼向前，收拍到头高
- [ ] 下网比出界少；出界时减少向上而不是减速
- [ ] 打完借动量回位，下一板换成拉上旋的拍形，扣挡球时抬肩
- [ ] 侧身就侧到底；对削先读加转还是不转
