# 反手发球（Backhand Serve）

适用：任何水平的主力或配套发球；短球控制、发低最省心｜难度：入门（反手侧上/侧下）→ 中级（转与不转、急长）→ 高级（反手逆侧旋、同一动作多种旋转）｜相关卡片：`../techniques/serve-basics-and-rules.md` `../techniques/serve-forehand-pendulum.md` `../techniques/serve-reverse-pendulum.md` `../techniques/serve-hook-and-squat.md` `../techniques/serve-fast-long-and-high-toss.md` `../techniques/receive.md` `../techniques/transitions.md` `../fundamentals/spin.md` `../fundamentals/grip.md` `../fundamentals/racket-angle-timing-contact.md`

> 本卡按右手横拍写；**左手持拍者左右互换**（"从左向右挥"变成"从右向左挥"，"右侧旋"变成"左侧旋"，站位偏左/偏右也互换）。直拍发球的握法调整见 `../techniques/penhold.md`。
> 拍面角度用"拍面与台面的夹角"：90° 为垂直，小于 90° 为前倾，大于 90° 为后仰（中国教育电视台《击球技巧》口径）。本卡没有可靠出处的角度一律只写定性描述。
> 引用格式：Hodges（node/N）对应参考来源里 tabletenniscoaching.com/node/N 那一篇。

## 1. 定义与用途

**反手发球**：用反手拍面发球，身体基本正对球台，球拍在身体左前方由左向右（或由右向左）挥动摩擦球。美国国家级教练 Hodges 把反手侧旋（backhand sidespin）列为赛场上占绝对多数的四种发球动作之一（另三种是正手钟摆、正手逆钟摆、正手 tomahawk——拍头朝上的正手发球，国内资料常称勾手，术语对应因资料而异，见 `../techniques/serve-hook-and-squat.md`），并说它是第二常见的发球，在初中级尤其多（Hodges（node/144））。

本卡覆盖的六种做法（旋转名称按右手持拍者、从发球方看）。挥拍是一个由左向右的小半圆：下行段 → 横向段 → 上行段（Hodges（node/28））：

| 做法 | 挥拍方向与触球段 | 旋转 | 用途 |
|---|---|---|---|
| 反手侧上旋（右侧上旋，side-topspin） | 左→右，在横向段转上行段的过渡处触球，拍向右上 | 右侧旋 + 上旋 | 短球让对方搓高、摆不短；长球逼反手 |
| 反手侧下旋（右侧下旋，side-backspin） | 左→右，在下行段转横向段的过渡处触球，拍向右下 | 右侧旋 + 下旋 | 短球防对方直接拉；和侧上旋互相掩护 |
| 纯下旋 / 纯上旋（少见） | 同一半圆；纯下旋在横移之前的下行段触球，纯上旋在横移之后的上行段触球 | 几乎无侧旋 | 变化 |
| 反手不转（no-spin） | 动作同加转；靠拍柄触球（Hodges），或同一触拍点靠手指手腕减少摩擦（乒乓网），见 3.4 | 很弱 | 和下旋配套，让对方搓高或下网 |
| 反手急长（急球、急下旋） | 同一动作，触球更低、更往前 | 上旋或下旋、速度快 | 偶尔突袭对方反手或中路 |
| 反手逆侧旋（又称反手逆旋转发球，reverse backhand serve） | 右→左 | 左侧旋；可带上旋或下旋成分（逆侧上、逆侧下，中文维基"乒乓球"技术列表） | 少见的高级变化；孔令辉曾用（Hodges（node/144）） |

**球的走向**（右手对右手）：普通反手发球的旋转与正手逆旋转发球相同（Hodges（node/144））。球在空中向接发球方的右侧拐（Hodges（node/34）："A backhand serve will break to your right."），对方如果用不对的拍面挡，回球往发球方的右侧、也就是你的正手方向偏（Hodges（node/144）："the spin will tend to put your return toward the server's forehand side"；中国教育电视台：对方挡住后"向其左侧上（下）反弹"）。

**优点**（Hodges（node/144）；日文维基"卓球"）
- 最好控制、最容易发低；同一动作能发出纯下旋、侧下、纯侧、侧上、上旋全谱，转与不转也好配。
- 发短到对方正手时侧旋向外拐，接发者常最后一刻伸手够球而失误。
- 日文维基：反手发球的站姿接近相持时，发完更快回到准备姿势，但旋转量一般不如正手发球（无第二来源）。

**弱点**（Hodges（node/144），必须知道）
1. **侧旋方向固定**：会反手逆侧旋的人太少，所以对方知道侧旋永远是同一个方向。
2. **很难用这个动作发快长**，少了一种重要变化（中国教育电视台课程里有"反手发急球"，能发，但不容易发得又快又隐蔽）。
3. **发完是反手站姿**，接下来要用正手衔接比较难。
4. 大家见得多，已经习惯。

## 2. 三位标杆怎么做（只写有出处的）

**马龙**
- 2020 年国乒奥运模拟赛按奥运标准严判发球，他"使用自己擅长的正手发球手法，结果被裁判直接判罚发球遮挡丢分……受此判罚影响，马龙只好改用反手发球"（央视网转《羊城晚报》2020-08-17）。说明反手发球是他的备用手段。
- 2024 年澳门世界杯男单决赛 0:3 落后林高远，"第四局开始，马龙增加了反手发球，这个变化让比赛逐渐回到了马龙最擅长的节奏"，最终 4:3 逆转（人民网 2024-04-22；"反手发球"这一细节只有人民网一家）。
- 独立分析博客 Edges and Nets（2021，单场观察）：国乒模拟赛对徐晨皓 4–8 落后时第一次使出反手发球，徐把马龙的第一个反手发球接冒高，第二个接下网；对周启豪时周也误判过他的反手发球；2020 世界杯对张本一文称他"还有反手发球等手段"。
- 他反手发球的具体动作（站位、拍形、旋转种类）：**暂无可靠出处**。上面几条只能说明"他在比分落后或需要变化时用过反手发球"，不能说成"招牌发球"。

**张继科**
- 反手发球：**暂无可靠出处**。英文维基写他"often employs the reverse-pendulum short serve"（常用正手逆旋转短球，该句标了 citation needed）；ETT 播客中教练看录像后说他的发球多为侧旋、也发侧下旋。见 `../techniques/serve-reverse-pendulum.md`。

**樊振东**
- 反手发球：**暂无可靠出处**。Edges and Nets（2021）写他在一个关键分"从球台反手一侧发了一个刁钻的侧旋球"（"served a tricky sidespin serve off the backhand side of the table"），但没说是反手发球还是正手发球，不能当作证据。央视网说他在 2017 年总决赛冠军点用了逆旋转发球（原文没有说明正手还是反手），见 `../techniques/serve-reverse-pendulum.md`。

**业余怎么借鉴**：从马龙的例子能学到的是用法——把反手发球当作"换节奏"的工具，在对方适应了你的正手发球时拿出来；而不是去模仿某个具体动作。

## 3. 动作分解

### 3.1 站位与准备
- **站位（球台左右）**：中国教材写"站位左半台"（百度百科"反手右侧旋发球"）；Hodges（node/3617）指出多数人习惯从反手角发，因为平时准备姿势身体就偏反手。反手发球的击球点在身体左前方，所以**人站在中间或略偏右**时，击球点大约落在球台中线附近：发对方正手短、反手长都有角度，发完离正手位也近。Hodges（node/3617）建议被对方适应后，把同样的发球换到中间或正手位去发，对方常会突然不适应。业余建议：先在中间偏左练稳，再把"中间"和"偏右"作为变化。
- **离台距离**：贴近球台，前臂伸出时击球点在端线后、台面以上即可（规则要求，见"规则要点"）。离太远球要飞得长，难发短。
- **脚**：两脚平行或右脚稍前，身体略向左偏斜（百度百科）。比相持站位略窄或相同，前脚掌着地。站太宽会让重心转移变僵；站成正手发球那样侧身则失去反手发球的意义。
- **膝**：两膝微屈（基本姿势，中国教育电视台《攻球技巧》）。想把击球点压低时屈膝降身体，不要只弯腰低头。
- **髋、腰/躯干**：上体前倾、收腹（中国教育电视台《发球方式》："注意收腹和转腰动作"）。腰略向左转，为向右挥拍留出空间。
- **肩**：两肩基本平行于端线或右肩稍前；放松，不耸肩。
- **大臂/肘**：持拍臂肘部抬起、离开身体，在身体前方，留出前臂横向挥动的空间。肘贴肚子会让拍子挥不开、只能"推"。
- **前臂**：大致与台面平行，横在腹前。
- **手腕**：放松，准备向内（掌心一侧）卷。
- **手指/握拍**：可以把后三指放松、虚握，让手腕更自由；拇指和食指控制拍面。PingSkills 发球握拍课用钟摆式发球演示，原理同样适用于反手发球（推断）。发完要立刻换回正常握拍（PingSkills 有专门一课讲发球握拍和相持握拍的切换）。握死了手腕甩不动，转不起来。
- **拍面/拍头**：拍在腹前偏左，拍头大致指向左方或左前方，反手面朝前。
- **不执拍手**：手掌张开、平放，球自然放在掌心；手静止在台面以上、球在端线之后（规则）。
- **视线/头**：先看对方站位，再看球；头稳定，眼睛跟球到触球。

### 3.2 抛球
- **方向**：近乎垂直向上，不能斜抛、不能让球旋转（规则 2.6.2；裁判手册解释为偏离垂直"只能几度"）。
- **高度**：**尽量低，但从手掌算起，球上升的距离至少 16 厘米**（规则 2.6.2），比一个网高（15.25 厘米）略多。参照物是"手掌到球最高点的距离"，不是球台网顶：反手发球时手掌本身就在台面以上，球的最高点高过网顶也可能上升不足 16 厘米，照样违例。Hodges（node/144）说反手发球好控制、能发低，关键之一就是把抛球降到尽可能低，但不能为求低而犯规。
- **为什么低**：抛得低，球下落速度慢、落点稳，触球时机好控制；低抛还让你在触球前最后一刻有更多动作空间来伪装（Hodges（node/144））。抛高能加转，但难控制（高抛见 `../techniques/serve-fast-long-and-high-toss.md`）。
- **抛球手之后**：球一离手，**不执拍手和手臂马上移出"球与球网之间的空间"**（规则 2.6.5），常见做法是向左下方收到身体左侧。
- **脚**：位置不动，重心偏左脚（百度百科：随后才从左脚移向右脚）。
- **膝**：保持微屈不动；抛球时跟着站起来，击球点就跟着变高。
- **髋、腰/躯干**：抛球的同时腰略向左转（百度百科："左手向上抛球的同时，腰部略向左转，右上臂内旋并向身体腹部的左侧方引拍"）。
- **肩**：放松，不随抛球耸起。
- **大臂/肘、前臂**：右上臂开始内旋，持拍手向腹部左侧引（百度百科）；动作连贯但不抢先——球还没离手就已经引完拍，后面只能停住等球，节奏断开。
- **手腕**：开始内卷，为甩腕蓄好距离。
- **手指/握拍**：保持准备时的虚握，不要在抛球时攥紧。
- **拍面/拍头**：拍面先不暴露旋转，各种旋转在这时看起来都一样（见"旋转变化与伪装"）。
- **视线/头**：眼睛跟着球上升，头不跟着抬。
- 做错了：从手掌算起上升不满 16 厘米或斜抛 → 判失分；抛得忽高忽低 → 触球时机每次不同，长短乱。

### 3.3 引拍
- **脚、膝**：重心偏左脚（百度百科：随后从左脚移向右脚）；膝保持弯曲，不站起来。
- **髋、腰**：腰向左转一小段，带动拍子到身体左侧；幅度小，以不破坏平衡为限。
- **肩、大臂/肘**：右上臂内旋，肘略抬、向前，把拍引到腹部左侧（百度百科）。
- **前臂**：向左、向身体方向收。
- **手腕**：向内卷（腕屈），拍头指向左后或左下，"蓄"住手腕。引拍时手腕伸直不卷，后面就没有甩腕的距离，转不起来。
- **手指/握拍**：后三指虚握，拇指和食指定住拍面；这时握紧，手腕就卷不深。
- **拍面**：发侧下旋时拍面开始后仰；发侧上旋时拍面较立（本卡据摩擦方向推断，无教学原文）。引拍时的拍面最好**各种旋转看起来都一样**（伪装要求，见"旋转变化与伪装"）。
- **视线**：盯住下落的球。

### 3.4 触球
- **时机**：球从最高点下落后才能击球（规则）；尽量等球落低、接近台面再击，越低出球越低（Hodges（node/32）："to serve low, one must contact the ball low to the table"；ETT："let the ball drop really low before you make contact"）。ETT 还提醒：很多人以为自己击球点已经低，其实在胸口高度。急球的击球点"在身体的左前侧与网同高或比网稍低"（中国教育电视台）。
- **击球点**：身体左前方、腹前偏左，在端线后、台面以上。不可离身体太远，否则手腕发不上力。
- **挥拍路线**：拍从左向右做一个小半圆（Hodges（node/28）半圆挥拍法；PingSkills 反手发球课："semi-circular swing and wrist movement"）。下行段触球出下旋、横向段出侧旋、上行段出上旋。
- **膝**：保持高度，不站起——站起来击球点就高了，球也跟着高。
- **髋、腰**：腰由左向右回转，"辅以腰部的转动"（百度百科）；发力主体不是腰。
- **肩**：放松不耸，右肩随腰略向右回转；耸肩会让前臂发紧、挥不快。
- **大臂/肘**：肘作支点，基本稳住，不大幅前后移动。
- **前臂**：由左向右快速挥动，带动手腕。
- **手腕**：由内卷快速向外甩（"充分利用手腕转动配合前臂发力"，中国教育电视台）。侧上旋时"手腕有一个上勾动作"。
- **手指**：触球瞬间拇指、食指微调拍面。
- **拍面与触球部位**：
  - 侧上旋："球拍从球的中部向右上方摩擦，手腕有一个上勾动作"（中国教育电视台《发球方式》）；拍面较立是本卡据摩擦方向推断，无教学原文。
  - 侧下旋："拍面稍后仰，击球瞬间球拍从球的中下部向右侧下摩擦"（中国教育电视台《发球方式》）。
  - 不转，两种方法：**方法 A**（Hodges）：同一动作，用靠拍柄的部位触球，那里即使全力挥拍也走得慢（node/144："contact the ball near the base of the blade"；node/583）。**方法 B**（乒乓网）：和下旋用"相同的触拍点和相似的动作"，拍面略立、不完全垂直，触球在拍的中下部、"靠近甜区下方"，触球瞬间靠手指和手腕减少摩擦、向上向前挑送。
- **摩擦方向**：拍子在触球时要有明显**向前**的分量，不要只横着擦球的背面——横擦时球要往前走、拍子却往侧面走，旋转和长短都难控制（Expert Table Tennis，专讲反手侧旋发球）。
- **拍头**：要转就用靠拍头的部位触球，那里线速度最快（Hodges（node/144）同一原理：靠拍柄慢、靠拍头快）。
- **重心**：由左脚移向右脚（百度百科）。
- **视线/头**：头稳定，看着拍子触球。

### 3.5 随挥
- **方向**：顺挥拍方向向右（侧上旋向右上、侧下旋向右下），但为了伪装，可以触球后立即反向夸张：发侧下旋往上侧收，发侧上旋往下侧收（Hodges（node/336）："When you serve side-backspin, follow-through up and to the side; when you serve side-topspin, follow through down and to the side."），用一个紧凑的小半圆，不要停住再反向。
- **幅度**：短球随挥短，手腕甩完即收；长球、急球向前送得多一些。
- **膝**：保持微屈，不随随挥站直。
- **髋、腰**：腰向右回转到大致正对球台即停，不继续转过头。
- **肩**：放松，随腰略转，不前探。
- **肘、前臂**：随挥结束时拍在身体右前方，肘仍在身前。
- **手腕**：甩完马上放松，不要一直绷着往前推。
- **手指/握拍**：随即准备换回相持握法。
- **拍面/拍头**：拍面随反向假动作翻转（发侧下旋时拍头往上带，发侧上旋时往下带），让对方看到的收拍方向和真实旋转相反。
- **重心**：落在右脚或两脚之间，不前扑。
- **视线/头**：触球后视线马上转向对方，看他的拍面和站位，判断回球。
- 做错了：随挥一直往前推 → 球出台；随挥时身体前扑 → 来不及还原。

### 3.6 还原与衔接
- **立刻还原**：逆旋转发球的教学口诀"完成发球动作之后，要立即还原，身体向后退半步到一步"（百度百科"逆旋转发球"），反手发球同理：发完离台稍远一点，给第三板留空间。
  - **脚**：两脚回到准备站位，必要时后撤半步。
  - **膝**：重新微屈，前脚掌着地，准备移动。
  - **髋、腰、肩**：转回正对球台。
  - **大臂/肘、前臂**：肘回到身前，前臂回到腹前。
  - **手腕**：回到放松的中立位置。
  - **手指/握拍**：换回相持握法（PingSkills 发球握拍课）。
  - **拍面/拍头**：拍回到身前，拍头回到准备方向。
  - **视线/头**：盯住对方回球。
- **反手站姿的问题**：Hodges（node/144）指出反手发球发完处于反手站姿，接正手衔接较难。对策：
  1. 发球前就想好第三板（Hodges（node/24）："Serve with a plan"）；
  2. 站位稍偏右、发完向右转体回中，正手覆盖更容易；
  3. 发短侧旋到对方正手，侧旋会让对方回球偏向你的正手——提前准备正手抢攻；但 Hodges（node/144）给接发方的建议是多回发球方的反手大角，所以这一路也要防。
- **衔接技术**：正手拉/攻见 `../techniques/forehand-loop-vs-backspin.md`、`../techniques/forehand-loop-vs-topspin.md`；发短下旋后对方最常搓长，反手第三板见 `../techniques/backhand-loop-vs-backspin.md`；对方挑打或回上旋时用 `../techniques/backhand-tear.md`；转换见 `../techniques/transitions.md`。

## 4. 拍面角度、击球点、击球时间、触球部位

| 做法 | 拍面 | 击球点 | 击球时间 | 触球部位 / 摩擦方向 |
|---|---|---|---|---|
| 侧上旋 | 较立（本卡推断），手腕上勾（中国教育电视台） | 身体左前方，尽量低 | 球下落、尽量接近台面 | 球的中部，向右上方摩擦；横向段转上行段处触球 |
| 侧下旋 | 稍后仰 | 同上 | 同上 | 球的中下部，向右侧下方摩擦；下行段转横向段处触球 |
| 纯下旋 | 更后仰 | 同上 | 同上 | 在半圆下行段（横移之前）触球 |
| 纯上旋（少用） | 较立或稍前倾 | 同上 | 同上 | 在半圆上行段（横移之后）触球 |
| 不转 | 略立、不完全垂直（乒乓网） | 同上 | 同上 | 方法 A：靠拍柄触球（Hodges）；方法 B：拍中下部、靠近甜区下方，减少摩擦、向前挑送（乒乓网） |
| 急球 / 急下旋 | 急球较立，急下旋稍后仰 | 身体左前侧，与网同高或稍低 | 球落低时 | 向前发力多，手腕抖动；第一落点靠近本方端线 |
| 逆侧旋 | 依上下旋调整 | 身体右前方到正前方 | 同上 | 拍由右向左摩擦 |

出处：中国教育电视台《发球方式》；Hodges（node/28、node/144）；乒乓网"高阶反手迷惑性不转与下旋发球"（逆侧旋一行只按挥拍方向推出，无教学出处）。具体角度数值：**暂无可靠出处**；有研究发现不同运动员发球拍面角相差很大（Ngo 2017），所以不存在"标准度数"，以出球效果来调。

**第一落点**：发短球第一落点不要太靠网，也不要靠端线（中国教育电视台写"发球的第一落点在球台，不要离网太近"；百度百科"发球"词条写"在球台中区"；ETT 用"网像镜子"的说法：第一跳离网越近，第二跳也越近网）；发长球第一落点靠近本方端线（中国教育电视台；PingSkills）。

## 5. 发力：顺序、方向、摩擦与撞击

- **顺序**：抛球时腰左转、引拍 → 腰向右回转起头 → 前臂由左向右加速 → 手腕最后甩出。"以前臂和手腕发力为主，辅以腰部的转动"（百度百科）；发短球时"手腕的力量大于前臂的力量"（中国教育电视台）。腿只负责稳住重心和由左向右的小幅转移。
- **方向**：主方向向右，同时有向前的分量；侧上旋带向上，侧下旋带向下。
- **摩擦与撞击**：旋转发球以摩擦为主——拍子全速加速但只"擦"到球（Hodges（node/24）："accelerate your racket to full speed, and then just graze the ball"）；球吃进海绵越多，球越快、越难转、越难短（ETT）。不转球反过来：减小摩擦、增加向前推送（中国教育电视台："减小拍面后仰角度，增加前推的力量"）。急球摩擦少、撞击多。
- **放松**：拍速来自放松的前臂—手腕鞭打，不要刻意死甩手腕（ETT）。
- **别往下砍**：向下砍球会让球在对方台面弹高（Hodges（node/32）："Part of serving low ... is serving without hitting the ball downward into the table"；ETT："Don't hack the ball straight down onto the table"）；要"加速 + 擦"，让球轻轻飘落在本方台面。

## 6. 面对不同情况的调整

- **落点组合**：中国教育电视台建议反手侧旋"发球落点以左方斜线长球配合中右近网短球为佳"（即长球斜线压对方反手，短球放对方中路偏正手）。Hodges（node/144）也说这个发球发短到对方正手特别有效（侧旋向外拐）；右手发球员的反手发球发给右手接发者的正手通常更难接（Hodges（node/30））。
- **对方习惯了**：换站位（中间、偏右）发同样的球（Hodges（node/3617））；或加入急长、逆侧旋。
- **对方早早侧身等长球**：偶尔发急长到对方正手大角；急长只能偶尔用，用多了失效（Hodges（node/29、node/71）讲快长的通用战术）。
- **左手接发者**：你看过去球台左侧是右手者的正手、却是左手者的反手。球仍往这一侧拐，所以发到这里，对左手者就是往他反手外侧拐；要按对方持拍手重新选落点。
- **双打**：规则要求发球从本方右半区落到对方右半区（规则 2.6.3），站位要偏右，落点范围更窄。
- **紧张或严判发球时**：Hodges（node/144）说反手发球常是最容易控制的发球；马龙在模拟赛严判发球时也改用了反手发球（见第 2 节）。

## 规则要点

完整条文见 `../techniques/serve-basics-and-rules.md`。和反手发球最相关的几条（ITTF 规则 2026；ITTF 裁判手册第 17 版）：
1. 发球开始时，球自然放在静止、张开的不执拍手掌上；手要先在台面以上静止，不能从台下一个连续动作上抛（2.6.1；手册 10.2.2）。
2. 近乎垂直上抛、不加旋转，**离开手掌后至少上升 16 厘米**（2.6.2）。量的是从手掌算起的上升距离，不是球离台面多高；"抛过网顶"不等于合法。反手发球追求"低抛"，最容易在这条上被判。
3. 球从最高点下落后才能击球（2.6.3；手册 10.4.1）。
4. 从发球开始到击球，球要在台面以上、端线之后，不得被身体或衣物遮挡（2.6.4）。反手发球时球在身体前方，上身前探时要注意球仍在端线后。
5. 球一抛起，不执拍手和手臂必须移出"球与球网之间的空间"（2.6.5）。
6. 裁判"拿不准"时一场只警告一次；明显违例不先警告，直接判分（2.6.6.1；手册 10.6）。
7. 自 2002 年起禁止遮挡发球（Jin & Ma 2026），伪装只能靠动作。

## 旋转变化与伪装

**同一动作出不同旋转**（Hodges、PingSkills、中国教育电视台）
- 起始站位、引拍、收拍保持一样，只改变触球（PingSkills "Service Disguise"）。
- 半圆挥拍：下行段触球 = 下旋，横向段 = 侧旋，上行段 = 上旋；侧下在下行段转横向段处、侧上在横向段转上行段处触球；挥得快，对方看不清在哪一段触到球（Hodges（node/28）；PingSkills 反手发球课）。
- 多发侧上、侧下，少发纯上、纯下——侧旋成分让对方更难判断（Hodges（node/28））。

**转与不转**（两种方法，出处不同）
- 方法 A（Hodges（node/27、node/144、node/583））：动作和加转完全一样、同样用力，只换触球部位，用靠拍柄的部位触球。
- 方法 B（乒乓网）：触拍点相同、动作相似，触球瞬间靠手指和手腕的精细控制减少摩擦、向上向前挑送。
- 不转的价值来自"有旋转的威胁"——先让对方吃过真转，不转才有用（Hodges（node/583））。

**随挥假动作**
- 触球后立刻反向夸张随挥（见 3.5），对方本能地把向下的动作读成下旋、向上读成上旋（Hodges（node/336））。
- 触球前后突然改变方向的"双重动作"（Hodges（node/3448）的例子是正手；反手同理）。

**反手逆侧旋（反手逆旋转发球，reverse backhand serve）**
- Hodges（node/144）：可以由右向左挥发反手逆侧旋，"伟大的中国选手孔令辉曾经这样发"，但多数人觉得难，所以少见；会正反两种侧旋的人能形成"一二组合"，解决反手发球"侧旋方向固定"的弱点。
- 中文维基"乒乓球"的技术列表里反手发球包括逆侧旋、逆侧上旋、逆侧下旋，即可以带上旋或下旋成分。
- 动作要点：拍从身体右前方向左挥过球，旋转方向与普通反手发球相反（左侧旋），球在空中向对方左侧拐。**具体手法（拍形、腕的用法、逆侧上与逆侧下怎么区分）暂无可靠教学出处**，以上只按旋转方向说明。练法可借用 PingSkills 对正手逆旋转发球的顺序：先练纯侧旋，再加下旋（借用属推断）。

**变落点、变长短**
- 短球为主，配合半出台（第二跳在对方端线附近，让对方拿不准出不出台，Hodges（node/583））和偶尔急长。
- 变化旋转"量"可能比变化旋转"种类"更有效（PingSkills）。

## 8. 常见错误：表现 → 原因 → 纠正

| 表现 | 原因 | 纠正 |
|---|---|---|
| 发不短，总出台 | 擦得不够薄（吃进海绵）、触球点太高、第一落点太靠端线 | 只擦胶皮表层；等球落低；第一落点放到本方半台中部（Hodges（node/583）、ETT） |
| 球弹得高 | 向下砍球、击球点高 | 拍子向前加速擦，让球飘落（ETT、Hodges（node/32）） |
| 旋转弱 | 手腕没蓄（引拍不卷腕）、握拍太紧、只横擦球背面、用拍中间触球 | 引拍卷腕、后三指放松、加向前分量、用靠拍头部位触球 |
| 侧旋、下旋、不转一眼被看穿 | 引拍和随挥每种旋转都不同；不转时动作明显变慢 | 统一引拍和收拍；不转也全速挥；加反向随挥 |
| 抛球被判 | 从手掌算起上升不到 16 厘米、斜抛、抛前手在台下或在动 | 侧面拍视频看球离掌后的上升距离，或在手掌旁放一个约 16 厘米长的物体作参照；抛前手先静止在台面以上 |
| 不执拍手挡在球和网之间 | 抛完手停在原处 | 抛完立即把手向左下收到身侧 |
| 发完第三板正手来不及 | 发完还停在反手站姿、身体前扑 | 发前想好第三板；站位略偏右；发完立即还原、后撤半步 |
| 急长下网或出界 | 触球点高、往下打、第一落点离端线远 | 让球落低、往前打，第一落点贴近本方端线（中国教育电视台、PingSkills） |
| 只会一种侧旋 | 没练逆侧旋、只靠单一动作 | 把转与不转、长短、落点练成套；有余力再学逆侧旋 |

## 9. 练习方法（入门 → 进阶）

1. **徒手**：对镜做"抛球—卷腕引拍—半圆挥拍—还原"，检查抛球手是否移开、各旋转的引拍是否一样（扬州职大教学步骤"徒手作发球前的预备姿势"）。
2. **离台擦球**：先离开球台练，体会薄而快的摩擦（PingSkills："practising away from the table first"）。
3. **单项多球**：一筐球，只练反手侧下短球，第一落点固定在本方半台中部；再练侧上短球。目标：对方台面弹两次（Hodges（node/30）定义的"短球"）。
4. **抛球标准化**：侧面拍视频，看球离掌后的上升距离；或在手掌旁放一个约 16 厘米长的物体作参照，确认每次上升都够、近乎垂直。不要拿网顶作参照。
5. **转与不转对比**：同一动作交替发下旋和不转（方法 A 或 B 选一种），请同伴搓回，看能否分辨；分辨不出说明伪装合格。
6. **同引拍 + 反向随挥**：侧上和侧下用同一个引拍交替发，每球都做反向随挥；同伴每球喊出他判断的旋转，统计他判对的比例，比例越低说明伪装越好。
7. **落点**：在对方台面放目标（正手短、中路、反手长），每个落点 10 球计成功数。
8. **换站位**：同一组发球，在中间偏左、中间、偏右各发 10 个，记录落点成功率，以及发完后第三板正手准备是否到位。
9. **急长**：每发 5 个短球插 1 个急长，动作前段不变。
10. **发球 + 第三板**：发反手侧旋短到对方正手，同伴按 Hodges 的分析把球摆或挑到你的正手方向，练发完立刻正手抢攻（见 `../training/drills.md`）。
11. **进阶**：反手逆侧旋，先练纯侧旋再加下旋；再把普通反手侧旋与逆侧旋做成同一引拍下的"一二组合"。
12. **比赛化**：练习赛中规定某局只能用反手发球，逼自己用旋转、落点、长短去变化。

## 10. 视频检查要点

**机位**（见 `../analysis/recording-guide.md`）
- 主机位：**侧面**，从你的右侧、与台面差不多高，全身和整张球台入画。看抛球从手掌算起的上升距离、抛球是否垂直、击球点高低、身体前倾。
- 补充机位：**正面**（对面）或右前 45°，看不执拍手有没有移开、球有没有被挡、挥拍是否由左向右、站位在球台左右哪里。
- 慢动作 120/240 帧；文件帧率与拍摄帧率不同时加 `--capture-fps`。
- **拍面角度、握拍、触球部位（拍头还是拍柄）骨架测不出来**，只能看手部放大图：自动模式是 `stroke_NN_zoom.jpg`，手动模式是 `measured_NN_zoom.jpg`（击球前后各 2 帧）。
- 球不被脚本追踪：抛球高度、第一落点、球的弧线**只能看关键帧和 timeline 图目测**，没有指标。
- 发球手速低、动作小，自动分板常找不到（`NO_STROKES`）。按 `../analysis/analysis-protocol.md` 第 4–6 步：先用 `--timeline` 出密集画面，再用 `--strokes` 手动给出 5 个时刻：ready = 球在掌上静止、backswing_end = 拍引到腹前左侧最远、contact = 触球、finish = 随挥最远、recovery = 回到准备姿势。
- **看抛球**：5 个时刻都不覆盖"球离掌"和"球到最高点"。用 `--timeline <球离掌前约 0.2 秒> <触球时刻> <1/帧率>` 出逐帧画面，在侧面机位里找两帧：球刚离开手掌、球到最高点，比较两帧之间球上升的距离和水平偏移；正面机位看球离掌后不执拍手是否已经移开。

**各阶段看什么，对应哪个指标**（指标定义见 `../analysis/metrics-reference.md`）

| 阶段 | 关键帧里看什么 | 指标 |
|---|---|---|
| 识别 | 是否识别为反手、击球点在身体左前方 | `side_guess`、`contact_lateral_m` |
| 站位与准备 | 站在球台中间/偏左/偏右；两脚宽度；膝微屈；身体正对球台 | 图上目测站位；`stance_width_ratio`、`knee_angle_deg.playing.ready`、`knee_angle_deg.other.ready` |
| 抛球 | 近乎垂直、从手掌算起上升够 16 厘米；抛前手静止在台面以上；抛后手移开（看法见上面"看抛球"） | 只能目测 timeline 逐帧图；`free_arm_height_level` 只能说明手的高低，**是否离开球与网之间的空间要看正面图** |
| 引拍 | 腰左转、拍到腹前左侧、手腕卷起；各种旋转引拍是否一样 | `backswing_ms`、`elbow_angle_deg.backswing_end`、`shoulder_turn_deg`（单机位只作参考）、`trunk_lean_deg.backswing_end` |
| 触球 | 击球点低、在身体左前方；膝不站起；肘在身前稳住；头稳 | `contact_height_level`（越低越好；只用来比较同一视频各板之间或练习前后的变化，不设硬门槛）、`contact_forward_m`、`elbow_body_gap_m`、`elbow_angle_deg.contact`、`trunk_lean_deg.contact`、`knee_angle_deg.playing.contact`、`knee_angle_deg.other.contact`、`head_motion` |
| 触球（手部放大图） | 拍面立/后仰；触球用拍头还是靠拍柄；是否擦球 | 只能目测 zoom 图 |
| 挥拍方向 | 是否由左向右的小半圆 | 由左向右只看 timeline 和 sheet 图；`swing_path.horiz` 只有大小、没有左右方向。`swing_path.angle_deg` 反映的是随挥结束时的方向，用了反向假动作就不能拿它判断旋转种类，只能比较同一种发球各板之间稳不稳定；`forward_ms` |
| 随挥 | 短、收得快；有没有反向假动作 | `follow_ms`、`finish_height_level`、`elbow_angle_deg.finish` |
| 重心 | 左脚到右脚的小幅转移；不前扑 | `weight_shift.backswing_end`、`weight_shift.finish`、`weight_shift.delta`：右手反手发球时 backswing_end 偏向 1（左脚），finish 偏向 0（右脚），delta 应为负（和正手相反）；发球转移幅度小，接近 0 也算正常；脚被挡住时为 null |
| 还原与衔接 | 发完多快回到准备姿势、是否后撤 | `recovery_dist`；图上看 recovery 时刻 |
| 伪装一致性 | 加转和不转是否同样快、同样路线 | 比较各板 `peak_hand_speed`、`backswing_ms`；同一种随挥方式下再比 `swing_path.angle_deg`：差异大说明动作暴露 |
| 发力顺序 | 腰先、前臂、手腕最后 | `sequence_ms.hip`、`sequence_ms.shoulder`、`sequence_ms.elbow`、`sequence_order_ok`（发球转体很小，单机位测不准，只作提示） |
| 可信度 | 数字能不能信 | `quality.pose_coverage`、`quality.mean_visibility`、`quality.low_visibility_parts`、`quality.reliable`；正面机位的肘角、膝角误差大 |

## 11. 自查清单

- [ ] 站位：能在中间偏左、中间、偏右三个位置发同一个发球。
- [ ] 球在静止张开的掌上，手在台面以上、球在端线后。
- [ ] 抛球近乎垂直，从手掌算起每次上升至少 16 厘米（比一个网高略多），但不高。
- [ ] 抛完不执拍手立刻离开球与网之间。
- [ ] 引拍：腰略左转，拍到腹前左侧，手腕卷起，肘在身前。
- [ ] 侧上、侧下、不转的引拍看起来一样。
- [ ] 等球落低、接近台面再触球，触球时膝不站起；急球与网同高或稍低。
- [ ] 侧上旋：球中部向右上擦，手腕上勾；侧下旋：拍稍后仰，中下部向右下擦。
- [ ] 不转：同样全速挥，靠拍柄触球（或同一触拍点减摩擦、向前挑送）。
- [ ] 摩擦有向前的分量，不横擦球背面、不往下砍。
- [ ] 短球在对方台面能弹两次；长球第一落点贴近本方端线。
- [ ] 会用反向随挥做假动作。
- [ ] 发完立刻换回相持握拍、还原，第三板有准备（尤其正手）。
- [ ] 知道反手发球的弱点：侧旋方向固定、难发快长、正手衔接难，并各有对策。
