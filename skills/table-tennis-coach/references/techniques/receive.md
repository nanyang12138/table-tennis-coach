## 1. 接发球的任务与总原则

发球是一个回合里最难预测的一板，所以接发球难（英文维基 Table tennis）。总原则三条：

1. **长球要攻**：出台的发球尽量拉（不会拉就打），因为你离对方远、角度小，消极回接等于给对方充裕时间准备抢攻（LH:80、LH:257）。
2. **短球要变**：短下旋、不转要会挑、摆短、劈长三样，互相变化；短侧上、短上旋以进攻为主：正手挑，反手用缩短动作的反手快攻/弹（LH:80）；也可反手拧拉（PS:table-tennis-receiving-techniques/attacking-short-serves）。
3. **先控制再发力**：发球变化（旋转、速度、长短、方向）比相持球多得多，所以接发球要**缩短动作换控制**（"To control your return of serve, shorten your stroke."，LH:3242）。动作短→力量小但拍面稳；除非对方发高了或发出了好拉的长球，接发球的目标是落点、深浅、高度、旋转和变化，把对方的发球优势化解成均势（同上）。

## 2. 站位与准备姿势

### 2.1 站在哪里
- **左右**：根据对方发球的位置调整，一般与发球者"斜角对立"（BK-接发球）。PingSkills：先让球拍大致对着球台中线，再按对方从哪里发、发长还是发短来调整（PS:table-tennis-receiving-techniques/receiving-position-and-footwork）。
- **前后**：扬州职大教材给出"一般离台 30—40 厘米为好"；PingSkills 的口径是"站在伸手刚好能碰到球台的地方"（同上）；BK-台内球称顶级选手接发球多离台约一小步。三者一致：**近台，一步能够到网前短球**。
- 对方常发急长球时，可以稍后退一点，或原地不动（PS 同上；PS:returning-types-of-table-tennis-serves/returning-long-fast-serve-with-heavy-back-spin）。

### 2.2 准备姿势（逐部位）
| 部位 | 做什么 | 为什么 / 做错了会怎样 |
|---|---|---|
| 脚 | 两脚平行或右脚稍前，比肩略宽，脚跟提起、前脚掌着地（BK-接发球；CETV-姿势） | 脚跟落地起动慢；太窄上步不稳 |
| 膝 | 两膝微屈，重心放低（BK-接发球；"they start out low"，LH:3491） | 直腿站立，短球够不到、长球退不及 |
| 髋/腰/躯干 | 上体稍前倾、收腹，重心在两脚之间（BK-接发球；CETV-姿势） | 后坐→上步时臀部掉在后面 |
| 肩 | 放松，不端肩 | 端肩发紧，拍面微调不灵 |
| 大臂/肘 | 肘部向下，自然离身（CETV-姿势） | 肘贴死或张开都会让正反手衔接变慢 |
| 前臂 | 自然平举（CETV-姿势） | |
| 手腕 | 自然放松（CETV-姿势） | 腕僵就做不出小幅度的拍面修正 |
| 手指/握拍 | 握松，便于触球时小幅调整拍面（PS:table-tennis-receiving/receiving-principles） | 握死→吃转后无法临时改角度 |
| 拍 | 持拍手与台面同高（扬州职大），不低于台面（BK-台内球），拍子在身前 | 拍放太低，接短球要先抬拍，晚半拍 |
| 视线/头 | 盯住发球者球拍触球的瞬间和方向（BK-接发球） | 看人不看拍，容易被假动作骗 |

### 2.3 起动：先低，对方出手时小跳
高水平选手接发球普遍先蹲低；发球来时身体稍立起、小跳一下，落下时就能快速起动——向左、向右或上步都更快（LH:3491，Hodges 以樊振东对波尔的比赛视频为例）。PingSkills 教练分析张继科发球、樊振东接发的照片：张继科抛球时，樊振东上身向上抬起（PSQ:analysis-of-movements-on-return-of-serve）。做错：全程静止蹲着或全程站直，都会起动慢。

### 2.4 接发球步法
- **接短球用单步**：先把重心移到左脚，右脚迎着来球方向往右前方插一步（扬州职大）。PingSkills 与 Hodges 都主张右手持拍者接所有短球都上**右脚**（PS:table-tennis-footwork/footwork-for-a-short-ball；LH:33），接完立刻退回。Hodges 补充：反手位短球也可以上左脚，便于补正手。BK-接发球（出处乒乓球吧）的挑接规则：正手位上右脚；反手位用反手挑时，也可上持拍手同侧的脚（右手持拍即右脚）；侧身位上左脚。
- 上步细节：右膝弯曲前顶，重心压在前脚掌或两脚之间（BK-侧拧，正手位短球上步）；**重心要完全跟上去**，避免臀部掉在后面、手臂伸得过直（BK-台内球）；手臂离身体近一些，不要过早伸入台内（BK-接发球）。
- 正手大角度出右腿，反手大角度出左腿；起始站位好，一步就够（PS 站位与步法课）。
- 正手位长球一般用并步；角度大或速度快时可用交叉步、跨步、跳步（扬州职大）。详见 `../techniques/footwork.md`。

### 2.5 接短球与接长球的身体要领（逐部位）
| 部位 | 接短球（上步进台内：摆短、劈长、挑、拧） | 接长球（拉、打、挡） |
|---|---|---|
| 脚/步法 | 先把重心移到左脚，右脚向来球插到台下（扬州职大；PS 短球步法课） | 正手位并步，大角度交叉步/跨步；急长常来就稍后退（扬州职大；PS 站位课） |
| 膝 | 右膝弯曲前顶（BK-侧拧） | 屈膝降重心，下旋长球要能从台面以下引拍（LH:80） |
| 髋/重心 | 重心完全跟上到前脚，臀部不留在后面（BK-台内球） | 侧旋要先移动到球将去的位置再击球（LH:34；PS 长侧旋课） |
| 腰/躯干 | 上体前倾探向台内，头随身体一起过去 | 按拉球卡转腰；拉侧上长球时**右肩别沉太多**（LH:80） |
| 大臂/肘 | 手臂离身体近，不要过早伸进台内，不要伸直（BK-接发球；BK-台内球） | 不伸手够球，上步迎球（LH:144） |
| 前臂/手腕 | 摆短前臂相对稳定、手腕发力（BK-摆短）；劈长前臂带手腕快抖（乒乓网-劈长） | 不转（平）急长：缩短动作、手腕帮着提（PS 急长课）；上旋急长不要上提，拍面前倾向前（LH:80） |
| 手指/握拍 | 握松，像舵一样微调拍面（PS receiving-principles） | 同左 |
| 拍面/拍头 | 拍在台面以上起动；按第 4 节对旋转调角度 | 对下旋向上提，对上旋/侧旋以向前为主（LH:80）；接外拐侧旋时拍子保持较高（LH:144）；下旋长球则从台面以下引拍向上提（LH:80） |
| 视线/头 | 盯对方触球→盯球落台→触球 | 同左 |
| 还原 | 接完立即退回（PS 短球步法课） | 准备第四板（`../techniques/transitions.md`） |

## 3. 判断：旋转、长度、落点

### 3.1 先看触球，别看前后
读旋转只看触球瞬间球拍的方向和速度，触球前拍往哪走可以不管（"Ignore the direction the racket is moving until contact."，LH:79）。BK-接发球同样强调"尤其要看清对方球拍触球瞬间的触球部位和挥拍方向"。

### 3.2 判断旋转
- **种类看挥拍方向**：从球的后部或底部向下 = 下旋；横擦球的后部或侧面 = 侧旋；向上或向前上 = 上旋；方向可以组合（侧上、侧下）（PS:table-tennis-receiving/reading-spin；LH:28 半圆挥拍：下行段触球下旋、横向段侧旋、上行段上旋）。
- **多少看摩擦的快和薄**：拍速快、摩擦薄 = 转得多；平着撞 = 球往前走、旋转少（PS 同上）。
- **触球位置**：靠拍头触球最转、靠拍柄处可以发出同动作的不转球（LH:3393）。看得出来就是线索，看不出也别硬猜。
- **球的飞行与落台**：再根据飞行弧线、速度判断（BK-接发球）；"挥臂动作大，力量重多长球"（扬州职大）。
- 侧旋拐向见 3.5；具体发球的旋转见第 7 节和各发球卡（`../techniques/serve-forehand-pendulum.md` 等）。

### 3.3 识破假动作（How to Read Serves with Fake Movements）
发球者会在触球**之后**加动作扰乱判断，但球离拍以后，这些动作改变不了已经在球上的旋转（PS:table-tennis-receiving/fake-movements）。常见伪装是触球后立刻往反方向夸张随挥：发下旋往上收、发上旋往下收（LH:336）。做法：
1. 把注意力集中在触球那一瞬间的拍面朝向和运动方向，收拍动作一律忽略。
2. 对方抛球时就盯拍，不要盯人。
3. 看不清触球（被身体挡、动作太快）时，记下这种发球，回接时用 3.6 的过渡方法，并看自己回球的去向来修正（见第 4 节"舵"）。

### 3.4 判断长度
- 定义：给它机会会在你台面弹两次以上的是**短球**，否则是**长球**（LH:80）；**半出台**是第二跳正好在端线附近、让人拿不准出不出台的发球（LH:29）。
- 线索：对方第一落点靠近球网，球往往短；第一落点靠近他自己的端线，球往往深（Hodges 2016-05-16 "Depth Control on Serves with CBS"，LH:2408）。但高水平发球者常故意让第一落点贴近自己端线、仍发成短球（同文），所以这条只是倾向，最终要看第二跳。PingSkills 的 Alois 接发球时先看两件事：**长还是短、高还是低**（PS:table-tennis-receiving/returning-examples-commentary）。
- 半出台：要准备两手——一是早出手、靠近第一跳去摆短或搓；二是让球过来、用较大的动作拉（PS:table-tennis-receiving-techniques/dealing-with-the-half-long-serve）。一直盯着，球真长了就拉，逼发球者必须把长度控制准（PS:table-tennis-receiving-further-learning/returning-half-long-backspin-serves）。

### 3.5 判断落点与侧旋拐向（拉侧旋发球时预判拐向）
- 侧旋球会在接近你时拐弯，要**预判、提前站到它要去的位置**，不要等它拐了再反应（LH:34）。
- 右手持拍者的**反手发球**拐向你的右侧；**正手拍头朝下的发球（钟摆）**拐向你的左侧（LH:34）。逆钟摆、勾手（tomahawk）的侧旋与反手发球同向，也往你的右侧拐（LH:144）。
- 拉侧旋时要**调整触球在球的内侧/外侧**：球往你右拐（如反手发球），用正手拉时若打球的正后方，球会往左偏——要触球的**内侧（左侧）**，甚至拉出"内向外"往右拐的弧圈；球往你左拐时相反，触球的**外侧（右侧）**（LH:34）。
- **对方是左手持拍：同名发球拐向全部反过来**（由上一条左右镜像得出）。左手的正手钟摆往你的**右侧（正手外侧）**拐，碰拍后往**左**跳；左手的反手发球、逆钟摆往你的**左侧**拐，碰拍后往右跳。Hodges 也说左手最让右手难受的之一就是"发到你正手、往外拐的正手发球"（LH:489）。所以判断时**先看对方持拍手和挥拍方向，再定拐向**，不要只凭"这是钟摆"套右手的经验——套错了，拍面偏斜和触球内外侧正好做反，回球会偏出边线。第 4 节表格按拐向分行，按你判断出的拐向查即可。

### 3.6 判断不准时怎么办（过渡）
- BK-接发球："在判断不准的情况下可轻轻地托一板或撇一板。"
- BK-侧旋球（单一来源，原网页打不开）："若判断不清旋转，可采用拍面立起约45度并向前推送的方式作为过渡。"原文没说这 45° 从哪里量，所以只把它理解为定性做法：**拍面不要极端打开或压死，较立，以向前推送为主、动作短**。
- 对付长球、旋转又看不清时，Alois 选择**用很强的上旋拉过去压住旋转**（PS:table-tennis-receiving/returning-examples-commentary）。
- 每接一板都看自己回球去向，下一板修正拍面（第 4 节）。

## 4. 接各种旋转的拍形对照
**拍子像"舵"**：放松握拍，按来球的下旋、上旋、侧旋及其组合改变拍面角度，并**看自己的回球往哪里去**，用来修正下一次判断（PS:table-tennis-receiving/receiving-principles）。

| 来球旋转 | 回球会怎样（拍面不修正时） | 拍面与触球部位 | 出处 |
|---|---|---|---|
| 上旋 | 往上、往远飞，冒高或出界 | 拍面适当前倾，击球中上部 | BK-接发球 |
| 下旋 | 往下沉，下网 | 拍面后仰；下旋越重越要后仰（极重时拍面几乎朝天），并增加向前的力量 | BK-搓球；PSQ:push-heavy-backspin-serve |
| 不转 | 用接下旋的拍形会冒高 | 拍子稍立，增加向下的力量 | BK-搓球；LH:3600 |
| 往你左侧拐：左侧上 / 左侧下（正手由右向左挥出的左侧旋，如钟摆，CETV-发球；**左手**发球者则是逆钟摆、反手发球） | 往你右侧偏 | 侧上拍面稍前倾、侧下拍面后仰，并略向左偏斜；触球**偏右侧（外侧）**的中上（侧上）/中下（侧下）部 | BK-接发球；LH:34 "contact the ball on the outside (right side)" |
| 往你右侧拐：右侧上 / 右侧下（逆钟摆、反手发球、勾手；**左手**发球者则是正手钟摆） | 往你左侧偏（对方正手） | 侧上拍面稍前倾、触球**左侧（内侧）**中上部；侧下拍面后仰、触球左侧中下部；拍面略转向右；回球多瞄对方反手 | BK-接发球；LH:34；LH:144 |

马龙接樊振东一个侧旋发球时，触球瞬间明显把拍面转向右侧抵消旋转（对应上表第 5 行；PSQ:ma-longs-service-receive，教练看视频的观察）。

## 6. 各回接技术要点索引

| 技术 | 何时 | 一句话要点 | 卡片 |
|---|---|---|---|
| 摆短（short push / drop） | 短下旋、短侧下 | 快上步，**上升期**触球中下部，向前下方摩擦；前臂相对稳定、手腕发力；手臂离身近、不要过早伸进台内（BK-摆短；BK-接发球）。回球低、近网，对方拉不起来（PS:table-tennis-strokes/short-push） | `../techniques/short-touch.md` |
| 劈长（long push，快劈） | 弧线稍高、下旋不强的短球 | 动作小而急，板形较立，前臂带手腕快速抖动，（正手劈长）切球**右侧中下部**，上升后期或高点期出手（乒乓网-劈长；反手劈长见 `../techniques/long-push.md`）；要快、低、转、大角度（LH:80） | `../techniques/long-push.md` |

| 搓（push） | 短下旋，搓长作变化 | 拍面后仰，前下方送出；搓长要**主动选择**，不能因为只会这一种（LH:80） | `../techniques/push.md` |

| 托、撇 | 判断不准时 | 见 3.6；晃撇（单一来源）：最高点触球后中下部，手腕略外展，向左侧前下方摩擦，出左侧下旋（BK-接发球） | `../techniques/push.md` |

**直拍接发球**：步法、重心、还原和上面一样，差在握拍和拍面怎么调，细节见 `../techniques/penhold.md` 第 7 节。
- **搓**：拍面后仰、前倾靠**前臂内旋（后仰）、外旋（前倾）配合放松的手腕**来调，不要用拇指、食指死压拍肩——压死了手腕前臂发紧，吃转后改不了角度（BK-搓球）。
- **摆短**：上升初期触球，借来球的力量和旋转控制，不主动加力摩擦；手臂在台内迎球时近似与台面平行（BK-摆短）。
- **劈长**：板形较立、触球后中部或中下部且稍偏来球右侧，前臂带手腕突然加速，有"切、砍"的感觉（BK-劈长）。
- **挑**：直拍正手挑打威力最大，尽量在高点期用拍头触球（BK-挑打）；台内下旋可积极侧身用正手挑，挑不了就用正手晃撇到对方反手（BK-下旋球）。
- **正手快点**：靠拇指与中指调拍面，击球瞬间食指向前顶、拇指向下压（BK-正手快点）。
- **反手台内进攻两种做法**：① 传统反手快点：左脚上步、重心左移，前臂伸进台内，拍头稍高、拍面前倾、手腕内收，最高点用前臂和手腕击球中上部；下旋强时击中下部、向前上方发力（BK-直板反手）。② 横打：用反面拧（`../techniques/penhold.md` 5.5）。
- **对方是直拍发球者**：直拍手腕活动多，容易用相似动作发出旋转不同的球（`../techniques/penhold.md` 第 8 节），更要只看触球（3.1），转与不转尤其要分清。

## 7. 按发球类型接

- **正手钟摆（pendulum）**：拐向你的左侧（反手外侧）。理想是正手拉；短球或发到反手大角而你步法不够快时，反手接——出台就用反手拉或打。够球时别把拍放太低（重下旋除外）。能接直线最好；做不到至少回得深、到对方反手大角，并把落点藏到最后一刻（LH:144）。见 `../techniques/serve-forehand-pendulum.md`。
- **正手逆钟摆（reverse pendulum）与反手侧旋发球**：往你右侧拐，回球会被旋转带向对方正手，所以要**多往对方反手方向瞄**；读对旋转时反手较好进攻；很多发球者预期你回正手或中路，回反手大角能打乱他（LH:144）。见 `../techniques/serve-reverse-pendulum.md` `../techniques/serve-backhand.md`。
- **勾手发球**：英文 tomahawk 指拍头朝上的正手发球，Hodges 描述其侧旋向接发者正手外侧拐（LH:144）；中文"勾手发球"与 tomahawk 是否完全对应没找到权威出处，按你看到的挥拍方向判断。要点：短的接法同逆钟摆/反手发球；它常从对方正手位发到你正手短，可以接直线压他正手。最难的是拐出正手大角的长球——**上步迎球，不要伸手够，拍保持较高**；也可以接直线到对方反手，不必和侧旋硬顶（LH:144）。PingSkills：像舵一样调拍面，带下旋时打开拍面、带上旋时关拍面（PS:returning-types-of-table-tennis-serves/returning-the-tomahawk-serve；PS:returning-types-of-table-tennis-serves/returning-topspin-sidespin-tomahawk-serve）。见 `../techniques/serve-hook-and-squat.md`。
- **短重下旋**：最安全的是搓/摆短（PS:returning-types-of-table-tennis-serves/push-heavy-backspin-serve）；极重时拍面几乎朝天，必要时触球时略向上推（PSQ:push-heavy-backspin-serve）；下旋很重时一般不上手；要上手需球够高、下旋不强（PS:table-tennis-receiving-techniques/attacking-short-serves）。练拧拉可按张继科的顺序：上旋 → 弱下旋 → 强下旋（见三位标杆）。
- **长下旋**：拉。长球没有球台挡着，可以从台面以下引拍向上提，第一时间、第二时间拉都可以这样引拍（LH:80）；PingSkills 重点讲反手拉长下旋及线路，并配多球练（PS:returning-types-of-table-tennis-serves/options-against-a-long-backspin-serve）。
- **长侧旋**：侧旋会把球带离你预想的击球点，用**移动**把球放进自己舒服的击球区，必要时侧移或后退，再用反手拉（PS:returning-types-of-table-tennis-serves/returning-a-long-sidespin-serve）。往外拐时也可用反手上旋回接（PS:table-tennis-receiving-further-learning/playing-with-the-spin）。据 Hodges 经验，以正常速度攻侧旋，侧旋只让球偏约一英尺以内，初学先瞄得比角落稍靠内（LH:80）。
- **急长、快而不转**：容易被当成下旋；比下旋来球更快，要**缩短动作、用手腕帮着提**（PS:returning-types-of-table-tennis-serves/returning-long-fast-serve-with-heavy-back-spin）。**急长上旋/侧上**则相反：拍面前倾、以向前为主（拉、打或挡），不要上提（LH:80）。
- **左手持拍者的发球（整体镜像）**：上面各条的拐向都按右手发球者写，对左手要左右对调（3.5）。最常见也最难受的是**左手正手钟摆发到你正手、往外拐**（往你右侧拐出正手大角，碰拍后往左跳）（LH:489）：
  - **别等到最后一刻再扑**：扑的时候拍子跟着往下掉，回球多半出界（LH:489）。做法同上面"外拐"球：早判断、上步迎球，拍保持较高（LH:144）。
  - **线路**：先摆出接他正手直线的样子，逼他准备防直线，最后一刻改斜线到他反手。这是假设他正手更强；他反手更强就反过来（LH:489）。
  - **落点习惯要改**：对右手常压的反手位，对左手是正手；对右手正手的快球，到了左手反手，还给他斜线打你正手大角的角度（LH:489）。接发落点按对方持拍手重新选，详见 `../techniques/tactics.md` 11.7。
  - 左手的逆钟摆、反手发球则往你左侧拐，按第 4 节"往你左侧拐"那行接。

**接正手位"外拐"侧旋的常见错误**（逆钟摆、反手发球、勾手发到你正手，往你右边拐出去）：伸手去够→拍子跟着球往下掉，本来拉球就要降拍，又再降，结果拍位过低、把球拉出端线；同时伸手够球时拍面自然朝左，而这种球碰拍后往左跳，应往右瞄（或接直线到对方反手）。纠正：**上步向球而不是伸手，拉球时拍子也保持较高**（LH:144）。反手位外拐（钟摆发到你反手大角，往你左边拐）左右相反：球碰拍后往右跳，应往左瞄（LH:34）。拉侧上旋长发球时右肩沉得太多也会出界（LH:80）。

## 8. 拉接的"第一时间"与"第二时间"
BK-接发球（出处乒乓球吧，单一来源）："手低于台面接触球……可以认为是第二时间，高于球台或基本与球台在一个平面上时，可认为是第一时间。"
- 第一时间：手在台面高度或以上击球。出手早，留给对方的时间少；要求起动早、上步到位，常用于半出台和不太低的长球。
- 第二时间：手低于台面击球（BK-接发球）。自己准备时间多，适合来不及时；代价是对方也多了准备时间（长球回接越慢，对方越从容，LH:257）。
- 两种都要会，按来球旋转和自己是否到位选择。视频里对照台面看击球帧即可分辨（见"视频检查要点"）。

## 9. 接发球抢攻
- **不可过凶**：对方发加转下旋时要用提拉手法；抢冲的力量越小，越要注意线路和落点，一般多打对方反手（CETV-接抢）。
- **长球要养成进攻的习惯**（最好拉）；一开始失误多，正是要坚持攻的理由（LH:257）。例外：对不擅长对付下旋的对手，可偶尔搓长作变化（同文）。
- **短球抢攻**有风险：球够高、下旋少才攻，就算球会弹两次也可以（PS:table-tennis-receiving-techniques/attacking-short-serves）。拧拉的目的是阻止对方第三板抢攻（张继科本人语，见三位标杆）；挑打则是"缴械"对方发球（disarm an opponent's serve，LH:80）。
- **线路**：多打大角或对方持拍手肘部（正反手交界）；通常回反手最好，但对方爱侧身时可突然回正手（LH:80）。挑打要把方向藏到触球前一刻（同上）。
- 接发后衔接：接完马上退回准备位（PS 短球步法课），准备对方第三板，衔接见 `../techniques/transitions.md`，战术见 `../techniques/tactics.md`。

## 10. 双打接发球
双打发球必须从发球方右半区落到接发球方右半区（ITTF 规则 2.6.3），你的站位和来球角度都与单打不同（PS:table-tennis-receiving/doubles-return-of-serve）。站位、让位与轮换见 `../techniques/doubles.md`。

## 三位标杆（只写有出处的）
- **马龙**：比赛报道里常见接发球摆短、随后正手抢拉得分（央视网 2017 日本公开赛决赛、2018 中国公开赛决赛）；也会接发直接拧拉（2017 世乒赛对庄智渊）、反手翻挑（东京奥运半决赛对奥恰洛夫）、打追身（2017 世界杯）——都是单场描述。Hodges 指出包括马龙在内的许多顶尖选手会用**反手接正手位短球**（LH:3650）。PingSkills 教练观察到他接樊振东侧旋发球时触球瞬间把拍面明显转向右侧（PSQ:ma-longs-service-receive）。他具体的站位距离：暂无可靠出处。
- **张继科**：被日本《卓球レポート》称为第一位以拧拉（chiquita）为核心称霸世界的选手（2020-05-14）。本人说：10～15 年前（乒坛）接发球的主流是搓；他看到拧拉后，认为它能阻止对手第三板，不是队里要求，是自己主动研究的；练法是先拧上旋球、再拧稍带下旋、最后拧强下旋；手腕和手指的用法很关键，但不必照抄他的动作（2019-03-07 采访）。2013 年巴黎世乒赛半决赛对许昕，该刊称他接发球"完美"。
- **樊振东**：Butterfly 以"凶狠的香蕉球（拧拉）接发球"作为他的标签（2021-11-01）。Jin & Ma 2026 对 2021–2023 年 40 场比赛的统计：接发轮第二板他用反手上手显著多于正手，反手拧拉使用率显著高于其他技术，接抢段反手技术得分率在 65% 以上；但反手上手后的连续进攻、接发后的线路变化有待提高（doi:10.3389/fbioe.2026.1763704）。准备动作：对方抛球时上身抬起（PSQ:analysis-of-movements-on-return-of-serve），Hodges 用他的视频示范接发球小跳（LH:3491）。也有接发劈长得分的报道（央视网 2019-07-21）。

业余怎么学：先学会**稳摆短、随后抢下一板**（比赛报道里马龙常见的套路），同时按张继科说的顺序练拧拉；以反手拧拉为主的接发（如樊振东）对手腕、肘负荷大（BK-侧拧），要循序渐进。

## 常见错误 → 纠正
| 表现 | 原因 | 纠正 |
|---|---|---|
| 接短下旋下网、接侧上冒高出界 | 读错旋转，或用同一拍形接所有球 | 只看触球瞬间（3.1）；按第 4 节调拍面；看自己回球去向修正 |
| 推/搓短侧上或上旋飞出端线、边线 | 用搓下旋的后仰拍面 | 改切挡、挑或拧；要摆短就"从球后面往下"（LH:80；PS 短上旋课） |
| 被假动作骗 | 看收拍、看人 | 只看触球；忽略触球后的反向随挥（PS fake-movements；LH:336） |
| 伸手够正手位外拐球，拉出端线或回偏 | 拍随球下掉、拍面朝左 | 上步迎球，拍保持较高，往右瞄或接直线（LH:144）；反手位外拐左右相反 |
| 接左手发球回偏、出边线 | 按右手的拐向判断，拍面偏斜和触球内外侧做反了 | 先看持拍手和挥拍方向再定拐向（3.5）；左手正手发到你正手外拐时别最后一刻扑（LH:489） |
| 拉侧上长球出界 | 右肩沉太多 | 肩部别下沉，以向前为主（LH:80） |
| 短球够不着、手臂伸直、臀部在后 | 右脚没插进台下，重心没跟上，手臂过早伸进台 | 先移重心再上右脚，重心跟上，手臂离身近（扬州职大；BK-台内球；BK-接发球） |
| 动作大、拍面不稳 | 拿相持球的挥幅接发 | 缩短动作（LH:3242） |
| 只会搓长，被对方第三板抢冲 | 没有摆短、挑打 | 搓长只作主动选择，搓就要快、低、转、大角；练摆短（LH:80） |
| 挑打用力过猛失误多 | 当成全力进攻 | 重隐蔽和落点（LH:80） |
| 长球被动搓回或软推 | 不敢攻 | 养成攻长球的习惯，失误正是练的理由（LH:257） |
| 起动慢 | 全程静蹲或站直 | 先低，对方出手时小跳（LH:3491） |
| 急长不转接下网 | 当成下旋，动作过大 | 缩短动作、手腕提（PS 急长课） |
| 半出台摆短摆出台，或拉球碰台、够不着 | 没判断第二跳在不在台内，犹豫 | 两手准备：早出手摆短，或等它出台再拉；一直盯到底，真长了就拉（PS 半出台两课，3.4） |

## 练习方法
按顺序推进；每一级做到"进级标准"再进下一级（标准是定性的，由你和陪练看回球判断）。
0. **入门：一种发球、一种回接**：喂球者只发一种慢的短下旋，你只练摆短，体会上步、上升期触球、看回球去向修正拍面。进级：回球多数低、短、落在指定半区，接完能自然退回。
1. **单一难发球反复接**：找能发你最怕的发球的人，先反复接同一种，体会旋转效果、调整回球（PS:table-tennis-receiving/how-to-practice-receiving；LH:257）。进级：这种发球你已很少直接失误，回球不再冒高或下网。
2. **加入变化**：同一动作发不同旋转、落点、速度，你判断后选技术（同上）。可按第 5 节表格一行一行练：短下旋（摆短/劈长/快搓交替）→短不转（挑、拧）→短侧上（拧、挑、切挡）→半出台（拉或摆）→长球（拉）。进级：多数球能在触球前选对技术，选错时也能马上从回球去向看出来。
3. **多球**：喂球者模拟各种发球，练判断+上步+还原；反手拉长下旋可用多球（PS:returning-types-of-table-tennis-serves/options-against-a-long-backspin-serve）。进级：连续多球中步法不乱、每板都还原到位。
4. **接发入相持与比赛**：接发后打完一回合；最后用比赛检验（PS 同课；Hodges 十步法 LH:22 也把"接发入相持"放在比赛之前）。进级标准就是比赛里接发不再是主要丢分环节。
5. **拧拉专项**：上旋来球→弱下旋→强下旋（张继科练法）。
6. **徒手**：对镜练"先低→小跳→上右脚→退回"。更多练法见 `../training/drills.md`。

## 视频检查要点
**机位**（按 `../analysis/recording-guide.md` 第 3 节）：首选**正面**、架高俯拍，拍全身，看起动、小跳、左右移动、还原；补拍**持拍手一侧的侧面**、略高于台面，看上步、膝、躯干前倾、手臂是否伸直、台内拍面后仰（与指南"搓、摆短、劈长、挑打 → 侧面"一致）。本卡额外建议：想检查判断（是否吃转）时，可再加一台在接发者**身后斜上方**，同时拍到发球者触球和你的回球落点。手机慢动作 120/240 fps，导出后用 `--capture-fps` 校正（`../analysis/recording-guide.md`）。画面里有发球者，脚本可能报 `MULTI_PERSON`，用 `--player` 锁定接发者；台内动作小，可能报 `NO_STROKES`：先看 `timeline_*.jpg` 找击球时刻，再用 `--strokes "ready,backswing_end,contact,finish,recovery; ..."` 手动指定；`--start/--end` 只用来裁掉无关片段。**脚本看不到球和旋转**，判断对不对只能由 Claude 看帧上回球的高度与落点。

| 阶段 | 关键帧看什么 | 对应指标 |
|---|---|---|
| 准备 | 是否先蹲低；两脚宽度；拍是否在台面高度 | `knee_angle_deg.{playing,other}.ready`、`stance_width_ratio` |
| 起动/上步 | 对方出手时是否小跳；短球右脚是否插到台下、重心是否跟上 | 小跳主要看帧（`head_motion` 只作参考）、`weight_shift.backswing_end`（正手接短球应偏向 0＝右脚）、`knee_min_deg.playing`、`trunk_lean_deg.backswing_end` |
| 引拍 | 动作是否短 | `backswing_ms`、`elbow_angle_deg.backswing_end` |
| 击球瞬间 | 手臂是否伸直、离身是否太远；击球点前后；拉接是第一还是第二时间（对照台面看帧） | `elbow_angle_deg.contact`（接近 180° 说明伸直了）、`elbow_body_gap_m`、`contact_forward_m`、`contact_lateral_m`、`contact_height_level`、`trunk_lean_deg.contact` |
| 随挥 | 挥拍方向（摆短向前下、挑拉向前上）；收拍是否短 | `swing_path.{up,horiz,angle_deg}`、`finish_height_level`、`follow_ms`、`peak_hand_speed` |
| 还原 | 是否立即退回 | `weight_shift.finish`、`recovery_dist` |
| 整体 | 正手还是反手、数据可信度 | `side_guess`、`forward_ms`、`sequence_ms.{hip,shoulder,elbow}`、`sequence_order_ok`（台内小动作参考价值低）、`quality.{pose_coverage,mean_visibility,low_visibility_parts,reliable}` |

**拍面角度**：骨架测不出，必须看击球前后的**手部放大图**（`stroke_NN_zoom.jpg`）：接下旋拍面是否后仰、接侧旋拍面是否按第 4 节偏转、触球后手腕是否乱甩。`quality.reliable` 为假或手腕在 `low_visibility_parts` 里时不下结论，按拍摄指南重拍。

## 自查清单
- [ ] 站位近台，一步能够到网前；持拍手在台面高度
- [ ] 先蹲低，对方抛球/出手时小跳起动
- [ ] 只看触球瞬间的拍面方向和摩擦快慢，忽略收拍
- [ ] 能分出短、半出台、长（先看第一落点和高度，最终看第二跳）
- [ ] 侧旋提前判断拐向，拉的时候调触球内/外侧；对方左手持拍时拐向反过来
- [ ] 接短球上右脚、重心跟上、手臂不伸直、接完立即退回
- [ ] 长球能攻（拉或打），不会只搓回去
- [ ] 短下旋会摆短、劈长、快搓、挑或拧中至少三种并能变化
- [ ] 判断不准时有过渡办法（托、立拍前送、上旋压过去）
- [ ] 每一板都看自己回球去向并修正拍面
- [ ] 接发动作比相持短
