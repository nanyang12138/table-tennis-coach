# 报告模板（分析视频或照片后，按这个结构用中文回复用户）

规则：
- 先给结论，再给证据。每个判断都要写清证据：第几板、哪个时刻（t=…s）、哪张图、哪个数字。
- 看不清的就写"看不清"，并说明原因（例如机位、帧率、被挡住）。
- 用户是业余球员：用大白话写，术语第一次出现时加一句解释。
- 篇幅：问题聚焦在最重要的 3 个；逐部位评估用一张表。

---
