# 按症状查错（Error Index by Symptom）

> 适用：所有技术（含挑打、劈长、削球、放高球、直拍、战术）。多数链接跳到卡片的"常见错误"一节，其余跳到相关原理小节；另见[多球与练习]、[伤病]、[指标说明]。按右手持拍写，**左手持拍者左右互换**。表中越靠前越常见、越该先查；【】是出问题的部位或环节。

## 0. 怎么用这份索引

1. **先数清楚症状**：记下每个失误的类型（下网、出界、冒高、侧飞……）、技术和来球。可以从记 30–50 个失误开始，按自身情况调整（Hodges 也建议统计下网、出界比例 [LH:3634]）。
2. **先查握拍和站位** [LH:331]，再按判断 → 步法 → 击球时间和击球点 → 拍面 → 发力顺序往下查；前面错了，后面改了也不稳。
3. **一次只改一项**：动作、触球、时机、步法、读旋转分开练，再组合 [LH:3628]。
4. 改完用同一机位录像前后对比（[指标说明]）。症状常同源（肩紧 → 肘上浮 → 拍面朝下 → 下网），表里常互相指向。

## 1. 下网（Into the Net）

先分清是对**下旋**还是**上旋**来球下网，两者原因常相反。

| 原因【部位】 | 怎么认 | 改法 | 去看 |
|---|---|---|---|
| 【拍面】对下旋用了攻上旋的前倾拍面 | 对搓球、下旋发球下网多 | 下旋越强拍面越开、越向上 | [正手拉下旋]、[拍形] |
| 【前臂/挥拍路线】向上不够、收拍太低 | 收拍停在胸前 | 拉下旋收拍到头高 | [正手拉下旋]、[反手拉下旋] |
| 【膝/髋】重心太高、拍没低于球 | 引拍时拍在球上方、腿直 | 膝高起拍，降重心 | [正手拉下旋]、[反手拉下旋] |
| 【时间】击球太晚，球已低于网 | 触球帧里球低于网 | 提早到位，见 §7 | [击球时间] |
| 【肩/肘/腕】肘上浮、手腕下垂，拍面朝下 | 正手前挥时肘先抬 | 见 §9.1 | [正手攻] |
| 【拍面】挡、搓弱旋转球仍压拍 | 对不转、弱上旋下网 | 挡弱旋转开拍面；不转球拍稍竖、向前送 | [反手挡]、[旋转] |
| 【器材】海绵太硬、拍速不够吃不进 | 拉球"打不动" | 换软海绵，或先练腿腰发力 | [器材] |

**某项技术下网：** 【拍面/腕】反手攻拍面前倾过早 → 徒手引拍使拍面稍后仰（CETV ⑥）[反手攻]；【拍面/时间】挑打没打开拍面或球已下落才挑 → 读旋转后开拍面向上刷，高点期前出手 [正手挑]、[反手挑]；【拍面】劈长对强下旋拍形太立 → 放平、向前下送 [劈长]；【前臂】削球只向下砍 → 远削加前送 [削球]；【落点】急长第一落点太靠网 → 第一跳靠近本方端线 [急长与高抛]。

**练法：** 多球连续喂下旋只练拉，规则是"宁出界不下网" [LH:3501]。可以从每组 20 球、3 组开始，按自身情况调整；目标：下网比例下降，出界可以暂时增加 [LH:3634]。
**视频：** 侧面。引拍结束看拍是否低于球，击球看拍面和高度，随挥结束看收拍；`swing_path.angle_deg`（拉下旋应明显为正）、`finish_height_level`、`contact_height_level`。

## 2. 出界、冒高（Long / Popping Up）

### 2.1 相持中出界（多见于对上旋）

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【挥拍路线】对上旋还用拉下旋的向上路线 | 向前而不是向上；收拍到额头前 | [正手拉上旋]、[反手拉上旋] |
| 【拍面/腕】拍面前倾不够；翻腕想把球"兜"起来 | 关一点拍面；反手作平击发球练习，体会击球时手腕外旋（CETV ⑦） | [正手攻]、[反手攻] |
| 【前臂】反手攻引拍太低，由下向上蹭 | 引拍到腹前偏左，前臂与台面平行 | [反手攻] |
| 【髋/躯干】重心后坐、过于向上发力 | 身体始终前倾，腰带前臂向前上方发力 | [反手拉下旋]、[反手撕] |
| 【肩】拉侧上旋长发球时右肩沉太多 | 肩别下沉，以向前为主 [LH:80] | [接发球] |
| 【拍面】挡弧圈拍面不够关 | 见 §14 | [反手挡] |
| 【器材】底板太快 | 换中速底板，练完整挥拍 | [器材] |

### 2.2 台内球冒高、出台

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【判断/拍面】把不转、侧上旋当下旋，拍面开太大 | 拍稍立、往下切；短侧上旋改挑 | [搓球]、[摆短]、[旋转] |
| 【时间】在高点期搓 | 改上升期或下降期 [LH:3641] | [搓球] |
| 【前臂/手指】前送太多；握紧把来球弹回去 | 摆短几乎不前送，握拍放松吸收 | [摆短] |
| 【拍面/随挥】挑打对上旋、不转仍用后仰拍面上刷 | 拍面关一点、更向前，随挥短 | [正手挑]、[反手挑] |
| 【拍面/时间】劈长拍形太平或击球偏晚；来球其实带上旋 | 拍形立、往下切，提前到上升后期；先判断旋转 | [劈长] |
| 【器材】张力胶轻触也吃进海绵 | 只用胶皮表层轻擦 | [器材] |

### 2.3 侧边出界、侧飞

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【拍面】侧旋没抵消，拍面正对来球 | 拍面向对方挥拍来的方向偏 | [旋转]、[摆短] |
| 【拍面】劈长对侧旋、侧上旋没调拍面 | 先判断旋转，侧上旋不劈 | [劈长] |
| 【肩/大臂】手臂横扫过身体 | 见 §5.2 | [反手拉上旋] |
| 【瞄准】自己拉侧旋没算拐弯 | 左拐瞄偏右、右拐瞄偏左 | [侧旋弧圈] |
| 【脚/拍头】接外拐侧旋伸手够球 | 见 §13.1 | [接发球] |

### 2.4 削球、放高球冒高或出界

- 削球 [削球]：【拍面/腕】冒高（拍面太朝天、削弧圈手腕不固定）→ 触球中下部，拍面别过分后仰；削弧圈锁住手腕，越转拍面越竖。【判断】攻球手应急削出界（不知道下旋会飘长）→ 轻削，瞄准让球落在自己这边。
- 放高球、鱼跃 [放高球]：【前臂】太浅被大角度扣 → 深度第一，宁高也要深；【躯干/拍面】高球不转（正对球台平托）→ 侧身，像拉弧圈一样向上擦出上旋、侧旋；【前臂】直接出界（引拍太快、向前太多）→ 慢引拍，主要向上；【拍面】鱼跃冒高（触球太靠下、往上捞）→ 触球后部，向前为主。

**练法：** 多球上旋、下旋交替喂，挥拍路线不变只改拍面 [拍形]。可以从每组 20 球、3 组开始，按自身情况调整；目标：每组出界加下网不超过你基线的一半。
**视频：** 侧面看 `swing_path.angle_deg`（对上旋应比对下旋平）、`finish_height_level`；正面看 `trunk_lean_deg.contact`（前后对比看是否后坐）。

## 3. 拉不起来（Can't Lift Backspin）

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【拍面】拍面太关、摩擦太薄（"飞碟"、擦拍边） | 拍面开到接近垂直，手腕向内向前转 | [正手拉下旋] |
| 【膝/髋/肩】重心高、拍高于球；不沉右肩 | 拍低于球，降重心；拉下旋沉肩（打挡球才抬肩） | [正手拉下旋] |
| 【前臂】手臂直线前推，没有弧线 | 以肘为轴向左前上方小弧形挥 | [正手拉下旋] |
| 【腿/腰】只用手臂 | 先徒手练"蹬—转髋—转腰" | [发力] |
| 【判断】所有下旋一个拍形；慢转拉成软短球 | 先看对方拍再选拍形；慢转全力但薄擦、落点深 | [正手拉下旋] |
| 【时间】触球太晚 | 见 §7 | [正手拉下旋] |

### 3.1 "吃不住球"

表现：球在拍上"停不住"，滑出或弹飞，弧线忽高忽低。原因：**收前臂过晚**（爆发力没出来球已离拍）或**过早**（力量用完才触球）[BK-弧圈球]；拍面太前倾、摩擦太薄也会这样。改法：转腰和收前臂接近同时到达击球点；多球慢节奏体会，听触球声是否一致 [LH:3539]。去看：[正手拉下旋]、[发力]。

### 3.2 钩手腕（Hooked Wrist）

表现：拉下旋时手腕向内勾，拍从低处一路勾到头顶以上 [PSQ-hooked]。改法：膝高或稍高起拍，拍面稍开，向上向前，收在头高；**手腕中立或略上翘**，先徒手练，再用下旋不重的多球练、逐步加重；对镜或看录像检查；腕背贴胶带提醒；近台练，不给大幅勾手留空间 [PSQ-hooked]。去看：[正手拉下旋]、[拍形]。

**练法：** 先徒手，再多球下旋。可以从徒手 3 组 × 15 次、多球 3 组 × 20 球开始，按自身情况调整；目标：连续 10 球过网、收拍都在头高附近。
**视频：** 侧面；`swing_path.angle_deg`、`knee_min_deg.playing`、`contact_height_level`、`weight_shift.delta`；"吃不住球"在帧率 ≥100 时看 `sequence_ms.elbow` 离击球是否太远；腕形、拍面看 `stroke_NN_zoom.jpg`。

## 4. 打滑（Ball Slips Off the Rubber）

表现：球像"滑"掉，声音轻、发闷或擦拍边，球软、不转、往下掉；拉弧圈出"飞碟"。

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【拍面】拍面过于前倾、摩擦过薄 | 稍立拍面，对上旋以中等吃进海绵为主 [LH:3539] | [正手拉上旋]、[旋转] |
| 【腕/拍头】手腕下垂太多、拍头太低，打在拍边 | 拍头靠手腕"放"下，别整个手腕塌下去 | [侧旋弧圈] |
| 【时机】收前臂过早或过晚 | 见 §3.1 | [发力] |
| 【拍速】只"放拍"，被来球旋转带走 | 加速穿过球，盖过来球旋转 [LH:3478] | [正手拉上旋] |
| 【器材】胶皮脏旧；海绵太硬 | 清洁、按时换胶；换软海绵 | [器材]、[保养] |

**练法：** 多球每组 20 球，可以从 3 组开始，按自身情况调整；目标：每板触球声一样 [LH:3539]。
**视频：** `stroke_NN_zoom.jpg` 看球碰在拍边还是中心、拍面角度；`peak_hand_speed` 只做前后对比。

## 5. 被对方顶住、被压（Jammed / Rushed）

表现：来球又快又转时只能"放拍挡回"，球软；越打越往后退；追身球被夹住。

### 5.1 被压时引拍仓促

原因：准备时拍举太高或站得太贴台，来不及把拍放下；反手可调的时间本来就少 [LH:3379]。改法：拍放在腹前，离台约一臂 [LH:3739]；**引拍末端练出一个短暂停顿** [LH:3379]。去看：[反手拉上旋]、[反手撕]。

### 5.2 手臂横扫过身体（Swinging Across the Body）

表现：反手拉上旋（尤其对挡球）时手臂横扫过身体，动作走形 [PS-bh-block]。常见原因：发力方向往侧面跑。改法：收拍点定在右前方，练"右前上方"挥拍，横向分量跟着向前走。正手侧旋弧圈同理：手臂按普通弧圈走，只变手腕和拍面，别横扫身体 [PS-sidespin]。去看：[反手拉上旋]、[反手撕]、[侧旋弧圈]。

### 5.3 其他原因

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【前臂】快带、挡球引拍过大，击球点落到身后 | 引拍只到身体侧前方 | [正手快带] |
| 【躯干/脚】重心后坐被顶退；太早退台 | 上体前倾，动作缩短，站在一臂内 | [正手快带] |
| 【脚】被上旋高球顶住：站太近 | 读到上旋就后退一点 | [扣杀] |
| 【准备】被快搓、急长顶住：拍举太高、引拍太晚 | 见 §5.1 | [反手拉下旋] |
| 【手指】预判到快球就攥紧 | 松到别人能从背后把拍抽走 [LH:2271] | [握拍] |

**练法：** 同伴连续压你反手中等力量的快球或弧圈，只练小引拍 + 一停 + 前挥。可以从每组 1 分钟、4–6 组开始，按自身情况调整；目标：连续回 10 板不后退。
**视频：** 正面或斜 45°；`backswing_ms`、`elbow_angle_deg.backswing_end`、`contact_forward_m`（被挤时变小）、`trunk_lean_deg.contact`（后坐）。

## 6. 来不及（Late to the Ball）

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【视线/判断】看对方大动作、收拍，读旋转慢 | 只看对方触球那一刻 | [旋转判断]、[接发球] |
| 【判断/引拍】落点判断不准、引拍不到位 | 先接平击发球，再练连续推挡（CETV ⑤） | [反手挡] |
| 【膝/脚】站得笔直、脚跟踩实 | 屈膝前倾，重心在前脚掌 | [站位] |
| 【脚】不做小垫步或时机错 | 对方触球瞬间小跳落地 [LH:3637] | [站位] |
| 【脚】起动第一步迈错脚 | 往右先迈右脚，往左先迈左脚 [LH:590] | [站位] |
| 【还原】打完站着看 | 对方击球时应已站稳，略偏但站稳好过还在移动 [LH:3425] | [站位]、[正手攻] |
| 【动作】引拍、随挥过大 | 挡、撕缩短动作和收拍 | [反手挡]、[反手撕] |
| 【站位】接发球站太远（拧拉来不及） | 离台约一小步，早判断长短 | [拧拉] |
| 【髋】来球稍晚就转不动髋 | 早判断、早移步，保证转髋和重心跟上 | [正手拉下旋] |

2026 年一项比赛分析指出，来球稍晚时樊振东的正手"不能主动转髋，导致失误"（论文作者解读）[Jin2026]。
**练法：** 徒手"小垫步 → 左右并步 → 挥拍"，再上台练正手位、反手位两点。可以从每组 30 秒、6 组开始，按自身情况调整；目标：对方每次触球时你都已落地站稳。
**视频：** 正面略高；看准备时膝弯和站宽、对方击球时是否站稳、还原位置；`knee_angle_deg.playing.ready`、`stance_width_ratio`、`recovery_dist`、`backswing_ms`。

## 7. 触球太晚 与 击球点太靠前（Late Contact vs. Too Far in Front）

这是**两个问题**：**时间**（弹起后哪一段打）和**空间**（球在身体哪个位置）。PingSkills 把"触球太晚"列为正手拉三大错误之一（另两个是打得太平、收拍太低）[PS-top3]；Hodges 把"击球点太靠前、手臂向前时身体落在后面"列为常见错误 [LH:2415]。两者要分开查。

| | 触球太晚（时间） | 击球点太靠前（空间） |
|---|---|---|
| 指什么 | 球已落到下降后期，或被挤到身侧后方 | 球在身体正前方太远，要伸手够 |
| 表现 | 拉下旋下网、动作憋住、被顶 | 手臂伸直、身体前扑、只用手臂、转体不足 |
| 常见原因【部位】 | 【判断】慢；【引拍】晚；【脚】退台太多 | 【肩/大臂】转体前手臂先走；【脚】没到位或站太远 |
| 改法 | 提早引拍；对弧圈别随便退台 | 等球进入身体侧面（右腿旁）再打，绕头顶竖轴转体 [LH:2415][LH:3147]；靠脚步调距离 |
| 正确的样子 | 击球点在身体侧前方，最晚到身体侧面 [BK-弧圈球] | 同左 |
| 去看 | [击球时间]、[正手拉上旋] | [击球点]、[正手拉上旋]、[发力] |

另排除两个相反错误：**抢得太早**致动作变形（先在高点期打稳再提前，离台退四分之一到半步 [PS-rush][LH:480]）；**击球点离身体太近或落到身后**（步法没到位）[拍形]、[扣杀]。
**练法：** 多球定点，喂球者喊"早"或"晚"，你只改时间；另一组只改距离（站位前后移半步）。可以从每组 15 球、两项各 3 组开始，按自身情况调整；目标：10 球里能按口令改对 8 球。
**视频：** 侧面 + 正面，击球帧看球在身前多远、手臂是否伸直；`contact_forward_m`（越大越靠前，同一视频内比）、`contact_lateral_m`、`elbow_angle_deg.contact`（接近伸直＝在够）；时间看 `stroke_NN_contact_raw.jpg` 里球相对网和台面的高度。

## 8. 动作变形（Stroke Breaks Down）

表现：单练时好，一到比赛、快球或移动中就走形。

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【脚】没到位就出手、伸手够；机会球没调重心就抡臂 | 先动脚，把球放进固定击球区 [LH:22] | [扣杀]、[拍形] |
| 【时间】抢得太早 | 先在高点期打稳再提前 [PS-rush] | [拍形] |
| 【全身】用"全力"，挥拍抽搐 | 不用全力，平滑加速 [LH:3698] | [发力] |
| 【前臂/全身】挥拍不敢挥够、中途停顿 | 徒手模仿，把拍挥够（CETV ①） | [正手攻] |
| 【准备】被压时引拍仓促 | 见 §5.1 | [反手拉上旋] |
| 【手指/肩】紧张时握死、耸肩 | 握松，每分前垂臂放松 | [握拍] |
| 【拍面】走到台前手变成搓的拍形 | 上步时就摆好挑的拍形 | [反手挑]、[正手挑] |
| 【基础】基本动作没定型就练变化 | 先练稳直线上旋，侧旋只占一小部分 | [侧旋弧圈] |
| 【器材】器材太快，动作越打越小 | 换慢一档的器材 | [器材] |

**练法：** Hodges 的步骤：同点 → 正反手结合 → 移动 → 随机 → 发接发进入相持 → 比赛 [LH:22]。每步可以从每组 2–3 分钟、3–4 组开始，按自身情况调整；能连续 20 板再进下一步 [LH:25]。
**视频：** 比同一视频各板的 `elbow_angle_deg.contact`、`swing_path.angle_deg`、`contact_forward_m`，波动大的就是变形板；先看 `quality.reliable`。

## 9. 正手肘上浮（Floating Elbow）与其他手臂形态错误

### 9.1 肘上浮：抬肘、手腕下垂

表现：前挥时**肘先抬起**、**手腕下垂** [PSQ-float]；抬肘容易拍面朝下、击球上方 → 下网 [BK-正手攻]。原因：**肩紧张**，肩转不动，肘只能上抬（"floating elbow syndrome"）[PSQ-float]；引拍时整个肘连大臂往后拉（应以肘关节为轴），常与两脚平站有关 [BK-正手攻]。改法：放松肩、把肘压低，训练里反复练，比赛才改得过来 [PSQ-float]；近台快攻练习，强调击球时**肘、肩向后下方**（CETV ③）；调整站位，别两脚平站 [BK-正手攻]。去看：[正手攻]、[正手拉上旋]、[正手快带]。

### 9.2 夹肘、拖肘（CETV ②）

大臂贴死身体（夹角过小）或往体后拖 → 击球点太近、发不上力。放松肩部，加大上臂与身体的距离；左手托住右肘、离上体约两拳做徒手挥拍（单一来源 [BK-正手攻]）。去看：[正手攻]、[正手快带]、[反手攻]。

### 9.3 手腕下垂（吊腕、吊板，CETV ④）

球拍与前臂成直角。正手：手腕内旋、拍柄向左，徒手模仿；推挡：手腕外展、拍柄靠近虎口 [BK-推挡]。去看：[正手攻]、[反手挡]、[直拍]。

### 9.4 直臂打球、甩腕

直臂动作慢、肘易伤 → 腋下夹软物挥拍，逼自己用肘屈伸；攻球甩腕拍面不稳 → 手腕相对固定。去看：[正手攻]、[伤病]。

**练法：** 对镜徒手，先慢后快。可以从每组 20 次、3 组开始，按自身情况调整；目标：侧面看前挥全程肘不高于肩线。
**视频：** 侧面 + 正面；`elbow_body_gap_m`（夹肘小、外张大，同一视频内比）、`elbow_angle_deg.backswing_end/contact`；肘高在 `stroke_NN_sheet.jpg` 看前挥中段肘是否先于手抬到肩线；手腕下垂看 `stroke_NN_zoom.jpg`。

## 10. 发力不足（Lack of Power）

发力顺序应是 腿 → 髋/腰 → 肩 → 手臂 → 手腕，平滑依次 [LH:3698]。

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【脚/膝/腰】只用手臂，击球点在身体正前方 | 击球点放到身体侧面；徒手练"手放胸前只转腰" | [发力]、本页 §7 |
| 【膝/重心】重心不转换，腿直 | 正手引拍时压在右脚、右膝弯，前挥蹬右脚 | [发力]、[正手攻] |
| 【顺序】身体先转完手才动，或手先走身体不动 | 体会转腰和收前臂接近同时到达击球点 | [动力链] |
| 【手指/肩】握死、耸肩 | 握松，留有余力 | [握拍]、[发力] |
| 【大臂/腰】拉肘引拍；腰转过大（"掷铁饼"） | 转腰带臂引拍；转到重心落到右脚即可 | [发力] |
| 【撞击/摩擦】把攻打成拉，摩擦多于撞击 | 近台攻快球，逼自己"改摩为打" | [正手攻] |
| 【前臂】扣杀缺最后的前臂甩 | 近网自拍自扣，强调前臂甩 | [扣杀] |
| 【拇指/肘】反手握太松、拇指没顶住；不会用肘作支点 | 触球瞬间握紧、拇指在拍后支撑；体会"支肘 → 收肘" | [反手攻]、[反手拉上旋] |
| 【大臂/肘】加力推用不上力 | 见 §20 推挡 | [直拍] |
| 【器材】粘胶只用手臂 | 多球练蹬腿转腰 | [器材] |

**练法：** 徒手 → 弹力带 → 多球（[发力]第 5 节）。可以从徒手 3 组 × 15 次开始，按自身情况调整；目标：徒手动作连贯，多球每板触球声一致。
**视频：** 侧面 + 正面；引拍结束重心是否压右脚、膝是否弯，随挥结束是否到左脚；`weight_shift.delta`（正手应为正）、`knee_min_deg.playing`、`sequence_ms.hip/shoulder/elbow` 与 `sequence_order_ok`、`peak_hand_speed`；转体类见 §21。

## 11. 旋转弱（Weak Spin）

### 11.1 拉球不转

【拍面/前臂】撞多擦少、拍速不够、只放拍 → 加速穿过球，薄擦但别"飞碟"（[旋转]、[造旋转]、[正手拉上旋]）；【手指/腕】握太紧、手腕锁死 [握拍]；【判断】慢转拉成软短球 → 全力但薄擦 [正手拉下旋]；【器材】底板太快、胶皮脏旧 → [器材]。

### 11.2 搓球、劈长不转

【前臂】碰到球就停，前送不够 → 击球后小臂继续前送；【腕】滥用手腕、腕臂脱节 → 手腕跟前臂一起发力 [搓球]。劈长纯撞没下旋 → 撞摩结合 [劈长]。

### 11.3 发球不转

【拍面】撞多、吃进海绵；【拍头】靠拍柄附近触球（拍头线速度最快）；【腕/手指】握太紧、拍背放两指 → 改发球握法、全程放松；【拍速】求稳放慢 → 全速只擦一点；练习只求稳不求转 → 用最大旋转练 [LH:3622]。去看：[发球基础]、[正手钟摆]、[逆旋转]、[握拍]。

**练法：** 离台对地毯发下旋 [正手钟摆]。可以从每次 3 组 × 20 个开始，按自身情况调整；目标：10 个里 7 个落地后往回滚。
**视频：** 发球用侧面，`stroke_NN_zoom.jpg` 看触球在拍头还是拍柄附近、拍面角度；拉球看 `peak_hand_speed`（前后对比）。

## 13. 接发球吃转（Misreading Serve Spin）

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【视线】看对方大动作和收拍，被假动作骗 | 只看触球瞬间拍头方向和速度 | [旋转判断]、[接发球] |
| 【拍面】一个拍形接所有球 | 按来球旋转调拍面 | [接发拍形] |
| 【拍面】用后仰拍面接短侧上、上旋 → 飞出 | 改切挡、挑或拧；摆短就"从球后面往下" | [接发球]、[搓球] |
| 【判断】把不转当下旋 → 冒高；把下旋当不转 → 下网 | 下旋开拍向上；不转向前送、别压 | [旋转] |
| 【拍面】侧旋没抵消 → 出边 | 拍面向对方挥拍来的方向偏 | [旋转] |
| 【手臂】过早伸进台内，被侧上旋"顶"出界 | 等球过网再进台 | [摆短] |
| 【前臂】用相持的大动作接发 | 缩短动作 [LH:3242] | [接发球] |

| 【判断】对长胶按反胶的常理回球 | 长胶会把你的旋转大体反过来：你拉上旋，回来带下旋；你搓下旋，回来带上旋或不转。按自己刚打出的球预判 | [对长胶] |

### 13.1 接外拐侧旋出界

"外拐"指往你身体外侧拐走的侧旋（如发到你正手、越走越远的侧旋长球）。Hodges：球碰拍后往一侧跳，要往反方向瞄；一伸手够，拍子随球下掉，加上拉球本来放低拍，就拉出端线。改法：**上步迎球，不伸手够；拍保持较高**，拉时也是；也可改接直线 [LH:144]。去看：[接发球]、[判断拐向]。

**练法：** 请同伴反复发你最怕的一种发球，再逐步加变化 [PS-recv][LH:257]。可以从每次 30 个开始，按自身情况调整；目标：连续 10 个不冒高、不出界。
**视频：** 正面略高看上步和起动；侧面看拍面（`stroke_NN_zoom.jpg`）；`contact_forward_m` 很大＝在伸手够。

## 14. 挡球吃转（Block Bounces Off Heavy Topspin）

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【拍面】拍面不够关：平时多挡弱旋转球，形成错误本能 | 拍面比感觉的再关一点、瞄网 [LH:3445] | [反手挡]、[正手快带] |
| 【前臂】只放拍、没有轻撞 | 至少给一个轻撞（light punch），减少吃转 [LH:3445] | [反手挡] |
| 【时间】挡晚了，等球下降 | 贴近球台，上升期挡 | [反手挡] |

**练法：** 发下旋 → 你搓 → 他拉加转 → 你挡，不打完，马上下一球 [LH:3445]。可以从每组 10 球、5 组开始，按自身情况调整；目标：10 个里 7 个过网不出界。
**视频：** 反手正面或斜 45°；拍面看 `stroke_NN_zoom.jpg`；`contact_forward_m`（应在身前）、`backswing_ms`（应很短）。

## 17. 发球冒高、发不短（Serve Too High / Too Long）

"短球"指对方不接时会在对方台面弹两次 [ETT-short]。

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【拍面/腕】擦得不够薄，球吃进海绵 | 更快、更薄地擦；越转越容易短 [LH:583] | [发球基础]、[正手钟摆]、[反手发球] |
| 【时间/高度】触球点太高 | 让球落低再触；Hodges 经验值：不高于约 8 英寸（约 20 cm，单一来源）[LH:32] | [发球基础]、[逆旋转] |
| 【挥拍方向】往下砍，把球砸到台上 | 向前擦，让球"飘"着落台 [ETT-low] | [发球基础]、[正手钟摆] |
| 【落点】第一落点太靠本方端线 | 第一跳前移到本方半台中部或更靠网 [ETT-short] | [发球基础] |
| 【膝】触球时站起来、身体前扑 | 抛球到触球全程屈膝，脚不动 | [逆旋转]、[下蹲与勾手] |

**视频：** 侧面；`stroke_NN_contact_raw.jpg` 看触球时球比网顶高还是低（网高 15.25 cm [ITTF2026]）；动作小时脚本可能报 `NO_STROKES`，直接看关键帧。

## 18. 发球违例（Illegal Serve）

规则要点（ITTF 2.6）[ITTF2026]：球放在静止、张开的不执拍手掌上，**近乎垂直**抛起、不旋转，**离开手掌后至少上升 16 cm**，下落时才击球；球**先落本方台面，再直接落到对方台面**，双打依次落在本方和对方的右半区（2.6.3）；从开始到击球，球在台面以上、本方端线之后，不被身体或穿戴物遮挡；抛起后不执拍手臂移出"球与球网之间的空间"；让裁判相信发球合法是发球员的责任。

| 表现【部位】 | 原因 | 纠正 |
|---|---|---|
| 【手掌/手臂】抛球太低、斜抛、握球捻球 | 用手指或手腕抛 | 手掌平展，用手臂直上直下送；球离开手掌后至少上升 16 cm（大约一个网高，15.25 cm [ITTF2026]）。练习时看球的最高点比手掌高出多少，不要拿网顶的绝对高度来比 |
| 【全身】边移动边抛；手从台下撩起 | 准备不静止 | 先停稳再抛 |
| 【时间】球在上升途中就击 | 急 | 等球过最高点 |
| 【脚/躯干】球在端线内或台面下触球 | 身体前扑 | 站位后移 |
| 【拍面/挥拍方向】球没先落本方台面就直接过网 | 当成直接击球过网 | 发球时看第一落点在本方台面 |
| 【落点】双打发球没从本方右半区斜线落到对方右半区 | 按单打习惯发 | 第一落点放本方右半区，斜线发到对方右半区 |
| 【左臂/头/躯干】遮挡 | 抛完左臂不收；侧身过度 | 抛完左臂立即收到身体左侧，让对方看到球 |

马龙也被判过：2020 年一次按奥运标准判罚的模拟赛中，他擅长的正手发球被判遮挡丢分，之后改用反手发球 [CCTV-ML2020]。去看：[规则要点]、[违例表]、[急长与高抛]、[反手发球]、[下蹲与勾手]。
**练法：** 对着镜子或墙单练抛球，可以从每天 50 次开始，按自身情况调整；目标：每次离掌后上升都明显超过一个网高、几乎垂直。
**视频：** 侧面看抛球最高点比手掌高出多少、是否垂直。是否遮挡只能看关键帧：正面（接发球方位置）机位，从抛球到触球逐帧看球是否被身体或左臂挡住。`free_arm_height_level` 只反映左手高低，不能判断是否遮挡。

## 19. 落点单一、总被对方预判（Predictable Placement）

| 原因【部位】 | 改法 | 去看 |
|---|---|---|
| 【战术】相持总往对方反手送（习惯斜线） | 两大角加中路，先攻强侧再攻弱侧 | [战术] |
| 【战术】接发一律挑或一律摆 | 长球攻，短球在摆、劈、挑、拧中变 | [战术]、[接发球] |
| 【节奏】只会快不会慢 | 慢球要低、短；用减力挡变节奏 | [战术] |
| 【准备/拍面】劈长、挑打被提前识破；只会一条线 | 准备和引拍同摆短；斜线、直线、追身都练 | [劈长]、[正手挑] |

**练法：** 请同伴记下你一局每板的落点（正手大角、反手大角、中路）。可以从每次记一局开始，按自身情况调整；目标：三个落点都用上，没有一个明显占多数。
**视频：** 正面略高录整局，人工标落点（脚本不追踪球）。

## 20. 官方纠错清单：攻球七条（含反手 ⑥⑦，CETV）与推挡常见错误

中国教育电视台的攻球七条（⑥⑦ 是反手攻）[CETV-纠错]，官方纠正写在各节：

| # | 错误 | 官方纠正见本页 |
|---|---|---|
| ① | 正手攻球时不敢大胆挥拍，有停顿，弧线制造不好（指向前挥拍时中途犹豫、挥不够，不是引拍前把拍举着等球） | §8 |
| ② | 上臂与身体夹角过小 | §9.2 |
| ③ | 抬肘抬臂 | §9.1 |
| ④ | 手腕下垂，球拍与前臂垂直 | §9.3 |
| ⑤ | 判断球的落点不准，引拍动作不到位 | §6 |
| ⑥ | （反手攻）反手攻球时拍面前倾过早 | §1 |
| ⑦ | （反手攻）拍面前倾不够 | §2.1 |

**推挡常见错误** [BK-推挡]（CETV 未单列）：① 吊板（手腕下垂）→ 手腕外展，让拍柄靠近虎口；② 判断落点不准、拍形控制不好 → 提高判断能力，加强手腕灵活性；③ 击球时间过早或过晚 → 在来球上升期击球，控制好拍形前倾角度；④ 肘关节离身体过远 → 大臂和肘关节稍靠近身体；⑤ 动作不连贯、还原慢 → 利用重心移动和转腰做好还原；加力推手臂前伸不够、用不上力 → 大臂和肘前送，小臂和手腕协调用力。

**挡球常见错误** [BK-挡球]：拍面过度前倾下网 → 多球练手腕角度；击球时机滞后 → 用节奏口令强化上升期击球；重心后坐 → 徒手挥拍配合步法移动；落点判断不准 → 反复练习、主动迎球；正手挡吊腕 → 同推挡 ①。直拍推挡、横打见[直拍]；更多挡球错误见[反手挡]、§14。

## 21. 视频检查要点

拍摄方法见[拍摄指南]（慢动作视频用 `--capture-fps` 给出真实帧率）；各症状的机位、关键帧和指标见各节"视频"行。通用注意：
- **拍面角度、握拍、手腕形态测不出来**，只能看手部放大图 `stroke_NN_zoom.jpg`（击球前后各取 2 张，不一定是相邻帧）和 `stroke_NN_contact_raw.jpg`。
- `quality.reliable` 为 false 的板不下结论；`quality.low_visibility_parts` 里的关节数字不用。
- 帧率 <100 不看 `sequence_ms`，<60 时时间类数字只能粗看（`LOW_FPS`）。
- 转体类（`hip_turn_deg`、`shoulder_turn_deg`、`x_factor_deg`）单机位可信度低，只当提示。
- 只做**同一机位前后对比**，别和论文里的数直接比。
